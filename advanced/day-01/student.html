День 1. Как устроена спецификация

Выжимка лекции: что определяет ECMA-262, из чего состоит документ и как читать шаги его алгоритмов.

Главное

ECMA-262 — стандарт ядра языка, его пишет комитет TC39. Редакция выходит раз в год; курс читает tc39.es/ecma262/2026/. Интернационализация — отдельный стандарт, ECMA-402.
Алгоритм спецификации описывает, что должно получиться, а не как: движок считает по-своему, лишь бы результат совпадал. Пересказ всегда проверяем опытом в Chrome.

Карта документа

ГлавыЧто там
1–4вступление: соответствие, обзор языка, 42 термина

11–17язык: исходный текст, лексика, выражения, инструкции, функции

Кто что определяет

console.log(new Date("12.10.2026").toDateString());   // Thu Dec 10 2026 — не ISO: решает реализация
console.log(typeof setTimeout);                       // function — даёт хозяин, в ECMA-262 его нет
implementation-defined — решает реализация (разбор строки даты не ISO); implementation-approximated — приближает идеал стандарта (Math.sin); host-defined — решает хозяин, список в приложении D. Ввода и вывода в языке нет: console, alert, setTimeout — от браузера.

Шаги алгоритма

Let x be — завести имя (не копия!); Set x to — поменять; If / Else, Repeat, while, For each — как в коде; Assert — подсказка читателю, движок её не проверяет.
Сложное выражение в шаге вычисляется слева направо, изнутри наружу — операнды в языке тоже.
Ранние ошибки проверяются до первой строки скрипта: при SyntaxError не выполнится ничего.

Знаки ? и !

Операция возвращает Completion Record: normal, break, continue, return или throw. ? Op() — внезапную запись вернуть выше, обычную развернуть. ! Op() — здесь ошибки не бывает. Шаги с ? — все места, где алгоритм может бросить.

includes по шагам

const from = { valueOf() { console.log("fromIndex прочитан"); return 0; } };
console.log([].includes(1, from));                       // false — шаг 3 раньше шага 4
console.log([NaN].includes(NaN), [NaN].indexOf(NaN));    // true -1 — SameValueZero против ===
console.log([, 1].includes(undefined));                  // true — дырку Get читает как undefined

Числа и <=

console.log(-7 % 3);                 // -1 — знак делимого; «modulo» спецификации дал бы 2
console.log(null <= 0, null < 0);   // true false — a <= b считается как «не (b < a)»
<= → IsLessThan → ToPrimitive → OrdinaryToPrimitive: у объекта первым вызывается valueOf. У дат Temporal он бросает TypeError — их сравнивают через compare.
  1. Найдите на tc39.es разделы Map.prototype.get и String.prototype.at. Выпишите у каждого шаги со знаком ? и придумайте вызов, который бросит ошибку на первом из них.
  2. Найдите в любом алгоритме шаг со знаком ! и объясните своими словами, почему там ошибки быть не может.
  3. Найдите в своём проекте курса 2 по одной строке, которую определяет стандарт, реализация и хозяин.
  4. Прочитайте на MDN раздел «Standardization process» страницы JavaScript technologies overview и выпишите, чем предложение отличается от стандарта.
