# День 1. Как устроена спецификация

<Subtitle>Выжимка лекции: что определяет ECMA-262, из чего состоит документ и как читать шаги его алгоритмов.</Subtitle>

## Главное

<Definition>
**ECMA-262** — стандарт ядра языка, его пишет комитет TC39. Редакция выходит раз
в год; курс читает [tc39.es/ecma262/2026/](https://tc39.es/ecma262/2026/).
Интернационализация — отдельный стандарт, ECMA-402.
</Definition>

<KeyPoint>
Алгоритм спецификации описывает, **что** должно получиться, а не как: движок
считает по-своему, лишь бы результат совпадал. Пересказ всегда проверяем опытом в Chrome.
</KeyPoint>

## Кто что определяет

```js
console.log(new Date("12.10.2026").toDateString());   // Thu Dec 10 2026 — не ISO: решает реализация
console.log(typeof setTimeout);                       // function — даёт хозяин, в ECMA-262 его нет
```

<Remember>
**implementation-defined** — решает реализация (разбор строки даты не ISO);
**implementation-approximated** — приближает идеал стандарта (`Math.sin`);
**host-defined** — решает хозяин, список в приложении D. Ввода и вывода в языке
нет: `console`, `alert`, `setTimeout` — от браузера.
</Remember>

## Шаги алгоритма

<NoteBox>
**Let x be** — завести имя (не копия!); **Set x to** — поменять;
**If / Else**, **Repeat, while**, **For each** — как
в коде; **Assert** — подсказка читателю, движок её не проверяет.
\
Сложное выражение в шаге вычисляется **слева направо, изнутри наружу** —
операнды в языке тоже.
\
Ранние ошибки проверяются до первой строки скрипта: при `SyntaxError` не
выполнится ничего.
</NoteBox>

## Знаки ? и !

<Remember>
Операция возвращает **Completion Record**: normal, break, continue, return
или throw. `? Op()` — внезапную запись вернуть выше, обычную развернуть.
`! Op()` — здесь ошибки не бывает. Шаги с `?` — все места, где
алгоритм может бросить.
</Remember>

## includes по шагам

```js
const from = { valueOf() { console.log("fromIndex прочитан"); return 0; } };
console.log([].includes(1, from));                       // false — шаг 3 раньше шага 4
console.log([NaN].includes(NaN), [NaN].indexOf(NaN));    // true -1 — SameValueZero против ===
console.log([, 1].includes(undefined));                  // true — дырку Get читает как undefined
```

## Числа и \<=

```js
console.log(-7 % 3);                 // -1 — знак делимого; «modulo» спецификации дал бы 2
console.log(null <= 0, null < 0);   // true false — a <= b считается как «не (b < a)»
```

<Remember>
`<=` → IsLessThan → ToPrimitive → OrdinaryToPrimitive: у объекта первым
вызывается `valueOf`. У дат `Temporal` он бросает
`TypeError` — их сравнивают через `compare`.
</Remember>
