2. ToIntegerOrInfinity на деле
Легко7 мин

пройти пять шагов операции на настоящих значениях.

Метод at (раздел 23.1.3.1) превращает номер операцией ToIntegerOrInfinity (7.1.5). Предскажите три строки вывода, потом проверьте.

const marks = [10, 20, 30, 40];
console.log(marks.at(2.9), marks.at(-2.9), marks.at("3"));
console.log(marks.at(NaN), marks.at(null), marks.at("x"));
console.log(marks.at(Infinity), marks.at(-Infinity));
  • предсказания записаны до запуска;
  • для каждого вызова назван шаг ToIntegerOrInfinity, который решил дело, и шаг at, который выбрал элемент;
  • объяснено, почему −2.9 стало −2, а не −3: какая математическая функция из 5.2.6 работает в шаге 5.

5. Знак ? своими руками
Средне12 мин

развернуть ? в код, как это делает спецификация.

Продолжите модель раздела 12 лекции (normal, thrown). Напишите toObjectRecord(x): для null и undefined — запись throw с TypeError, иначе normal(Object(x)). Затем includesRecord(o, search) по шагам 1, 3, 10 и 11 метода includes; длину берите прямо из length.

includesRecord(["kitap", "suw"], "suw");    // { type: "normal", value: true }
includesRecord([NaN], NaN).value;           // true
includesRecord([], 1).value;                // false
includesRecord(null, 1).type;               // "throw"
includesRecord(null, 1).value.message;      // "Cannot convert undefined or null to object"
  • в коде нет ни throw, ни try — только записи;
  • каждый ? развёрнут в две строки, как в doubleRecord;
  • SameValueZero написан сам: x === y || (x !== x && y !== y), и объяснено, почему не подходит Object.is (подсказка: −0);
  • все пять строк примера дают то, что в комментариях.

7. «Карточки 2.0»: due без <=
Средне14 мин

применить разбор раздела 15 к коду проекта.

Перепишите метод соседа функцией due(cards, progress, today): карточка нужна сегодня, если прогресса по ней нет или её next не позже today. Даты сравнивайте через Temporal.PlainDate.compare.

const today = Temporal.PlainDate.from("2026-10-28");
const progress = new Map([
  [1, { next: Temporal.PlainDate.from("2026-10-27"), step: 2 }],
  [2, { next: Temporal.PlainDate.from("2026-11-01"), step: 4 }],
  [3, { next: Temporal.PlainDate.from("2026-10-28"), step: 1 }],
]);
const cards = [{ id: 1 }, { id: 2 }, { id: 3 }, { id: 4 }];
due(cards, progress, today).map((c) => c.id);   // [1, 3, 4]
  • в коде нет < и <= между датами;
  • карточка 3 (повтор сегодня) и карточка 4 (без прогресса) — в ответе;
  • записана цепочка из пяти шагов, по которой старый код бросал TypeError, — с номерами разделов;
  • проверено и объяснено: если next — строка "2026-10-27" (прогресс прочитан из JSON без reviver), compare по-прежнему работает, а <= по-прежнему бросает.

8. includes по шагам
Сложно10 мин

перенести алгоритм спецификации в код шаг за шагом.

Напишите includesBySteps(o, search, fromIndex) по всем 11 шагам раздела 23.1.3.16. У каждого шага — комментарий с его номером.

includesBySteps([1, 2, 3], 3, -1);                         // true
includesBySteps([1, 2, 3], 1, -1);                         // false
includesBySteps([NaN], NaN);                               // true
includesBySteps([, 1], undefined);                         // true
includesBySteps({ length: "2", 0: "a", 1: "b" }, "b");     // true
includesBySteps([], 1, { valueOf() { throw new Error("шаг 4"); } });   // false
ToIntegerOrInfinity: NaN → 0, бесконечности остаются, иначе Math.trunc. LengthOfArrayLike: длина как целое от 0 до 253 − 1.

  • последняя строка не бросает: шаг 3 стоит раньше шага 4;
  • добавлены два своих случая, где встроенный метод и ваш ведут себя одинаково необычно.
