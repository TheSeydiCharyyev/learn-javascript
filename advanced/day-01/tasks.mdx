<Criteria>

  который выбрал элемент;
- объяснено, почему −2.9 стало −2, а не −3: какая математическая функция из 5.2.6 работает
  в шаге 5.
</Criteria>
</Task>

<Task title="5. Знак ? своими руками" level="medium" time="12">
<Goal>развернуть `?` в код, как это делает спецификация.</Goal>

Продолжите модель раздела 12 лекции (`normal`, `thrown`). Напишите
`toObjectRecord(x)`: для `null` и `undefined` — запись throw
с `TypeError`, иначе `normal(Object(x))`. Затем
`includesRecord(o, search)` по шагам 1, 3, 10 и 11 метода `includes`; длину
берите прямо из `length`.

<Example>
```js
includesRecord(["kitap", "suw"], "suw");    // { type: "normal", value: true }

includesRecord(null, 1).type;               // "throw"
includesRecord(null, 1).value.message;      // "Cannot convert undefined or null to object"
```
</Example>

<Criteria>
- в коде нет ни `throw`, ни `try` — только записи;
- каждый `?` развёрнут в две строки, как в `doubleRecord`;
- SameValueZero написан сам: `x === y || (x !== x && y !== y)`, и объяснено,
  почему не подходит `Object.is` (подсказка: −0);
- все пять строк примера дают то, что в комментариях.
</Criteria>
</Task>

<Task title="7. «Карточки 2.0»: due без <=" level="medium" time="14">
<Goal>применить разбор раздела 15 к коду проекта.</Goal>

Перепишите метод соседа функцией `due(cards, progress, today)`: карточка нужна сегодня,
если прогресса по ней нет или её `next` не позже `today`. Даты сравнивайте
через `Temporal.PlainDate.compare`.

<Example>
```js
const today = Temporal.PlainDate.from("2026-10-28");
const progress = new Map([
  [1, { next: Temporal.PlainDate.from("2026-10-27"), step: 2 }],
  [2, { next: Temporal.PlainDate.from("2026-11-01"), step: 4 }],
  [3, { next: Temporal.PlainDate.from("2026-10-28"), step: 1 }],
]);
const cards = [{ id: 1 }, { id: 2 }, { id: 3 }, { id: 4 }];
due(cards, progress, today).map((c) => c.id);   // [1, 3, 4]
```
</Example>

<Criteria>
- в коде нет `<` и `<=` между датами;
- карточка 3 (повтор сегодня) и карточка 4 (без прогресса) — в ответе;
- записана цепочка из пяти шагов, по которой старый код бросал `TypeError`, —
  с номерами разделов;
- проверено и объяснено: если `next` — строка `"2026-10-27"` (прогресс
  прочитан из JSON без reviver), `compare` по-прежнему работает, а
  `<=` по-прежнему бросает.
</Criteria>
</Task>

<Task title="8. includes по шагам" level="hard" time="10">
<Goal>перенести алгоритм спецификации в код шаг за шагом.</Goal>

Напишите `includesBySteps(o, search, fromIndex)` по всем 11 шагам раздела 23.1.3.16.
У каждого шага — комментарий с его номером.

<Example>
```js
includesBySteps([1, 2, 3], 3, -1);                         // true
```

<Criteria>

  `includes`;
- последняя строка не бросает: шаг 3 стоит раньше шага 4;
