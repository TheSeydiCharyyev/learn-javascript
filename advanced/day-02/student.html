День 2. Грамматики и исходный текст

Выжимка лекции: как текст становится токенами; пробелы, переводы строк, комментарии и имена.

Главное

Путь программы: исходный текст (кодовые точки Unicode) → лексическая грамматика → токены → синтаксическая грамматика → дерево разбора → ранние ошибки → выполнение.
SyntaxError — до первой строки: скрипт не начинается, его try не поможет. TypeError и ReferenceError — уже на ходу.

Три грамматики

ЗнакГрамматикаЧто во что
::лексическая (глава 12), регулярных выраженийкодовые точки → токены, шаблон
:::числовых строк (7.1.4.1)строка → число
:синтаксическая (главы 13–16)токены → дерево
Xopt — можно пропустить; [In] — параметр; one of — любой из списка; [lookahead ∉ …] — следующий токен не из набора; [no LineTerminator here] — без перевода строки; but not — кроме.

Лексер

let a = 1, b = 2;
console.log(a+++b, a, b);                       // 3 2 2 — самый длинный кусок: a++ + b
const ready = true;
console.log(ready?.5:0);                        // 0.5 — ?. перед цифрой не цепочка
console.log(Number(" 12 "), Number("1_000"));   // 12 NaN — у строк своя грамматика
Слева направо, каждый раз — самый длинный токен. / — по месту: где ждут оператор — деление, где ждут значение — регулярка.

Пробелы, переводы строк, комментарии

Пробел (таблица 30): TAB, VT, FF, U+FEFF, Space_Separator (с U+00A0); U+0085 — ошибка.
Перевод строки (таблица 31): LF, CR, LS, PS; CR LF — один.
/* */ не вкладываются; с переводом строки внутри — сам перевод строки. #! — только первый символ скрипта. 
const LS = String.fromCharCode(0x2028);
const body = "let m = 4; // комментарий" + LS + "m = 5; return m;";
console.log(new Function(body)());   // 5 — LS кончает однострочный комментарий
function total() {
  return /*
  */ 5;
}
console.log(total());                // undefined — такой /* */ равен переводу строки

Имена и слова

Имя: ID_Start, $ или _, дальше ID_Continue (в нём и ZWNJ, ZWJ) и $. Сравнение — по кодовым точкам, без нормализации. Ключевое слово через escape не записать.
СловоКак имя переменной
Math, _, async, of, getвсегда
if, class, enum, importникогда
awaitвне async-функций и модулей
yieldвне генераторов и строгого кода
let, static, private…только в нестрогом коде
eval, argumentsв строгом коде не объявить
 
const parse = (code) => {
  try { new Function(code); return "разобрано"; } catch (e) { return `${e.name}: ${e.message}`; }
};
const composed = "caf" + String.fromCharCode(0xE9), decomposed = "cafe" + String.fromCharCode(0x301);
const body = `let ${composed} = 1, ${decomposed} = 2; return ${composed} + ${decomposed};`;
console.log(new Function(body)());              // 3 — два разных имени «café»
console.log(parse("const enum = 1;"));          // SyntaxError: Unexpected reserved word
console.log(parse("const els\\u{65} = 1;"));   // SyntaxError: Keyword must not contain escaped characters
Слэш в строке для parse удвоен: одиночный раскрыла бы сама строка, и разбор получил бы готовое else.
  1. Есть ли в списке ReservedWord (раздел 12.7.2) yield, let, async? Объясните через parse, почему let yield = 1; разбирается, а "use strict"; let yield = 1; — нет.
  2. Напишите две строки с / в начале новой строки: в одной — деление, в другой — регулярное выражение. Проверьте в Chrome.
  3. Разберите на токены одну строку своих «Карточек 2.0», как в разделе 13 лекции.
