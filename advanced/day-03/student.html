День 3. Литералы, точка с запятой, висячие запятые

Выжимка лекции: числа, строки и шаблоны; где язык ставит точку с запятой сам; где можно висячую запятую.

Главное

Литерал — значение, записанное прямо в тексте. Видов шесть: null, true/false, число, строка, регулярка, шаблон. undefined, NaN, Infinity — не литералы, а имена; -2 — два токена.
Точку с запятой язык вставляет не на каждом переводе строки, а только по трём правилам. Если следующая строка подходит к предыдущей, они склеятся.

Числа

console.log(0xFF, 0b101, 1_000_000, 1e3);           // 255 5 1000000 1000 — формы и разделитель
console.log(1..toString(), 0777, 0o777);             // 1 511 511 — 0777 — старая восьмеричная
console.log(9007199254740993, 9007199254740993n);   // 9007199254740992 9007199254740993n — точно только с n
_ — только между двумя цифрами; в Number("1_000") и \u{…} его нет ([~Sep]). n — только у целых. После числа — не буква и не цифра: 1.toString() — ошибка. Запись → точное MV → ближайший Number.

Строки, шаблоны, регулярки

Прямо в строке нельзя: свою кавычку, \, CR, LF. LS и PS — можно. \ и перевод строки — продолжение строки. Escape: \n \t \0 \x41 \u0042 \u{1F600}; неизвестный \z — просто «z»; \7 в строгом коде — ошибка.
Шаблон с ${} — три токена: голова, середина, хвост; CR LF в нём становится LF.
Для регулярки лексер ищет только конец; каждое вычисление литерала — новый объект. 
console.log("a\zb", "\x41\u0042\u{43}", "\u{1F600}".length);   // azb ABC 2 — неизвестный escape — сам символ
const tag = (strings) => `${strings[0]} | ${strings.raw[0]}`;
console.log(tag`\unicode`);                                // undefined | \unicode — неверный escape в теге
console.log(/a/ === /a/);                                  // false — два литерала, два объекта

Точка с запятой

Правило 12.10.1Когда
1токен не подходит, а перед ним перевод строки; или это }; или ) конца do-while
2текст кончился, а программа не сложилась
3перевод строки на [no LineTerminator here]: после return, break, continue, throw, yield, перед постфиксным ++ и =>
запретне пустой инструкцией и не в заголовке for
 
let a, b = 1, c = 1
a = b
++c
console.log(a, b, c)   // 1 1 2 — ++ на новой строке — префикс к c
let x = 5
-1
console.log(x)         // 4 — строка с - склеилась с предыдущей
function total() {
  return
    1 + 1
}
console.log(total())   // undefined — после return перевод строки
Строка начинается с (, [, `, +, - или / — в конце предыдущей нужна точка с запятой, иначе строки склеятся.

Висячие запятые

МожноНельзя
массивы, объекты, параметры, аргументы, деструктуризация, import/export, import() f(,), после ...rest, в JSON
Одна висячая запятая ничего не меняет. В массиве каждая следующая — дырка: [1, 2, 3, , ,].length — 5. {2,} в регулярке — «два и больше».
  1. Найдите в разделе 12.9.3 правило HexDigits[Sep] и объясните по нему, почему 0x_FF — ошибка, а 0xF_F — нет. Проверьте через parse.
  2. Уберите точки с запятой из файла своих «Карточек 2.0»: какие строки начинаются с опасного символа и что сломается?
  3. Объясните своими словами последний пример раздела 12.10.2: a = b + c и на следующей строке (d + e).print().
  4. Прочитайте на MDN раздел «Trailing commas in destructuring» страницы Trailing commas и напишите деструктуризацию, где висячая запятая разрешена, и такую, где — ошибка.
