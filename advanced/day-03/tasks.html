День 3. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Открыты спецификация, tc39.es/ecma262/2026/, и консоль Chrome. Код пишем в папке day-03 курса 3. В заданиях 4 и 7 точек с запятой нет нарочно. Каждое «почему» — с номером раздела.

Разминка

1. Число по частям
Легко7 мин

читать числовой литерал по правилам 12.9.3.

Предскажите восемь строк: значение или текст ошибки.

const codes = ["0b1_0", "0B11", "0o_7", "0x1F_FFn", "1_0.5_0", "1e-1_0", "08", "0.1e1n"];
for (const code of codes) {
  try {
    console.log(code, "→", String(new Function(`return ${code};`)()));
  } catch (e) {
    console.log(code, "→", e.message);
  }
}
  • для каждой записи назван нетерминал, который её описывает, или правило, которое она нарушает;
  • объяснено, почему у BigInt в выводе нет буквы n;
  • проверено, что станет с 08, если первой строкой тела поставить "use strict".
2. Длина строки
Легко7 мин

знать, во что превращается каждая escape-последовательность.

Предскажите длину каждой строки или текст ошибки.

const strings = [
  '"a\\zb"', '"\\x4"', '"\\u{1F600}"', "'It\\'s'",
  '"\\08"', '"\\0"', "`a\\nb`", '"a\\\nb"',
];
strings.forEach((code, i) => {
  try {
    console.log(i + 1, new Function(`return ${code};`)().length);
  } catch (e) {
    console.log(i + 1, e.message);
  }
});
  • для каждой строки названо правило 12.9.4: SingleEscapeCharacter, NonEscapeCharacter, LineContinuation и другие;
  • объяснено, почему в массиве каждая косая удвоена и что видит new Function в строке 8 — там их три;
  • найдено, какая из строк станет ошибкой в строгом коде.

console.log([1, 2,].length, [1, 2, ,].length, [, ,].length, f.length);

Основные задания

4. Склеятся ли строки
Средне12 мин

предсказывать, где правило 1 не вставит точку с запятой.

Каждая строка массива — тело функции без точек с запятой. Предскажите, что вернёт каждое или какую ошибку бросит.

const bodies = [
  "const a = 1\n(2 + 3)\nreturn a",
  "const list = [1, 2]\n[0, 1].forEach((i) => list.push(i))\nreturn list.length",
  "const s = 'a'\n`b`\nreturn s",
  "let n = 2\n-n\nreturn n",
  "const k = 4\n/2/g.flags\nreturn k",
  "const a = 1\nconst b = (a)\nreturn b",
];
bodies.forEach((body, i) => {
  try {
    console.log(i + 1, new Function(body)());
  } catch (e) {
    console.log(i + 1, `${e.name}: ${e.message}`);
  }
});
  • для каждого тела записано, во что склеились строки, — одной строкой кода;
  • для тела 4 объяснено, почему ошибка про n, а не про минус;
  • каждое сломанное тело починено одной точкой с запятой, и объяснено, почему тело 6 чинить не нужно.
5. «Карточки 2.0»: колода с лишней запятой
Средне14 мин

отличать грамматику JSON от грамматики литералов.

Учитель правит decks.json руками и оставляет висячие запятые, как в коде, — и колода не загружается (день 35 курса 2). Напишите looseJSON(text): убрать запятые, за которыми, кроме пробелов, идёт ] или }, и передать текст в JSON.parse. Запятые внутри строк не трогать.

looseJSON('[1, 2, 3, ]');                        // [1, 2, 3]
looseJSON('{"word": "kitap", "step": 2, }');    // { word: "kitap", step: 2 }
looseJSON('[\n  "kitap",\n  "suw",\n]');           // ["kitap", "suw"]
looseJSON('{"text": "a, ]"}');                  // { text: "a, ]" }
looseJSON('{"text": "\\"a, }"}').text;          // '"a, }'
  • все пять строк примера дают то, что в комментариях;
  • объяснено, почему простая замена регуляркой /,\s*([\]}])/g ломает строки 4 и 5;
  • looseJSON('[1, , 2]') по-прежнему бросает: записано, чем дырка отличается от висячей запятой.
6. Линтер на пяти символах
Средне12 мин

превратить правило 12.10.3.1 в проверку кода.

Напишите asiHazards(code): номера строк, которые начинаются с (, [, `, +, - или / (но не с комментария), если предыдущая непустая строка не кончается на ;, { или ,.

asiHazards("const a = 1\n(1).toString()");                // [2]
asiHazards("const a = 1;\n(1).toString()");               // []
asiHazards("let x = 5\n-1\nconsole.log(x)");              // [2]
asiHazards("if (ok) {\n  [1, 2].forEach(show)\n}");        // []
asiHazards("const total = 3\n// итог\n/hi/g.test(s)");    // [3]
  • все пять строк примера дают то, что в комментариях;
  • линтер прогнан по коду лекции дня 3 и по одному файлу своих «Карточек 2.0»;
  • объяснено, почему после if (ok) {} строка (1) не склеится и линтер шумит зря, а после const f = function () {} — склеится.
7. Перевод строки на запретном месте
Средне12 мин

применять правило 3 и список ограниченных правил 12.10.1.

Предскажите, что вернёт каждое тело или какую ошибку бросит.

const restricted = [
  "return\n  { ok: true }",
  "return (\n  { ok: true }\n)",
  "let i = 1\ni\n++i\nreturn i",
  "throw\n  new Error('x')",
  "const f = (a)\n  => a * 2\nreturn f(2)",
  "const f = (a) =>\n  a * 2\nreturn f(2)",
  "outer: for (;;) {\n  break\n  outer\n}\nreturn 'вышли'",
];
restricted.forEach((body, i) => {
  try {
    console.log(i + 1, JSON.stringify(new Function(body)()));
  } catch (e) {
    console.log(i + 1, `${e.name}: ${e.message}`);
  }
});
  • для каждого тела назван токен, перед которым язык вставил точку с запятой, или сказано, что не вставил;
  • объяснено, почему тело 4 — ошибка разбора, а тело 1 — нет;
  • объяснено, почему в теле 7 метка outer на своей строке не дала ReferenceError, хотя в разделе 12 лекции дала.

Со звёздочкой

8. Свой NumericValue
Сложно10 мин

перенести правила 12.9.3 в проверку и подсчёт.

Напишите numericValue(text): проверить запись по правилам раздела (разделители, приставки, n только у целых) и вернуть Number или BigInt; на неверной записи — SyntaxError.

numericValue("1_000");                // 1000
numericValue("0xA0_B0");              // 41136
numericValue("0b1010_0001");          // 161
numericValue("1_050.95e-2");          // 10.5095
numericValue("0xFFn") === 255n;       // true
numericValue(".5") + numericValue("5.");   // 5.5
Когда запись проверена, разделители можно убрать, а остальное отдать Number или BigInt: грамматика числовых строк (A.6) понимает и 0x, и порядок, но не _.
  • шесть строк примера дают то, что в комментариях;
  • "1__0", "1_", "0_1", "0x_1", "1.5n" бросают SyntaxError, как Chrome;
  • для "9007199254740993" и "9007199254740993n" объяснено, почему значения разные.
9. Незнакомый раздел: TV и TRV
Сложно10 мин

прочитать подразделы, которых не было на лекции.

Прочитайте подразделы 12.9.6.1 TV и 12.9.6.2 TRV — готовое и сырое значение части шаблона — и предскажите три строки.

const parts = (strings) => strings.map((s, i) => `${JSON.stringify(s)} ${JSON.stringify(strings.raw[i])}`).join(" | ");
console.log(parts`a\tb`);
console.log(parts`\u{41}${1}\x`);
console.log(parts`$5 \${x}`);
  • предсказаны все части, у каждой — правило TV и правило TRV, которые её дали;
  • объяснено, почему в сыром значении косая осталась, а в готовом нет;
  • объяснено, откуда undefined во второй строке и почему без тега та же запись — ошибка.
