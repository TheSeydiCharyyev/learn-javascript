День 4. Типы языка и типы спецификации

Выжимка лекции: восемь типов языка, Number и BigInt, объект изнутри, Completion Record и Reference Record.

Главное

Типы языка (6.1) — значения программы: Undefined, Null, Boolean, String, Symbol, Number, BigInt, Object. Типы спецификации (6.2) — служебные значения алгоритмов: в переменную их не положить.
Ответ typeof — не тип: для null он «object», для функции — «function», потому что так записан его алгоритм.

Number, BigInt, Object

console.log(typeof null, typeof (() => {}), typeof 1n);          // object function bigint — ответ typeof
console.log(Object.is(0, -0), 0 === -0, 9007199254740993);        // false true 9007199254740992 — ничья к чётному
console.log(Object.keys({ 1: "a", [Symbol("s")]: 2 }).length);    // 1 — ключ 1 стал строкой «1», символ не виден
Number: 264 − 253 + 3 значения, один NaN, +0 и −0, целые точно до 253; ближайшее ±21024 — бесконечность. BigInt — целые любого размера, без неявного смешивания с Number.
Ключ — строка или символ; индекс массива — до 232 − 2. Атрибуты: [[Value]], [[Writable]], [[Get]], [[Set]], [[Enumerable]], [[Configurable]], по умолчанию false.
11 внутренних методов у всех объектов, у функций ещё [[Call]] и [[Construct]]; внутренние слоты — не свойства.

Completion Record

ПолеЧто там
[[Type]]normal или внезапные: break, continue, return, throw
[[Value]]значение или empty
[[Target]]метка или empty
Консоль печатает [[Value]] итоговой записи: if (true) { 5 } → 5. var и пустая ; завершаются пусто — остаётся прежнее значение; if без значения даёт undefined (14.6.2).
try...finally: обычный finally — итог блока try; внезапный — итог finally, даже поверх ошибки. 
function g() { try { throw new Error("пропала"); } finally { return "ошибки нет"; } }
function k() { try { return "из try"; } finally { "уборка"; } }
console.log(g());   // ошибки нет — внезапная запись finally победила throw
console.log(k());   // из try — обычный finally итог не меняет

Reference Record

Поля: [[Base]] (значение, Environment Record или unresolvable), [[ReferencedName]], [[Strict]], [[ThisValue]] (для super).
GetValue ненайденного имени — ReferenceError, но typeof смотрит раньше и даёт «undefined». PutValue ненайденного: нестрогий код — свойство глобального объекта, строгий — ошибка.
this при вызове — из [[Base]] ссылки. 
const card = { word: "kitap", show() { return this === card; } };
console.log(typeof nope, (card.show)(), (0, card.show)());   // undefined true false — ссылка, ссылка, значение
const { show } = card;
console.log(show(), show.call(card));                         // false true — без ссылки this передают явно
