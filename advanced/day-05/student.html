День 5. Преобразования и сравнения

Выжимка лекции: ToPrimitive и подсказка, таблицы ToBoolean, ToNumber, ToString, ключи свойств, SameValue, IsLessThan и лестница ==.

Главное

Абстрактные операции (глава 7) из кода не вызвать — их видно по операторам. Почти каждое преобразование для объекта сначала зовёт ToPrimitive, а потом повторяет себя для примитива.
Подсказка: number — +x, x < y; string — String(x), шаблон, ключ; без подсказки — x + y, x == y (как number). Порядок: string — toString, valueOf; иначе — valueOf, toString.

ToPrimitive

const log = [];
const mark = { valueOf() { log.push("v"); return 5; }, toString() { log.push("t"); return "пять"; } };
console.log(+mark, `${mark}`, mark + "", log.join(""));   // 5 пять 5 vtv — number, string, без подсказки
Метод, вернувший объект, пропускается; оба вернули объекты — TypeError. Свой Symbol.toPrimitive есть у дат (без подсказки — строка) и символов — день 17.

Три таблицы

console.log(!!"0", !![], !!0n, !!document.all);            // true true false false — ToBoolean
console.log(+"", +" 12 ", +[5], +"1_000", +"-0x1F");       // 0 12 5 NaN NaN — ToNumber по грамматике
console.log(String(-0), String([1, [2]]), String(1e21));   // 0 1,2 1e+21 — ToString
ToBoolean — ложны undefined, null, ±0, NaN, 0n, "" (и document.all). ToNumber — строка по грамматике A.6, Symbol и BigInt — ошибка. ToString — Symbol бросает, но String(sym) работает. ToPropertyKey — символ или строка: 1 и «1» — один ключ. Map и Set ключ не переводят: −0 → +0, потом SameValue, — «1» и 1 для них разные.

Сравнения

console.log("10" < "9", "10" < 9, [10, 9, 1].sort().join());   // true false 1,10,9 — строки по кодам
console.log([] == ![], null == 0, null == undefined);          // true false true — лестница ==
console.log(Object.is(NaN, NaN), NaN === NaN, [NaN].includes(NaN));   // true false true — три равенства
Ступень == (7.2.13)Что делает
1один тип — как ===
2null и undefined — true
3–4строка с числом — ToNumber, с BigInt — StringToBigInt
5boolean — в число
6объект с примитивом — ToPrimitive без подсказки
7–8BigInt и Number — по значению; остальное — false
IsLessThan: две строки — по 16-битным кодам; иначе числа; NaN — «не сравнимо», то есть false. SameValue (Object.is): NaN равен NaN, нули разные; SameValueZero (includes): и нули равны; ===: NaN не равен себе.

  2. Пройдите по ступеням 7.2.13 "1" == [1] и [0] == false, записывая каждый шаг.
