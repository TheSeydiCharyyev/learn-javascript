# День 5. Преобразования и сравнения

<Subtitle>Выжимка лекции: ToPrimitive и подсказка, таблицы ToBoolean, ToNumber, ToString, ключи свойств, SameValue, IsLessThan и лестница `==`.</Subtitle>

## Главное

<Definition>
**Абстрактные операции** (глава 7) из кода не вызвать — их видно по операторам. Почти каждое
преобразование для объекта сначала зовёт **ToPrimitive**, а потом повторяет себя для примитива.
</Definition>

<KeyPoint>
Подсказка: `number` — `+x`, `x < y`; `string` —
`String(x)`, шаблон, ключ; без подсказки — `x + y`, `x == y` (как number).
Порядок: `string` — `toString`, `valueOf`; иначе — `valueOf`,
`toString`.
</KeyPoint>

## ToPrimitive

```js
const log = [];
const mark = { valueOf() { log.push("v"); return 5; }, toString() { log.push("t"); return "пять"; } };
console.log(+mark, `${mark}`, mark + "", log.join(""));   // 5 пять 5 vtv — number, string, без подсказки
```

<Remember>
Метод, вернувший объект, пропускается; оба вернули объекты — `TypeError`. Свой
`Symbol.toPrimitive` есть у дат (без подсказки — строка) и символов — день 17.
</Remember>

## Три таблицы

```js
console.log(!!"0", !![], !!0n, !!document.all);            // true true false false — ToBoolean
console.log(+"", +" 12 ", +[5], +"1_000", +"-0x1F");       // 0 12 5 NaN NaN — ToNumber по грамматике
console.log(String(-0), String([1, [2]]), String(1e21));   // 0 1,2 1e+21 — ToString
```

<Remember>
**ToBoolean** — ложны `undefined`, `null`, ±0, NaN, `0n`,
`""` (и `document.all`). **ToNumber** — строка по грамматике A.6, Symbol и
BigInt — ошибка. **ToString** — Symbol бросает, но `String(sym)` работает.
**ToPropertyKey** — символ или строка: `1` и «1» — один ключ. `Map` и
`Set` ключ не переводят: −0 → +0, потом SameValue, — «1» и 1 для них разные.
</Remember>

## Сравнения

```js
console.log("10" < "9", "10" < 9, [10, 9, 1].sort().join());   // true false 1,10,9 — строки по кодам
console.log([] == ![], null == 0, null == undefined);          // true false true — лестница ==
console.log(Object.is(NaN, NaN), NaN === NaN, [NaN].includes(NaN));   // true false true — три равенства
```

| Ступень `==` (7.2.13) | Что делает |
| --- | --- |
| 1 | один тип — как `===` |
| 2 | `null` и `undefined` — `true` |
| 3–4 | строка с числом — ToNumber, с BigInt — StringToBigInt |
| 5 | boolean — в число |
| 6 | объект с примитивом — ToPrimitive без подсказки |
| 7–8 | BigInt и Number — по значению; остальное — `false` |

<Remember>
**IsLessThan**: две строки — по 16-битным кодам; иначе числа; NaN — «не сравнимо», то есть
`false`. **SameValue** (`Object.is`): NaN равен NaN, нули разные;
**SameValueZero** (`includes`): и нули равны; `===`: NaN не равен себе.
</Remember>
