День 6. Числа как биты

Выжимка лекции: ToInt32 и ToUint32, дополнительный код, побитовые операторы и сдвиги, приоритет, BigInt, маски и оператор void.

Главное

ToInt32 (7.1.6): ToNumber; NaN, ±Infinity и ±0 — сразу +0; отбросить дробь; взять остаток modulo 232 (он всегда ≥ 0); если 231 и больше — вычесть 232. ToUint32 — то же без последнего шага. Отрицательное число в 32 разрядах — дополнительный код: разряд 31 весит −231, а ~x = −x − 1.
Приоритет от сильного к слабому: + -, сдвиги, < >, == ===, &, ^, |, && ||. Побитовое рядом со сравнением — всегда в скобках.

ToInt32 и сдвиги

console.log(3e9 | 0, 2 ** 32 | 0, 2.9 | 0, NaN | 0);   // -1294967296 0 2 0 — ToInt32
console.log(-1 >>> 0, -9 >>> 2, -9 >> 2);             // 4294967295 1073741821 -3 — ToUint32 и сдвиги
console.log(1 << 31, 1 << 32, ~9, ~~-2.7);            // -2147483648 1 -10 -2 — счётчик по модулю 32
ОператорОперандыЧто делает
& | ^ToInt32 и ToInt32по разрядам: оба — 1 / хотя бы один / ровно один
~ToInt32переворачивает все разряды
<<ToInt32 и ToUint32 % 32влево, справа нули
>>ToInt32 и ToUint32 % 32вправо, слева копии знака: деление вниз
>>>ToUint32 и ToUint32 % 32вправо, слева нули: всегда ≥ 0
x | 0 и ~~x — это ToInt32, а не Math.trunc: за 231 знак меняется, NaN молча становится 0. Секунды с 1970 года перестанут влезать 19 января 2038 года.

Приоритет и маски

const n = 4, EDIT = 1 << 2;
let rights = 0b0011;
rights |= EDIT;
console.log(n & 1 === 0, (n & 1) === 0, rights.toString(2), (rights & EDIT) !== 0);   // 0 true 111 true — скобки!
console.log(-3 % 2, -3 & 1, (0xFF851B >> 8) & 0xFF);        // -1 1 133 — чётность и байт цвета
Флажок F = 1 << k: |= ставит, &= ~F снимает, ^= переключает, (r & F) !== 0 проверяет. Чётность — n & 1: у −3 остаток −1, а младший разряд — 1. Верхний байт 32-битного числа — >>> 24 или (x >> 24) & 0xFF, но не голый >> 24.

BigInt и void

const attempt = (f) => { try { return f(); } catch (e) { return e.name; } };
console.log(1n << 64n, -1n & 0xFFn, attempt(() => 5n >>> 1n));   // 18446744073709551616n 255n TypeError — разрядов без конца
console.log(void 0, void 2 === "2", attempt(() => void nope));      // undefined false ReferenceError — void зовёт GetValue
У BigInt разрядов бесконечно много: нет обрезки и модуля у счётчика, а >>> бросает TypeError; BigInt с числом смешивать нельзя. void x вычисляет x (геттер сработает) и возвращает undefined; () => void f() ничего не возвращает.
  1. Пройдите шаги ToInt32 для 4294967295.7 и -2147483649, записывая каждый, и проверьте ответ через | 0.
  2. Прочитайте шаги Number::leftShift (6.1.6.1.9) и объясните, почему 1 << -1 отрицательное, а 1 << 33 — 2.
  3. Найдите в своих «Карточках 2.0» числа, которые могут перейти 231 (миллисекунды, номера, суммы), и проверьте, не проходят ли они через побитовый оператор.
  4. Откройте на MDN страницу Unsigned right shift assignment, найдите пример с BigInt и выполните его в Chrome. Что обещает страница и что происходит на самом деле?
