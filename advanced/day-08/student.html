День 8. Синтаксически управляемые операции

Выжимка лекции: операции по дереву разбора, списки объявленных имён, подъём, метки, Contains и вывод имени функции.

Главное

Синтаксически управляемая операция задана кусками — по одному на правило грамматики; у правила «A : B» без своего куска она передаётся к B. Статические работают до выполнения, на них стоят ранние ошибки; выполнения — Evaluation и его помощники.

Имена и подъём

const parse = (code) => { try { new Function(code); return "ok"; } catch (e) { return e.name; } };
console.log(parse("let x; var x;"), parse("var x; var x;"), parse("{ var x; } let x;"));   // SyntaxError ok SyntaxError — лексические против var
console.log(parse("function f() {} var f;"), parse("{ function f() {} var f; }"));      // ok SyntaxError — наверху функция как var
console.log(typeof later, typeof ready);                                                // undefined function — подъём
var later = 1;
function ready() {}

Ошибка — повтор среди лексических имён, имя и в лексических, и в var одной области, параметр среди лексических имён тела. var + var — можно. В модуле функция — лексическое имя. Подъём: var — undefined, let/const — мёртвая зона, функция — готова. Блок при каждом входе получает новое окружение.

Имя функции

const arrow = () => {};
const paren = (function () {});
const comma = (0, function () {});
const obj = { method() {}, get size() { return 1; } };
obj.later = () => {};
const show = (list) => list.map((f) => JSON.stringify(f.name)).join(" ");
console.log(show([arrow, paren, comma]));   // "arrow" "paren" "" — скобки пропускают, запятая нет
console.log(show([obj.method, Object.getOwnPropertyDescriptor(obj, "size").get, obj.later]));   // "method" "get size" "" — obj.x не имя
Имя даёт NamedEvaluation: безымянное определение функции или класса там, где известно имя, — инициализатор let/const/var, = и &&=, ||=, ??= простому имени, ключ, значение по умолчанию, поле класса, export default. Приставки «get», «bound» и [символ] добавляет SetFunctionName.

Метки, super и цели присваивания

const parse = (code) => { try { new Function(code); return "ok"; } catch (e) { return e.name; } };
console.log(parse("a: { continue a; }"), parse("a: for (;;) { (() => { break a; }); }"));   // SyntaxError SyntaxError — continue к циклу, метка не видна в функции
console.log(parse("class A extends B { constructor() { () => super(); } }"), parse("f() = 1;"), parse("(a, b) = 1;"));   // ok ok SyntaxError — стрелка прозрачна, вызов — web-compat
Contains не заглядывает в функции, но стрелку проходит насквозь для this, super, new.target. f() = 1 в нестрогом коде — ошибка только при выполнении, после вызова f; по тексту 2026 в строгом коде — ранняя ошибка, но Chrome 156 и там ждёт выполнения.
  1. Прочитайте ранние ошибки блока (14.2.1) и найдите условие, при котором { function f() {} function f() {} } разрешено. Проверьте его в строгом коде.
  2. Предскажите и проверьте name: const a = function b() {}, let c; c = class {}, ({ ["x" + 1]: () => {} }).x1, [() => {}][0], const { d = function () {} } = {}.
  3. Найдите в своём main.js «Карточек 2.0» безымянные слушатели. Какой из них может понадобиться снять через removeEventListener? Дайте ему имя константой.
  4. Прочитайте на MDN раздел «JavaScript compressors and minifiers» страницы Function: name и объясните через NamedEvaluation, почему имя меняется при сжатии кода.
