# День 8. Синтаксически управляемые операции

<Subtitle>Выжимка лекции: операции по дереву разбора, списки объявленных имён, подъём, метки, Contains и вывод имени функции.</Subtitle>

## Главное

<Definition>
**Синтаксически управляемая операция** задана кусками — по одному на правило грамматики; у правила
«A : B» без своего куска она передаётся к B. **Статические** работают до выполнения, на них стоят
ранние ошибки; **выполнения** — Evaluation и его помощники.
</Definition>

## Имена и подъём

```js
const parse = (code) => { try { new Function(code); return "ok"; } catch (e) { return e.name; } };
console.log(parse("let x; var x;"), parse("var x; var x;"), parse("{ var x; } let x;"));   // SyntaxError ok SyntaxError — лексические против var
console.log(parse("function f() {} var f;"), parse("{ function f() {} var f; }"));      // ok SyntaxError — наверху функция как var
console.log(typeof later, typeof ready);                                                // undefined function — подъём
var later = 1;
function ready() {}
```

| Список (8.2) | Что в нём | Докуда |
| --- | --- | --- |
| BoundNames | имена объявления, шаблона, параметров | одно объявление |
| LexicallyDeclaredNames | `let`, `const`, `class`, функции в блоке | свой блок |
| VarDeclaredNames | `var` | сквозь блоки до функции или скрипта |
| TopLevel… | функции наверху тела — как `var` | верх функции и скрипта |

<Remember>
Ошибка — повтор среди лексических имён, имя и в лексических, и в `var` одной области, параметр среди
лексических имён тела. `var` + `var` — можно. В модуле функция — лексическое имя.
Подъём: `var` — `undefined`, `let`/`const` — мёртвая зона, функция —
готова. Блок при каждом входе получает новое окружение.
</Remember>

## Имя функции

```js
const arrow = () => {};
const paren = (function () {});
const comma = (0, function () {});
const obj = { method() {}, get size() { return 1; } };
obj.later = () => {};
const show = (list) => list.map((f) => JSON.stringify(f.name)).join(" ");
console.log(show([arrow, paren, comma]));   // "arrow" "paren" "" — скобки пропускают, запятая нет
console.log(show([obj.method, Object.getOwnPropertyDescriptor(obj, "size").get, obj.later]));   // "method" "get size" "" — obj.x не имя
```

<Remember>
Имя даёт NamedEvaluation: безымянное определение функции или класса там, где известно имя, — инициализатор
`let`/`const`/`var`, `=` и `&&=`, `||=`,
`??=` простому имени, ключ, значение по умолчанию, поле класса, `export default`.
Приставки «get», «bound» и `[символ]` добавляет SetFunctionName.
</Remember>

## Метки, super и цели присваивания

```js
const parse = (code) => { try { new Function(code); return "ok"; } catch (e) { return e.name; } };
console.log(parse("a: { continue a; }"), parse("a: for (;;) { (() => { break a; }); }"));   // SyntaxError SyntaxError — continue к циклу, метка не видна в функции
console.log(parse("class A extends B { constructor() { () => super(); } }"), parse("f() = 1;"), parse("(a, b) = 1;"));   // ok ok SyntaxError — стрелка прозрачна, вызов — web-compat
```

<Remember>
Contains не заглядывает в функции, но стрелку проходит насквозь для `this`, `super`,
`new.target`. `f() = 1` в нестрогом коде — ошибка только при выполнении, после вызова
`f`; по тексту 2026 в строгом коде — ранняя ошибка, но Chrome 156 и там ждёт выполнения.
</Remember>
