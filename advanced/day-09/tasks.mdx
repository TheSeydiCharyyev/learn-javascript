## Основные задания

<Task title="4. Своя GetThisEnvironment" level="medium" time="12">
<Goal>перенести 9.4.3–9.4.5 и HasThisBinding записей в код.</Goal>

Запись окружения — объект: `{ kind: "declarative", outer }`,
`{ kind: "function", status, thisValue, newTarget, outer }` (`status` —
`"lexical"`, `"initialized"` или `"uninitialized"`),
`{ kind: "module", outer }`, `{ kind: "global", thisValue, outer: null }`. Напишите
`hasThisBinding(env)` — кусками по видам, `getThisEnvironment(env)`,
`resolveThisBinding(env)` (ReferenceError, пока `this` не связан) и
`getNewTarget(env)`.

<Example>
```js
const attempt = (f) => { try { return f(); } catch (e) { return e.name; } };
const global = { kind: "global", thisValue: "window", outer: null };
const method = { kind: "function", status: "initialized", thisValue: "obj", newTarget: undefined, outer: global };
const arrow = { kind: "function", status: "lexical", outer: method };
const block = { kind: "declarative", outer: arrow };
const ctor = { kind: "function", status: "uninitialized", newTarget: "Child", outer: global };
const inCtor = { kind: "function", status: "lexical", outer: ctor };
resolveThisBinding(block);                                           // "obj"
getThisEnvironment(block) === method;                                // true
resolveThisBinding({ kind: "declarative", outer: { kind: "module", outer: global } });   // undefined
getNewTarget(inCtor);                                                // "Child"
attempt(() => resolveThisBinding(inCtor));                           // "ReferenceError"
```
</Example>

<Criteria>
- все пять строк примера дают то, что в комментариях;
- поиск — один цикл по `outer`, как шаг 2 раздела 9.4.3, без проверки на `null`, и
  объяснено, почему она не нужна;
- та же цепочка в настоящем коде — блок в стрелке в методе — даёт тот же ответ.
</Criteria>
</Task>

<Task title="5. Своя очередь заданий" level="medium" time="14">
<Goal>собрать требования 9.5 и порядок браузера в одной модели.</Goal>

Напишите `makeLoop()` с методами `script(fn)` и `task(fn)` — поставить задачу,
`microtask(fn)`, `log(text)`, `run()` и `journal()`. `run`
берёт задачи по одной; после каждой выполняет все микрозадачи, даже добавленные по ходу. Ошибка задания не
останавливает очередь: в журнал пишется «ошибка: текст».

<Example>
```js
const loop = makeLoop();
loop.script(() => {
  loop.log("скрипт");
  loop.task(() => loop.log("таймер"));
  loop.microtask(() => {
    loop.log("микро 1");
    loop.microtask(() => loop.log("микро 3"));
  });
  loop.microtask(() => loop.log("микро 2"));
});
loop.script(() => {
  loop.microtask(() => loop.log("микро второго скрипта"));
  throw new Error("сбой");
});
loop.run();
loop.journal().join(" | ");   // "скрипт | микро 1 | микро 2 | микро 3 | ошибка: сбой | микро второго скрипта | таймер"
```
</Example>

<Criteria>
- строка примера даёт то, что в комментарии;
- первый скрипт, переписанный на `setTimeout` и `Promise.resolve().then`, печатает в
  Chrome тот же порядок;
- каждое требование 9.5 (пустой стек, одно за раз, до конца, свои ошибки) показано строкой модели.
</Criteria>
</Task>

<Task title="6. «Карточки 2.0»: одна загрузка на всех" level="medium" time="12">
<Goal>не начинать работу второй раз, пока идёт первая.</Goal>

Две буквы подряд грузят колоды дважды (раздел 16 лекции). Напишите `once(asyncFn)`: пока вызов
не закончился, все вызовы получают тот же промис; после выполнения или отказа следующий вызов начинает заново.
Оберните ею `openAll` в своём `main.js`.

<Example>
```js
let loads = 0;
const slow = async () => {
  loads++;
  await null;
  return "колоды";
};
const openAll = once(slow);
const first = openAll();
first === openAll();   // true
loads;                 // 1
```
</Example>

<Criteria>
- обе строки примера дают то, что в комментариях;
- после того как `first` выполнился, новый вызов грузит снова: `loads` — 2;
- после отказа следующий вызов тоже пробует снова, а не отдаёт старый отказ.
</Criteria>
</Task>

</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Свои ResolveBinding и PutValue" level="hard" time="10">
<Goal>пройти путь имени: 9.4.2, 9.1.2.1, 6.2.5.5–6.2.5.6.</Goal>

Запись окружения — `{ bindings: Map, outer }`. Напишите `resolveBinding(name, env, strict)` —
ссылку `{ base, name, strict }`, где `base` — запись с именем или
`"unresolvable"`; `getValue(ref)`; `putValue(ref, value, globalObject)` —
`globalObject` играет роль глобального объекта текущего реалма.

<Example>
```js
const attempt = (f) => { try { return f(); } catch (e) { return e.name; } };
const globalObject = {};
const global = { bindings: new Map([["label", "страница"]]), outer: null };
const fn = { bindings: new Map([["x", 1]]), outer: global };
getValue(resolveBinding("x", fn, false));                                     // 1
getValue(resolveBinding("label", fn, false));                                 // "страница"
putValue(resolveBinding("leak", fn, false), 5, globalObject);
globalObject.leak;                                                            // 5
attempt(() => putValue(resolveBinding("y", fn, true), 1, globalObject));     // "ReferenceError"
attempt(() => getValue(resolveBinding("nope", fn, false)));                  // "ReferenceError"
```
</Example>

<Criteria>
- все пять проверяемых строк примера дают то, что в комментариях;
- флажок `strict` хранится в ссылке, как `[[Strict]]` Reference Record (день 4), и
  читается только при записи;
- объяснено, почему чтение неразрешимой ссылки бросает и в нестрогом коде.
</Criteria>
</Task>

<Task title="9. Задание для thenable по шагам" level="hard" time="10">
<Goal>прочитать, как resolve ставит задание и какой реалм ему даёт.</Goal>

Прочитайте [27.2.1.3 CreateResolvingFunctions](https://tc39.es/ecma262/2026/#sec-promise-resolve-functions)
и [27.2.2.2 NewPromiseResolveThenableJob](https://tc39.es/ecma262/2026/#sec-newpromiseresolvethenablejob),
найдите вызов HostEnqueuePromiseJob и предскажите строку.

```js
const log = [];
const thenable = { then(resolve) { log.push("then"); resolve("готово"); } };
Promise.resolve().then(() => log.push("1"));
new Promise((resolve) => resolve(thenable)).then((v) => log.push(v));
Promise.resolve().then(() => log.push("2")).then(() => log.push("3")).then(() => log.push("4"));
setTimeout(() => console.log(log.join(" ")), 0);
```

<Criteria>
- предсказана строка, у каждого слова — задание, которое его записало;
- найдено, откуда берётся реалм задания: GetFunctionRealm функции `then`, и что будет, если
  это отозванный прокси (день 16);
- объяснено, почему «готово» записано после «2»: сколько лишних заданий дал thenable и сколько дал бы
  вместо него выполненный промис (день 28 курса 2).
</Criteria>
</Task>
