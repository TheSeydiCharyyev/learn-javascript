День 10. Выражения по спецификации

Выжимка лекции: приоритет и порядок вычисления, доступ и вызов, необязательная цепочка, delete и typeof, сложение и сравнения, три формы присваивания.

Главное

Приоритет задаёт грамматика — форму дерева. Порядок вычисления задают шаги Evaluation: левый операнд, правый, операция. Цель присваивания — ссылка (Reference Record): её вычисляют первой, а приводят ключ (ToPropertyKey) только при чтении или записи.

Порядок и ссылка

const log = [];
const v = (name, value) => { log.push(name); return value; };
console.log(v("f", 1) + v("g", 2) * v("h", 3), log.join(" "));   // 7 f g h — слева направо, хотя * раньше +
const a = [];
let i = 0;
a[i++] = i;
console.log(JSON.stringify(a));                                   // [1] — ключ 0 вычислен до правой части
log.length = 0;
const key = { toString() { log.push("ключ"); return "k"; } };
const o = {};
o[key] = v("правая", 1);
console.log(log.join(" "));                                       // правая ключ — ToPropertyKey после правой части
Вызов и new: сначала аргументы, потом проверка «is not a function» или «is not a constructor». null[f()] вызывает f и только потом падает. Скобки ссылку не теряют, запятая и присваивание — теряют.

?., delete и typeof

const obj = { a: null };
console.log(obj?.a?.b, null?.x.y.z);                      // undefined undefined — одна проверка на всю цепочку
console.log(delete obj.a, delete obj.nope, "a" in obj);   // true true false — удалить можно и то, чего нет
var counter = 1;
console.log(delete counter, typeof undeclaredName);       // false undefined — var не удалить; typeof неразрешимого имени
console.log(typeof document.all, typeof class {});        // undefined function — [[IsHTMLDDA]] и [[Call]]
?. проверяет только основу, скобки кончают цепочку. Нельзя: слева от =, в ++, после new, с тегом шаблона. delete: не ссылка и неразрешимое имя — true; в строгом коде имя — SyntaxError, неудача — TypeError; приватное поле — никогда. typeof защищает только само имя: если имени нет, typeof имя?.y бросает.

Присваивание

const log = [];
const obj = { get v() { log.push("get"); return 1; }, set v(x) { log.push(`set ${x}`); } };
obj.v ||= 5;
obj.v += 1;
console.log(log.join(", "));                    // get, get, set 2 — ||= не записал, += прочитал до записи
const steps = [];
const k = { toString() { steps.push("ключ"); return "k"; } };
const target = { k: 1 };
target[k] += 1;
console.log(steps.join(" "), target.k);         // ключ ключ 2 — Chrome 156; по тексту 2026 «ключ» один раз
let d1, d2;
({ d1 = "умолчание", d2 = "умолчание" } = { d1: null, d2: undefined });
console.log(d1, d2);                            // null умолчание — умолчание только для undefined
