День 17. Reflect и встроенные символы

Выжимка лекции: функции Reflect и их отличие от Object, пересылка с Receiver и newTarget, встроенные символы и алгоритмы, которые их спрашивают, объекты Symbol.

Главное

Reflect (28.1) — обычный объект, не функция: 13 функций, по одной на внутренний метод, с теми же именами и аргументами, что у ловушек прокси. Каждая проверяет аргументы и отдаёт ответ метода как есть. Встроенный символ — ключ, под которым язык сам ищет метод или значение объекта (Get или GetMethod); нет ответа — работает алгоритм по умолчанию.

Ловушка пересылает без потерь, если зовёт функцию Reflect с тем же именем и всеми своими аргументами: return Reflect.get(t, key, receiver). Обработчик-прокси может отвечать Reflect[имя] на любое имя ловушки. Reflect.construct — единственный способ задать new.target: так ловушка construct и модель bind не теряют newTarget наследника.

Встроенные символы

const price = { [Symbol.toPrimitive](hint) { return hint === "number" ? 12 : hint === "string" ? "12 манат" : "цена"; } };
console.log(+price, `${price}`, price + "");              // 12 12 манат цена — подсказки number, string, default
const d = new Date(2026, 10, 3);
console.log(typeof (d + 1), typeof (d - 1));              // string number — дата считает default строкой
class Deck extends Array {
  static get [Symbol.species]() { return Array; }
  get [Symbol.toStringTag]() { return "Deck"; }
}
const deck = Deck.from(["kitap", "galam"]);
console.log(Object.prototype.toString.call(deck), deck.map((w) => w) instanceof Deck, Deck.of(1) instanceof Deck);   // [object Deck] false true — тег из геттера; map через species, of через this
console.log([1].concat({ length: 1, 0: "a", [Symbol.isConcatSpreadable]: true }).length);   // 2 — подобие массива раскрыто

Метод toPrimitive обязан вернуть примитив; из встроенных объектов свой есть только у Date и Symbol. Тег — любая строка, даже у массива, поэтому toString — не проверка типа. of и from создают через this, без species. Встроенные символы общие для всех реалмов, а свойства Symbol.iterator и другие — неизменяемые.

Function.prototype[Symbol.hasInstance] незаписываемый: своё свойство — только через defineProperty или static. «Карточки 2.0»: колода с тегом Deck, toPrimitive для чисел и строк и species — map отдаёт простые слова.

  3. У class D extends Array статический геттер Symbol.species возвращает undefined. Чему равны D.from([1, 2]).map((x) => x) instanceof D и D.of(1) instanceof D? Что будет, если геттер вернёт 1? Объясните по шагам ArraySpeciesCreate.
