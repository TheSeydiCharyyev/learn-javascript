# День 17. Reflect и встроенные символы

<Subtitle>Выжимка лекции: функции Reflect и их отличие от Object, пересылка с Receiver и newTarget, встроенные символы и алгоритмы, которые их спрашивают, объекты Symbol.</Subtitle>

## Главное

<Definition>
Reflect (28.1) — обычный объект, не функция: 13 функций, по одной на внутренний метод, с теми же именами и
аргументами, что у ловушек прокси. Каждая проверяет аргументы и отдаёт ответ метода как есть. Встроенный символ —
ключ, под которым язык сам ищет метод или значение объекта (Get или GetMethod); нет ответа — работает алгоритм по
умолчанию.
</Definition>

## Reflect и пересылка

```js
const run = (f) => { try { f(); return "ok"; } catch (e) { return e.name; } };
const frozen = Object.freeze({ word: "kitap" });
console.log(Reflect.defineProperty(frozen, "x", { value: 1 }), run(() => Object.defineProperty(frozen, "x", { value: 1 })), run(() => Reflect.getPrototypeOf(1)));   // false TypeError TypeError — ответ метода как есть, цель-примитив — ошибка
const card = { word: "kitap", get title() { return this.word.toUpperCase(); } };
console.log(Reflect.get(card, "title", { word: "suw" }), Reflect.ownKeys({ b: 1, 1: 2, [Symbol("s")]: 3 }).length);   // SUW 3 — receiver стал this геттера; ownKeys — строки и символы
const kid = Object.create(new Proxy(card, { get(t, key, receiver) { return Reflect.get(t, key, receiver); } }));
kid.word = "galam";
console.log(kid.title);                                   // GALAM — receiver наследника дошёл до геттера
class Card { constructor(w) { this.w = w; } }
class Other {}
console.log(Reflect.construct(Card, ["kitap"], Other) instanceof Other, run(() => Reflect.apply(Math.max, null)));   // true TypeError — прототип от newTarget; аргументы — только объект
```

| Reflect | Без Reflect | Разница |
| --- | --- | --- |
| `defineProperty`, `set`, `deleteProperty`, `setPrototypeOf` | `Object.*`, присваивание, `delete` | false вместо TypeError, и в строгом коде |
| `getPrototypeOf`, `isExtensible` | `Object.*` | цель-примитив — TypeError, без ToObject |
| `ownKeys` | `getOwnPropertyNames` и `getOwnPropertySymbols` | одним массивом: индексы, строки, символы |
| `get`, `set` | `t[k]`, `t[k] = v` | receiver — `this` геттера и сеттера, на нём создают свойство |
| `apply` | `f.apply` | свой `f.apply` не спрашивают; аргументы — объект |
| `construct` | `new C(...args)` | newTarget по выбору |

<Remember>
Ловушка пересылает без потерь, если зовёт функцию Reflect с тем же именем и всеми своими аргументами:
`return Reflect.get(t, key, receiver)`. Обработчик-прокси может отвечать
`Reflect[имя]` на любое имя ловушки. Reflect.construct — единственный способ задать
`new.target`: так ловушка `construct` и модель `bind` не теряют newTarget
наследника.
</Remember>

## Встроенные символы

```js
const price = { [Symbol.toPrimitive](hint) { return hint === "number" ? 12 : hint === "string" ? "12 манат" : "цена"; } };
console.log(+price, `${price}`, price + "");              // 12 12 манат цена — подсказки number, string, default
const d = new Date(2026, 10, 3);
console.log(typeof (d + 1), typeof (d - 1));              // string number — дата считает default строкой
class Deck extends Array {
  static get [Symbol.species]() { return Array; }
  get [Symbol.toStringTag]() { return "Deck"; }
}
const deck = Deck.from(["kitap", "galam"]);
console.log(Object.prototype.toString.call(deck), deck.map((w) => w) instanceof Deck, Deck.of(1) instanceof Deck);   // [object Deck] false true — тег из геттера; map через species, of через this
console.log([1].concat({ length: 1, 0: "a", [Symbol.isConcatSpreadable]: true }).length);   // 2 — подобие массива раскрыто
```

| Символ | Кто спрашивает | Без ответа |
| --- | --- | --- |
| `toPrimitive` | ToPrimitive | OrdinaryToPrimitive |
| `toStringTag` | `Object.prototype.toString` | тег по слотам |
| `species` | `map`, `filter`, `slice`…, `then`, `finally` | конструктор по умолчанию |
| `hasInstance` | `instanceof` | OrdinaryHasInstance |
| `isConcatSpreadable` | `concat` | IsArray |
| `match` | IsRegExp: `RegExp(x)`, `includes`, `replaceAll` | слот \[\[RegExpMatcher\]\] |
| `unscopables` | `with` (день 31) | все имена видны |

<Remember>
Метод toPrimitive обязан вернуть примитив; из встроенных объектов свой есть только у Date и Symbol. Тег — любая
строка, даже у массива, поэтому toString — не проверка типа. `of` и `from` создают через
`this`, без species. Встроенные символы общие для всех реалмов, а свойства `Symbol.iterator`
и другие — неизменяемые.
</Remember>

## hasInstance и объекты Symbol

```js
const run = (f) => { try { f(); return "ok"; } catch (e) { return e.name; } };
class Even { static [Symbol.hasInstance](n) { return Number.isInteger(n) && n % 2 === 0; } }
function Plain() {}
Plain[Symbol.hasInstance] = () => true;
console.log(4 instanceof Even, {} instanceof Plain, run(() => 1 instanceof {}));   // true false TypeError — static работает, присваивание отклонено, справа не функция
const s = Symbol("kitap");
const box = Object(s);
console.log(typeof box, box == s, box === s, ({ [s]: 1 })[box]);   // object true false 1 — обёртка: == и ключ идут через ToPrimitive
console.log(run(() => new Symbol()), Symbol.for("kitap") === Symbol.for("kitap"), Symbol.keyFor(s), String(s), run(() => `${s}`));   // TypeError true undefined Symbol(kitap) TypeError — без new; реестр; строкой — только явно
```

| Что | Откуда | `Symbol.keyFor` |
| --- | --- | --- |
| `Symbol("x")` | новый при каждом вызове | undefined |
| `Symbol.for("x")` | реестр, общий для реалмов | "x" |
| `Symbol.iterator` и другие | свойства Symbol, неизменяемые | undefined |
| `Object(sym)` | обёртка со слотом \[\[SymbolData\]\] | TypeError |

<Remember>
`instanceof` сначала ищет метод Symbol.hasInstance (правому операнду не нужен \[\[Call\]\]), иначе —
OrdinaryHasInstance. Function.prototype\[Symbol.hasInstance\] незаписываемый: своё свойство — только через
defineProperty или `static`. «Карточки 2.0»: колода с тегом Deck, toPrimitive для чисел и строк и
species — `map` отдаёт простые слова.
</Remember>
