День 19. Мини-проект: наблюдаемое хранилище на Proxy и Reflect

Выжимка лекции: куда приходит запись через прокси, как устроены хранилище и доска и как проверить, что проект готов.

Части программы

// store.js    createStore(data, allowed) → { state, subscribe }; subscribe возвращает отписку
//             get — обёртка вложенного объекта; WeakMap цель → прокси: у объекта один прокси
//             defineProperty — проверка typeof и allowed, обёртка → цель, Reflect.defineProperty, notify()
//             deleteProperty — Reflect.deleteProperty, notify(); ловушки set нет
//             notify — флажок planned и Promise.resolve().then: подписчики один раз на всё действие
// index.html  три колонки section[data-status] со списками, форма, фильтр, #error
// main.js     данные из localStorage или first; globalThis.board = state — окно для консоли
//             makeCard и render только читают state; subscribe(render), subscribe(сохранение)
//             слушатели только пишут: push, task.status = …, splice, state.filter = …
Слушатель пишет в state, ловушка проверяет запись и уведомляет, подписчики рисуют и сохраняют. render() руками не зовут никогда: если страница не обновилась, виновато хранилище, а не забытый вызов.

Ловушка обязана вернуть булево. undefined — TypeError в строгом коде, хотя запись уже сделана; страница MDN handler.defineProperty() так и пишет: метод «must return a Boolean». Если ловушка set всё же нужна — Reflect.set(target, key, value, receiver): без receiver получатель — цель (28.1.12, шаг 3.a), и запись идёт мимо defineProperty.
Обёртка — только объектам; функции вроде push отдаются как есть. Один прокси на объект — WeakMap, иначе indexOf даёт −1, а splice(-1, 1) удаляет последнее. splice пишет назад прочитанные обёртки — перед записью обёртку меняют на цель. Замороженное в хранилище не кладут: get замороженного свойства обязан вернуть то же значение (10.5.8).
Консоль: board — то же хранилище, что у страницы. board.tasks[0].status = "done" перерисует доску сама, когда команда закончится. Сколько раз сработал render, покажет console.count("render") первой строкой функции. Вернуть первые данные — localStorage.clear() и обновить страницу.
