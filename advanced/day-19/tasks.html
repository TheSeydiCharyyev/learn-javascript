День 19. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Проект — в папке board: index.html, store.js и main.js из лекции, запуск через Live Server. Каждую доработку делайте в копии папки. Копии на одном Live Server делят localStorage: перед каждым заданием — localStorage.clear() и обновить страницу.

Основные задания

4. Сортировка в колонке

В каждой колонке карточки идут по имени того, кто делает, а у одного человека — по названию задания.

Порядок — дело показа. В render после filter — toSorted («the copying version of the sort() method») со сравнением a.who.localeCompare(b.who, "ru") || a.title.localeCompare(b.title, "ru").
  • в «Надо» — «Сохранение storage.js — Аман», потом «Проверки tests.js — Мерет»; после «→» у «Сохранение storage.js» в «Делаю» — «Модуль card.js», потом «Сохранение storage.js»;

  • в копии render начинается с if (++n > 50) throw new Error("стоп"); и state.tasks.sort(…) (let n = 0 — над функцией): консоль сразу показала «Uncaught (in promise) Error: стоп»; объяснено, почему без ограничителя круг перерисовок не кончился бы.
5. Поля нового задания
Средне12 мин

проверять не только запись, но и записанный объект.

Сейчас board.tasks.push({ id: 9, title: "x", who: "y", status: "готово" }) проходит: хранилище видит запись индекса, а не поля объекта. Пусть check проверяет и поля значения-объекта.

В начале check: если значение — объект, пройти Object.entries(value) и вызвать check(value, k, v) для каждого поля. Рекурсия дойдёт и до вложенных объектов.

Испорченные руками данные для третьего критерия — три строки в консоли:

const data = JSON.parse(JSON.stringify(board));
data.tasks[0].status = "готово";
localStorage.setItem("board-js-1", JSON.stringify(data));
  • push с «готово» — RangeError: status: можно только todo, doing, done, board.tasks.length — 4, карточек — 4;
  • форма, стрелки и «✕» работают без ошибок, хотя splice при переносе записывает задания целиком;
  • после трёх строк в консоли и обновления страницы доска открылась без ошибки: «Заданий: 4 · готово: 0», карточек 3; объяснено, почему проверка это пропустила.
6. Пауза сохранения
Средне12 мин

пользоваться отпиской.

Рядом с фильтром — флажок «Не сохранять». Пока он включён, доска не пишет в localStorage; выключили — сразу сохраняет текущее состояние.

subscribe возвращает отписку: let stopSaving = subscribe(save). Флажок включили — stopSaving(); выключили — подписаться снова и сразу вызвать save().
  • флажок включён, «✕» у «Разметка страницы», обновление — «Разметка страницы» на месте;
  • флажок включён, «✕», флажок выключен, обновление — «Разметки страницы» нет;
  • с включённым флажком доска перерисовывается как обычно; объяснено, почему отписка одного подписчика не трогает другого;
  • subscribe(save) дважды подряд — save зовётся один раз за изменение, а первая же отписка снимает его совсем; объяснено, при чём здесь Set.
7. Подписка на поля
Средне14 мин

звать подписчика, только когда изменилось нужное.

subscribe(listener, keys): второй аргумент необязателен — список ключей. Подписчик со списком зовётся, только если в пачке изменений есть один из его ключей. Каждый подписчик получает массив изменённых ключей; подписчики без списка зовутся, как раньше.

notify(key) копит ключи в Set, микрозадача отдаёт их массивом и чистит Set. listeners — Map: подписчик → список или null.
  • subscribe(() => console.log("фильтр:", state.filter), ["filter"]): «аман» по буквам — четыре строки, «→», «✕» и форма — ни одной;
  • подписчик без списка получил за «→» — ["status"], за «✕» у первой из четырёх — ["0", "1", "2", "3", "length"], за форму после этого — ["3", "length", "nextId"];
  • подписчик на ["title"] сработал и от board.title = "JS-2", и от board.tasks[0].title = "x"; объяснено почему и что нужно, чтобы различать их.

Со звёздочкой

8. Отменить
Сложно10 мин

построить историю изменений на подписчике.

Кнопка «Отменить» возвращает задания и nextId на одно действие назад. При загрузке и когда отменять нечего, она неактивна.

Подписчик кладёт снимок JSON.stringify({ tasks: state.tasks, nextId: state.nextId }) в массив, если он отличается от последнего; первый снимок — при загрузке. Отмена убирает последний снимок и записывает предыдущий в state.
  • при загрузке «Отменить» неактивна (disabled);
  • задание «Тесты» (Сапар), «→» у него, «✕» у «Разметка страницы», «аман» в фильтре и обратно пусто — три «Отменить» возвращают первую доску, кнопка снова неактивна;
  • после этого новое задание снова получает номер 5;
  • объяснено, почему само восстановление не попадает в историю и почему без сравнения с последним снимком отменяется только одно действие, а дальше «Отменить» ничего не меняет.
9. Три жалобы
Сложно10 мин

искать ошибку хранилища от симптома.

Одноклассник прислал свою доску и три жалобы:

  • «Один щелчок „✕“ — и console.count("render") вырос на пять, хотя доска правильная».
  • «Удалил задание, обновил страницу — пустая страница, в консоли SyntaxError: "[object Object]" is not valid JSON».
  • «Набрал в фильтре „аман“, обновил страницу — поле пустое, а на доске только задания Амана».

От проекта лекции его доска отличается в этих местах:

// store.js — notify
function notify() {
  Promise.resolve().then(() => {
    for (const listener of listeners) listener();
  });
}

// main.js — сохранение
subscribe(() => localStorage.setItem(SAVED, state));

// main.js — первый показ, без строки filter.value = state.filter;
render();
Начните с вопроса «что в localStorage?»: localStorage.getItem("board-js-1").
  • каждая жалоба воспроизведена и сопоставлена со своим фрагментом;
  • объяснено, почему без флажка planned перерисовок пять, а доска всё равно верная;
  • показано, что в localStorage лежит "[object Object]", и объяснено, откуда эта строка: ToString (7.1.17, шаг 10) превращает объект через ToPrimitive;
  • все три исправлены; объяснено, почему после исправления второй жалобы страница пустая до localStorage.clear().
