# Day 1. What JavaScript is

<Subtitle>A short summary of the lecture: reread it before the next lesson.</Subtitle>

## The main points

<Definition>
**JavaScript** is a programming language. A program in it is a list of instructions that
run in order. In the browser it is responsible for the **behavior** of the page.
</Definition>

<KeyPoint>
Three layers of a page: **HTML** is the content, **CSS** is the appearance,
**JavaScript** is the behavior.
</KeyPoint>

<Definition>
An **engine** is a program inside the browser that runs code. V8 in Chrome and Edge,
SpiderMonkey in Firefox, JavaScriptCore in Safari. The V8 engine also works without a browser — that is **Node.js**.
</Definition>

<Definition>
**ECMAScript** is the official standard of the language. A new edition comes out every year: ES2015, ES2016
and so on. Old code keeps working.
</Definition>

<Definition>
**Core and environment.** The language core — numbers, strings, functions, `Math`,
`JSON` — is the same everywhere. The environment adds its own things: the browser adds the page
(`document`), windows and events; Node.js adds files and the server (`process`).
</Definition>

```js
typeof document;   // "object" in the browser, "undefined" in Node.js
typeof process;    // "undefined" in the browser, "object" in Node.js
```

## Where JavaScript works

- pages and web apps — in the browser;
- servers — Node.js;
- phone apps — React Native;
- desktop programs — Electron (VS Code, Discord).

## What the browser allows and what it forbids

| Allowed | Not without permission |
| --- | --- |
| change the page, react to actions | read files on the disk |
| request data from a server | start programs |
| save data in the browser | turn on the camera and find your location |

## Code from the lecture

```js
alert("Hello, Mary!");

const name = prompt("What is your name?");
alert("Hello, " + name + "!");

console.log(60 * 24 * 7); // 10080 — minutes in a week
```

## The console

The console shows the value of the last expression by itself. `console.log` prints but
returns nothing — that is why the console writes `undefined` after the output. An unfinished
line (`function greet() {`) does not run on <Kbd>Enter</Kbd> but waits for
the rest; to start a new line yourself, press <Kbd>Shift</Kbd> + <Kbd>Enter</Kbd>.

```js
3 + 5;               // 8
console.log(3 + 5);  // prints 8, and below it — undefined
```

## The first three errors

| Code | What Chrome writes | Why |
| --- | --- | --- |
| `console.log(summa);` | `ReferenceError: summa is not defined` | there is no such name |
| `console.lg("test");` | `TypeError: console.lg is not a function` | `console` has no method `lg` |
| `consol.log("test");` | `ReferenceError: consol is not defined` | the very first name is unknown |
| `alert("hello);` | `SyntaxError: Invalid or unexpected token` | the quote is not closed |

## Words to know

| Word | Meaning |
| --- | --- |
| code | the text of a program |
| statement | one command of a program |
| console | a browser window where code runs at once (<Kbd>F12</Kbd>) |
| engine | the program that runs code |
| variable | a named box for a value |
| function | a ready-made command with a name; it is called with parentheses |
