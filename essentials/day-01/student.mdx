# День 1. Что такое JavaScript

<Subtitle>Короткая выжимка лекции: перечитать перед следующим занятием.</Subtitle>

## Главное

<Definition>
**JavaScript** — язык программирования. Программа на нём — это список инструкций, которые
выполняются по порядку. В браузере он отвечает за **поведение** страницы.
</Definition>

<KeyPoint>
Три слоя страницы: **HTML** — содержимое, **CSS** — внешний вид,
**JavaScript** — поведение.
</KeyPoint>

<Definition>
**Движок** — программа внутри браузера, которая выполняет код. V8 в Chrome и Edge,
SpiderMonkey в Firefox, JavaScriptCore в Safari. Движок V8 работает и без браузера — это **Node.js**.
</Definition>

<Definition>
**ECMAScript** — официальный стандарт языка. Новая редакция выходит каждый год: ES2015, ES2016
и так далее. Старый код при этом продолжает работать.
</Definition>

<Definition>
**Ядро и окружение.** Ядро языка — числа, строки, функции, `Math`,
`JSON` — одинаково везде. Окружение добавляет своё: браузер — страницу
(`document`), окна, события; Node.js — файлы и сервер (`process`).
</Definition>

```js
typeof document;   // "object" в браузере, "undefined" в Node.js
typeof process;    // "undefined" в браузере, "object" в Node.js
```

## Где работает JavaScript

- страницы и веб-приложения — в браузере;
- серверы — Node.js;
- приложения для телефона — React Native;
- программы для компьютера — Electron (VS Code, Discord).

## Что браузер разрешает и что запрещает

| Можно | Нельзя без разрешения |
| --- | --- |
| менять страницу, реагировать на действия | читать файлы на диске |
| запрашивать данные с сервера | запускать программы |
| сохранять данные в браузере | включать камеру и узнавать место |

## Код из лекции

```js
alert("Привет, Мары!");

const name = prompt("Как вас зовут?");
alert("Здравствуйте, " + name + "!");

console.log(60 * 24 * 7); // 10080 — минут в неделе
```

## Консоль

Консоль сама показывает значение последнего выражения. `console.log` печатает, но
ничего не возвращает — поэтому после вывода консоль пишет `undefined`. Незаконченная
строка (`function greet() {`) не выполняется по <Kbd>Enter</Kbd>, а ждёт
продолжения; перенос вручную — <Kbd>Shift</Kbd> + <Kbd>Enter</Kbd>.

```js
3 + 5;               // 8
console.log(3 + 5);  // печатает 8, а ниже — undefined
```

## Три первые ошибки

| Код | Что пишет Chrome | Почему |
| --- | --- | --- |
| `console.log(summa);` | `ReferenceError: summa is not defined` | такого имени нет |
| `console.lg("тест");` | `TypeError: console.lg is not a function` | у `console` нет метода `lg` |
| `consol.log("тест");` | `ReferenceError: consol is not defined` | неизвестно уже первое имя |
| `alert("привет);` | `SyntaxError: Invalid or unexpected token` | кавычка не закрыта |

Подключение файла со скриптом к странице:

```html
<script src="app.js" defer></script>
```

<Remember>
Java и JavaScript — разные языки. Общее у них только часть названия.
</Remember>

## Слова, которые нужно знать

| Слово | Значение |
| --- | --- |
| код | текст программы |
| инструкция | одна команда программы |
| консоль | окно браузера, где можно выполнить код сразу (<Kbd>F12</Kbd>) |
| движок | программа, которая выполняет код |
| переменная | именованная коробочка для значения |
| функция | готовая команда с именем, вызывается со скобками |
