## The workplace

<KeyPoint>
A browser + the VS Code editor + a project folder. The **Live Server** extension opens the page
at `http://127.0.0.1:5500` and refreshes it by itself after saving.
</KeyPoint>


```js
// app.js
console.log("File connected");
```

<Remember>
File names: Latin letters, lowercase, no spaces. On Windows `App.js` and
`app.js` are one file, but on many servers on the internet they are different.
<code><span lang="ru">арр</span>.js</code> typed with Cyrillic letters will not be found anywhere.
</Remember>

## Console commands

```js
console.log("text", value);
console.info("information");
console.warn("a warning");
console.error("an error");

console.table(students);     // a table
console.dir(document.body);  // a tree of properties

console.group("section");
console.groupEnd();

console.time("label");
console.timeEnd("label");

console.count("got here");
console.assert(age >= 18, "too young");
console.trace();
console.clear();
```

Substitutions: `console.log("Student %s got %d", "Aman", 5)` — each one takes
the next value. In the console `$_` keeps the result of the previous line. Without a name
`console.count()` counts under the name `default`; an unknown name in
`timeEnd` gives the warning `Timer '…' does not exist`.

<Definition>
**Step-by-step debugging.** Do not guess — stop and look: in the average function,
at the first stop Scope showed `i: 1` — the loop skipped the first mark.
</Definition>

<Definition>
A **breakpoint** is a mark on a line of code where the browser stops the program so that you can
look at the values of the variables. You set it by clicking a line number in the Sources tab or with the word
`debugger` right in the code.
</Definition>

## When nothing works

1. look at the console and read the error;
2. check that the file is saved;
3. reload the page with <Kbd>Ctrl</Kbd> + <Kbd>F5</Kbd>;
4. put `console.log("the file works")` as the first line;
5. read the file name and the path letter by letter.

A script that is not found gives two red lines in the console: `404 (Not Found)` and
`Refused to execute script … MIME type ('text/html')`. Which address the page tried
to load is shown by `document.scripts[0].src`.

</NoteBox>
