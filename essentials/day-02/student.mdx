# День 2. Инструменты

<Subtitle>Редактор, проект из двух файлов, консоль и отладка.</Subtitle>

## Рабочее место

<KeyPoint>
Браузер + редактор VS Code + папка проекта. Расширение **Live Server** открывает страницу
по адресу `http://127.0.0.1:5500` и сама обновляет её после сохранения.
</KeyPoint>

## Проект из двух файлов

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>День 2</title>
  <script src="app.js" defer></script>
</head>
<body>
  <h1>Проверка инструментов</h1>
</body>
</html>
```

```js
// app.js
console.log("Файл подключён");
```

<Remember>
Имена файлов — латиницей, маленькими буквами, без пробелов. На Windows `App.js` и
`app.js` — один файл, а на многих серверах в интернете — разные. `арр.js` с
русскими буквами не найдётся нигде.
</Remember>

## Инструменты разработчика

| Вкладка | Зачем |
| --- | --- |
| Elements | разметка и стили страницы |
| Console | вывод программы, выполнение кода |
| Sources | файлы скриптов, точки останова |
| Network | запросы к серверу (день 31) |

## Команды консоли

```js
console.log("текст", значение);
console.info("информация");
console.warn("предупреждение");
console.error("ошибка");

console.table(students);     // таблица
console.dir(document.body);  // дерево свойств

console.group("раздел");
console.groupEnd();

console.time("метка");
console.timeEnd("метка");

console.count("сюда зашли");
console.assert(age >= 18, "мало лет");
console.trace();
console.clear();
```

Подстановки: `console.log("Ученик %s получил %d", "Аман", 5)` — каждая забирает
следующее значение. В консоли `$_` хранит результат предыдущей строки. Без имени
`console.count()` считает под именем `default`; неизвестное имя в
`timeEnd` даёт предупреждение `Timer '…' does not exist`.

<Definition>
**Отладка по шагам.** Не гадать, а остановиться и посмотреть: в функции среднего балла
на первой остановке Scope показал `i: 1` — цикл пропускал первую оценку.
</Definition>

<Definition>
**Точка останова** — метка на строке кода, где браузер остановит программу, чтобы вы
посмотрели значения переменных. Ставится щелчком по номеру строки во вкладке Sources или словом
`debugger` прямо в коде.
</Definition>

## Если ничего не работает

1. посмотреть в консоль и прочитать ошибку;
2. проверить, сохранён ли файл;
3. обновить страницу через <Kbd>Ctrl</Kbd> + <Kbd>F5</Kbd>;
4. поставить `console.log("файл работает")` первой строкой;
5. прочитать имя файла и путь по буквам.

Ненайденный скрипт даёт в консоли две красные строки: `404 (Not Found)` и
`Refused to execute script … MIME type ('text/html')`. Какой адрес страница пыталась
загрузить, покажет `document.scripts[0].src`.

<NoteBox>
**Горячие клавиши VS Code:** <Kbd>Ctrl</Kbd> + <Kbd>S</Kbd> —
сохранить, <Kbd>Ctrl</Kbd> + <Kbd>/</Kbd> — комментарий,
<Kbd>Alt</Kbd> + стрелки — двигать строку, <Kbd>Ctrl</Kbd> +
<Kbd>D</Kbd> — выделить такое же слово.
</NoteBox>
