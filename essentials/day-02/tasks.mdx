# День 2. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Сегодня много работы руками: ставим редактор, собираем проект, осваиваем консоль. Все файлы складываем в папку `day-02`.</Subtitle>

## Разминка

<Task title="1. Рабочее место" level="easy" time="7">
<Goal>поставить редактор и завести папку курса.</Goal>

Установите VS Code, поставьте расширение Live Server. Создайте папку курса и внутри неё папку
`day-02`. Откройте её в редакторе: File → Open Folder.

<Criteria>
- в левой панели редактора видно имя папки `day-02`;
- расширение Live Server установлено;
- включено автосохранение (File → Auto Save).
</Criteria>
</Task>

<Task title="2. Страница и скрипт" level="easy" time="7">
<Goal>подключить файл со скриптом к странице.</Goal>

Создайте `index.html` и `app.js`. В странице — заголовок «День 2» и подключение
скрипта с `defer`. В скрипте — вывод «Файл подключён». Откройте страницу через Live Server.

<Criteria>
- в адресной строке `http://127.0.0.1:5500`, а не `file:///`;
- надпись видна в консоли;
- после изменения текста и сохранения страница обновилась сама.
</Criteria>
</Task>

<Task title="3. Четыре уровня сообщений" level="easy" time="6">
<Goal>увидеть разницу между log, info, warn и error.</Goal>

Выведите по одному сообщению каждым из четырёх методов. Затем в консоли найдите фильтр уровней
и оставьте только ошибки и предупреждения.

<Hint>
Фильтр уровней — выпадающий список над сообщениями консоли, справа от строки поиска.
</Hint>

<Criteria>
- четыре сообщения выведены;
- получилось спрятать обычные сообщения фильтром;
- записано, каким цветом показывается каждый уровень.
</Criteria>
</Task>

## Основные задания

<Task title="4. Таблица оценок" level="medium" time="13">
<Goal>показать список данных читаемо.</Goal>

Соберите список из пяти учеников с оценками и выведите его двумя способами: обычным
`console.log` и методом `console.table`. Сравните, что удобнее читать.

<Example>
```js
const students = [
  { name: "Аман", mark: 5 },
  { name: "Мерет", mark: 4 },
];
console.table(students);
```
</Example>

<Criteria>
- в таблице пять строк и два столбца;
- записан вывод: в каком случае таблица удобнее обычного вывода.
</Criteria>
</Task>

<Task title="5. Группы сообщений" level="medium" time="13">
<Goal>навести порядок в длинном выводе.</Goal>

Выведите расписание на три дня: каждый день — своя группа, внутри группы три предмета.
Один из дней сделайте сразу свёрнутым.

<Hint>
Свёрнутая группа открывается методом `console.groupCollapsed`, закрывается так же —
`console.groupEnd`.
</Hint>

<Criteria>
- три группы, в каждой по три строки;
- одна группа свёрнута при открытии страницы;
- группы раскрываются и сворачиваются щелчком.
</Criteria>
</Task>

<Task title="6. Замер времени" level="medium" time="12">
<Goal>измерить, а не гадать.</Goal>

Замерьте время двух циклов: на сто тысяч шагов и на десять миллионов. Выведите оба результата
и сравните. Внутри цикла складывайте числа в переменную.

<Example>
```js
console.time("маленький");
let sum = 0;
for (let i = 0; i < 100000; i++) { sum = sum + i; }
console.timeEnd("маленький");
```
</Example>

<Criteria>
- оба замера выведены с разными именами меток;
- записано, во сколько раз второй цикл медленнее;
- объяснено, почему время в разных запусках немного отличается.
</Criteria>
</Task>

<Task title="7. Счётчик вызовов" level="medium" time="12">
<Goal>узнать, сколько раз выполняется кусок кода.</Goal>

Напишите функцию приветствия, которая внутри вызывает `console.count`. Вызовите её
пять раз с разными именами, потом обнулите счётчик и вызовите ещё дважды.

<Criteria>
- счётчик дошёл до 5, обнулился и начал считать заново;
- записано, что пишет консоль, если обнулить счётчик, которого ещё не было;
- использован `console.countReset`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Остановиться и осмотреться" level="hard" time="10">
<Goal>поработать с точкой останова.</Goal>

Напишите код, который считает стоимость покупки: цена, количество, скидка. Поставьте точку останова
перед подсчётом итога — щелчком по номеру строки во вкладке Sources. Обновите страницу и посмотрите
значения переменных. Затем пройдите программу по шагам до конца.

<Hint>
Кнопки управления находятся над списком переменных: продолжить, шаг через строку, зайти внутрь.
</Hint>

<Criteria>
- программа останавливается в нужной строке;
- выписаны значения всех переменных на момент остановки;
- то же самое повторено словом `debugger` в коде, а затем строка убрана.
</Criteria>
</Task>

<Task title="9. Сломай и почини" level="hard" time="10">
<Goal>научиться читать ошибки и порядок действий при поломке.</Goal>

Сломайте свой проект тремя способами по очереди, каждый раз записывая текст ошибки из консоли
и то, как вы её нашли:

1. измените в подключении имя файла на `apps.js`;
2. напишите `consol.log("тест")` с одной буквой «e»;
3. уберите закрывающую кавычку в строке.

<Criteria>
- для каждой поломки записан текст ошибки;
- указано, в какой строке браузер нашёл проблему;
- проект после всех трёх правок снова работает;
- отдельно проверено имя `App.js` с большой буквы и записано, почему на Windows
  оно сработало.
</Criteria>
</Task>
