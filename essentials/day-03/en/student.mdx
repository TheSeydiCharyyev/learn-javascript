# Day 3. Language overview

<Subtitle>A summary of the lecture: eight types, variables, operators, program flow, the first program and reading errors.</Subtitle>

## The main points

<Definition>
A program is built from four things: a **value**, an **expression**
(calculated into a value), a **statement** (one action) and a **block**
(statements in curly braces). It runs from top to bottom.
</Definition>

<KeyPoint>
There is nothing to learn by heart today. The task of the day is to recognize the parts of the language in other people’s code
and to know on which day of the course we will come back to them.
</KeyPoint>

## Eight types of values

| Group | Types |
| --- | --- |
| primitives (7) | `Number`, `BigInt`, `String`, `Boolean`, `Symbol`, `Undefined`, `Null` |
| objects (everything else) | `{ }`, `[ ]`, a function, `Date`, `Error`… |

```js
3 / 2;              // 1.5 — there are no separate whole and fractional numbers
0.1 + 0.2;          // 0.30000000000000004 — fractions are stored approximately
NaN === NaN;        // false — the only value not equal to itself
typeof [1, 2];      // "object" — an array is an object too
typeof null;        // "object" — an old mistake of the language
```

<Remember>
Only six values are falsy: `false`, `0`, `""`, `NaN`,
`null`, `undefined`. Everything else is truthy — including `"0"`,
`[]` and `{}`.
</Remember>

`undefined` — nobody put a value. `null` — emptiness was put on purpose.

## Variables

```js
const city = "Mary";   // by default we write this
let count = 0;         // if the value will change
var old = 1;           // an old word, we do not write it in new code

const user = { name: "Aman" };
user.name = "Meret";   // allowed: const forbids reassignment, not change
user = { };            // TypeError
```

## Operators

```js
"3" + 4 + 5;      // "345" — a plus with a string joins
3 + 4 + "5";      // "75"
123 == "123";     // true  — loose, converts the types
123 === "123";    // false — strict, we write only this
0 && "Salam";     // 0       — short-circuit evaluation
"" || "Guest";    // "Guest" — a fallback value
```

## Program flow

| Structure | What for |
| --- | --- |
| `if / else if / else` | a fork |
| `switch` | many branches on one value; `break` is needed |
| `for`, `while`, `do...while` | repetition |
| `for...of` / `for...in` | over the values of an array / over the properties of an object |
| `try...catch`, `throw` | catch and throw an error |

## Objects, arrays, functions

```js
const student = { name: "Gülnar", marks: [5, 4, 5] };
student.name;         // with a dot
student["marks"];     // with brackets
student.city = "Mary";     // a property added on the fly

function add(x, y) { return x + y; }   // a declaration
const add2 = (x, y) => x + y;          // an arrow function
function greet(name = "Guest") { }     // a default value
function avg(...numbers) { }           // rest parameters
```

<Remember>
Objects and arrays are passed **by reference**: `const b = a` is not a copy but a second
name for the same object. That is why `{ } === { }` is always `false`.
</Remember>

<Remember>
**The language and the environment.** The language itself is numbers, strings, objects, functions, `if`,
`for`; it has no input or output. `console`, `document`,
`fetch` and `alert` come from the browser, and in Node.js there are files and the network instead.
</Remember>

## The first program

```js
const student = { name: "Aman", marks: [5, 4, 5, 3, 5] };

function average(numbers) {
  let sum = 0;
  for (const n of numbers) sum += n;
  return sum / numbers.length;
}

const score = average(student.marks);
const line = `${student.name}: average mark ${score.toFixed(2)}`;
console.log(line);
document.getElementById("result").textContent = line;
```

Connecting it to the page: `<script src="app.js" defer></script>` —
the word `defer` is required, otherwise the code runs before the markup.

## Reading an error

```js
// Uncaught   TypeError   : Cannot set...    at app.js:27:47
//    |            |              |                  |
// not caught    kind       what is wrong    file:line:column — clickable!
```

| Kind | Where to look |
| --- | --- |
| `SyntaxError` | parentheses and quotes; breaks the whole file at once |
| `ReferenceError` | a typo in the name, or the variable is declared further down |
| `TypeError` | there is `null`/`undefined` there, or something that is not a function was called |
| `RangeError` | a number outside the limits, endless recursion |

<NoteBox>
**Common mistakes.** A value on the line after `return` — the engine puts in a semicolon
by itself, and the function returns `undefined`. `if (x = 5)` assigns
instead of comparing. `average` without parentheses is the function itself, not its result.
Case matters: `name` and `Name` are different variables.
</NoteBox>
