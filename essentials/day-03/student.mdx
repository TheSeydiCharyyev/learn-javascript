# День 3. Обзор языка

<Subtitle>Выжимка лекции: восемь типов, переменные, операторы, ход программы, первая программа и чтение ошибок.</Subtitle>

## Главное

<Definition>
Программа собирается из четырёх вещей: **значение**, **выражение**
(вычисляется в значение), **инструкция** (одно действие) и **блок**
(инструкции в фигурных скобках). Выполняется сверху вниз.
</Definition>

<KeyPoint>
Заучивать сегодня нечего. Задача дня — узнавать части языка в чужом коде и знать, на каком дне
курса мы к ним вернёмся.
</KeyPoint>

## Восемь типов значений

| Группа | Типы |
| --- | --- |
| примитивы (7) | `Number`, `BigInt`, `String`, `Boolean`, `Symbol`, `Undefined`, `Null` |
| объекты (всё остальное) | `{ }`, `[ ]`, функция, `Date`, `Error`… |

```js
3 / 2;              // 1.5 — целых и дробных отдельно нет
0.1 + 0.2;          // 0.30000000000000004 — дробные хранятся приближённо
NaN === NaN;        // false — единственное значение, не равное себе
typeof [1, 2];      // "object" — массив тоже объект
typeof null;        // "object" — старая ошибка языка
```

<Remember>
Ложны только шесть значений: `false`, `0`, `""`, `NaN`,
`null`, `undefined`. Всё остальное истинно — включая `"0"`,
`[]` и `{}`.
</Remember>

`undefined` — значения никто не клал. `null` — пустоту поставили намеренно.

## Переменные

```js
const city = "Мары";   // по умолчанию пишем так
let count = 0;         // если значение будет меняться
var old = 1;           // старое слово, в новом коде не пишем

const user = { name: "Аман" };
user.name = "Мерет";   // можно: const запрещает переприсваивание, а не изменение
user = { };            // TypeError
```

## Операторы

```js
"3" + 4 + 5;      // "345" — плюс со строкой склеивает
3 + 4 + "5";      // "75"
123 == "123";     // true  — нестрогое, приводит типы
123 === "123";    // false — строгое, пишем только так
0 && "Салам";     // 0      — короткое замыкание
"" || "Гость";    // "Гость" — запасное значение
```

## Ход программы

| Конструкция | Для чего |
| --- | --- |
| `if / else if / else` | развилка |
| `switch` | много веток по одному значению; нужен `break` |
| `for`, `while`, `do...while` | повторение |
| `for...of` / `for...in` | по значениям массива / по свойствам объекта |
| `try...catch`, `throw` | перехватить и бросить ошибку |

## Объекты, массивы, функции

```js
const student = { name: "Гүлнар", marks: [5, 4, 5] };
student.name;         // через точку
student["marks"];     // через скобки
student.city = "Мары";     // свойство добавили на ходу

function add(x, y) { return x + y; }   // объявление
const add2 = (x, y) => x + y;          // стрелочная
function greet(name = "Гость") { }     // значение по умолчанию
function avg(...numbers) { }           // остаточные параметры
```

<Remember>
Объекты и массивы передаются **по ссылке**: `const b = a` не копия, а второе
имя того же объекта. Поэтому `{ } === { }` — всегда `false`.
</Remember>

<Remember>
**Язык и среда.** Сам язык — числа, строки, объекты, функции, `if`,
`for`; ввода и вывода у него нет. `console`, `document`,
`fetch`, `alert` даёт браузер, а в Node.js вместо них файлы и сеть.
</Remember>

## Первая программа

```js
const student = { name: "Аман", marks: [5, 4, 5, 3, 5] };

function average(numbers) {
  let sum = 0;
  for (const n of numbers) sum += n;
  return sum / numbers.length;
}

const score = average(student.marks);
const line = `${student.name}: средний балл ${score.toFixed(2)}`;
console.log(line);
document.getElementById("result").textContent = line;
```

Подключение к странице: `<script src="app.js" defer></script>` —
слово `defer` обязательно, иначе код выполнится раньше разметки.

## Чтение ошибки

```js
// Uncaught   TypeError   : Cannot set...    at app.js:27:47
//    |            |              |                  |
// не поймали   вид ошибки   что не так    файл:строка:столбец — кликается!
```

| Вид | Куда смотреть |
| --- | --- |
| `SyntaxError` | скобки и кавычки; ломает весь файл сразу |
| `ReferenceError` | опечатка в имени или переменная объявлена ниже |
| `TypeError` | там `null`/`undefined` или вызвали не функцию |
| `RangeError` | число вне пределов, бесконечная рекурсия |

<NoteBox>
**Частые ошибки.** Значение на строке после `return` — движок сам поставит
точку с запятой, и функция вернёт `undefined`. `if (x = 5)` присваивает,
а не сравнивает. `average` без скобок — это сама функция, а не её результат.
Регистр важен: `name` и `Name` — разные переменные.
</NoteBox>
