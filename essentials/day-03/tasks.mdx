# День 3. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-03` с файлами `index.html` и `app.js`.</Subtitle>

## Разминка

<Task title="1. Кто какого типа" level="easy" time="6">
<Goal>увидеть, что тип принадлежит значению.</Goal>

Откройте консоль и спросите `typeof` у каждого значения из списка. Результат запишите
в тетрадь в две колонки: значение и ответ.

```js
42        "Мары"        true        undefined        null
{ }       [1, 2]        console.log        10 / 0        "5" * 2
```

<Criteria>
- все десять ответов записаны;
- отмечены ответы, которые расходятся с ожиданием — их не меньше двух;
- для каждого такого ответа записано одно предложение: чего вы ждали и что получили.
</Criteria>
</Task>

<Task title="2. Шесть лжецов" level="easy" time="7">
<Goal>запомнить список ложных значений на практике, а не наизусть.</Goal>

Проверьте каждое значение через `Boolean(...)` и выпишите отдельно те, что дали
`false`.

```js
const values = [0, 1, -1, "", " ", "0", [], { }, null, undefined, NaN];
```

<Hint>
Ложных значений шесть, но в этом списке их меньше — часть ловушек истинны, хотя выглядят пустыми.
</Hint>

<Criteria>
- для каждого значения записан ответ;
- найдены все ложные из списка;
- объяснено, почему `"0"` и `[]` истинны.
</Criteria>
</Task>

<Task title="3. Сначала предскажи" level="easy" time="7">
<Goal>поймать себя на ловушках плюса и сравнения.</Goal>

Сначала напишите в тетради, что, по-вашему, выведет каждая строка. Только потом проверьте
в консоли и отметьте, где ошиблись.

```js
"3" + 4 + 5
3 + 4 + "5"
"10" - 5
123 == "123"
123 === "123"
0.1 + 0.2 === 0.3
```

<Criteria>
- предсказания записаны *до* проверки;
- рядом стоят настоящие ответы;
- для каждого расхождения записано одно предложение — почему так.
</Criteria>
</Task>

## Основные задания

<Task title="4. Табель: собрать программу" level="medium" time="15">
<Goal>запустить свою первую полноценную программу из двух файлов.</Goal>

Заведите папку `day-03`, создайте в ней `index.html` и `app.js`
и наберите программу «Табель» из раздела 12 лекции. **Наберите руками, не копируйте.**
Откройте страницу через Live Server.

<Criteria>
- на странице вместо «Считаем...» появилась строка с баллом;
- та же строка есть в консоли;
- консоль чистая — красных сообщений нет;
- в `<script>` стоит `defer`.
</Criteria>
</Task>

<Task title="5. Табель: свои данные и четвёртая ветка" level="medium" time="12">
<Goal>поменять работающую программу, не сломав её.</Goal>

Доработайте программу из задания 4:

- поставьте своё имя и свои оценки — не меньше шести;
- добавьте в вывод количество оценок: сколько всего;
- добавьте четвёртую ветку условия: если балл ровно 5 — «круглый отличник»;
- подберите оценки так, чтобы по очереди увидеть все четыре ветки.

<Hint>
Сколько оценок — это `student.marks.length`. Новую ветку ставьте
**первой**: условия проверяются по порядку, и `>= 4.5` сработает
раньше, чем «ровно 5».
</Hint>

<Criteria>
- в строке есть имя, балл, количество оценок и словесная оценка;
- все четыре ветки показаны и записаны в тетрадь с набором оценок для каждой;
- программа по-прежнему работает без ошибок.
</Criteria>
</Task>

<Task title="6. Три поломки" level="medium" time="12">
<Goal>научиться читать сообщение об ошибке на своём же коде.</Goal>

Ломайте программу по одному разу, каждый раз возвращая всё назад. Для каждой поломки запишите
в таблицу: вид ошибки, её текст, файл и строку.

1. уберите слово `defer` из `<script>`;
2. напишите имя функции с опечаткой: `avarage(student.marks)`;
3. сотрите закрывающую фигурную скобку у функции.

<WriteBox>
таблицу из трёх строк: что сломали → вид ошибки → строка из консоли.
</WriteBox>

<Hint>
Щёлкните по адресу вида `app.js:14:15` справа в консоли — браузер откроет файл на нужной
строке. Это самый быстрый способ найти место ошибки.
</Hint>

<Criteria>
- для каждой поломки назван вид ошибки;
- записано, на какую строку показал браузер;
- объяснено, почему третья поломка не даёт выполниться даже первой строке файла.
</Criteria>
</Task>

<Task title="7. Разобрать чужой код" level="medium" time="11">
<Goal>узнавать части языка в незнакомом коде — главный навык дня.</Goal>

Перепишите этот код в тетрадь и подпишите на нём восемь вещей: объект, массив, объявление функции,
параметр функции, переменную, которая меняется, цикл по значениям, условие, шаблонную строку.

```js
const shop = {
  name: "Bereket",
  prices: [12, 40, 7.5],
};

function total(list) {
  let sum = 0;
  for (const price of list) {
    sum += price;
  }
  return sum;
}

const bill = total(shop.prices);

if (bill > 50) {
  console.log(`${shop.name}: дорого, ${bill.toFixed(2)} манат`);
} else {
  console.log(`${shop.name}: нормально`);
}
```

<Criteria>
- все восемь подписей расставлены;
- без запуска записано, что выведет программа;
- ответ проверен запуском и совпал.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Охота на четыре ошибки" level="hard" time="10">
<Goal>пройти путь отладки целиком: от мёртвого файла до правильного числа.</Goal>

В этом коде четыре ошибки. Наберите его в новый файл, запустите и чините **по одной**,
каждый раз перезапуская страницу. Для каждой запишите вид ошибки и что вы сделали.

```js
const marks = [5, 4, 3, 5];

function average(numbers) {
  let sum = 0;
  for (const n of numbers) {
    sum += numbers;
  }
  return
    sum / numbers.length;
}

const score = Average(marks);
console.log("Средний балл: " + score.toFixed(2);
```

<Hint>
Ошибки вскрываются по очереди, и это не случайность: пока в файле есть
`SyntaxError`, не выполняется ни одна строка. Четвёртая ошибка сообщения не даёт
вообще — она выдаёт себя неправильным ответом.
</Hint>

<Criteria>
- найдены все четыре ошибки;
- для первых трёх назван вид ошибки, для четвёртой — почему браузер промолчал;
- исправленная программа выводит «Средний балл: 4.25»;
- записан порядок, в котором ошибки проявлялись.
</Criteria>
</Task>

<Task title="9. Своя программа по образцу" level="hard" time="10">
<Goal>собрать программу с нуля, а не по написанному.</Goal>

Напишите свою программу того же устройства, но про другое. На выбор: расходы за неделю,
температура по дням, время в дороге до школы, количество страниц, прочитанных за неделю.

В программе обязательно должны быть: объект с названием и массивом чисел, функция, которая
считает по массиву одно число, условие хотя бы с двумя ветками, шаблонная строка и вывод результата
и в консоль, и на страницу.

<Hint>
Не обязательно считать среднее. Можно сумму, можно количество дней выше нормы — считайте
циклом, как в «Табеле».
</Hint>

<Criteria>
- все пять обязательных частей на месте;
- программа работает без красных сообщений в консоли;
- результат на странице совпадает с результатом в консоли;
- имена переменных говорят, что внутри.
</Criteria>
</Task>
