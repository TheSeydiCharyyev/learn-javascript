# День 4. Переменные

<Subtitle>Выжимка лекции: три слова объявления, область видимости, мёртвая зона, шесть ошибок.</Subtitle>

## Главное

<Definition>
**Переменная** — имя, за которым закреплено значение. У неё три свойства:
**имя** (как зовут), **изменяемость** (можно ли положить другое значение)
и **срок жизни** (с какой строки и до какой она существует).
</Definition>

<KeyPoint>
Правило выбора на весь курс: пишем `const`; если значение надо заменить — меняем
на `let`. `var` не пишем никогда, но уметь читать обязаны.
</KeyPoint>

## Три слова

|  | `const` | `let` | `var` |
| --- | --- | --- | --- |
| заменить значение | нет | да | да |
| нужен инициализатор | да | нет | нет |
| видна только в блоке | да | да | нет |
| объявить повторно | нет | нет | да, молча |
| обращение до объявления | ошибка | ошибка | `undefined` |
| попадает в `globalThis` | нет | нет | да |

## Объявление

```js
let score = 42;   // let score — объявление, = 42 — инициализатор
let empty;        // undefined
// const total;   → SyntaxError: Missing initializer in const declaration

let first = 1, second = first + 1;   // список: second видит first, second = 2
let x = y = 5;          // ловушка: y стала случайной глобальной
```

## const держит имя, а не содержимое

```js
const city = "Мары";
// city = "Ашхабад";    → TypeError: Assignment to constant variable.

const basket = ["хлеб"];
basket.push("чай");     // работает — меняем содержимое, не имя
const user = { n: 1 };
user.n = 2;             // тоже работает
```

<Remember>
В переменной лежит не объект, а адрес объекта. `const` запрещает поменять адрес,
но не запрещает прийти по нему и переставить вещи внутри.
</Remember>

## Где переменная видна

```js
if (true) { let b = 1; var c = 2; }
// console.log(b);   → ReferenceError: b is not defined — let не вышла из блока
console.log(c);   // 2 — var не знает про блок

let s = 1;
{ let s = 2; }    // затенение: другая переменная
console.log(s);   // 1

for (const n of [1, 2, 3]) { }   // for...of — const
for (let i = 0; i < 3; i++) { }  // обычный for — let
```

<Remember>
Видимость идёт только вглубь: изнутри блока видно внешние переменные, снаружи внутренние — нет.
Нужно значение после блока — объявите его `let` **до** блока, внутри
только присваивайте.
</Remember>

## Обращение до объявления

```js
// в app.js:
console.log(m);  var m = 1;   // undefined — объявление поднято, значение нет
typeof nothingAtAll;          // "undefined" — имени нет вообще, и это не ошибка

// console.log(n);  let n = 1;   → ReferenceError: Cannot access 'n' before initialization
// { typeof i; let i = 10; }     → ReferenceError: Cannot access 'i' before initialization
```

Мёртвая зона длится от открывающей скобки блока до строки объявления.

## Шесть ошибок дня

| Код | Сообщение в Chrome |
| --- | --- |
| `const x = 1; x = 2;` | `TypeError: Assignment to constant variable.` |
| `const x;` | `SyntaxError: Missing initializer in const declaration` |
| `var = 5;` | `SyntaxError: Unexpected token '='` |
| `console.log(a); let a = 1;` | `ReferenceError: Cannot access 'a' before initialization` |
| `"use strict"; b = 5;` | `ReferenceError: b is not defined` |
| `const o = Object.freeze({ x: 1 }); o.x = 2;` | `TypeError: Cannot assign to read only property 'x' of object '#<Object>'` |

`SyntaxError` — не выполнилась ни одна строка, ищите скобку или кавычку.
`ReferenceError` и `TypeError` — на ходу, значит всё до них отработало.
Последние две строки таблицы срабатывают только в строгом режиме.

## Необъявленная переменная

```js
let total = 0;
totl = total + 5;     // опечатка: молча создалась глобальная
console.log(total);   // 0, а ждали 5 — и ни одного сообщения
```

<NoteBox>
**Имена.** Регистр важен: `userName` и `username` — разные
переменные. Пишем латиницей: обычные — `camelCase`, настройки — `MAX_SCORE`,
«да / нет» — `isReady`, списки — во множественном числе.
\
**Ловушки.** `if (true) let a = 1;` — SyntaxError, нужны скобки.
Лишняя `;` после `for (...)` закрывает цикл. Вложенные `/* */`
дают загадочное «Invalid regular expression».
</NoteBox>
