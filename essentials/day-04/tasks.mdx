# День 4. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–2 делаем в консоли, дальше — в папке `day-04`.</Subtitle>

## Разминка

<Task title="1. const или let" level="easy" time="6">
<Goal>научиться выбирать слово объявления по смыслу.</Goal>

Для каждой величины напишите строку объявления и выберите `const` или `let`.
Рядом одним словом — почему.

- название вашего города;
- счётчик правильных ответов в игре;
- число дней в неделе;
- текущая температура на улице;
- список предметов в расписании, куда потом добавят ещё один.

<Hint>
Последний пункт — ловушка. Спросите себя: меняется имя или содержимое?
</Hint>

<Criteria>
- пять строк объявлений написаны;
- для каждой указана причина выбора;
- список предметов объявлен через `const` — и объяснено, почему это не мешает
  добавлять предметы.
</Criteria>
</Task>

<Task title="2. Что запрещает const" level="easy" time="7">
<Goal>увидеть границу между именем и содержимым своими глазами.</Goal>

Выполните строки по очереди и запишите, что ответила консоль: значение или ошибку.

```js
const city = "Мары";
city = "Ашхабад";

const marks = [5, 4];
marks.push(3);
marks[0] = 2;
marks = [1];

const user = { name: "Аман" };
user.name = "Мерет";
user.age = 17;
user = { };
```

<Criteria>
- для каждой строки записан результат;
- найдены все три строки, которые дают ошибку;
- одним предложением сформулировано общее правило.
</Criteria>
</Task>

<Task title="3. Сначала предскажи: видна или нет" level="easy" time="7">
<Goal>поймать разницу между `let` и `var` до запуска.</Goal>

Сначала запишите в тетради, что выведет каждый `console.log`. Потом проверьте
в `app.js`, по одному фрагменту: ошибка останавливает файл, и следующие строки
не выполнятся.

```js
// 1
if (true) {
  let a = 1;
  var b = 2;
}
console.log(b);
console.log(a);

// 2
console.log(c);
var c = 3;

// 3
console.log(d);
let d = 4;
```

<Criteria>
- предсказания записаны *до* проверки;
- рядом настоящие ответы, расхождения отмечены;
- объяснено, почему две строки дали разные ошибки.
</Criteria>
</Task>

## Основные задания

<Task title="4. «Табель» на константах" level="medium" time="14">
<Goal>применить всё сегодняшнее к работающей программе.</Goal>

Скопируйте папку `day-03` в `day-04` и доработайте `app.js`:

- вынесите пороги `4.5` и `3.5` в константы `MIN_EXCELLENT`
  и `MIN_GOOD` наверх файла;
- добавьте в массив оценок ещё одну через `push`, не трогая объявление;
- проверьте, что `verdict` объявлен **до** `if`;
- пройдите по файлу и поменяйте на `const` всё, что не меняется.

<Criteria>
- в файле не осталось голых чисел в условиях;
- `let` остался только там, где значение правда меняется;
- программа работает, в консоли чисто;
- записано, сколько `let` осталось и почему каждое.
</Criteria>
</Task>

<Task title="5. Один порог — весь вывод" level="medium" time="10">
<Goal>понять, зачем настройки выносят в константы.</Goal>

На программе из задания 4 подберите значения `MIN_GOOD` так, чтобы при одних
и тех же оценках получить по очереди все три вердикта. Меняйте **только одну строку** —
объявление константы.

<WriteBox>
таблицу: значение `MIN_GOOD` → какой вердикт вышел.
</WriteBox>

<Hint>
Если пришлось править больше одной строки — значит, где-то в коде осталось голое число.
Найдите его.
</Hint>

<Criteria>
- таблица из трёх строк заполнена;
- каждый раз менялась ровно одна строка файла;
- записан вывод: чем это удобнее, чем числа прямо в условии.
</Criteria>
</Task>

<Task title="6. Переменная сбежала из блока" level="medium" time="13">
<Goal>научиться чинить самую частую ошибку с областью видимости.</Goal>

Этот код не работает. Найдите причину, почините двумя разными способами и решите, какой лучше.

```js
const temperature = 31;

if (temperature > 30) {
  const advice = "сидите дома";
} else {
  const advice = "можно гулять";
}

console.log(`Сегодня ${temperature} градусов: ${advice}`);
```

<Hint>
Способа ровно два, и они противоположные: либо **поднять объявление** выше блока,
либо **опустить использование** внутрь блока. Во втором случае строку вывода
придётся написать дважды.
</Hint>

<Criteria>
- назван вид ошибки и её причина;
- работают оба варианта починки;
- в первом варианте пришлось взять `let` — объяснено, почему
  `const` здесь не подойдёт;
- во втором варианте `const` остался — объяснено, почему теперь можно;
- записано, какой вариант вы бы оставили и почему.
</Criteria>
</Task>

<Task title="7. Переписать старый код" level="medium" time="13">
<Goal>уметь читать `var` и приводить код к сегодняшним правилам.</Goal>

Перепишите на `const` и `let` по алгоритму из раздела 8 лекции.
Программа должна выводить то же самое.

```js
var prices = [12, 40, 7.5];
var total = 0;

for (var i = 0; i < prices.length; i++) {
  var price = prices[i];
  total = total + price;
}

var message = "Итого: " + total + " манат";
console.log(message);
console.log(i);
```

<Criteria>
- в коде не осталось `var`;
- для каждой переменной объяснено, почему `const` или `let`;
- найдена строка, которая после переписывания перестаёт работать;
- записано, почему она работала раньше и что это говорит о `var`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Тихая опечатка" level="hard" time="10">
<Goal>увидеть, чем опасна необъявленная переменная, и научиться её ловить.</Goal>

Этот код не выдаёт ошибок, но считает неправильно. Запустите, найдите причину, почините.

```js
let summa = 0;
const prices = [10, 20, 30];

for (const price of prices) {
  sumaa = summa + price;
}

console.log("Итого:", summa);
```

Затем проделайте два опыта: наберите в консоли `globalThis.sumaa`, а потом поставьте
первой строкой файла `"use strict";` и перезапустите.

<Criteria>
- названо, что именно выводит программа и что должна;
- записано, что ответил `globalThis.sumaa` и откуда эта переменная взялась;
- записано, что изменилось после `"use strict";` — с точным текстом ошибки;
- сделан вывод: почему опечатку в имени труднее найти, чем синтаксическую ошибку.
</Criteria>
</Task>

<Task title="9. Четыре ловушки" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя неожиданно.</Goal>

Для каждого фрагмента **сначала** запишите предсказание, потом проверьте
и объясните расхождение одним предложением.

```js
// 1
let n = 0;
for (let i = 0; i < 3; i++);
  n++;
console.log(n);

// 2
let x = y = 5;
console.log(globalThis.y);

// 3
for (var a of [1, 2, 3]);
console.log(a);

// 4
const frozen = Object.freeze({ value: 1 });
frozen.value = 99;
console.log(frozen.value);
```

<Hint>
Все четыре не выдают ошибок в обычном режиме. Именно поэтому они и опасны: программа
«работает», а результат не тот.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- для каждого фрагмента названа причина: пустая инструкция, необъявленная переменная,
  область видимости `var`, заморозка объекта;
- четвёртый фрагмент проверен ещё раз с `"use strict";`, разница записана;
- первый фрагмент переписан так, чтобы выводил 3.
</Criteria>
</Task>
