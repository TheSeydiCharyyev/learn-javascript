День 5. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-05.

Разминка

1. Таблица typeof
Легко6 мин

увидеть все ответы typeof своими глазами.

Спросите typeof у каждого значения и запишите ответ. Затем отметьте два места, где ответ не совпадает с настоящим типом значения.

const values = [42, 9007199254740993n, "Мары", true, Symbol("id"),
  undefined, null, { }, [1, 2], function () { }, new Date()];
  • все одиннадцать ответов записаны;
  • отмечены null и массив с объяснением, чем ответ неверен;
  • записано, сколько всего разных ответов получилось.
2. Три превращения
Легко7 мин

запомнить, что даёт каждая функция превращения.

Заполните таблицу: для каждого значения примените Number(), String() и Boolean().

const values = ["42", "12px", "", "0", null, undefined, [], [5], { }];
Два ответа в колонке Number() — это ноль там, где ожидается NaN. Найдите их.
  • таблица 9 × 3 заполнена;
  • найдены оба случая, где Number() даёт 0;
  • объяснено, почему Boolean([]) — это true.
3. Сначала предскажи: истина или ложь
Легко7 мин

выучить шесть ложных значений на практике.

Сначала запишите в тетради предсказание для каждой строки, потом проверьте.

Boolean(0)
Boolean("0")
Boolean("")
Boolean(" ")
Boolean([])
Boolean({ })
Boolean(NaN)
Boolean(-1)
Boolean(null)
!!"false"
  • предсказания записаны до проверки;
  • рядом настоящие ответы, расхождения отмечены;
  • выписаны все ложные значения из списка — их должно быть четыре;
  • объяснено, что делает !!.

Основные задания

4. Охота на NaN
Средне12 мин

научиться ловить NaN правильной проверкой.

Выполните каждое выражение и запишите, получился ли NaN. Затем проверьте каждый результат тремя способами: === NaN, isNaN() и Number.isNaN().

Number("салам")
Math.sqrt(-1)
0 * Infinity
Infinity - Infinity
7 * "blabla"
"5" * 2
new Date("blabla").getTime()
таблицу: выражение → результат → три ответа проверок.

Затем второй опыт. Примените обе функции не к результату, а к самим значениям:

isNaN("салам");          Number.isNaN("салам");
isNaN(undefined);        Number.isNaN(undefined);
isNaN("42");             Number.isNaN("42");
  • найдено выражение, которое не даёт NaN;
  • показано, что === NaN не работает никогда;
  • отмечено, что на результатах первой таблицы isNaN() и Number.isNaN() совпали всюду;
  • во втором опыте найдены все случаи, где они разошлись, и объяснено, почему: одна функция сначала превращает значение в число, другая — нет;
  • сделан вывод, какую проверку писать в коде.
5. Функция определения типа
Средне14 мин

собрать все сегодняшние проверки в одну работающую функцию.

Напишите функцию describe(value), которая возвращает строку с настоящим типом значения. Она должна правильно различать: число, NaN, строку, логическое значение, null, undefined, массив, объект, функцию.

describe(42);        // "число"
describe(NaN);       // "не число (NaN)"
describe(null);      // "null"
describe([1, 2]);    // "массив"
describe({ });       // "объект"
Порядок проверок важен. null проверяйте до typeof === "object", а NaN — внутри ветки числа.
  • все девять случаев различаются правильно;
  • describe(null) не возвращает «объект»;
  • describe(NaN) не возвращает «число»;
  • функция проверена на всех девяти значениях, результаты записаны.
6. Проверка ввода в «Табеле»
Средне13 мин

применить проверку типов к настоящей программе.

Скопируйте папку day-04 в day-05 и добавьте функцию parseMark(input): она принимает строку, возвращает число от 2 до 5 или null, если ввод негодный.

Проверьте её на списке и запишите, что вернулось для каждого:

const inputs = ["5", "пять", "", "  4  ", "10", "3.5", null];
Одно из этих значений превращается в число, хотя выглядит пустым, а другое даёт число вне диапазона оценок. Обе ситуации функция должна отсечь.
  • для всех семи значений записан ответ;
  • "" не проходит как оценка — объяснено, почему это неочевидно;
  • "10" не проходит;
  • негодный ввод даёт именно null, а не undefined — объяснено, зачем эта разница.
7. Идти влево от точки
Средне11 мин

научиться читать TypeError и находить настоящую строку ошибки.

Запустите и почините. Для каждой ошибки запишите: текст сообщения, какое свойство в скобках и на какой строке настоящая причина.

const group = {
  name: "ИТ-1",
  students: [
    { name: "Аман", marks: [5, 4] },
  ],
};

console.log(group.students[0].marks.length);
console.log(group.students[1].marks.length);
console.log(group.teacher.name);
console.log(group.name.lenght);
Четвёртая строка — особый случай: она не падает. Подумайте, почему, и что это говорит об опечатках в именах свойств.
  • для двух падающих строк записан точный текст ошибки;
  • для каждой названо, что именно оказалось пустым слева от точки;
  • объяснено, почему последняя строка не падает и что выводит;
  • код починен так, чтобы ни одна строка не падала.

Со звёздочкой

8. Ноль, пустота и ничего
Сложно10 мин

увидеть, почему короткая проверка !x бывает ошибкой.

Функция должна сообщать «укажите возраст», только если возраст не передали. Она работает неправильно. Найдите, на каком значении, и почините.

function checkAge(age) {
  if (!age) {
    return "укажите возраст";
  }
  return `возраст: ${age}`;
}

console.log(checkAge(17));
console.log(checkAge(0));
console.log(checkAge(null));
console.log(checkAge(undefined));
console.log(checkAge(""));
  • названо значение, на котором функция врёт;
  • объяснено, при чём тут список из шести ложных значений;
  • функция починена, и checkAge(0) даёт «возраст: 0»;
  • записано, что теперь вернёт checkAge("") и правильно ли это.
9. Пять ловушек типов
Сложно10 мин

собрать вместе всё, что сегодня ведёт себя не так, как кажется.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением.

// 1
console.log(typeof null === "object" && null.length);

// 2
const flag = new Boolean(false);
if (flag) {
  console.log("да");
} else {
  console.log("нет");
}

// 3
console.log(null + 1, undefined + 1);

// 4
console.log(isNaN("салам"), Number.isNaN("салам"));

// 5
let word = "Мары";
word[0] = "К";
console.log(word);
Один из пяти фрагментов бросает ошибку, остальные четыре тихо выдают неожиданный результат. Найдите, какой именно, и почему.
  • предсказания записаны до запуска;
  • найден единственный фрагмент с ошибкой, назван её вид;
  • для остальных четырёх названа причина: обёртка, превращение null, разница проверок NaN, неизменяемость строк;
  • фрагмент 5 переписан так, чтобы получилось «Кары».
