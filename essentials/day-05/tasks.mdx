# День 5. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-05`.</Subtitle>

## Разминка

<Task title="1. Таблица typeof" level="easy" time="6">
<Goal>увидеть все ответы `typeof` своими глазами.</Goal>

Спросите `typeof` у каждого значения и запишите ответ. Затем отметьте два места,
где ответ не совпадает с настоящим типом значения.

{/* ahead-ok: день 17, курс 2 */}

```js
const values = [42, 9007199254740993n, "Мары", true, Symbol("id"),
  undefined, null, { }, [1, 2], function () { }, new Date()];
```

<Criteria>
- все одиннадцать ответов записаны;
- отмечены `null` и массив с объяснением, чем ответ неверен;
- записано, сколько всего разных ответов получилось.
</Criteria>
</Task>

<Task title="2. Три превращения" level="easy" time="7">
<Goal>запомнить, что даёт каждая функция превращения.</Goal>

Заполните таблицу: для каждого значения примените `Number()`, `String()`
и `Boolean()`.

```js
const values = ["42", "12px", "", "0", null, undefined, [], [5], { }];
```

<Hint>
Два ответа в колонке `Number()` — это ноль там, где ожидается `NaN`.
Найдите их.
</Hint>

<Criteria>
- таблица 9 × 3 заполнена;
- найдены оба случая, где `Number()` даёт 0;
- объяснено, почему `Boolean([])` — это `true`.
</Criteria>
</Task>

<Task title="3. Сначала предскажи: истина или ложь" level="easy" time="7">
<Goal>выучить шесть ложных значений на практике.</Goal>

Сначала запишите в тетради предсказание для каждой строки, потом проверьте.

```js
Boolean(0)
Boolean("0")
Boolean("")
Boolean(" ")
Boolean([])
Boolean({ })
Boolean(NaN)
Boolean(-1)
Boolean(null)
!!"false"
```

<Criteria>
- предсказания записаны *до* проверки;
- рядом настоящие ответы, расхождения отмечены;
- выписаны все ложные значения из списка — их должно быть четыре;
- объяснено, что делает `!!`.
</Criteria>
</Task>

## Основные задания

<Task title="4. Охота на NaN" level="medium" time="12">
<Goal>научиться ловить `NaN` правильной проверкой.</Goal>

Выполните каждое выражение и запишите, получился ли `NaN`. Затем проверьте каждый
результат тремя способами: `=== NaN`, `isNaN()` и `Number.isNaN()`.

{/* ahead-ok: день 17 */}

```js
Number("салам")
Math.sqrt(-1)
0 * Infinity
Infinity - Infinity
7 * "blabla"
"5" * 2
new Date("blabla").getTime()
```

<WriteBox>
таблицу: выражение → результат → три ответа проверок.
</WriteBox>

Затем второй опыт. Примените обе функции не к результату, а к самим значениям:

```js
isNaN("салам");          Number.isNaN("салам");
isNaN(undefined);        Number.isNaN(undefined);
isNaN("42");             Number.isNaN("42");
```

<Criteria>
- найдено выражение, которое **не** даёт `NaN`;
- показано, что `=== NaN` не работает никогда;
- отмечено, что на результатах первой таблицы `isNaN()`
  и `Number.isNaN()` совпали всюду;
- во втором опыте найдены все случаи, где они разошлись, и объяснено, почему:
  одна функция сначала превращает значение в число, другая — нет;
- сделан вывод, какую проверку писать в коде.
</Criteria>
</Task>

<Task title="5. Функция определения типа" level="medium" time="14">
<Goal>собрать все сегодняшние проверки в одну работающую функцию.</Goal>

Напишите функцию `describe(value)`, которая возвращает строку с настоящим типом
значения. Она должна правильно различать: число, `NaN`, строку, логическое значение,
`null`, `undefined`, массив, объект, функцию.

<Example>
```js
describe(42);        // "число"
describe(NaN);       // "не число (NaN)"
describe(null);      // "null"
describe([1, 2]);    // "массив"
describe({ });       // "объект"
```
</Example>

<Hint>
Порядок проверок важен. `null` проверяйте **до**
`typeof === "object"`, а `NaN` — внутри ветки числа.
</Hint>

<Criteria>
- все девять случаев различаются правильно;
- `describe(null)` не возвращает «объект»;
- `describe(NaN)` не возвращает «число»;
- функция проверена на всех девяти значениях, результаты записаны.
</Criteria>
</Task>

<Task title="6. Проверка ввода в «Табеле»" level="medium" time="13">
<Goal>применить проверку типов к настоящей программе.</Goal>

Скопируйте папку `day-04` в `day-05` и добавьте функцию
`parseMark(input)`: она принимает строку, возвращает число от 2 до 5 или
`null`, если ввод негодный.

Проверьте её на списке и запишите, что вернулось для каждого:

```js
const inputs = ["5", "пять", "", "  4  ", "10", "3.5", null];
```

<Hint>
Одно из этих значений превращается в число, хотя выглядит пустым, а другое даёт число
вне диапазона оценок. Обе ситуации функция должна отсечь.
</Hint>

<Criteria>
- для всех семи значений записан ответ;
- `""` не проходит как оценка — объяснено, почему это неочевидно;
- `"10"` не проходит;
- негодный ввод даёт именно `null`, а не `undefined` —
  объяснено, зачем эта разница.
</Criteria>
</Task>

<Task title="7. Идти влево от точки" level="medium" time="11">
<Goal>научиться читать `TypeError` и находить настоящую строку ошибки.</Goal>

Запустите и почините. Для каждой ошибки запишите: текст сообщения, какое свойство
в скобках и на какой строке **настоящая** причина.

```js
const group = {
  name: "ИТ-1",
  students: [
    { name: "Аман", marks: [5, 4] },
  ],
};

console.log(group.students[0].marks.length);
console.log(group.students[1].marks.length);
console.log(group.teacher.name);
console.log(group.name.lenght);
```

<Hint>
Четвёртая строка — особый случай: она не падает. Подумайте, почему, и что это говорит
об опечатках в именах свойств.
</Hint>

<Criteria>
- для двух падающих строк записан точный текст ошибки;
- для каждой названо, что именно оказалось пустым слева от точки;
- объяснено, почему последняя строка не падает и что выводит;
- код починен так, чтобы ни одна строка не падала.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Ноль, пустота и ничего" level="hard" time="10">
<Goal>увидеть, почему короткая проверка `!x` бывает ошибкой.</Goal>

Функция должна сообщать «укажите возраст», только если возраст не передали. Она работает
неправильно. Найдите, на каком значении, и почините.

```js
function checkAge(age) {
  if (!age) {
    return "укажите возраст";
  }
  return `возраст: ${age}`;
}

console.log(checkAge(17));
console.log(checkAge(0));
console.log(checkAge(null));
console.log(checkAge(undefined));
console.log(checkAge(""));
```

<Criteria>
- названо значение, на котором функция врёт;
- объяснено, при чём тут список из шести ложных значений;
- функция починена, и `checkAge(0)` даёт «возраст: 0»;
- записано, что теперь вернёт `checkAge("")` и правильно ли это.
</Criteria>
</Task>

<Task title="9. Пять ловушек типов" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя не так, как кажется.</Goal>

Для каждого фрагмента **сначала** запишите предсказание, потом проверьте
и объясните расхождение одним предложением.

{/* ahead-ok: день 7 */}

```js
// 1
console.log(typeof null === "object" && null.length);

// 2
const flag = new Boolean(false);
if (flag) {
  console.log("да");
} else {
  console.log("нет");
}

// 3
console.log(null + 1, undefined + 1);

// 4
console.log(isNaN("салам"), Number.isNaN("салам"));

// 5
let word = "Мары";
word[0] = "К";
console.log(word);
```

<Hint>
Один из пяти фрагментов бросает ошибку, остальные четыре тихо выдают неожиданный результат.
Найдите, какой именно, и почему.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- найден единственный фрагмент с ошибкой, назван её вид;
- для остальных четырёх названа причина: обёртка, превращение `null`,
  разница проверок `NaN`, неизменяемость строк;
- фрагмент 5 переписан так, чтобы получилось «Кары».
</Criteria>
</Task>
