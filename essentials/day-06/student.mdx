# День 6. Арифметика и присваивание

<Subtitle>Выжимка лекции: пять операторов, остаток, присваивание, инкремент, точность.</Subtitle>

## Главное

<Definition>
**Оператор** — знак, который что-то делает со значениями (операндами).
Бинарный берёт два значения (`2 + 3`), унарный одно (`-5`,
`i++`), тернарный три (день 7).
</Definition>

<KeyPoint>
`+` — единственный арифметический оператор с двойным поведением: если хоть один
операнд строка, он **склеивает**. Все остальные всегда считают числами.
</KeyPoint>

## Пять операторов

```js
2 + 3;        // 5        сложение
"2" + 3;      // "23"     склейка!
"10" - 5;     // 5        минус всегда число
"10" * 2;     // 20
10 / 3;       // 3.3333333333333335
10 / 0;       // Infinity — не ошибка
10 % 3;       // 1        остаток, НЕ проценты
2 ** 10;      // 1024     степень
```

<Remember>
Порядок склейки важен: `1 + 2 + "3"` даёт `"33"`,
а `"1" + 2 + 3` даёт `"123"`. Считается слева направо.
</Remember>

## Остаток %: четыре приёма

```js
const n = 7;
const days = ["пн", "вт", "ср"];
let i = 0;
n % 2 === 0;                     // false — чётность
1234 % 10;                       // 4 — последняя цифра
((i - 1) % days.length + days.length) % days.length;   // 2 — назад, без минуса
i = (i + 1) % days.length;       // 1 — круговой счётчик вперёд

// время из секунд
const total = 3725;
Math.floor(total / 3600);        // 1 — часы
Math.floor(total / 60) % 60;     // 2 — минуты
total % 60;                      // 5 — секунды
```

<Remember>
**Знак остатка берётся от делимого:** `-10 % 3` это `-1`,
а не 2. Деление отвечает «сколько целых», остаток — «сколько осталось».
</Remember>

## Особые значения

| x | `x + 2` | `x * 2` |
| --- | --- | --- |
| `null`, `""` | `2` | `0` |
| `undefined`, `NaN` | `NaN` | `NaN` |
| `true` | `3` | `2` |
| `"5"` | `"52"` | `10` |

`null` тихо считается нулём и даёт неверное число без сообщения —
это опаснее, чем `NaN`.

## Степень и унарные

```js
2 ** 3 ** 2;   // 512 — справа налево, это 2 ** 9
// -2 ** 2;    → SyntaxError — нужны скобки
(-2) ** 2;     // 4
-(2 ** 2);     // -4

+"42";         // 42  — унарный плюс = Number()
+"";           // 0
+"abc";        // NaN
const a = "5", b = "3";
+a + +b;       // 8 — два унарных плюса, потом сложение
```

## Присваивание

```js
let x;
console.log(x = 5);   // 5 — присваивание это выражение
let p, q, r;
p = q = r = 7;        // цепочка, справа налево
if (x = 0) { }        // ЛОВУШКА: присвоили, а не сравнили; x теперь 0

x += 5;               // 5 — так же -=, *=, /=, %=, **=

let x2 = 10;
x2 += "5";            // "105" (string!) — += наследует склейку

const user = {};
user.name = "Аман";   // присваивать можно свойству
const marks = [5, 4];
marks[0]++;           // и элементу массива: теперь [6, 4]
```

## Инкремент

```js
let i = 5;
const a = i++;   // a = 5, i = 6   постфикс: отдал старое, потом увеличил
let j = 5;
const b = ++j;   // b = 6, j = 6   префикс: увеличил, потом отдал
```

<Remember>
Если результат никуда не идёт — разницы нет. В `for (let i = 0; i < 5; i++)`
можно писать любую форму. `++` не работает с `const` и превращает
значение в число.
</Remember>

## Порядок и точность

```js
2 + 3 * 4;          // 14 — умножение раньше
const m1 = 5, m2 = 4, m3 = 3;
m1 + m2 + m3 / 3;   // 10 — неверное среднее!
(m1 + m2 + m3) / 3; // 4 — верное

0.1 + 0.2;                                      // 0.30000000000000004
(0.1 + 0.2).toFixed(2);                         // "0.30"  — для показа
Math.abs((0.1+0.2) - 0.3) < Number.EPSILON;     // true    — для сравнения
// для денег: хранить в тенге целыми, делить только при выводе
```

<NoteBox>
**Частые ошибки.** `"10" + 5` даёт `"105"` — значение
из поля ввода всегда строка. `%` — это не проценты. `(i - 1) % n`
для хода назад даёт минус. `if (x = 5)` присваивает.
`[object Object]` в выводе значит, что вывели объект вместо текста.
</NoteBox>
