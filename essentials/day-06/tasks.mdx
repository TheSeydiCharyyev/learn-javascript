# День 6. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-06`.</Subtitle>

## Разминка

<Task title="1. Плюс или склейка" level="easy" time="6">
<Goal>поймать разницу между сложением и склейкой.</Goal>

Сначала предскажите результат каждой строки в тетради, потом проверьте.

```js
2 + 3
"2" + 3
2 + "3"
1 + 2 + "3"
"1" + 2 + 3
"10" - 5
"10" * 2
true + true
```

<Criteria>
- предсказания записаны *до* проверки;
- рядом настоящие ответы, расхождения отмечены;
- объяснено, почему две строки с одинаковыми числами дали разное.
</Criteria>
</Task>

<Task title="2. Остаток на практике" level="easy" time="7">
<Goal>освоить `%` на простых задачах.</Goal>

Посчитайте в консоли и запишите ответы:

- чётное ли число 2026;
- последняя цифра числа 2026;
- две последние цифры числа 2026;
- сколько полных недель в 100 днях и сколько дней останется;
- `10 % 0` — что получится.

<Hint>
Полные недели — это деление с отбрасыванием дробной части: `Math.floor(100 / 7)`.
</Hint>

<Criteria>
- все пять ответов записаны;
- для недель показаны оба числа — целые и остаток;
- объяснено, почему `10 % 0` даёт именно такой результат.
</Criteria>
</Task>

<Task title="3. Постфикс против префикса" level="easy" time="7">
<Goal>увидеть, что возвращает каждая форма.</Goal>

Выполните каждый фрагмент на свежих переменных и запишите оба значения.

```js
let i = 5;
const a = i++;
console.log(a, i);

let j = 5;
const b = ++j;
console.log(b, j);

let k = 5;
k++;
console.log(k);
```

<Criteria>
- для всех трёх фрагментов записаны значения;
- объяснено, почему в третьем фрагменте форма не важна;
- записано, что вернёт `const c = 1; c++;` и почему.
</Criteria>
</Task>

## Основные задания

<Task title="4. Время из секунд" level="medium" time="13">
<Goal>применить деление и остаток вместе.</Goal>

Напишите функцию `formatTime(sec)`, которая из числа секунд делает строку
вида «ч:мм:сс». Проверьте на значениях 65, 600, 3725 и 0.

<Example>
```js
formatTime(3725);   // "1:02:05"
formatTime(65);     // "0:01:05"
```
</Example>

<Hint>
Часы — `Math.floor(sec / 3600)`. Минуты — `Math.floor(sec / 60) % 60`.
Секунды — `sec % 60`. Ведущий ноль можно добавить условием или строкой
`String(m).padStart(2, "0")`.
</Hint>

<Criteria>
- все четыре значения дают правильный ответ;
- минуты и секунды выводятся с ведущим нулём;
- записано, за что отвечает деление, а за что остаток;
- проверено, что `formatTime(0)` не ломается.
</Criteria>
</Task>

<Task title="5. Счёт за заказ" level="medium" time="13">
<Goal>собрать формулу из нескольких шагов, не перепутав порядок.</Goal>

Товар стоит 1200, берут 3 штуки, скидка 10%, затем на получившуюся сумму налог 5%.
Посчитайте итог, разбив расчёт на именованные шаги и выведя каждый.

Затем ответьте на два вопроса, поменяв код:

- сколько выйдет, если налог считать **до** скидки, а не после;
- сколько выйдет без скидки вообще.

<WriteBox>
три суммы и вывод: влияет ли порядок «скидка — налог» на итог.
</WriteBox>

<Criteria>
- расчёт разбит минимум на три шага с понятными именами;
- каждый шаг выведен в консоль;
- все три суммы посчитаны;
- сделан вывод о порядке, подтверждённый числами.
</Criteria>
</Task>

<Task title="6. Карусель в обе стороны" level="medium" time="12">
<Goal>применить остаток для кругового счётчика и починить ход назад.</Goal>

Есть массив `["пн", "вт", "ср", "чт", "пт"]` и переменная `i = 0`.
Напишите две строки: одна двигает `i` вперёд по кругу, другая назад.
Проверьте, что от `i = 0` шаг назад даёт последний день, а не ошибку.

<Hint>
Вперёд просто. Назад `(i - 1) % n` не годится — проверьте, что он вернёт,
и вспомните формулу из раздела 6 лекции.
</Hint>

<Criteria>
- шаг вперёд от «пт» даёт «пн»;
- шаг назад от «пн» даёт «пт»;
- записано, что возвращает наивный вариант `(i - 1) % 5` при i = 0;
- объяснено, почему `arr[-1]` не ошибка, а `undefined`.
</Criteria>
</Task>

<Task title="7. «Табель» со статистикой" level="medium" time="12">
<Goal>довести программу курса до настоящего расчёта.</Goal>

Скопируйте папку `day-05` в `day-06` и добавьте в «Табель»:

- сумму всех оценок через `+=`;
- средний балл с двумя знаками после запятой;
- процент от максимума (максимум — 5), целым числом;
- вывод списка с нумерацией с единицы, где каждая вторая строка помечена;
- сколько оценок чётных и сколько нечётных.

<Criteria>
- все пять пунктов работают;
- средний балл не выводится как 4.333333333333333;
- нумерация начинается с 1, а не с 0;
- чётные и нечётные посчитаны через `%`, а не перечислением.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Копейка рубль бережёт" level="hard" time="10">
<Goal>увидеть проблему дробной точности и обойти её.</Goal>

Выполните и запишите результаты:

```js
0.1 + 0.2
0.1 + 0.2 === 0.3
(0.1 + 0.2).toFixed(2)
Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON
Math.round(1.005 * 100) / 100
0.1 * 3
```

Затем посчитайте стоимость трёх товаров двумя способами — дробными числами и целыми
(в тенге, деление только при выводе) — для двух цен: **12 манат 50 тенге**
и **1 манат 10 тенге**. Сравните результаты в обоих случаях.

<Hint>
Для одной из двух цен оба способа дадут одно и то же, для другой — нет. Это и есть
самое интересное: погрешность появляется не всегда, а значит, поймать её тестами трудно.
</Hint>

<Criteria>
- все шесть результатов записаны;
- объяснено, почему `Math.round(1.005 * 100)` даёт не то, что ожидается;
- обе версии расчёта написаны для обеих цен — четыре числа;
- названа цена, на которой способы разошлись;
- сделан вывод, в каком виде хранить деньги и почему «у меня и так работает»
  — плохой довод.
</Criteria>
</Task>

<Task title="9. Шесть ловушек" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя неожиданно.</Goal>

Для каждого фрагмента **сначала** запишите предсказание, потом проверьте —
каждый фрагмент отдельно — и объясните расхождение одним предложением.

```js
// 1
let x = 10;
x += "5";
console.log(x, typeof x);

// 2
console.log(-10 % 3);

// 3
console.log(2 ** 3 ** 2);

// 4
console.log(-2 ** 2);

// 5
let y = 5;
if (y = 0) { console.log("вошли"); }
console.log(y);

// 6
console.log([] + [], [] + { });
```

<Hint>
Один фрагмент вообще не запустится. Остальные пять тихо дадут неожиданный результат —
это опаснее.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- найден единственный фрагмент с ошибкой, записан её вид и текст;
- для остальных пяти названа причина: склейка в `+=`, знак остатка,
  правая ассоциативность степени, присваивание в условии, превращение объектов;
- фрагменты 3, 4 и 5 переписаны так, чтобы делали то, что от них ожидают.
</Criteria>
</Task>
