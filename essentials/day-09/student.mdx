# День 9. Условия

<Subtitle>Выжимка лекции: `if`, лестница `else if`, `switch`, `break` и провал.</Subtitle>

## Главное

<Definition>
**Ветвление** — развилка: программа смотрит на условие и выбирает дорогу.
Выполнится **ровно одна** ветка, после чего программа пойдёт дальше как
обычно.
</Definition>

<KeyPoint>
Фигурные скобки ставим **всегда**, даже для одной строки. Без них
`if` забирает ровно одну инструкцию, а всё остальное выполняется всегда —
и отступ это прячет.
</KeyPoint>

## if и лестница

```js
const mark = 4;

if (mark === 5) {
  console.log("отлично");
} else if (mark === 4) {
  console.log("хорошо");
} else {
  console.log("остальное");
}
```

Лестница проверяется **сверху вниз** и останавливается на первой подошедшей
ветке. Поэтому сверху ставят **самое строгое** условие.

<Remember>
`if (score >= 50) ... else if (score >= 90)` — при 95 сработает первая ветка,
и отличник получит тройку. Нижние не сработают никогда.
</Remember>

## Проверка на границах

```js
// для порога 90 проверяем три значения
function isFive(score) {
  return score >= 90;
}
isFive(89);   // false
isFive(90);   // true — ровно на границе
isFive(91);   // true

// дырка между ветками
const score = 90;
let g;
if (score > 90) { g = "5"; } else if (score < 90) { g = "4"; }
g;            // undefined — 90 не попало никуда
```

Ошибки живут **на краях** диапазонов, в середине всё обычно работает.
У строк край — `""` и `"   "`, у массивов — пустой, у ввода —
`null` и `undefined`.

## Что считается условием

```js
const name = "Аман";
const marks = [];

if (name) { console.log("имя есть"); }      // непустая строка — истина
if (marks.length) { console.log("есть"); }  // 0 — ложь, не выведется

// ложны только: false 0 "" NaN null undefined
```

<Remember>
`if (count)` и `if (count !== undefined)` расходятся на нуле
и пустой строке. Если ноль — законные данные (счётчик, температура), пишите точную
проверку.
</Remember>

## Распутать вложенность

```js
const isLoggedIn = true;
const hasTicket = true;
const user = { age: 20 };

// 1. объединить через &&
if (isLoggedIn && hasTicket) { console.log("проходите"); }

// 2. ранний выход — сначала отказы (в одну строку можно без скобок)
function check(mark) {
  if (mark === undefined) return "негодная";
  if (mark < 2 || mark > 5) return "негодная";
  return "годится";
}
check(7);     // "негодная"

// 3. дать условию имя
const isAdult = user !== null && user.age >= 18;
if (isAdult) { console.log("взрослый"); }
```

## switch

```js
const mark = 4;
let word;

switch (mark) {
  case 5:
    word = "отлично";
    break;          // забыли — провалится в следующую ветку!
  case 4:
    word = "хорошо";
    break;
  default:
    word = "неизвестно";
}
word;               // "хорошо"

const day = "вс";
switch (day) {
  case "сб":
  case "вс":        // группировка: общий код на два значения
    word = "выходной";
    break;
  default:
    word = "рабочий";
}
word;               // "выходной"
```

<Remember>
`case` — это **метка входа**, а не отдельная ветка. Совпадение
говорит, откуда начать; останавливает только `break`. Сравнение —
через `===`, без приведения типов.
</Remember>

## Три ловушки switch

```js
// 1. весь switch — ОДИН блок:
// case 1: let a = 1; break; case 2: let a = 2;
//   → SyntaxError: Identifier 'a' has already been declared
// лечится своими { } у ветки:
const x = 2;
switch (x) {
  case 1: { let a = 1; break; }
  case 2: { let a = 2; break; }
}

// 2. default не обязан быть последним — но ставьте последним
// 3. диапазоны через switch не проверить — нужна лестница else if
```

## Что выбрать

| Задача | Чем |
| --- | --- |
| две ветки, одна проверка | `if...else` |
| диапазоны, сложные условия | лестница `else if` |
| одно значение, перечислимые варианты | `switch` |
| выбрать значение, а не выполнить действия | `? :` (день 7) |

<NoteBox>
**Частые ошибки.** `if (x = 5)` присваивает. Широкое условие выше
узкого — нижние ветки мертвы. Забытый `break` проваливает выполнение дальше.
Лестница без последней ветки молча возвращает `undefined`.
\
**`try...catch`** (день 11) — не замена проверкам. Что можно
проверить условием — проверяйте условием.
</NoteBox>
