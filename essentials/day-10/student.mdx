# День 10. Циклы

<Subtitle>Выжимка лекции: `for`, `while`, `do...while`, `break`, `continue`, метки.</Subtitle>

## Главное

<Definition>
**Цикл** — способ написать действие один раз, а выполнить много. Вместе
с ветвлением этого достаточно, чтобы выразить любой алгоритм.
</Definition>

<KeyPoint>
В `for` шаг выполняется **после** тела, а условие —
**перед**. Поэтому на первом проходе счётчик равен начальному значению,
а при ложном условии тело не выполнится ни разу.
</KeyPoint>

## Три цикла

```js
for (let i = 0; i < 3; i++) { }     // начало; условие; шаг — всё в заголовке

let i = 0;
while (i < 3) { i++; }              // шаг внутри тела

let j = 0;
do { j++; } while (j < 3);          // условие ПОСЛЕ тела; точка с запятой нужна
```

| Ситуация | Цикл |
| --- | --- |
| знаем, сколько раз; идём по массиву | `for` |
| повторяем, пока условие верно | `while` |
| тело должно выполниться хотя бы раз | `do...while` |
| нужны только значения, индекс не нужен | `for...of` — день 11 |

## Формы счётчика

```js
const arr = [5, 4, 3];

for (let i = 0; i < arr.length; i++) { }        // вперёд
for (let i = arr.length - 1; i >= 0; i--) { }   // назад: -1 и >= 0
for (let i = 0; i < 10; i += 2) { }             // через один
for (let i = 0, j = 5; i < j; i++, j--) { }     // два счётчика
```

<Remember>
`i <= arr.length` — лишний проход с `undefined`. Индексы кончаются
на `length - 1`. Цикл назад с `i > 0` пропустит нулевой элемент.
</Remember>

## Пять приёмов

```js
const marks = [5, 4, 3, 5, 2, 4];
let sum = 0;
let fives = 0;
let max = marks[0];
for (let i = 0; i < marks.length; i++) {
  sum += marks[i];                             // накопитель
  if (marks[i] === 5) { fives++; }             // счётчик
  if (marks[i] > max) { max = marks[i]; }      // максимум
}
let has = false;
for (let i = 0; i < marks.length; i++) {
  if (marks[i] === 2) { has = true; break; }   // флаг: нашли — вышли
}
[sum, fives, max, has];                        // [23, 2, 5, true]
// сборка строки — тот же накопитель, только с текстом
```

На днях 19 и 20 всё это запишется короче — через `reduce`, `filter`,
`includes`, `join`. Но внутри них те же циклы.

## Вечный цикл

```js
// не запускайте — оба цикла вечные:
// while (i < 3) { console.log(i); }       → i++ забыли
// for (let i = 0; i !== 10; i += 3) { }   → 0, 3, 6, 9, 12 — мимо 10
```

<Remember>
Три проверки: **меняется** ли переменная из условия, меняется ли
в **нужную сторону**, **достижимо** ли условие остановки.
В условиях пишите `<` и `>`, а не `!==`.
\
На время отладки ставьте страховку: `guard++; if (guard > 1000) break;`
</Remember>

## break и continue

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) { break; }         // выйти из цикла совсем
  if (i % 2 === 0) { continue; }  // пропустить проход, идти к шагу
  console.log(i);
}
```

<Remember>
**`continue` в `while` до шага = вечный цикл**,
потому что шаг лежит в теле и будет пропущен. `continue` дружит
с `for`.
</Remember>

## Вложенные циклы и метки

```js
for (let i = 0; i < 3; i++) {
  for (let j = i + 1; j < 3; j++) { }   // j = i + 1 — пары без повторов
}

outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    break outer;      // выход из ВНЕШНЕГО цикла
  }
}
```

Внутренний цикл прокручивается целиком на каждый шаг внешнего. Вложенные циклы
**перемножают работу**: 1000 × 1000 — миллион проходов. Счётчики должны быть
разными.

<NoteBox>
**Три ошибки дня.** `break` вне цикла — `Illegal break
statement`. `continue` вне цикла — `Illegal continue statement`.
Несуществующая метка — `Undefined label 'x'`. Все три синтаксические, а значит
отключают **весь файл**.
\
**Метки** в настоящем коде почти не пишут: чаще вложенные циклы выносят
в функцию и выходят через `return`.
</NoteBox>
