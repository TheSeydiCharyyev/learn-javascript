День 10. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-10.

Перед началом. Сегодня легко зависнуть. Если вкладка перестала отвечать — закройте её и откройте заново, ничего страшного не случилось. На время отладки ставьте страховку: guard++; if (guard > 1000) break;

Разминка

1. Один результат, три цикла
Легко7 мин

увидеть, что три цикла — это один механизм.

Выведите числа от 1 до 10 тремя способами: for, while и do...while. Вывод должен быть одинаковым.

  • все три цикла написаны и дают одинаковый вывод;
  • в for счётчик объявлен в заголовке через let;
  • записано, где в каждом варианте находятся начало, условие и шаг;
  • после do...while стоит точка с запятой.
2. Сначала предскажи: сколько раз
Легко6 мин

поймать разницу между while и do...while и ошибку «на единицу».

Для каждого фрагмента предскажите, сколько строк он напечатает. Потом проверьте.

// А
let i = 10;
while (i < 3) { console.log(i); i++; }

// Б
let j = 10;
do { console.log(j); j++; } while (j < 3);

// В
const arr = [7, 8, 9];
for (let k = 0; k <= arr.length; k++) { console.log(arr[k]); }

// Г
for (let n = 5; n > 0; n--) { console.log(n); }
  • четыре предсказания записаны до проверки;
  • объяснено, почему Б печатает на строку больше, чем А;
  • во фрагменте В найдено лишнее значение и объяснено, откуда оно;
  • фрагмент В исправлен.
3. break против continue
Легко7 мин

увидеть разницу на одном и том же цикле.

Запустите цикл дважды — с break и с continue — и запишите оба вывода.

for (let i = 0; i < 6; i++) {
  if (i === 3) {
    break;      // потом замените на continue
  }
  console.log(i);
}
  • записаны оба вывода;
  • своими словами объяснено, что делает каждое слово;
  • записано, какое из двух выполняет шаг i++, а какое нет;
  • предсказано и проверено, что напечатает continue при условии i % 2 === 0.

Основные задания

4. Пять приёмов
Средне14 мин

освоить заготовки, из которых состоит большинство задач на циклы.

Для массива [5, 4, 3, 5, 2, 4] напишите пять отдельных циклов:

  1. сумма всех оценок;
  2. сколько пятёрок;
  3. максимальная оценка;
  4. есть ли хоть одна двойка (выйти сразу, как нашли);
  5. строка «5, 4, 3, 5, 2, 4» без запятой на конце.
В приёме «максимум» начинайте с arr[0], а счётчик — с i = 1. Подумайте, почему let max = 0 — плохая идея, и приведите пример массива, где это даст неверный ответ.
  • все пять циклов работают и дают правильные ответы;
  • в приёме «флаг» стоит break;
  • в строке нет запятой после последнего элемента;
  • записан пример массива, на котором let max = 0 ошибается.
5. Таблица умножения
Средне12 мин

написать вложенный цикл и понять, как он крутится.

Выведите таблицу умножения от 2 до 9: по одной строке на число, в строке — все произведения от 1 до 10.

2x1=2  2x2=4  2x3=6  ...  2x10=20
3x1=3  3x2=6  3x3=9  ...  3x10=30
Строку собирайте в переменную внутри внешнего цикла, а выводите после внутреннего — иначе каждое произведение уйдёт на свою строку.
  • выведено ровно 8 строк;
  • счётчики разные: i и j;
  • посчитано и записано, сколько раз выполнилось тело внутреннего цикла;
  • записано, что изменится, если поменять циклы местами.
6. Поймать зависание
Средне12 мин

научиться находить причину вечного цикла, не вешая браузер.

В каждом фрагменте цикл не остановится. Сначала добавьте в каждый страховку на 1000 проходов, только потом запускайте. Найдите причину и почините.

// А
let i = 0;
while (i < 5) {
  console.log(i);
}

// Б
for (let i = 0; i !== 10; i += 3) {
  console.log(i);
}

// В
let n = 5;
while (n > 0) {
  console.log(n);
  n++;
}

// Г
let k = 0;
while (k < 5) {
  if (k === 2) { continue; }
  console.log(k);
  k++;
}
  • во все четыре добавлена страховка до первого запуска;
  • для каждого названа причина: не меняется, не достигает, не в ту сторону, пропущен шаг;
  • все четыре починены и останавливаются;
  • для фрагмента Г объяснено, почему continue тут опаснее, чем в for.
7. «Табель»: циклы в деле
Средне12 мин

собрать день в программе курса.

Скопируйте папку day-09 в day-10. Возьмите массив [5, 4, 9, 3, 5, 0, 4, 5] и сделайте четыре цикла:

  • for с continue — отобрать годные оценки (от 2 до 5) в новый массив, посчитать пропущенные;
  • for — сумма отобранных;
  • for с break — номер первой двойки или «двоек нет»;
  • while — сколько первых оценок дают половину суммы.
Все циклы после первого работают с отобранным массивом, а не с исходным. Иначе числа перестанут сходиться. Добавлять в массив — push.
  • все четыре цикла работают;
  • засчитано 6, пропущено 2, сумма 26;
  • четвёртый цикл — именно while, и объяснено почему;
  • проверено: замена 3 на 2 в исходном массиве меняет ответ третьего цикла — записано, на какой номер и почему он не совпадает с местом двойки в исходном массиве.

Со звёздочкой

8. Пары без повторов
Сложно10 мин

разобраться, как начальное значение внутреннего счётчика меняет всё.

Для массива ["Аман", "Мерет", "Гүлнар", "Сапар"] выведите все пары «кто с кем в команде». Пара «Аман и Мерет» и «Мерет и Аман» — это одна пара, и человек не может быть в паре с собой.

Сначала напишите вариант с j = 0, посчитайте строки, потом исправьте на j = i + 1 и посчитайте снова.

  • оба варианта написаны, число строк посчитано для каждого;
  • в правильном варианте ровно 6 пар;
  • объяснено, откуда берётся разница в числе строк;
  • записана формула: сколько пар получится для массива из n имён.
9. Шесть ловушек
Сложно10 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением. Два фрагмента зависают — им нужна страховка.

// 1
const arr = [7, 8, 9];
for (let i = 0; i <= arr.length; i++) { console.log(arr[i]); }

// 2
for (let i = arr.length - 1; i > 0; i--) { console.log(arr[i]); }

// 3
for (var v = 0; v < 3; v++) { }
console.log(v);

// 4
for (let l = 0; l < 3; l++) { }
console.log(typeof l);

// 5
let m = 0;
while (m < 3) { if (m === 1) continue; m++; }

// 6
for (let i = 0; i !== 10; i += 3) { }
Фрагменты 2 и 4 не зависают, но дают не то, что кажется: в одном теряется элемент, в другом — переменная. Фрагменты 5 и 6 — те самые, что зависают.
  • предсказания записаны до запуска;
  • найдены оба зависающих фрагмента, до запуска в них добавлена страховка;
  • для фрагментов 3 и 4 объяснена разница между var и let со ссылкой на день 4;
  • фрагменты 1, 2, 5 и 6 переписаны так, чтобы делали то, что от них ожидают.
