# День 12. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-12`.</Subtitle>

## Разминка

<Task title="1. Три функции" level="easy" time="7">
<Goal>написать первые функции своими руками.</Goal>

Напишите и проверьте каждую на трёх разных аргументах:

- `isEven(n)` — чётное ли число;
- `maxOf(a, b)` — большее из двух;
- `greet(name)` — возвращает «Салам, имя!».

<Criteria>
- все три функции работают, по три проверки на каждую;
- каждая **возвращает** значение, а не выводит его;
- имена соответствуют правилам: `is` для «да / нет»;
- записано, что вернёт `isEven` без аргумента.
</Criteria>
</Task>

<Task title="2. Сколько аргументов" level="easy" time="6">
<Goal>увидеть, что язык не проверяет число аргументов.</Goal>

Для функции `add(x, y)` вызовите и запишите результат:

```js
add(2, 3)
add(2, 3, 4)
add(2)
add()
add("2", "3")
add.length
add.name
```

<Criteria>
- все семь результатов записаны;
- объяснено, почему `add(2)` даёт `NaN`, а не ошибку;
- объяснено, откуда взялся результат `add("2", "3")` —
  со ссылкой на день 6;
- записано, что означают `length` и `name` у функции.
</Criteria>
</Task>

<Task title="3. Скобки и return" level="easy" time="7">
<Goal>поймать две самые частые ловушки.</Goal>

Предскажите вывод каждого фрагмента, потом проверьте.

```js
// А
function double(n) { return n * 2; }
console.log(double);
console.log(double(5));

// Б
function getCity() {
  return
    "Мары";
}
console.log(getCity());

// В
function check() {
  console.log("проверяю");
  return true;
  console.log("а это?");
}
console.log(check());
```

<Criteria>
- три предсказания записаны до проверки;
- объяснено, чем отличаются две строки во фрагменте А;
- объяснено, почему Б даёт `undefined`, и фрагмент исправлен;
- записано, является ли ошибкой то, что во фрагменте В строка не печатается.
</Criteria>
</Task>

## Основные задания

<Task title="4. Ранний выход" level="medium" time="12">
<Goal>убрать вложенность через `return`.</Goal>

Перепишите на ранний выход. Поведение менять нельзя.

```js
function describe(score) {
  if (typeof score === "number") {
    if (score >= 0) {
      if (score >= 90) {
        return "отлично";
      } else {
        if (score >= 75) {
          return "хорошо";
        } else {
          return "нормально";
        }
      }
    } else {
      return "балл не может быть отрицательным";
    }
  } else {
    return "нужно число";
  }
}
```

Проверьте оба варианта на `95`, `80`, `50`,
`-1`, `"сто"`, `0`.

<Criteria>
- переписанная версия даёт те же ответы на всех шести значениях;
- в ней нет ни одной вложенности;
- нет ни одного `else`;
- записано, сколько строк стало вместо скольких.
</Criteria>
</Task>

<Task title="5. Разбить на функции" level="medium" time="14">
<Goal>главный навык дня — разделить задачу.</Goal>

Эта функция делает слишком много. Разбейте её минимум на четыре, чтобы у каждой была
одна работа.

```js
function processMarks(marks) {
  const valid = [];
  for (const m of marks) {
    if (m >= 2 && m <= 5) {
      valid.push(m);
    }
  }
  let sum = 0;
  for (const m of valid) {
    sum += m;
  }
  const avg = valid.length === 0 ? 0 : sum / valid.length;
  let v;
  if (avg >= 4.5) { v = "отличник"; }
  else if (avg >= 3.5) { v = "хорошист"; }
  else { v = "надо подтянуть"; }
  return `${avg.toFixed(2)} — ${v}`;
}
```

<Hint>
Названия уже напрашиваются из кода: отобрать, сложить, оценить, собрать строку.
Каждую новую функцию проверьте отдельно, прежде чем собирать всё вместе.
</Hint>

<Criteria>
- получилось не меньше четырёх функций;
- у каждой имя без союза «и»;
- каждая проверена отдельным вызовом, результаты записаны;
- итоговая функция даёт тот же ответ, что исходная, на трёх наборах оценок;
- проверен пустой массив — должно быть 0.00, а не `NaN`.
</Criteria>
</Task>

<Task title="6. Функция как значение" level="medium" time="12">
<Goal>передавать функцию в функцию.</Goal>

Напишите `applyToAll(numbers, fn)`: проходит по массиву, применяет
к каждому элементу переданную функцию и возвращает новый массив.

Проверьте её тремя разными функциями: удвоить, возвести в квадрат, превратить в строку.

<Example>
```js
applyToAll([1, 2, 3], double);   // [2, 4, 6]
applyToAll([1, 2, 3], square);   // [1, 4, 9]
```
</Example>

<Hint>
Внутри — обычный цикл и `push`. Переданную функцию вызывают так же,
как любую другую: `fn(элемент)`.
</Hint>

<Criteria>
- функция работает со всеми тремя переданными;
- исходный массив не изменился — проверено выводом;
- записано, что будет, если передать `applyToAll([1,2], double())`
  со скобками, и почему;
- объяснено, что такое колбэк, своими словами.
</Criteria>
</Task>

<Task title="9. Шесть ловушек" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя неожиданно.</Goal>

Для каждого фрагмента **сначала** запишите предсказание, потом проверьте
и объясните расхождение одним предложением.

```js
// 1
function f(x, y) { return x - y; }
console.log(f(2, 10));

// 2
function g() { return; 42; }
console.log(g());

// 3
const five = 5;
console.log(five());

// 4
greet("Аман");
function greet(n) { console.log("Салам, " + n); }

// 5
hi("Аман");
const hi = function (n) { console.log("Салам, " + n); };

// 6
function outer() { const x = 1; }
outer();
console.log(x);
```

<Hint>
Три фрагмента падают, три — нет. Падающие вынесите в отдельные файлы, иначе
не проверите остальные.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- найдены все три падающих фрагмента, записан текст каждой ошибки;
- объяснено, почему 4 работает, а 5 нет;
- для фрагмента 1 объяснено, почему ошибки нет, хотя результат неверный;
- фрагменты 1, 2, 5 и 6 переписаны правильно.
</Criteria>
</Task>
