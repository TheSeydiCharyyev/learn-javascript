# День 13. Формы записи функций

<Subtitle>Выжимка лекции: объявление, функция-выражение, стрелочная функция.</Subtitle>

## Главное

<Definition>
Три формы делают одно и то же и вызываются одинаково. Разница — в поднятии, в имени
и в трёх мелочах, которых у стрелочных нет.
</Definition>

<KeyPoint>
Вторая и третья формы — **не объявление функции, а обычное присваивание**.
Справа от `=` стоит значение. Отсюда всё их поведение.
</KeyPoint>

## Три формы

```js
function add(a, b) { return a + b; }            // объявление
const sum = function (a, b) { return a + b; };  // выражение
const plus = (a, b) => a + b;                   // стрелочная
```

|  | `function` | выражение | стрелка |
| --- | --- | --- | --- |
| поднимается | да | нет | нет |
| своё имя | да | от переменной | от переменной |
| `this`, `arguments` | да | да | **нет** |
| годится методом | да | да | **нет** |
| где уместна | функции программы | старый код, IIFE | короткие колбэки |

## Сокращения стрелочной

{/* ahead-ok: день 14 */}

```js
n => n * 2;          // один простой параметр — скобки можно убрать
(a, b) => a + b;     // несколько — скобки обязательны
() => 42;            // ноль параметров — скобки обязательны
(n = 1) => n;        // значение по умолчанию — скобки обязательны
```

<Remember>
**Есть `{` после стрелки — должен быть `return`.**
Фигурные скобки выключают неявный возврат.
\
`(n) => n * 2` — вернёт 10. `(n) => { n * 2; }` — вернёт
`undefined`.
</Remember>

## Возврат объекта

```js
() => { a: 1 }      // undefined — это БЛОК, a: читается как метка
() => ({ a: 1 })    // правильно — круглые скобки
```

## Поднятие

```js
add(2, 3);  function add(a, b) { return a + b; }           // работает

sum(2, 3);  const sum = (a, b) => a + b;
// ReferenceError: Cannot access 'sum' before initialization (в консоли — sum is not defined)

plus(2, 3); var plus = function (a, b) { return a + b; };
// TypeError: plus is not a function ← имя есть, значение undefined
```

## Имена

```js
const myVar = function () { };   // myVar.name === "myVar"
const arrowFn = () => { };       // arrowFn.name === "arrowFn"
const outer = function inner(){}; // outer.name === "inner", снаружи inner нет
```

Имя видно в стеке вызовов. Анонимная функция прямо на месте покажется как строка
без имени — найти её труднее.

## Чего у стрелочных нет

{/* ahead-ok: курс 2 */}

```js
const o = { name: "Аман", say: () => this.name };   // не сработает — нет this
const f = () => arguments.length;   // ReferenceError: arguments is not defined
new (() => {})();                   // TypeError: не конструктор
```

<Remember>
**Методом объекта стрелочную не делают.** Перенос строки
**перед** `=>` — `SyntaxError`;
после стрелки переносить можно.
</Remember>

## IIFE

```js
(function () { /* ... */ })();
(() => { /* ... */ })();

// спрятать данные, оставив доступ:
const counter = (function () {
  let count = 0;
  return { inc: () => ++count, get: () => count };
})();
```

<NoteBox>
**Выбор.** Договорённость курса: `function` для функций программы,
стрелки для колбэков. Главное — не смешивать в одном файле без причины.
\
**Как читать:** слева от стрелки — параметры; есть `{` —
ищите `return`; куда передают — тот и вызовет.
\
**Ловушка передачи:** `filter(isFive)` — передали функцию,
`filter(isFive())` — вызвали и передали результат.
</NoteBox>
