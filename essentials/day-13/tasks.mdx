# День 13. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-13`.</Subtitle>

## Разминка

<Task title="1. Одна функция, три формы" level="easy" time="6">
<Goal>записать одно и то же тремя способами.</Goal>

Функция «возвращает квадрат числа». Запишите её:

- объявлением через `function`;
- функцией-выражением;
- стрелочной, максимально коротко.

Вызовите каждую и выведите `.name` каждой.

<Criteria>
- все три работают и дают одинаковый результат;
- в стрелочной нет лишних скобок и `return`;
- у второй и третьей в конце стоит точка с запятой — объяснено почему;
- записаны три значения `.name`.
</Criteria>
</Task>

<Task title="2. Сократить до предела" level="easy" time="7">
<Goal>пройти все шаги сокращения.</Goal>

Сократите каждую функцию настолько, насколько позволяет язык. Запишите все
промежуточные формы.

```js
const a = function (n) { return n + 1; };
const b = function (x, y) { return x * y; };
const c = function () { return "привет"; };
const d = function (n) { const m = n * 2; return m + 1; };
```

<Criteria>
- для каждой записаны все промежуточные формы;
- у `b` и `c` скобки остались — объяснено почему;
- у `d` блок остался — объяснено почему;
- все четыре проверены вызовом после сокращения.
</Criteria>
</Task>

<Task title="3. Сначала предскажи: что вернётся" level="easy" time="7">
<Goal>поймать ловушки фигурных скобок.</Goal>

Предскажите результат каждого вызова, потом проверьте.

```js
const f1 = (n) => n * 2;
const f2 = (n) => { n * 2; };
const f3 = (n) => { return n * 2; };
const f4 = () => { a: 1 };
const f5 = () => ({ a: 1 });

console.log(f1(5), f2(5), f3(5), f4(), f5());
```

<Criteria>
- пять предсказаний записаны до проверки;
- объяснено, почему `f2` и `f4` дают
  `undefined`;
- записано, чем `{` в `f4` отличается от `{`
  в `f5`;
- сформулировано правило про фигурные скобки одним предложением.
</Criteria>
</Task>

## Основные задания

<Task title="4. Поднятие на практике" level="medium" time="12">
<Goal>увидеть три разных исхода при одном и том же коде.</Goal>

Наберите три файла, в каждом вызов стоит **до** определения. Запишите,
что получилось.

```js
// файл А
add(2, 3);
function add(a, b) { return a + b; }
```

```js
// файл Б
add(2, 3);
const add = (a, b) => a + b;
```

```js
// файл В
add(2, 3);
var add = function (a, b) { return a + b; };
```

<Criteria>
- для всех трёх записан результат или точный текст ошибки;
- объяснено, почему у Б и В **разные** виды ошибки;
- объяснено, почему А работает — со ссылкой на день 4;
- записано, какой из трёх вариантов вы бы выбрали и почему.
</Criteria>
</Task>

<Task title="5. Развернуть и свернуть" level="medium" time="13">
<Goal>научиться читать плотный код со стрелками.</Goal>

Разверните эту строку в отдельные именованные функции — так, чтобы результат
не изменился:

```js
const result = marks.filter(m => m >= 4).map(m => m * 10);
```

Затем наоборот: сверните этот код в одну строку со стрелками.

```js
function isLow(m) {
  return m < 3;
}
function toText(m) {
  return "оценка " + m;
}
const low = marks.filter(isLow);
const texts = low.map(toText);
```

<Criteria>
- обе задачи выполнены, результаты совпали с исходными;
- проверено на массиве `[5, 4, 3, 5, 2]`, результаты записаны;
- записано, какая версия каждой задачи читается лучше и почему;
- объяснено, почему в `filter(isLow)` нет скобок после имени.
</Criteria>
</Task>

<Task title="6. Выбрать форму" level="medium" time="12">
<Goal>применить правило выбора к настоящим случаям.</Goal>

Для каждой задачи выберите форму записи и объясните выбор одним предложением.
Затем напишите её.

1. функция `calculateTotal`, 15 строк, вызывается из четырёх мест;
2. проверка «оценка больше 3» для передачи в `filter`;
3. метод `getName` объекта `student`;
4. обработчик нажатия кнопки, три строки;
5. функция, которую надо вызвать в начале файла, а написать в конце.

<Criteria>
- для всех пяти выбрана форма и дано объяснение;
- в пункте 3 выбрана **не** стрелочная — причина названа;
- в пункте 5 выбрано объявление — причина названа;
- все пять написаны и работают.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Спрятать счётчик" level="hard" time="10">
<Goal>собрать немедленно вызываемую функцию и понять, зачем она.</Goal>

Напишите `counter` через IIFE: переменная счётчика спрятана внутри,
а снаружи доступны только `inc`, `dec` и `get`.

<Example>
```js
counter.inc();
counter.inc();
counter.dec();
counter.get();        // 1
typeof count;         // "undefined" — до переменной не добраться
```
</Example>

<Hint>
IIFE возвращает объект с тремя стрелочными функциями. Переменная объявляется
внутри функции, до `return`.
</Hint>

<Criteria>
- все три метода работают;
- `typeof count` снаружи даёт `"undefined"`;
- проверено, что напрямую испортить счётчик нельзя;
- объяснено, чем это лучше обычной переменной рядом с функциями.
</Criteria>
</Task>

<Task title="9. Шесть ловушек" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя неожиданно.</Goal>

Для каждого фрагмента **сначала** запишите предсказание, потом проверьте
и объясните расхождение одним предложением.

{/* ahead-ok: курс 2 */}

```js
// 1
const f = (n) => { n * 2; };
console.log(f(5));

// 2
const g = () => { a: 1 };
console.log(g());

// 3
const h = (a)
  => a + 1;
console.log(h(1));

// 4
const add = n, m => n + m;

// 5
const obj = { name: "Аман", say: () => this.name };
console.log(obj.say());

// 6
const count = () => arguments.length;
console.log(count(1, 2, 3));
```

<Hint>
Ошибок три, но они разные. Два фрагмента — `SyntaxError`: они ломают
**весь файл**, вынесите их отдельно. Ещё один падает только при вызове.
Оставшиеся три тихо дают не то, что кажется.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- найдены все три ошибки, записан текст каждой;
- объяснено, чем два `SyntaxError` отличаются от третьей ошибки
  по последствиям;
- для фрагмента 4 объяснено, почему сообщение говорит не о стрелке;
- для фрагмента 5 записано, что вывелось у вас в браузере — и отмечено,
  что результат зависит от среды;
- для остальных названа причина: скобки выключают возврат, блок вместо объекта,
  перенос перед стрелкой, нет `this`, нет `arguments`;
- фрагменты 1, 2, 3 и 4 переписаны правильно.
</Criteria>
</Task>
