# Day 14. Default and rest parameters

<Subtitle>A summary of the lecture: how to set a default value and how to take any number of arguments.</Subtitle>

## The main points

<Definition>
A default is put in when there is no argument. A rest parameter collects all the extra
arguments into an array. The first is about “fewer than needed”, the second about “more”.
</Definition>

<KeyPoint>
A default is used **only on `undefined`**.
Neither `null`, nor `0`, nor `""` switches it on.
</KeyPoint>

## A default value

```js
function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Aman");                 // "Salam, Aman!"
makeGreeting("Aman", "Hoş geldiň");   // "Hoş geldiň, Aman!"
```

| What was passed | What the parameter gets |
| --- | --- |
| nothing or `undefined` | the value from the header |
| `null` | `null` |
| `0`, `""`, `false`, `NaN` | what was passed |

<Remember>
**The old trick `num = num || 1` breaks on zero and an empty string.**
The `??` operator works correctly, but a default in the header is better: it shows
right away that the parameter is optional.
</Remember>

## A default is an expression

```js
function calc(n, m = double(n)) { }   // you can call a function
function greet(name, g, msg = g + " " + name) { }   // what is to the LEFT is visible
function bad(a = b, b = 2) { }        // ReferenceError when bad() is called
```

It is evaluated anew at every call — and only if it is needed:

```js
function addMark(mark, marks = []) { marks.push(mark); return marks; }
addMark(5);   // [5]
addMark(4);   // [4], not [5, 4] — a new array every time
```

<Remember>
**Parameters with defaults are put at the end of the list.** Otherwise the next ones
cannot be reached — you will have to write `f(undefined, 7)`.
</Remember>

## The rest parameter

```js
function showArgs(first, second, ...others) {
  console.log(first, second, others);
}

showArgs("bir", "iki", "üç", "dört");  // bir iki ["üç", "dört"]
showArgs("bir", "iki");                // bir iki []
showArgs("bir");                       // bir undefined []
```

A rest parameter is **always an array**, even an empty one. Three rules:
it is the last one, there is only one, it never has a default. A comma after it is an error too.

## The rest parameter versus `arguments`

|  | `...args` | `arguments` |
| --- | --- | --- |
| a real array | yes | **no** |
| what it contains | only the extra ones | all the arguments |
| in arrow functions | works | **no** |

## Four errors

```js
function add(x, x) { }   // ALLOWED only without "use strict", defaults
                         // and a rest parameter (old code); in an arrow — an error

// function add(x, x = 1) { }         → SyntaxError: Duplicate parameter name not allowed in this context
// function f(arg) { let arg = 1; }   → SyntaxError: Identifier 'arg' has already been declared
// function f(...rest, last) { }      → SyntaxError: Rest parameter must be last formal parameter
// function f(...rest = []) { }       → SyntaxError: Rest parameter may not have a default initializer

function sum(x, y = 1) { }      // different names
function f(arg) { arg = 1; }    // assigning is allowed, declaring again is not
function g(last, ...rest) { }   // the rest parameter goes last
function h(...rest) { }         // no default: it is [] anyway
```

<NoteBox>
**The MDN texts are different** — they follow the Firefox wordings. Search the internet
by the text of your own browser.
\
**Parentheses in an arrow function:** `(n = 1) => n` — with a default
the parentheses are required.
\
**`f.length`** is the number of parameters before the first default;
the rest parameter is not counted.
</NoteBox>
