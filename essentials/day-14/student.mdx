# День 14. Параметры по умолчанию и остаточные

<Subtitle>Выжимка лекции: как задать значение по умолчанию и как принять сколько угодно аргументов.</Subtitle>

## Главное

<Definition>
Умолчание подставляется, когда аргумента нет. Остаточный параметр собирает все лишние
аргументы в массив. Первое — про «меньше, чем нужно», второе — про «больше».
</Definition>

<KeyPoint>
Умолчание срабатывает **только на `undefined`**.
Ни `null`, ни `0`, ни `""` его не включают.
</KeyPoint>

## Значение по умолчанию

```js
function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Аман");                 // "Salam, Аман!"
makeGreeting("Аман", "Hoş geldiň");   // "Hoş geldiň, Аман!"
```

| Что передали | Что получит параметр |
| --- | --- |
| ничего или `undefined` | значение из заголовка |
| `null` | `null` |
| `0`, `""`, `false`, `NaN` | то, что передали |

<Remember>
**Старый приём `num = num || 1` ломается на нуле и пустой строке.**
Оператор `??` работает правильно, но умолчание в заголовке лучше: по нему
сразу видно, что параметр необязательный.
</Remember>

## Умолчание — это выражение

```js
function calc(n, m = double(n)) { }   // можно вызвать функцию
function greet(name, g, msg = g + " " + name) { }   // видно то, что ЛЕВЕЕ
function bad(a = b, b = 2) { }        // ReferenceError при вызове bad()
```

Вычисляется при каждом вызове заново — и только если понадобилось:

```js
function addMark(mark, marks = []) { marks.push(mark); return marks; }
addMark(5);   // [5]
addMark(4);   // [4], а не [5, 4] — каждый раз новый массив
```

<Remember>
**Параметры с умолчаниями ставят в конец списка.** Иначе до следующих
не добраться — придётся писать `f(undefined, 7)`.
</Remember>

## Остаточный параметр

```js
function showArgs(first, second, ...others) {
  console.log(first, second, others);
}

showArgs("бир", "ики", "уч", "дёрт");  // бир ики ["уч", "дёрт"]
showArgs("бир", "ики");                // бир ики []
showArgs("бир");                       // бир undefined []
```

Остаточный параметр — **всегда массив**, даже пустой. Три правила:
он последний, он один, умолчания у него не бывает. Запятая после него — тоже ошибка.

## Остаточный против `arguments`

|  | `...args` | `arguments` |
| --- | --- | --- |
| настоящий массив | да | **нет** |
| что содержит | только лишние | все аргументы |
| в стрелочных | работает | **нет** |

## Четыре ошибки

```js
function add(x, x) { }   // МОЖНО только без "use strict", умолчаний
                         // и остаточного (старый код); в стрелочной — ошибка

// function add(x, x = 1) { }         → SyntaxError: Duplicate parameter name not allowed in this context
// function f(arg) { let arg = 1; }   → SyntaxError: Identifier 'arg' has already been declared
// function f(...rest, last) { }      → SyntaxError: Rest parameter must be last formal parameter
// function f(...rest = []) { }       → SyntaxError: Rest parameter may not have a default initializer

function sum(x, y = 1) { }      // имена разные
function f(arg) { arg = 1; }    // присвоить можно, объявить заново — нет
function g(last, ...rest) { }   // остаточный — последним
function h(...rest) { }         // без умолчания: и так []
```

<NoteBox>
**Тексты MDN другие** — они по формулировкам Firefox. Искать в интернете
надо по тексту своего браузера.
\
**Скобки у стрелочной:** `(n = 1) => n` — с умолчанием
скобки обязательны.
\
**`f.length`** — число параметров до первого умолчания;
остаточный не считается.
</NoteBox>
