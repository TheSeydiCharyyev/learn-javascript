# День 14. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке `day-14`.</Subtitle>

## Разминка

<Task title="1. Пять аргументов, одно умолчание" level="easy" time="6">
<Goal>увидеть своими глазами, что умолчание реагирует только на `undefined`.</Goal>

Напишите функцию и вызовите её пять раз, записав каждый результат:

```js
function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Аман");
makeGreeting("Аман", undefined);
makeGreeting("Аман", null);
makeGreeting("Аман", 0);
makeGreeting("Аман", "Hoş geldiň");
```

<Hint>
Два вызова дадут одинаковый результат — найдите какие. Остальные три покажут то,
что передали, без всякой подстановки.
</Hint>

<Criteria>
- записаны все пять результатов;
- названы два вызова, которые дали одно и то же, и объяснено почему;
- объяснено, почему `null` и `0` умолчание не включили;
- сформулировано правило одним предложением.
</Criteria>
</Task>

<Task title="2. Сначала предскажи: сработает или нет" level="easy" time="7">
<Goal>отличить умолчание от старого приёма с `||`.</Goal>

Предскажите результат каждого вызова, потом проверьте.

```js
function a(num = 10) { return num; }
function b(num) { num = num || 10; return num; }
function c(num) { num = num ?? 10; return num; }

console.log(a(), a(0), a(null));
console.log(b(), b(0), b(null));
console.log(c(), c(0), c(null));
```

<Hint>
Девять значений. Различия появятся только в столбцах `0` и
`null` — первый столбец у всех трёх одинаковый.
</Hint>

<Criteria>
- девять предсказаний записаны до проверки;
- найдено, где `b` расходится с `a`, и названа причина;
- найдено, где `c` расходится с `a`, и названа причина;
- записано, какую из трёх функций вы бы написали в своём коде и почему.
</Criteria>
</Task>

<Task title="3. Сложить что угодно" level="easy" time="7">
<Goal>написать первую функцию с остаточным параметром.</Goal>

Напишите `sumAll`, которая складывает любое число аргументов.
Проверьте на трёх, на одном и на нуле аргументов. Потом выведите
`typeof` остаточного параметра и `Array.isArray` от него.

<Hint>
Внутри функции это обычный массив — перебирайте его `for...of`
из дня 11. Начальное значение суммы — ноль, тогда вызов без аргументов
тоже отработает.
</Hint>

<Criteria>
- `sumAll(5, 4, 5)`, `sumAll(5)` и `sumAll()`
  дают 14, 5 и 0;
- записано, что показали `typeof` и `Array.isArray`;
- объяснено, почему вызов без аргументов не даёт ошибку;
- то же самое написано ещё раз стрелочной функцией.
</Criteria>
</Task>

## Основные задания

<Task title="4. Неудобный порядок" level="medium" time="12">
<Goal>понять на своей ошибке, почему необязательные параметры ставят в конец.</Goal>

Наберите функцию, у которой умолчание стоит первым, и попробуйте ею
воспользоваться:

```js
function report(greeting = "Salam", name) {
  return greeting + ", " + name;
}

report("Аман");   // хотели «Salam, Аман»
```

Получилось не то. Добейтесь нужного результата, не меняя объявление. Потом
перепишите функцию правильно и покажите, что она удобнее.

<Hint>
Аргументы раскладываются по местам, а не по именам: «Аман» попал в первое место.
Чтобы сказать «для первого возьми своё», есть ровно одно значение — оно из
раздела 3 лекции.
</Hint>

<Criteria>
- записано, что вернул `report("Аман")` и почему;
- найден вызов, который даёт «Salam, Аман» без правки объявления;
- функция переписана с умолчанием в конце, показаны два вызова;
- объяснено в одном предложении, чем второй вариант лучше.
</Criteria>
</Task>

<Task title="5. Переписать старый код" level="medium" time="12">
<Goal>заменить `arguments` остаточным параметром.</Goal>

Вот функция, написанная до 2015 года. Она склеивает все аргументы через пробел:

```js
function oldJoin() {
  const parts = Array.prototype.slice.call(arguments);   // курс 2
  let out = "";
  for (const p of parts) {
    out += p + " ";
  }
  return out;
}
```

Перепишите её на остаточный параметр так, чтобы результат совпал до символа.
Затем ответьте на вопрос: что изменится, если у функции появится первый
обязательный параметр `title`?

<Hint>
Строка со `slice.call` нужна была только ради превращения
`arguments` в массив — с остаточным параметром она не нужна совсем.
Для второго вопроса сравните `arguments.length` и длину остаточного.
</Hint>

<Criteria>
- новая версия короче и даёт тот же результат на `("бир", "ики")`;
- результаты обеих версий сравнены, совпадение проверено;
- объяснено, почему со старой версией `title` попал бы в вывод,
  а с новой — нет;
- записано, почему в стрелочной функции старую версию повторить нельзя.
</Criteria>
</Task>

<Task title="6. Умолчание, которое работает" level="medium" time="13">
<Goal>убедиться, что умолчание — это код, а не значение.</Goal>

Три опыта подряд, для каждого запишите вывод и объяснение.

1. Счётчик вызовов:
   ```js
   let calls = 0;
   function next() { calls = calls + 1; return calls; }
   function withCall(n = next()) { return n; }
   ```
   Вызовите `withCall()` дважды, потом `withCall(100)`.
   После каждого вызова печатайте `calls`.
2. Новый массив каждый раз: `function addMark(mark, marks = []) { marks.push(mark); return marks; }`.
   Вызовите дважды без второго аргумента, потом дважды с одним и тем же массивом.
3. Обязательный аргумент: напишите `required(name)`, которая бросает
   `TypeError`, и функцию с параметром
   `name = required("name")`.

<Hint>
В первом опыте важно печатать `calls` **после** каждого
вызова, иначе разницы не увидеть. В третьем вспомните `throw` из дня 11.
</Hint>

<Criteria>
- для опыта 1 записано значение `calls` после каждого из трёх
  вызовов и объяснено, почему третий его не изменил;
- для опыта 2 показано, что два вызова подряд не накапливают оценки,
  а с общим массивом — накапливают;
- для опыта 3 функция падает без аргумента и работает с аргументом;
- проверено, что вызов с `undefined` тоже вызывает ошибку,
  и объяснено почему.
</Criteria>
</Task>

<Task title="7. «Табель»: оценки россыпью" level="medium" time="13">
<Goal>перевести программу курса на новый способ передачи данных.</Goal>

- `makeReport` принимает оценки остаточным параметром, а имя получает

- `verdict` получает три необязательных порога:
  `excellent = 4.5`, `good = 3.5`, `pass = 2.5`;
- вызовы `makeReport` переписаны без квадратных скобок.

Добавьте пятый вызов — `makeReport()` вообще без аргументов.

<Hint>
Тела `isValidMark`, `sum`, `average` и

Если первые четыре отчёта изменились, значит, что-то поехало.

<Criteria>

## Со звёздочкой

<Task title="8. Четыре ошибки и одно исключение" level="hard" time="10">
<Goal>получить все четыре ошибки дня своими руками и найти ту, что ведёт себя по-разному.</Goal>

Каждый фрагмент — в отдельный файл: это `SyntaxError`, они ломают весь
файл целиком. Запишите точный текст каждой ошибки из своей консоли.

```js
// 1
function add(x, x) { return x; }
console.log(add(1, 2));

// 2
function add(x, x = 1) { return x; }

// 3
function f(arg) { let arg = "foo"; }

// 4
function replacer(match, ...groups, offset) { }

// 5
function doSomething(...args = []) { }
```

Фрагментов пять, а ошибок четыре. Разберитесь, что происходит с первым.

<Hint>
Первый фрагмент — единственный, который зависит от режима. Попробуйте добавить
в начало файла строку `"use strict";` и запустить снова. Сравните
с фрагментом 2 и сделайте вывод.
</Hint>

<Criteria>
- записан точный текст четырёх ошибок из своей консоли;
- для фрагмента 1 записано, что он вывел без строгого режима и что —
  с ним;
- объяснено, чем фрагмент 2 отличается от фрагмента 1, из-за чего
  появляется ошибка;
- тексты сверены с заголовками страниц MDN из справочника дня и отмечено,
  что они не совпадают;
- все пять фрагментов переписаны правильно.
</Criteria>
</Task>

<Task title="9. Универсальный список" level="hard" time="10">
<Goal>собрать функцию, где работают обе сегодняшние темы сразу.</Goal>

Напишите `makeList`, которая печатает нумерованный список:

<Example>
```js
makeList("Оценки", 5, 4, 5);   // "Оценки: 1) 5 2) 4 3) 5"
makeList("Оценки");            // "Оценки: пусто"
makeList();                    // "Список: пусто"
makeList(undefined, "бир");    // "Список: 1) бир"
```
</Example>

Заголовок необязателен и по умолчанию равен `"Список"`, элементов
может быть сколько угодно.

<Hint>
Порядок параметров задан примерами: сначала заголовок с умолчанием, потом
остаточный. Номер ведите отдельной переменной — она увеличивается на каждом шаге
`for...of`. Случай «элементов нет» проверьте **до** цикла.
</Hint>

<Criteria>
- все четыре вызова из примера дают ровно то, что написано;
- при нуле элементов цикл не выполняется ни разу;
- объяснено, почему `makeList(undefined, "бир")` печатает
  «Список», а не «undefined»;
- проверено, что `makeList("Оценки", [5, 4])` даёт один элемент,
  и объяснено почему;
- добавлен необязательный параметр-разделитель между заголовком и
  остаточным — и показано, как его пропустить.
</Criteria>
</Task>
