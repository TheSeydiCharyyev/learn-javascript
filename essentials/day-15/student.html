День 15. Разбиваем задачу на функции

Выжимка трёх частей: как резать, как отлаживать, как читать чужое.

Часть 1. Как резать

Кусок кода просится в функцию, если: его можно назвать одним глаголом; над ним хочется написать комментарий-заголовок; он повторяется; его хочется проверить отдельно.
Режут по смыслу, а не по длине. «Функция не длиннее двадцати строк» — плохое правило.
ПлохоХорошо
f, doIt, processcountPresent — глагол + что
check(mark)isValidMark(mark) — проверки на is/has
average печатаетgetAverage возвращает, showAverage печатает
В честном имени появилось «и» — дел больше одного. countAndPrint надо разделить: одна считает, другая показывает.
Параметров 0–2 хорошо, 3 нормально, 4 и больше — функция делает слишком много.
Возвращать, а не печатать. И всегда один и тот же тип. 
// sum — та же, что в «Табеле»
function showAverage(marks) { console.log(sum(marks) / marks.length); }
const a = showAverage([5, 4]);   // в консоли 4.5, а в a — undefined

function getAverage(marks) { return sum(marks) / marks.length; }
const b = getAverage([5, 4]);    // 4.5 — с этим можно работать дальше

Часть 2. Как отлаживать

Три места, и в таком порядке: вход (то ли пришло) → тело (то ли считается) → выход (то ли ушло). В тело лезут последним. 
function countPresent(present) {
  console.log("вошло:", present);   // печатаем значение ЦЕЛИКОМ
  let came = 0;
  for (const p of present) {
    if (p === 1) { came += 1; }
  }
  console.log("выходит:", came);
  return came;
}

countPresent([1, 0, 1]);   // вошло: (3) [1, 0, 1]   выходит: 2
countPresent("101");       // вошло: 101             выходит: 0 ← ошибки нет, ответ неверный
Самая опасная ошибка — когда программа не падает, а врёт. Две печати на границах ловят её за полминуты.

Часть 3. Как читать чужое

Порядок разбора: return (зачем функция) → параметры (как их используют, того они и типа) → ветки (что берём, что пропускаем) → имя придумываем последним и сразу вписываем. 
function f(a, b) {                 // было
  let r = "";
  for (const x of a) {
    if (x.length > b) { r = r + x + " "; }
  }
  return r;
}

function longNames(names, minLength = 5) {   // стало, шагами: имена → хвост → умолчание
  let result = "";
  for (const name of names) {
    if (name.length > minLength) {
      if (result !== "") { result += ", "; }
      result += name;
    }
  }
  return result;
}
Крайние случаи любой незнакомой функции: пустой вход, «ничего не подошло», «подошло всё», вызов без аргументов.
Переписывают маленькими шагами: один шаг — одна проверка, ответ после каждого шага обязан остаться прежним.
  1. Возьмите программу «кто пришёл» из раздела 1 лекции и разрежьте её сами, не подглядывая. Потом сравните свои границы с разделом 3 и запишите, где они разошлись.
  2. Добавьте в любые три свои функции печать на границах и запустите. Запишите, что вывелось, и уберите печать обратно.
  3. Уберите return из sum в «Табеле» и запустите. Ошибки не будет — запишите, где в отчётах видна беда, и объясните её путь: sum → average → makeReport.
  4. Найдите в своём коде за прошлые дни функцию, у которой в имени просится «и». Разделите её на две и проверьте, что программа работает как прежде.
