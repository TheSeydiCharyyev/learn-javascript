# День 15. Разбиваем задачу на функции

<Subtitle>Выжимка трёх частей: как резать, как отлаживать, как читать чужое.</Subtitle>

## Часть 1. Как резать

<Definition>
Кусок кода просится в функцию, если: его можно назвать одним глаголом; над ним хочется
написать комментарий-заголовок; он повторяется; его хочется проверить отдельно.
</Definition>

<KeyPoint>
Режут **по смыслу, а не по длине**. «Функция не длиннее двадцати строк» —
плохое правило.
</KeyPoint>

| Плохо | Хорошо |
| --- | --- |
| `f`, `doIt`, `process` | `countPresent` — глагол + что |
| `check(mark)` | `isValidMark(mark)` — проверки на `is`/`has` |
| `average` печатает | `getAverage` возвращает, `showAverage` печатает |

<Remember>
**В честном имени появилось «и» — дел больше одного.**
`countAndPrint` надо разделить: одна считает, другая показывает.
\
Параметров 0–2 хорошо, 3 нормально, 4 и больше — функция делает слишком много.
\
Возвращать, а не печатать. И всегда один и тот же тип.
</Remember>

```js
// sum — та же, что в «Табеле»
function showAverage(marks) { console.log(sum(marks) / marks.length); }
const a = showAverage([5, 4]);   // в консоли 4.5, а в a — undefined

function getAverage(marks) { return sum(marks) / marks.length; }
const b = getAverage([5, 4]);    // 4.5 — с этим можно работать дальше
```

## Часть 2. Как отлаживать

<Definition>
Три места, и в таком порядке: **вход** (то ли пришло) →
**тело** (то ли считается) → **выход** (то ли ушло).
В тело лезут последним.
</Definition>

```js
function countPresent(present) {
  console.log("вошло:", present);   // печатаем значение ЦЕЛИКОМ
  let came = 0;
  for (const p of present) {
    if (p === 1) { came += 1; }
  }
  console.log("выходит:", came);
  return came;
}

countPresent([1, 0, 1]);   // вошло: (3) [1, 0, 1]   выходит: 2
countPresent("101");       // вошло: 101             выходит: 0 ← ошибки нет, ответ неверный
```

<Remember>
Самая опасная ошибка — когда программа **не падает, а врёт**.
Две печати на границах ловят её за полминуты.
</Remember>

| Что видно | Что произошло | День |
| --- | --- | --- |
| `x is not a function` | вызвали не функцию | 12 |
| `undefined`, ошибки нет | забыли `return` | 12 |
| стрелка вернула `undefined` | скобки выключили возврат | 13 |
| аргумент «не дошёл» | перепутан порядок параметров | 14 |

<Remember>
**Уменьшай вход.** Падает или врёт на ста студентах — попробуйте двух,
одного, пустой список. Минимальный вызов с ошибкой помещается в голове целиком, и чаще
всего он оказывается пустым.
</Remember>

## Часть 3. Как читать чужое

<Definition>
Порядок разбора: **return** (зачем функция) → **параметры**
(как их используют, того они и типа) → **ветки** (что берём, что пропускаем)
→ **имя** придумываем последним и сразу вписываем.
</Definition>

```js
function f(a, b) {                 // было
  let r = "";
  for (const x of a) {
    if (x.length > b) { r = r + x + " "; }
  }
  return r;
}

function longNames(names, minLength = 5) {   // стало, шагами: имена → хвост → умолчание
  let result = "";
  for (const name of names) {
    if (name.length > minLength) {
      if (result !== "") { result += ", "; }
      result += name;
    }
  }
  return result;
}
```

<NoteBox>
**Крайние случаи** любой незнакомой функции: пустой вход, «ничего
не подошло», «подошло всё», вызов без аргументов.
\
**Переписывают маленькими шагами:** один шаг — одна проверка, ответ
после каждого шага обязан остаться прежним.
</NoteBox>
