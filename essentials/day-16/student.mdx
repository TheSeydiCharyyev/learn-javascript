# День 16. Строки и их методы

<Subtitle>Выжимка лекции: найти, отрезать, поправить, собрать.</Subtitle>

## Главное

<Definition>
Строку изменить нельзя. Любой метод возвращает **новую** строку,
а старая остаётся прежней.
</Definition>

```js
let text = "  Аман  ";
text.trim();          // результат пропал: text всё ещё "  Аман  "
text = text.trim();   // вот так правильно
```

<KeyPoint>
В обычном режиме `name[0] = "А"` молча не срабатывает, в строгом —
`TypeError: Cannot assign to read only property`.
</KeyPoint>

Раз каждый метод возвращает строку, у результата сразу можно вызвать следующий —
получается цепочка. Порядок шагов в ней важен:

```js
"  АмАн  ".trim().toLowerCase();   // "аман"
"  Аман  ".slice(0, 4);            // "  Ам" — резали вместе с пробелами
"  Аман  ".trim().slice(0, 4);     // "Аман"
```

## Длина и символы

```js
const name = "Гүлнар";
name.length;                             // 6, последний индекс — 5
name[0];  name.charAt(0);  name.at(0);   // "Г"
name.at(-1);                             // "р" — отрицательные понимает только at
```

| Индекс | `name[i]` | `charAt(i)` | `at(i)` |
| --- | --- | --- | --- |
| 99 | `undefined` | `""` | `undefined` |
| −1 | `undefined` | `""` | **последний** |

## Поиск

```js
const group = "Аман Мерет Аман";
group.indexOf("Аман");       // 0 — позиция или -1
group.lastIndexOf("Аман");   // 11 — с конца
group.includes("Мерет");     // true / false
group.startsWith("Аман");  group.endsWith("Аман");   // true
```

<Remember>
**`if (text.indexOf("Аман"))` — ошибка:** ноль означает
«нашёл в начале», но в условии это ложь. Писать `!== -1` или
`includes`.
\
**Все четыре метода различают регистр.**
</Remember>

## Отрезаем

```js
"Туркменистан".slice(0, 4);   // "Турк" — вторая граница НЕ входит
"Туркменистан".slice(4);      // "менистан"
"Туркменистан".slice(-6);     // "нистан"
"Туркменистан".slice(4, 2);   // "" — границы наоборот
```

| Случай | `slice` | `substring` |
| --- | --- | --- |
| границы наоборот | `""` | меняет их местами |
| отрицательная граница | считает с конца | считает нулём |

Договорённость курса: пишем `slice`, `substring` — только читаем.

## Правим и собираем

```js
"Аман".toUpperCase();   // "АМАН"
"АМАН".toLowerCase();   // "аман"

const a = "  АмАн ";
const b = "аман";
a.trim().toLowerCase() === b.trim().toLowerCase();   // true — сравнение по-человечески

"   Аман   ".trim();        // "Аман" — только края
"   Аман   ".trimStart();   // "Аман   "
"   Аман   ".trimEnd();     // "   Аман"

"5".padStart(3, "0");         // "005" — 3 это ДЛИНА РЕЗУЛЬТАТА, не добавка
"Аман".padEnd(10, ".");       // "Аман......"
String(5).padStart(2, "0");   // "05" — у числа методов строки нет
"-".repeat(40);               // линия

const student = "Аман";
const avg = 4.333;
`${student}: средний ${avg.toFixed(2)}`;   // "Аман: средний 4.33"
`перенос
прямо в тексте`;
```

<Remember>
`padEnd` — для текста (колонка слева), `padStart` — для чисел
(выравнивание вправо). Ширину берут по самому длинному значению, иначе таблица
разъедется.
</Remember>

## Коды и превращения

```js
"Аман".charCodeAt(0);        // 1040
"🙂".charCodeAt(0);          // 55357 — половина значка
"🙂".codePointAt(0);         // 128578 — значок целиком
String.fromCharCode(1040);   // "А"

String(5);                   // "5"
String(null);                // "null" — работает с чем угодно
(5).toString(2);             // "101" — система счисления
```

<NoteBox>
**Три ошибки дня, все `RangeError`:**
`"abc".repeat(-1)` → `Invalid count value: -1`;
`"abc".repeat(1e10)` → `Invalid string length`;
`String.fromCodePoint(-1)` → `Invalid code point -1`.
На MDN они озаглавлены по формулировкам Firefox.
\
**Не было сегодня:** `split`, `replace`,
`match` — они идут с регулярными выражениями в курсе 2.
</NoteBox>
