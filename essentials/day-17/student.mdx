# День 17. Числа и первые даты

<Subtitle>Выжимка лекции: превратить в число, проверить, округлить, поставить дату.</Subtitle>

## Из строки в число

<Definition>
`Number()` строгий — либо вся строка число, либо `NaN`.
`parseInt` и `parseFloat` читают слева, сколько получится.
</Definition>

| Строка | `Number` | `parseInt` | `parseFloat` |
| --- | --- | --- | --- |
| `"4.5"` | 4.5 | **4** | 4.5 |
| `"42px"` | **NaN** | 42 | 42 |
| `"px42"` | NaN | NaN | NaN |
| `""` | **0** | NaN | NaN |

<KeyPoint>
Для данных из формы берём `Number()`: он честно сообщает о мусоре вместо
того, чтобы молча прочитать половину.
</KeyPoint>

```js
parseInt("1010", 2);   // 10  — основание указывать явно
const day = "08";
parseInt(day, 10);     // 8   — так пишут в надёжном коде
```

## Проверки

```js
Number.isNaN("abc");     // false — честная проверка
isNaN("abc");            // true  — старая, сначала превращает в число
Number.isFinite("42");   // false
isFinite("42");          // true  — тоже старая
Number.isInteger(4);     // true  — лучшая проверка «пришло целое число»
const x = Number("пять");
x === NaN;               // false — ВСЕГДА, так не проверяют
```

<Remember>
В новом коде — только те проверки, что **с приставкой `Number.`**
Старые `isNaN` и `isFinite` втихую преобразуют аргумент.
</Remember>

## Округление

```js
(4.333).toFixed(2);   // "4.33" — это СТРОКА, не число
(7).toFixed(2);       // "7.00"
(1.005).toFixed(2);   // "1.00" — а не "1.01"

0.1 + 0.2;            // 0.30000000000000004
0.1 + 0.2 === 0.3;    // false
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON;   // true
```

Дроби хранятся приблизительно — это свойство двоичной записи, а не языка. Поэтому
деньги и оценки держат в целых, а дробь показывают только при выводе.

## Константы и системы счисления

```js
Number.MAX_SAFE_INTEGER;   // 9007199254740991 — граница точных целых
Number.EPSILON;            // 2.220446049250313e-16 — порог для сравнения дробей

(255).toString(16);   // "ff"
parseInt("ff", 16);   // 255
// (255).toString(1)  → RangeError: toString() radix argument must be between 2 and 36
```

## Даты

<Definition>
Дата внутри — одно число: миллисекунды с 1 января 1970 года. Поэтому даты можно
вычитать.
</Definition>

```js
Date.now();                               // сейчас, число
const d = new Date(2026, 8, 22, 14, 5);   // 22 сентября 2026, 14:05

d.getFullYear();   // 2026
d.getMonth();      // 8  — СЕНТЯБРЬ, месяцы с нуля!
d.getDate();       // 22
d.getHours();      // 14
d.getMinutes();    // 5

const start = new Date(2026, 8, 1);
const end = new Date(2026, 8, 22);
(end.getTime() - start.getTime()) / (1000 * 60 * 60 * 24);   // 21 — разница в днях
```

<Remember>
**Месяцы нумеруются с нуля**, а дни — с единицы. Январь — 0,
сентябрь — 8, декабрь — 11. Месяц 12 переедет в следующий год.
</Remember>

```js
d.toLocaleDateString("ru-RU");   // "22.09.2026"
d.toLocaleTimeString("ru-RU");   // "14:05:00"

const bad = new Date("не дата");
String(bad);                     // "Invalid Date"
bad.getTime();                   // NaN
!Number.isNaN(bad.getTime());    // false — так проверяют дату
```

<NoteBox>
**Три ошибки дня, все `RangeError`:** основание вне 2…36,
слишком много знаков в `toFixed`, `toISOString` от неверной
даты (`Invalid time value`).
\
**Не было сегодня:** разбор строк с датой, UTC-методы, сеттеры,
современная замена `Temporal` и настройки вывода дат через
`Intl` — всё это курс 2.
</NoteBox>
