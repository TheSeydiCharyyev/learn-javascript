# Day 18. Math and random numbers

<Subtitle>A summary of the lecture: round, find the extremes, roll a die.</Subtitle>

## The main points

<Definition>
`Math` is not a type of value but a box of functions and constants.
It is not created with `new`; everything is called from the word `Math`.
</Definition>

<KeyPoint>
`Math.round(x)` gives a **number** for calculations,
`x.toFixed(2)` gives a **string** for showing. Mixing them up is a common
mistake in reports.
</KeyPoint>

## Four kinds of rounding

```js
Math.round(4.5);   // 5   to the nearest, a half goes UP
Math.floor(4.9);   // 4   always down
Math.ceil(4.1);    // 5   always up
Math.trunc(4.9);   // 4   drop the fractional part
```

| Number | `round` | `floor` | `ceil` | `trunc` |
| --- | --- | --- | --- | --- |
| 4.5 | 5 | 4 | 5 | 4 |
| −4.1 | −4 | **−5** | −4 | **−4** |
| −4.5 | **−4** | −5 | −4 | −4 |

<Remember>
On negatives `floor` and `trunc` differ: “down” means further
from zero, “drop” means toward zero. And `Math.round(-4.5)` gives −4: a half
goes up along the line, not further from zero.
</Remember>

## Any rounding step

```js
const price = 1234.567;
Math.round(price / 10) * 10;     // 1230     to tens
Math.round(price / 100) * 100;   // 1200     to hundreds
Math.floor(price / 5) * 5;       // 1230     down to a multiple of five
Math.round(price * 100) / 100;   // 1234.57  to hundredths — AS A NUMBER, not a string
```

## Extremes and powers

```js
Math.abs(-5);        // 5
Math.sign(-5);       // -1
Math.sqrt(144);      // 12
2 ** 10;             // 1024 — the same as Math.pow(2, 10)
Math.hypot(3, 4);    // 5
Math.cbrt(27);       // 3

Math.max(3, 7, 5);     // 7
Math.max();            // -Infinity !
Math.max(3, NaN, 5);   // NaN !
const marks = [3, 5, 4];
Math.max(marks);       // NaN — an array is ONE argument
```

```js
const maxOf = (numbers) => {
  let best = numbers[0];
  for (const n of numbers) { best = Math.max(best, n); }
  return best;
};
```

## Random numbers

<Definition>
`Math.random()` gives a fractional number from zero inclusive to one
exclusive. One never comes out — the formula is built on this.
</Definition>

```js
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

randomInt(1, 6);   // a dice roll
```

<Remember>
**`Math.round(Math.random() * 6)` is a mistake.** There are seven outcomes,
and the edges come out half as often: about 5000 against 10000 in 60,000 rolls.
The program works anyway; the error is visible only with a counter.
\
Forgetting `+ 1` in `(max - min + 1)` means never
getting the maximum.
</Remember>

## Constants and angles

```js
Math.PI;   // 3.141592653589793 — without parentheses; also Math.E, Math.SQRT2, Math.LN2

const radius = 5;
Math.PI * radius ** 2;          // 78.53981633974483 — the area of a circle

Math.sin(90 * Math.PI / 180);   // 1 — the argument is in RADIANS
Math.sin(90);                   // 0.8939966636005579 — this is the sine of 90 radians
```

<NoteBox>
**Trigonometry and logarithms** are nineteen reference pages, given in one

`Math.log2` is needed more often than the others — “how many times to divide in half”.
\
**`Math.sumPrecise`** solves yesterday’s problem of an exact

</NoteBox>
