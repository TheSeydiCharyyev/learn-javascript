# Day 19. Tasks

<Subtitle>Lessons 2 and 3, 90 minutes. Warm-up — 20 minutes, main tasks — 50 minutes, starred tasks — 20 minutes. We write the code in the file `arrays.js` and run it on a page or in the console.</Subtitle>

## Warm-up

<Task title="1. A shopping list" level="easy" time="6">
<Goal>create an array and read its elements.</Goal>

Create an array of five purchases. Print the first element, the last one through `at`,
the length of the list and the element with index 2.

<Criteria>
- the last element is obtained through `at(-1)`, not by the number 4;
- all four values are printed to the console.
</Criteria>
</Task>

<Task title="2. A line in the canteen" level="easy" time="7">
<Goal>practice the four methods of the ends.</Goal>

The array `["Aman", "Meret"]`. Do in order: Sapar came (to the end),
the first one was served (remove from the start), Gülnar came in out of turn (to the start), the last one left (remove from the end).
After each step print the array.

<Hint>
Methods that remove an element return it: `const served = line.shift();`.
Methods that add return the new length.
</Hint>

<Criteria>
- all four methods are used: `push`, `shift`,
  `unshift`, `pop`;
- it is written down what `shift` and `pop` returned;
- it is explained whether it is a stack or a queue if people are served through `push` and `shift`.
</Criteria>
</Task>

<Task title="3. Is it in the list" level="easy" time="7">
<Goal>tell `indexOf` and `includes` apart.</Goal>

An array of subjects `["math", "physics", "computer science"]`. Check in two ways
whether it has “physics” and whether it has “chemistry”. Print the results.

<Hint>
`indexOf` answers with a number, `includes` with `true` or `false`.
</Hint>

<Criteria>
- both answers are shown for each subject;
- it is explained why `indexOf` returned −1.
</Criteria>
</Task>

## Main tasks

<Task title="4. A copy versus the original" level="medium" time="12">
<Goal>see the difference between `slice` and `splice` with your own eyes.</Goal>

Take the array `["a", "b", "c", "d", "e"]`. Do two things in this order:

1. get a copy of the elements with indices 1–3 and print the source array;
2. remove two elements from the source array starting at index 1 and print it again.

<Hint>
The second argument of `slice` is “up to which index, not including it”: elements 1–3 need
`slice(1, 4)`. The second argument of `splice` is “how many to remove”.
</Hint>

<WriteBox>
the result of each line and the conclusion: which method spoiled the source array.
</WriteBox>

<Criteria>
- after the first step the array did not change;
- after the second it changed;
- the conclusion is written in the notebook in one sentence.
</Criteria>
</Task>

<Task title="5. A timetable editor" level="medium" time="15">
<Goal>use `splice` for inserting and replacing.</Goal>

Given the timetable: `["algebra", "physics", "PE", "history"]`. Do this:

- insert “computer science” between physics and PE, removing nothing;
- replace “history” with “geometry”;
- remove the first lesson;
- print the result as a string joined with “ → ”.

<Hint>
Inserting without removing: `arr.splice(index, 0, value)`. The string is made with the method
`join(" → ")`.
</Hint>

<Criteria>
- all three changes are made through `splice`;
- the result is printed as one line;
- the order of the subjects is correct.
</Criteria>
</Task>

<Task title="6. Two groups of methods" level="medium" time="12">
<Goal>check in practice which methods change an array.</Goal>

For each method on the list run it on the array `[3, 1, 2]` and write into a table:
what the method returned and whether the source array changed. The methods: `push`, `slice`,
`reverse`, `concat`, `splice`, `join`, `toReversed`.

<Example>
```js
let a = [3, 1, 2];
const r = a.push(4);
console.log(r);   // what the method returned
console.log(a);   // whether the array changed
```
</Example>

<Criteria>
- the table of seven rows is filled in;
- each method is checked on a fresh array;
- the methods are correctly divided into two groups.
</Criteria>
</Task>

<Task title="7. The marks of a class" level="medium" time="11">
<Goal>build a small program from familiar methods.</Goal>

The array of marks `[5, 3, 4, 5, 2, 5]`. Print: how many marks in all, the index of the first five,
the index of the last five, whether there is a two, the list of marks as a string with commas, and the same list
in reverse order — so that the source array stays untouched.

<Hint>
For the reverse order without spoiling the original — `toReversed()`. At the end check
`console.log(marks)`: the array must be the same as before.
</Hint>

<Criteria>
- six answers are printed;
- after all the actions the source array is still `[5, 3, 4, 5, 2, 5]`.
</Criteria>
</Task>

## Starred tasks

<Task title="8. Traps: new Array and holes" level="hard" time="10">
<Goal>figure out why the constructor behaves unusually.</Goal>

Run and explain each line:

```js
console.log(Array.of(3));
console.log(new Array(3));
console.log(new Array(3).length);
console.log(Array.from("777"));
const h = [1, , 3];
console.log(h.includes(undefined), h.indexOf(undefined));
// console.log(new Array(2.5)); — uncomment it and read the error
```

<Hint>
Holes are described in section 3 of the lecture: when reading, a hole looks like `undefined`, but
search methods see it differently.
</Hint>

<Criteria>
- the result is written down for each line;
- the name of the error from the last line is found and written down;
- it is explained why `includes` and `indexOf` answered differently on the same array;
- a conclusion is drawn about which way to create an array in everyday work.
</Criteria>
</Task>

<Task title="9. The three latest purchases" level="hard" time="10">
<Goal>build a solution from several methods and not spoil the data.</Goal>

There is a purchase history: `["bread", "tea", "rice", "butter", "sugar", "salt"]`.
Write code that prints the three latest purchases in reverse order (the newest first),
as one string separated by commas. The source array must not be changed.

<Hint>
The three from the end are given by `slice(-3)`. A copy can be reversed with the method `toReversed`
or with `slice().reverse()`.
</Hint>

<Criteria>
- the result: “salt, sugar, butter”;
- after running, the source array did not change — checked by printing;
- the solution takes no more than three lines.
</Criteria>
</Task>
