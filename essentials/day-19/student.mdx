# День 19. Массивы

<Subtitle>Выжимка лекции: создание, доступ, добавление и удаление, поиск.</Subtitle>

## Главное

<Definition>
**Массив** — список значений с порядком. Номер элемента называется **индексом**
и начинается с нуля. Длина — `length`, индекс последнего — `length - 1`.
</Definition>

<KeyPoint>
Методы делятся на две группы: одни **меняют** исходный массив, другие возвращают
**новое значение**. Это главное, что нужно запомнить с этого дня.
</KeyPoint>

## Создание

```js
const marks = [5, 4, 5];        // литерал — обычный способ
const empty = [];               // пустой, заполним позже
Array.of(7);                    // [7]
Array.from("Мары");             // ["М", "а", "р", "ы"]
new Array(7);                   // пустой массив длиной 7 — так не пишем
```

## Доступ

```js
const a = ["x", "y", "z"];
a[0];           // "x"
a.at(-1);       // "z" — последний
a.length;       // 3
a[1] = "Y";     // замена по индексу
```

## Добавить и удалить

| Метод | Где | Возвращает |
| --- | --- | --- |
| `push(x)` | конец | новую длину |
| `pop()` | конец | убранный элемент |
| `unshift(x)` | начало | новую длину |
| `shift()` | начало | убранный элемент |

## slice и splice

```js
const l = ["a", "b", "c", "d"];
l.slice(1, 3);        // ["b", "c"] — копия, оригинал цел
l.splice(1, 2, "X");  // оригинал стал ["a", "X", "d"]
```

<Remember>
**slice** — отрезать себе копию. **splice** — вырезать из оригинала.
</Remember>

## Стек и очередь

**Стек** — «последним пришёл, первым ушёл»: `push` + `pop`, как
кнопка «Отменить». **Очередь** — «первым пришёл, первым ушёл»: `push` +
`shift`, как очередь в кассу. Работа с началом (`unshift`, `shift`)
на длинных массивах в сотни раз медленнее, чем с концом.

## Поиск и склейка

```js
const m = [5, 4, 5];
m.indexOf(5);       // 0
m.lastIndexOf(5);   // 2
m.indexOf(9);       // -1 — не найдено
m.includes(4);      // true

["Аман", "Мерет"].join(", ");   // "Аман, Мерет"
[1, 2].concat([3]);             // [1, 2, 3] — новый массив
Array.isArray([1]);             // true (typeof тут бесполезен)

[5, 4, 3].with(1, 5);           // [5, 5, 3] — копия с заменой
[5, 4, 3].toSpliced(1, 1);      // [5, 3] — копия без элемента
```

## Дыры и пустой массив

```js
const h = [1, , 3];         // дыра — элемента нет вовсе
h[1];                       // undefined
h.includes(undefined);      // true
h.indexOf(undefined);       // -1 — indexOf дыры пропускает

[].pop();                   // undefined — ошибки нет
[].indexOf(1);              // -1
```

Методы на пустом массиве ошибок не бросают, поэтому ошибка всплывает дальше:
`[].pop().toUpperCase()` — `TypeError`. Если массив может быть пустым,
проверяйте `length` заранее.

## Две группы методов

| Меняют массив | Возвращают новое |
| --- | --- |
| `push`, `pop`, `shift`, `unshift`, `splice`, `reverse`, `fill`, `copyWithin` | `slice`, `concat`, `join`, `at`, `includes`, `indexOf`, `with`, `toReversed`, `toSpliced` |

<NoteBox>
**Частые ошибки.** `if (arr.indexOf(x))` — неверно, если элемент первый:
индекс 0 означает «нет». `new Array(7)` — не `[7]`, а семь пустых мест.
`arr.push(...)` возвращает длину, а не массив.
</NoteBox>
