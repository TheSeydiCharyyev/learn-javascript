# День 19. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Код пишем в файле `arrays.js` и запускаем на странице или в консоли.</Subtitle>

## Разминка

<Task title="1. Список покупок" level="easy" time="6">
<Goal>создать массив и прочитать его элементы.</Goal>

Создайте массив из пяти покупок. Выведите первый элемент, последний через `at`,
длину списка и элемент с индексом 2.

<Criteria>
- последний элемент получен через `at(-1)`, а не по числу 4;
- все четыре значения выведены в консоль.
</Criteria>
</Task>

<Task title="2. Очередь в столовой" level="easy" time="7">
<Goal>потренировать четыре метода концов.</Goal>

Массив `["Аман", "Мерет"]`. Выполните по порядку: пришёл Сапар (в конец),
обслужили первого (убрать с начала), вне очереди зашла Гүлнар (в начало), последний ушёл (убрать с конца).
После каждого шага выводите массив.

<Hint>
Методы, которые убирают элемент, возвращают его: `const served = line.shift();`.
Методы, которые добавляют, возвращают новую длину.
</Hint>

<Criteria>
- использованы все четыре метода: `push`, `shift`,
  `unshift`, `pop`;
- записано, что вернули `shift` и `pop`;
- объяснено, стек это или очередь, если обслуживают через `push` и `shift`.
</Criteria>
</Task>

<Task title="3. Есть ли в списке" level="easy" time="7">
<Goal>различать `indexOf` и `includes`.</Goal>

Массив предметов `["математика", "физика", "информатика"]`. Проверьте двумя способами,
есть ли в нём «физика» и есть ли «химия». Выведите результаты.

<Hint>
`indexOf` отвечает числом, `includes` — `true` или `false`.
</Hint>

<Criteria>
- для каждого предмета показаны оба ответа;
- объяснено, почему `indexOf` вернул −1.
</Criteria>
</Task>

## Основные задания

<Task title="4. Копия против оригинала" level="medium" time="12">
<Goal>увидеть разницу между `slice` и `splice` своими глазами.</Goal>

Возьмите массив `["a", "b", "c", "d", "e"]`. Сделайте две вещи в таком порядке:

1. получите копию из элементов с индексами 1–3 и выведите исходный массив;
2. удалите из исходного массива два элемента начиная с индекса 1 и выведите его снова.

<Hint>
У `slice` второй аргумент — «до какого индекса, не включая»: элементам 1–3 нужен
`slice(1, 4)`. У `splice` второй аргумент — «сколько удалить».
</Hint>

<WriteBox>
результат каждой строки и вывод: какой метод испортил исходный массив.
</WriteBox>

<Criteria>
- после первого шага массив не изменился;
- после второго — изменился;
- в тетради записан вывод одним предложением.
</Criteria>
</Task>

<Task title="5. Редактор расписания" level="medium" time="15">
<Goal>применить `splice` для вставки и замены.</Goal>

Дано расписание: `["алгебра", "физика", "физкультура", "история"]`. Выполните:

- вставьте «информатику» между физикой и физкультурой, ничего не удаляя;
- замените «историю» на «геометрию»;
- уберите первый урок;
- выведите итог строкой через « → ».

<Hint>
Вставка без удаления: `arr.splice(индекс, 0, значение)`. Строка получается методом
`join(" → ")`.
</Hint>

<Criteria>
- все три изменения сделаны через `splice`;
- итог выведен одной строкой;
- порядок предметов правильный.
</Criteria>
</Task>

<Task title="6. Две группы методов" level="medium" time="12">
<Goal>проверить на практике, какие методы меняют массив.</Goal>

Для каждого метода из списка выполните его на массиве `[3, 1, 2]` и запишите в таблицу:
что вернул метод и изменился ли исходный массив. Методы: `push`, `slice`,
`reverse`, `concat`, `splice`, `join`, `toReversed`.

<Example>
```js
let a = [3, 1, 2];
const r = a.push(4);
console.log(r);   // что вернул метод
console.log(a);   // изменился ли массив
```
</Example>

<Criteria>
- таблица из семи строк заполнена;
- каждый метод проверен на свежем массиве;
- методы правильно разделены на две группы.
</Criteria>
</Task>

<Task title="7. Оценки класса" level="medium" time="11">
<Goal>собрать небольшую программу из знакомых методов.</Goal>

Массив оценок `[5, 3, 4, 5, 2, 5]`. Выведите: сколько всего оценок, индекс первой пятёрки,
индекс последней пятёрки, есть ли двойка, список оценок строкой через запятую и тот же список
в обратном порядке — так, чтобы исходный массив остался нетронутым.

<Hint>
Для обратного порядка без порчи оригинала — `toReversed()`. Проверьте в конце
`console.log(marks)`: массив должен быть прежним.
</Hint>

<Criteria>
- шесть ответов выведены;
- после всех действий исходный массив по-прежнему `[5, 3, 4, 5, 2, 5]`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Ловушки: new Array и дыры" level="hard" time="10">
<Goal>разобраться, почему конструктор ведёт себя необычно.</Goal>

Выполните и объясните каждую строку:

```js
console.log(Array.of(3));
console.log(new Array(3));
console.log(new Array(3).length);
console.log(Array.from("777"));
const h = [1, , 3];
console.log(h.includes(undefined), h.indexOf(undefined));
// console.log(new Array(2.5)); — раскомментируйте и прочитайте ошибку
```

<Hint>
Дыры описаны в разделе 3 лекции: при чтении дыра похожа на `undefined`, но
методы поиска видят её по-разному.
</Hint>

<Criteria>
- для каждой строки записан результат;
- найдено и записано название ошибки из последней строки;
- объяснено, почему `includes` и `indexOf` ответили по-разному на один и тот же массив;
- сделан вывод, каким способом создавать массив в обычной работе.
</Criteria>
</Task>

<Task title="9. Три последних покупки" level="hard" time="10">
<Goal>собрать решение из нескольких методов и не испортить данные.</Goal>

Есть история покупок: `["хлеб", "чай", "рис", "масло", "сахар", "соль"]`.
Напишите код, который выводит три последние покупки в обратном порядке (самая свежая первой),
одной строкой через запятую. Исходный массив менять нельзя.

<Hint>
Три с конца даёт `slice(-3)`. Перевернуть копию можно методом `toReversed`
либо `slice().reverse()`.
</Hint>

<Criteria>
- результат: «соль, сахар, масло»;
- после выполнения исходный массив не изменился — проверено выводом;
- решение занимает не больше трёх строк.
</Criteria>
</Task>
