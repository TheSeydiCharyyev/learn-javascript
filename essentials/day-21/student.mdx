# День 21. Объекты

<Subtitle>Выжимка лекции: свойства, проверки, перебор, копии.</Subtitle>

## Главное

<Definition>
Массив — «много однотипного по порядку». Объект — «одно целое из разных частей,
у каждой своё имя». Список товаров — массив объектов.
</Definition>

```js
const student = { name: "Аман", age: 17, city: "Мары" };

student.name;      // "Аман" — точка: имя читается буквально
student["name"];   // "Аман" — скобки: внутри любое выражение
const key = "age";
student[key];      // 17 — ключ в переменной: ТОЛЬКО скобки
student.phone;     // undefined, а не ошибка
```

<KeyPoint>
Скобки обязательны в трёх случаях: ключ в переменной, ключ с пробелом или дефисом,
ключ числовой. Числовые ключи при переборе всегда идут первыми и по возрастанию.
</KeyPoint>

## Менять можно всё

```js
const pupil = { name: "Мерет", age: 16 };

pupil.age = 17;          // изменили
pupil.group = "1-А";     // добавили
delete pupil.name;       // удалили
pupil;                   // { age: 17, group: "1-А" }
```

`const` объекту не мешает: он запрещает менять саму переменную,
а не содержимое. `delete` возвращает `true` почти всегда —
по его результату ничего не проверяют.

## Есть ли свойство

```js
const s = { name: "Аман", phone: undefined };

s.phone !== undefined;        // false — но свойство-то есть
"phone" in s;                 // true
Object.hasOwn(s, "phone");    // true

"toString" in s;              // true  — досталось от языка
Object.hasOwn(s, "toString"); // false — своего нет
```

<Remember>
Для своих данных берите **`Object.hasOwn`**: он отвечает
ровно на заданный вопрос и не находит унаследованное.
</Remember>

## Перебор

```js
Object.keys(student);      // ["name", "age", "city"]
Object.values(student);    // ["Аман", 17, "Мары"]
Object.entries(student);   // [["name", "Аман"], ["age", 17], …]

Object.keys(student).length;   // 3 — у объекта НЕТ length

Object.keys(student).forEach((key) => {
  console.log(key + ": " + student[key]);
});
```

`for...in` короче, но заглядывает в унаследованное и не отдаёт массив,
поэтому в новом коде чаще пишут `Object.keys`.

## Копии и ссылки

```js
const a = { x: 1 };
const b = a;                          // НЕ копия: та же ссылка
const copy = Object.assign({}, a);    // копия верхнего уровня

const defaults = { city: "Мары", group: "1-А" };
const given = { name: "Аман", city: "Ашхабад" };
Object.assign({}, defaults, given);   // { city: "Ашхабад", group: "1-А", name: "Аман" } — {} первым!
Object.assign(defaults, given);       // ОШИБКА:
defaults;                             // { city: "Ашхабад", group: "1-А", name: "Аман" } — испорчен
```

<Remember>
**Копия поверхностная.** Вложенные объекты остаются общими:
после `copy.address.city = "Ашхабад"` изменится и оригинал.
Плоские объекты копируются нормально, вложенные — нет.
</Remember>

## Методы и новое

```js
const o = {
  items: [],
  add(item) { this.items.push(item); },   // курс 2
  count() { return this.items.length; },  // курс 2
};

Object.fromEntries([["a", 1]]);                  // { a: 1 }
Object.groupBy([5, 4, 3, 5, 2], (m) => m >= 4 ? "ок" : "нет");
// { ок: [5, 4, 5], нет: [3, 2] } — метод совсем новый
```

<NoteBox>
**Девять страниц ошибок** — больше, чем в любом другом дне. Почти все
синтаксические: `{ x = 5 }` вместо `{ x: 5 }`, забытая скобка,
точка без имени. Chrome чаще всего говорит «Unexpected token» или «Unexpected identifier» и показывает
место — ищите ошибку строкой выше; формулировки MDN взяты из Firefox, они понятнее.
\
**Две ошибки только в строгом режиме:** присваивание свойства числу
и удаление защищённого свойства. Без строгого режима — тишина. Это четвёртый
и пятый такие случаи в курсе после дней 4, 14 и 16.
</NoteBox>
