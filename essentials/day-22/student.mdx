# День 22. Деструктуризация, spread, `?.`

<Subtitle>Выжимка лекции: разобрать, разложить, безопасно прочитать.</Subtitle>

## Главное

<Definition>
Новых возможностей сегодня нет — есть три короткие записи для вчерашнего:
разобрать объект на части, скопировать и объединить, прочитать поле, которого
может не быть.
</Definition>

## Деструктуризация

```js
const marks = [5, 4, 3];
const [first, second] = marks;   // first = 5, second = 4 — массив ПО ПОЗИЦИИ
const [, , third] = marks;       // third = 3 — пропуск
const [p, q, r, s = 0] = marks;  // s = 0 — умолчание (только на undefined)
const [head, ...tail] = marks;   // head = 5, tail = [4, 3] — остаток
let x = 1;
let y = 2;
[x, y] = [y, x];                 // x = 2, y = 1 — обмен; точка с запятой на строке ВЫШЕ

const student = { name: "Аман", age: 17, address: { city: "Мары" } };
const { name, age } = student;            // name = "Аман", age = 17 — объект ПО ИМЕНИ
const { name: studentName } = student;    // studentName = "Аман" — переименование
const { group = "1-А" } = student;        // group = "1-А" — умолчание
const { address: { city } } = student;    // city = "Мары" — вложенная
const { name: n, ...others } = student;   // others = { age: 17, address: {…} } — остаток
```

<KeyPoint>
У массива соответствие по позиции, имена придумываете вы. У объекта — по имени
свойства, порядок в образце не важен.
</KeyPoint>

Разбирать массив по позициям стоит только там, где позиция что-то значит, —
например, пару «ключ — значение» из `Object.entries`.

## В параметрах и колбэках

```js
function makeRow({ name, marks = [] } = {}) { }   // = {} спасает от вызова без аргументов

const cart = [{ name: "хлеб", price: 3.5 }, { name: "чай", price: 12 }];
cart.map(({ name, price }) => name + " — " + price);   // ["хлеб — 3.5", "чай — 12"]

const prices = { хлеб: 3.5, чай: 12 };
for (const [key, value] of Object.entries(prices)) { }
```

Плюс к краткости: у функции с объектом-параметром **порядок аргументов
перестаёт иметь значение**, и вызов читается сам по себе.

<Remember>
**Три ловушки.** Без `const` нужны круглые скобки:
`({ a } = obj)`. Разобрать `undefined` нельзя —
`TypeError: Cannot destructure property…`. Умолчание не сработает
на `null`.
</Remember>

## Spread — три точки раскладывают

```js
const copy = [...marks];                    // [5, 4, 3] — копия массива
const both = [...marks, ...[2, 1]];         // [5, 4, 3, 2, 1] — объединение
const defaults = { city: "Мары", group: "1-А" };
const given = { name: "Аман", city: "Ашхабад" };
const merged = { ...defaults, ...given };   // { city: "Ашхабад", group: "1-А", name: "Аман" }
const plus = { ...given, year: 2026 };      // копия плюс свойство

Math.max(...marks);   // 5 — массив → аргументы
[..."Аман"];          // ["А", "м", "а", "н"]
```

<Remember>
**Копия поверхностная** — вложенные объекты остаются общими,
как у `Object.assign`.
\
Строку нельзя начинать литералом объекта: в файле `{ ...obj };`
прочтётся как блок — `SyntaxError: Unexpected token '...'`. Кладите
результат в переменную.
</Remember>

## Три точки: где стоят — то и делают

| Место | Что делают | Пример |
| --- | --- | --- |
| объявление функции | **собирают** | `function f(...args)` |
| слева от `=` | **собирают** | `const [a, ...rest] = arr` |
| вызов функции | **раскладывают** | `f(...args)` |
| литерал | **раскладывают** | `[...arr]`, `{ ...obj }` |

## Необязательная цепочка

```js
const pupil = { name: "Мерет" };   // адреса нет
// pupil.address.city   → TypeError: Cannot read properties of undefined (reading 'city')
pupil.address?.city;             // undefined, без ошибки

const key = "name";
pupil?.[key];                    // "Мерет" — свойство по переменной
pupil.greet?.();                 // undefined — метода нет, вызова не было

pupil.address?.city ?? "не указан";   // "не указан"
pupil.address?.city.length;           // undefined — вся цепочка обрывается целиком
```

<NoteBox>
**Чего `?.` не делает:** не спасает от опечатки в имени
свойства (молча `undefined`) и от необъявленной переменной
(`ReferenceError`).
\
**Не ставьте его везде подряд:** программа перестанет падать,
но начнёт врать. Он нужен там, где отсутствие поля — нормальная ситуация.
</NoteBox>
