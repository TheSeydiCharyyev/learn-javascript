День 23. JSON

Выжимка лекции: объект в строку, строка в объект, и что теряется по дороге.

Главное

Объект живёт только в памяти работающей программы. Чтобы сохранить или передать его, нужен текст — этим и занимается JSON. 
const student = { name: "Аман", marks: [5, 4] };
const text = JSON.stringify(student);   // объект → строка
const back = JSON.parse(text);          // строка → НОВЫЙ объект
JSON — не JavaScript, а отдельный текстовый формат. Его понимают все языки, и правила в нём строже.
В JavaScriptВ JSON
{ name: "Аман" }ключ только в двойных кавычках
'Аман'одинарные кавычки запрещены
[1, 2, ]висячая запятая запрещена
// комментарийкомментариев нет
undefined, функциине бывает

Что теряется

JSON.stringify({ fn() {}, undef: undefined, nan: NaN, ok: 1 });
// '{"nan":null,"ok":1}'  — функция и undefined исчезли, NaN стал null

JSON.stringify([1, undefined, 3]);   // "[1,null,3]" — в массиве null
JSON.stringify(undefined);           // undefined, а не строка
Дата переживает только половину круга. stringify запишет её строкой, а parse строкой и оставит: back.when.getFullYear() упадёт с TypeError: … is not a function.

Полезные аргументы

const obj = { name: "Аман", age: 17, secret: "код" };
JSON.stringify(obj, null, 2);         // с отступами — для чтения
JSON.stringify(obj, ["name", "age"]); // '{"name":"Аман","age":17}' — только нужные поля

const saved = '{"when":"2026-09-25"}';
JSON.parse(saved, (key, value) =>
  key === "when" ? new Date(value) : value);   // оживитель: when снова дата

Ошибки

JSON.parse("{a:1}");
// SyntaxError: Expected property name or '}' in JSON at position 1 (line 1 column 2)

JSON.parse("");
// SyntaxError: Unexpected end of JSON input

const a = {}; a.self = a;
JSON.stringify(a);
// TypeError: Converting circular structure to JSON
Chrome обычно называет позицию ошибки — это редкий случай, когда он понятнее Firefox, на формулировках которого написана страница MDN. На «Unexpected token» вместо позиции он показывает сам символ.
Чужие данные разбирают только внутри try/catch из дня 11.

Сравнение через JSON

const a = { name: "Аман", age: 17 };
const c = { age: 17, name: "Аман" };   // те же данные, другой порядок

JSON.stringify(a) === JSON.stringify(c);   // false!

Приём «сравнить записи вместо объектов» работает только если вы сами создали оба объекта одинаково: запись зависит от порядка свойств.

Глубокая копия

const clone = JSON.parse(JSON.stringify(obj));

Работает, потому что parse строит всё заново — общих ссылок не остаётся. Цена: методы, даты, undefined и циклы круг не переживут. Для простых данных — отличный приём.

Где встретится: localStorage хранит только строки (день 31), ответ сервера приходит текстом (день 31), файлы настроек вроде package.json — это обычный JSON.
Для отладки: console.log(JSON.stringify(obj, null, 2)) показывает сложный объект целиком.
  1. Возьмите свой объект из дня 21, запишите его строкой и разберите обратно. Проверьте, что JSON.stringify(JSON.parse(text)) === text.
  2. Добавьте в объект функцию, undefined, NaN и дату. Прогоните через круг и запишите, что стало с каждым из четырёх.
  3. Сломайте JSON тремя способами и запишите текст ошибки вместе с позицией (или символом, если позиции нет) для каждого.
  4. Напишите parseOrNull(text) с try/catch и проверьте её на правильной строке, на битой и на пустой.
