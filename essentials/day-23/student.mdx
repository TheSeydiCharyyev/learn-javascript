# День 23. JSON

<Subtitle>Выжимка лекции: объект в строку, строка в объект, и что теряется по дороге.</Subtitle>

## Главное

<Definition>
Объект живёт только в памяти работающей программы. Чтобы сохранить или передать
его, нужен текст — этим и занимается JSON.
</Definition>

```js
const student = { name: "Аман", marks: [5, 4] };
const text = JSON.stringify(student);   // объект → строка
const back = JSON.parse(text);          // строка → НОВЫЙ объект
```

<KeyPoint>
JSON — не JavaScript, а отдельный текстовый формат. Его понимают все языки,
и правила в нём строже.
</KeyPoint>

| В JavaScript | В JSON |
| --- | --- |
| `{ name: "Аман" }` | ключ только в двойных кавычках |
| `'Аман'` | одинарные кавычки запрещены |
| `[1, 2, ]` | висячая запятая запрещена |
| `// комментарий` | комментариев нет |
| `undefined`, функции | не бывает |

## Что теряется

```js
JSON.stringify({ fn() {}, undef: undefined, nan: NaN, ok: 1 });
// '{"nan":null,"ok":1}'  — функция и undefined исчезли, NaN стал null

JSON.stringify([1, undefined, 3]);   // "[1,null,3]" — в массиве null
JSON.stringify(undefined);           // undefined, а не строка
```

<Remember>
**Дата переживает только половину круга.** `stringify`
запишет её строкой, а `parse` строкой и оставит:
`back.when.getFullYear()` упадёт с
`TypeError: … is not a function`.
</Remember>

## Полезные аргументы

```js
const obj = { name: "Аман", age: 17, secret: "код" };
JSON.stringify(obj, null, 2);         // с отступами — для чтения
JSON.stringify(obj, ["name", "age"]); // '{"name":"Аман","age":17}' — только нужные поля

const saved = '{"when":"2026-09-25"}';
JSON.parse(saved, (key, value) =>
  key === "when" ? new Date(value) : value);   // оживитель: when снова дата
```

## Ошибки

```js
JSON.parse("{a:1}");
// SyntaxError: Expected property name or '}' in JSON at position 1 (line 1 column 2)

JSON.parse("");
// SyntaxError: Unexpected end of JSON input

const a = {}; a.self = a;
JSON.stringify(a);
// TypeError: Converting circular structure to JSON
```

<Remember>
Chrome обычно называет **позицию** ошибки — это редкий случай, когда он
понятнее Firefox, на формулировках которого написана страница MDN. На «Unexpected token»
вместо позиции он показывает сам символ.
\
Чужие данные разбирают только внутри `try/catch` из дня 11.
</Remember>

## Сравнение через JSON

```js
const a = { name: "Аман", age: 17 };
const c = { age: 17, name: "Аман" };   // те же данные, другой порядок

JSON.stringify(a) === JSON.stringify(c);   // false!
```

Приём «сравнить записи вместо объектов» работает только если вы сами создали оба
объекта одинаково: запись зависит от порядка свойств.

## Глубокая копия

```js
const clone = JSON.parse(JSON.stringify(obj));
```

Работает, потому что `parse` строит всё заново — общих ссылок
не остаётся. Цена: методы, даты, `undefined` и циклы круг не переживут.
Для простых данных — отличный приём.

<NoteBox>
**Где встретится:** `localStorage` хранит только строки
(день 31), ответ сервера приходит текстом (день 31), файлы настроек вроде
`package.json` — это обычный JSON.
\
**Для отладки:** `console.log(JSON.stringify(obj, null, 2))`
показывает сложный объект целиком.
</NoteBox>
