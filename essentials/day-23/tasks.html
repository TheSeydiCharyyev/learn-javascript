День 23. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-23.

Разминка

1. Туда и обратно
Легко6 мин

пройти круг превращения и убедиться, что объект новый.

const student = { name: "Аман", age: 17, marks: [5, 4] };

Запишите объект строкой, выведите её и её длину. Разберите обратно, проверьте три вещи: совпадают ли значения, тот ли это объект, и что вернёт JSON.stringify(JSON.parse(text)) === text.

«Тот ли объект» проверяется через === — для объектов он отвечает не «одинаковы ли», а «это одна и та же коробка».
  • строка и её длина записаны;
  • значения после круга совпали, а сравнение объектов дало false;
  • объяснено, почему сравнение строк дало true;
  • записано, что вернёт typeof для строки и для результата разбора.
2. Что теряется
Легко7 мин

увидеть все потери формата своими глазами.

const tricky = {
  name: "Аман",
  fn() { return 1; },
  undef: undefined,
  nan: NaN,
  inf: Infinity,
  when: new Date(2026, 8, 25),
  nested: { ok: 1 },
};

console.log(JSON.stringify(tricky));
console.log(JSON.stringify([1, undefined, 3]));
console.log(JSON.stringify(undefined));
Сравните, сколько свойств было и сколько осталось. Поведение в объекте и в массиве разное — и причина у этой разницы простая.
  • для всех семи свойств записано, что с ними стало;
  • объяснено, почему в массиве вместо пропажи появился null;
  • записано, что вернул третий вызов и какого он типа;
  • после круга проверено typeof back.when и вызван getFullYear — записан текст ошибки.
3. Почини JSON
Легко7 мин

научиться видеть нарушения формата.

Каждая строка — сломанный JSON. Найдите ошибку, не запуская, потом проверьте разбором и почините.

const broken = [
  "{name: 'Аман'}",
  '{"marks": [5, 4,]}',
  "{'name': \"Аман\"}",
  '{"name": "Аман" "age": 17}',
  "{\"ok\": True}",
];
В пятой строке ошибка не из лекции — посмотрите внимательно на слово. В JSON, как и в JavaScript, оно пишется маленькими буквами.
  • для всех пяти названа причина до запуска;
  • записан текст ошибки и позиция для каждой, а где Chrome позицию не называет — символ, на который он жалуется;
  • все пять починены и разбираются;
  • записано, какие три нарушения встречаются чаще всего.

Основные задания

4. Разбор с защитой
Средне12 мин

сделать разбор безопасным для чужих данных.

Напишите parseOrDefault(text, fallback): она разбирает строку, а при любой беде возвращает запасное значение и пишет в консоль понятное сообщение.

Проверьте её на пяти входах: правильный JSON, сломанный, пустая строка, строка "undefined" и null.

Пустую строку и null стоит отсеять до parse — иначе на них потратится исключение там, где достаточно обычной проверки.
  • все пять входов обработаны без падения программы;
  • для каждого записано, что вернулось;
  • сообщение об ошибке включает текст из error.message;
  • объяснено, почему пустую строку проверяют отдельно;
  • добавлен шестой вход — правильный JSON массива — и проверено, что функция работает и с ним.
5. Глубокая копия
Средне13 мин

сравнить три способа копирования на одном объекте.

const order = {
  id: 1,
  customer: { name: "Аман", tags: ["vip"] },
  total: 40.5,
};

Сделайте три копии — через { ...order }, через Object.assign({}, order) и через круг JSON. В каждой измените customer.name и добавьте метку в customer.tags, каждый раз печатая оригинал.

Первые два способа дадут одинаковый результат — и это главное наблюдение задания. Третий отличается, и причина в том, что parse строит объекты заново.
  • для всех трёх способов записано состояние оригинала;
  • названо, какие два способа ведут себя одинаково и почему;
  • проверено clone.customer === order.customer для всех трёх;
  • добавлен в объект метод и дата — записано, что с ними стало в копии через JSON;
  • сделан вывод: когда круг JSON годится, а когда нет.
6. Читаем чужой JSON
Средне12 мин

разобраться в незнакомых данных кодом, а не глазами.

const text = '{"items":[{"id":1,"tags":["a","b"]},{"id":2,"tags":[]}],"total":2}';

Не разглядывая строку, выясните кодом: это объект или массив; какие у него поля; сколько элементов внутри items; какие поля у одного элемента; у всех ли элементов одинаковый набор полей.

Потом выведите эти же данные с отступами.

Последний вопрос решается сравнением Object.keys у элементов — например, через every из дня 20.
  • на все пять вопросов ответ получен кодом, а не чтением;
  • данные выведены с отступами одной строкой кода;
  • найден элемент с пустым массивом и записано, чем он отличается;
  • добавлен третий элемент с лишним полем — проверка «у всех ли одинаковые поля» должна это заметить;
  • записано, зачем такой разбор нужен на практике.
7. «Табель» из строки
Средне13 мин

развести расчёт и показ, как это сделано в лекции.

Скопируйте папку day-22 в day-23 и перестройте:

  • студенты приходят одной строкой JSON и разбираются JSON.parse;
  • makeReport(student) возвращает объект с числами, а не строку;
  • makeRow(report) превращает объект в строку таблицы;
  • отчёт по первому студенту выводится ещё и как JSON с отступами.
  • таблица совпала с днём 22 до символа;
  • в строке JSON все ключи в двойных кавычках — программа запускается;
  • отчёт-объект выведен с отступами;
  • объяснено, почему из строки таблицы числа обратно не достать;
  • весь список отчётов сохранён строкой и разобран обратно — проверено, что совпал.

Со звёздочкой

8. Своё хранилище
Сложно10 мин

собрать пару «сохранить — загрузить», которая не падает никогда.

Настоящее хранилище браузера будет на дне 31, а пока замените его обычным объектом, который хранит только строки.

const store = {};

save("students", [{ name: "Аман", marks: [5, 4] }]);
load("students");           // [{ name: "Аман", marks: [5, 4] }]
load("нет такого", []);     // []
load("битое", []);          // [] и сообщение в консоли
save кладёт строку, load достаёт и разбирает. Три случая, которые нужно пережить: ключа нет, строка пустая, строка сломана.
  • все четыре вызова из примера работают;
  • сломанные данные не роняют программу, а возвращают запасное значение;
  • проверено, что сохранённый и загруженный объекты — разные;
  • добавлено сохранение объекта с датой — записано, что вернулось;
  • объяснено, почему хранилище хранит строки, а не объекты.
9. Шесть подвохов
Сложно10 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

// 1
console.log(JSON.parse({ a: 1 }));

// 2
console.log(JSON.stringify("Аман").length);

// 3
const a = { name: "а" };
a.self = a;
console.log(JSON.stringify(a));

// 4
const o = { x: undefined, y: 1 };
console.log(Object.keys(JSON.parse(JSON.stringify(o))));

// 5
console.log(JSON.parse("2026-09-25"));

// 6
const d = { when: new Date(2026, 8, 25) };
console.log(JSON.parse(JSON.stringify(d)).when.getFullYear());
Четыре падают, два — нет, поэтому запускайте фрагменты по одному. Второй фрагмент не падает, но число удивит: посчитайте буквы в слове «Аман» и сравните.
  • предсказания записаны до запуска;
  • для падающих записан точный текст ошибки;
  • объяснено, откуда взялась длина во втором фрагменте;
  • объяснено, куда делось свойство в четвёртом;
  • все шесть переписаны правильно.
