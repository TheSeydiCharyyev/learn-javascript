# День 24. DOM: находим элементы

<Subtitle>Выжимка лекции: дерево страницы, поиск по `id` и селектору, переходы по соседям.</Subtitle>

## Главное

<Definition>
**DOM** — дерево объектов, которое браузер строит из HTML. JavaScript
меняет не файл, а это дерево. Вход в него — переменная `document`.
Это возможность браузера, а не языка: в Node `document` нет.
</Definition>

<KeyPoint>
Скрипт подключаем с `defer`. Без него код выполнится раньше, чем браузер
дочитает разметку, и `document.body` окажется `null`.
</KeyPoint>

```js
document.title;           // надпись на вкладке — можно и поменять
document.body.nodeName;   // "BODY" — имя тега большими буквами
document.body.nodeType;   // 1 — элемент (3 — текст, 9 — документ)
```

## Найти один элемент

```js
document.getElementById("title");     // id без решётки
document.querySelector("#title");     // тот же элемент через селектор
document.querySelector(".student");   // класс — с точкой
document.querySelector("nope");       // null — не нашлось, без ошибки
```

| Селектор | Что ищет |
| --- | --- |
| `li`, `.student`, `#list` | тег, класс, `id` |
| `li.absent` | тег и класс вместе |
| `main p` | `p` на любой глубине внутри `main` |
| `nav > a` | `a` прямо внутри `nav` |
| `li:not(.absent)` | все, кроме |
| `header a, footer p` | то или другое |

<Remember>
Не нашлось — `null`, и ошибка вылезет строкой ниже:
`Cannot read properties of null (reading '…')`. Искать причину нужно
в строке с поиском: опечатка, нет `defer`, чужая страница.
А селектор с ошибкой в записи (`"li..student"`) сразу бросает
`SyntaxError`.
</Remember>

## Найти все

```js
const items = document.querySelectorAll(".student");   // NodeList
items.length;   items[0];   items.item(0);

for (const li of items) { console.log(li); }   // перебор — for...of
items.forEach((li) => console.log(li));        // или forEach

[...items].map((li) => li.nodeName);           // map — только у массива
```

Ничего не нашлось — пустой список с длиной 0, а не `null`.
`for...in` по списку не годится: он выдаёт ещё и `length`,
`item`, `forEach`.

<NoteBox>
Старые методы `getElementsByClassName` и `getElementsByTagName`
возвращают **живую** `HTMLCollection`: она следит за
страницей, но `forEach` у неё нет. `querySelectorAll` делает
снимок. У любого элемента есть свой `querySelector`: так ищут внутри
контейнера, например `main.querySelectorAll("p")`.
</NoteBox>

## Переходы по дереву

| Все узлы | Только элементы |
| --- | --- |
| `parentNode` | `parentElement` |
| `childNodes` | `children` |
| `firstChild` / `lastChild` | `firstElementChild` / `lastElementChild` |
| `previousSibling` / `nextSibling` | `previousElementSibling` / `nextElementSibling` |

<Remember>
Переносы строк и отступы между тегами — тоже узлы, текстовые. Поэтому у списка из
пяти пунктов `childNodes.length` равен 11, а `firstChild` —
не первый пункт. **Ищете теги — берите переходы со словом
`Element`.** На краю дерева переход возвращает `null`.
</Remember>

## Проверить и подняться

```js
const meret = document.querySelector(".absent");   // Мерет

meret.matches(".absent");    // true — подходит ли под селектор
meret.closest("main");       // сам элемент или ближайший подходящий предок
meret.closest("footer");     // null — такого предка нет
document.body.contains(meret);   // true — лежит ли внутри
```

`closest` надёжнее цепочек `parentElement.parentElement`:
лишняя обёртка в разметке его не сломает.
