# День 24. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Почти все задания делаем на учебной странице «Группа JS-1» из лекции: соберите её в папке `day-24` и держите открытой консоль. ## Разминка

<Task title="1. Три способа" level="easy" time="6">
<Goal>убедиться, что разные способы поиска приводят к одному и тому же объекту.</Goal>

Найдите заголовок `h1` тремя способами и положите в три переменные:
через `getElementById`, через `querySelector` по `id`
и через `querySelector` по селектору `"header h1"`. Сравните
их попарно и выведите `nodeName`.

<Hint>
`===` для объектов спрашивает «та же ли это коробка». Если все три
сравнения дадут `true`, значит, в дереве один заголовок, а способов
добраться до него много.
</Hint>

<Criteria>
- три переменные, три разных способа поиска;
- все три сравнения дали `true`;
- записано, что вернул `nodeName` и почему большими буквами;
- объяснено, почему в `getElementById` решётка не нужна,
  а в селекторе обязательна.
</Criteria>
</Task>

<Task title="2. Сколько чего" level="easy" time="7">
<Goal>научиться предсказывать, что найдёт селектор.</Goal>

Сначала на бумаге запишите, сколько элементов найдёт каждый селектор. Потом проверьте:

```js
const selectors = ["li", ".absent", "li:not(.absent)", "p", ".note", "nav a", "main *"];

selectors.forEach((sel) => {
  console.log(sel, document.querySelectorAll(sel).length);
});
```

<Hint>
`*` — любой элемент, а `main *` — любой элемент внутри
`main`. Посчитайте по схеме дерева из лекции, сам `main`
в ответ не входит.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- для всех семи селекторов записан настоящий ответ;
- для каждого промаха объяснено, где ошиблись;
- добавлен восьмой селектор, который не находит ничего, — записано,
  что вернул `length`.
</Criteria>
</Task>

<Task title="3. Узлы и элементы" level="easy" time="7">
<Goal>увидеть текстовые узлы из пробелов и найти закономерность.</Goal>

```js
["#list", "nav", "footer", "header"].forEach((sel) => {
  const el = document.querySelector(sel);
  console.log(sel, el.childNodes.length, el.children.length);
});
```

Предскажите оба числа для каждого элемента, запустите и сравните. Потом выведите
`nodeName` у `firstChild` и у `firstElementChild`
каждого из четырёх.

<Hint>
Посмотрите в разметку: каждый ребёнок стоит на своей строке. Сколько кусков
«перенос строки плюс отступ» получается вокруг пяти пунктов списка?
</Hint>

<Criteria>
- предсказания записаны до запуска;
- найдена формула, связывающая два числа, и проверена на всех четырёх;
- записано, что у всех четырёх `firstChild` — текстовый узел;
- объяснено, что изменится, если записать список в одну строку без пробелов.
</Criteria>
</Task>

## Основные задания

<Task title="4. Селекторы" level="medium" time="12">
<Goal>подобрать селектор под задачу и проверить, что найдено ровно нужное.</Goal>

Создайте страницу с расписанием:

```html
<section id="week">
  <h2>Расписание</h2>
  <ul class="days">
    <li class="day">Понедельник <span class="subject">JavaScript</span></li>
    <li class="day off">Вторник</li>
    <li class="day">Среда <span class="subject">JavaScript</span> <span class="subject extra">HTML</span></li>
    <li class="day off">Четверг</li>
    <li class="day">Пятница <span class="subject">JavaScript</span></li>
  </ul>
  <p class="note">Выходные — суббота и воскресенье</p>
</section>
```

Для каждого пункта напишите один селектор и проверьте его через
`querySelectorAll(...).length`: все дни (5), выходные (2), рабочие дни (3),
все предметы (4), дополнительный предмет (1), предметы среды (2), первый и последний
день (по 1).

<Hint>
Для рабочих дней пригодится `:not`, для среды — `:nth-child(3)`
и пробел перед классом предмета. Проверяйте не только число, но и сами элементы:
выведите список в консоль.
</Hint>

<Criteria>
- все восемь селекторов дают ровно указанное число;
- каждый список выведен в консоль и просмотрен;
- нарочно сломан один селектор (две точки подряд) — записан текст ошибки;
- объяснено, чем `.day .subject` отличается от `.day > .subject`
  и почему здесь они находят одно и то же.
</Criteria>
</Task>

<Task title="5. Прогулка по дереву" level="medium" time="13">
<Goal>добраться до любого элемента переходами, без нового поиска.</Goal>

const meret = document.querySelector(".absent");

Начиная от `meret` и пользуясь только переходами и `closest`,

<Hint>
До дальних элементов удобно идти через общего предка: подняться к

<Criteria>

- до `main` проложено два пути: цепочкой `parentElement`
  и через `closest`;
- объяснено, какие пути сломаются, если обернуть `ul` в лишний

<Task title="6. Где лежит элемент" level="medium" time="12">
<Goal>отвечать на вопросы об элементе через `closest` и `matches`.</Goal>

Напишите `where(el)`: она возвращает `"шапка"`,
`"список"`, `"подвал"` или `"другое"` — смотря
где лежит элемент. Проверьте на заголовке, на Мерет, на абзаце из подвала и на абзаце
с расписанием.

<Example>
```js
where(document.querySelector("h1"));          // "шапка"
where(document.querySelector(".absent"));     // "список"
where(document.querySelector("footer p"));    // "подвал"
where(document.getElementById("info"));       // "другое"
```
</Example>

Потом посчитайте пропустивших двумя способами: через
`querySelectorAll(".absent")` и через массив всех `li`,
`filter` и `matches`.

<Hint>
`closest` возвращает элемент или `null`, а в условии
`if` элемент истинен, `null` — ложен. Для
`filter` список сначала превратите в массив.
</Hint>

<Criteria>
- все четыре проверки дали ожидаемый ответ;
- объяснено, почему абзац с расписанием — «другое», хотя он в `main`;
- оба способа подсчёта дали 2;
- проверено на ссылке из `nav` — записано, что вернула функция.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Путь к элементу" level="hard" time="10">
<Goal>пройти от элемента к корню и записать дорогу.</Goal>

Напишите `path(el)`: она поднимается от элемента до `body`
и возвращает дорогу строкой.

<Example>
```js
path(document.querySelector(".absent"));   // "BODY > MAIN > UL > LI"
path(document.querySelector("nav a"));     // "BODY > HEADER > NAV > A"
path(document.body);                       // "BODY"
```
</Example>

<Hint>
Цикл `while` с `parentElement`: на каждом шаге имя
добавляется в **начало** массива (`unshift` из дня 19),
в конце — `join(" > ")`. Подумайте, когда цикл должен остановиться.
</Hint>

<Criteria>
- все три примера дают указанный ответ;
- функция проверена на каждом пункте списка — дорога у всех одинаковая;
- добавлена `depth(el)` — число шагов до `body`;
- объяснено, что будет, если передать элемент из `head`,
  и как это исправить.
</Criteria>
</Task>

<Task title="9. Шесть подвохов" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня ведёт себя неожиданно.</Goal>

Запускайте фрагменты по одному: вставляйте в консоль каждый отдельно.

```js
// 1
console.log(document.getElementById("#list"));

// 2
console.log(document.querySelector("absent"));

// 3
console.log(document.querySelectorAll("li").map((li) => li.nodeName));

// 4

// 5
const first = document.querySelector("li");
console.log(first.closest(".student") === first);

// 6

```

<Hint>
Падает только один фрагмент. Ещё два молча возвращают `null`,
а шестой печатает то, что обычно видят у несуществующего свойства.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- для падающего фрагмента записан точный текст ошибки;
- объяснено, почему пятый даёт `true`;
- объяснено, откуда в четвёртом взялось такое имя;
- все шесть переписаны так, чтобы делать то, что, видимо, хотел автор.
</Criteria>
</Task>
