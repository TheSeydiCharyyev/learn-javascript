# Day 25. Changing the page

<Subtitle>A summary of the lecture: text, markup, attributes, classes, styles and your own data in the markup.</Subtitle>

## The main points

<Definition>
An element’s properties come in levels: `Node` gives `textContent`,
`Element` gives `innerHTML`, attributes and classes, `HTMLElement` gives
`innerText`, `style`, `dataset`, `hidden`.
A text node has neither classes nor style: it is not an element.
</Definition>

## Text and markup

```js
const el = document.querySelector("#info");
el.textContent = "text";           // tags stay letters; erases all the children
el.innerText;                      // "text" — as on the screen, without hidden parts
el.innerHTML = "<b>bold</b>";       // the string is parsed as HTML
el.insertAdjacentHTML("beforeend", "<i>the end</i>");   // next to it, the old part is untouched
```

<Remember>
**Data — only through `textContent`.** Through `innerHTML`
a string from data becomes markup, and a handler like `onerror` in it becomes code (XSS).
If you need both markup and data, write the markup as your own string and put the data into a ready
element as text.
</Remember>

`innerHTML += …` rebuilds all the contents: it is slow, and saved
references to the old elements lead nowhere. Append with `insertAdjacentHTML`.

## Attributes

```js
const link = document.querySelector("nav a");
link.getAttribute("href");         // "#list" — as in the markup, or null
link.href;                         // the full address — a reflecting property
link.setAttribute("title", "…");
link.removeAttribute("title");
link.hasAttribute("title");        // false — the attribute is removed
```

| Attribute | Property |
| --- | --- |
| `id` | `el.id` — `""` if there is no attribute |
| `class` | `el.className`, `el.classList` |
| `data-group-name` | `el.dataset.groupName` |
| `hidden` | `el.hidden` — `true` / `false` |

<Remember>
Everything read from the page is a **string**: `setAttribute("title", null)`
writes `"null"`, and `dataset.id + 1` gives `"21"`. A number —
through `Number`. For flag attributes presence matters: `hidden="false"` hides the element.
</Remember>

## Classes and style

```js
const li = document.querySelector(".absent");   // Meret
li.classList.add("star", "late");
li.classList.remove("late");
li.classList.toggle("star");         // false — it was there, removed; if not, it would be true
li.classList.toggle("star", li.dataset.id === "2");   // by condition: true
li.classList.contains("absent");     // true
li.classList.replace("absent", "late");   // true — replaced

li.className = "star";               // careful: erases all the other classes

const percent = 75;
li.style.backgroundColor = "#f5f3ff";   // camelCase names
li.style.width = percent + "%";         // units are required
li.style.color = "";                    // remove
```

<NoteBox>
`style` sees only the inline style: it will not show a color from a class. Its mistakes
are silent — a number without units, a typo in the value or in the name simply do nothing.
That is why **the look goes into classes** named by meaning (`absent`,
not `gray`), and `style` is only for what the program calculates.
</NoteBox>

## Your own data

```js
const meret = document.querySelector('[data-id="2"]');
meret.dataset.id;                   // "2" from data-id="2" — a string
Number(meret.dataset.id) + 1;       // 3
meret.dataset.groupName = "JS-1";   // data-group-name="JS-1" will appear
delete meret.dataset.groupName;     // true — and the attribute is gone
```

A name from the markup in the code: drop `data-`, and each hyphen with a letter after it
turns into a capital letter. An element with data is easy to find with an attribute selector:
`[data-name="Sapar"]`. And on day 27 `dataset` will tell which
student was clicked.

## Hide and scroll

```js
const secret = document.querySelector("#secret");
secret.hidden = true;                          // hide
secret.hidden = false;                         // show

const footer = document.querySelector("footer");
footer.scrollIntoView({ behavior: "smooth" }); // scroll smoothly to the element
```
