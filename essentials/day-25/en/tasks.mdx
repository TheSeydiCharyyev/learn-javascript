<Task title="2. Text or markup" level="easy" time="7">

Predict the four values, run the code, look at the page after each write.

<Hint>

- it is written down which of the two ways fits a name that came from a form;

</Criteria>
</Task>

## Starred tasks

<Task title="8. A safe card" level="hard" time="10">
<Goal>show other people’s data in your own markup so that it does not become code.</Goal>

Add an empty `<div id="card"></div>` to the page and write
`showStudent(card, student)`: it writes the card’s markup — a heading and a paragraph —
as its own string, and puts the name and the marks into them as text.

<Example>
```js
showStudent(card, { name: "Aman", marks: [5, 4, 5] });
// <h3>Aman</h3><p class="marks">Marks: 5, 4, 5</p>

showStudent(card, { name: "<img src=x onerror=alert(1)>", marks: [3] });
// the name is seen as letters, no alert window appears
```
</Example>

<Hint>
`card.innerHTML = '<h3></h3><p class="marks"></p>'`, then
`querySelector` inside the card and `textContent`. The marks are glued
into a string by `join` from day 19.
</Hint>

<Criteria>
- both calls give the expected look, `alert` does not fire;
- it is checked that there is not a single `img` inside the card;
- the name is also saved in `dataset.name`;
- for comparison the dangerous string is written through `innerHTML` — it is written down
  what happened, and it is explained why.
</Criteria>
</Task>
