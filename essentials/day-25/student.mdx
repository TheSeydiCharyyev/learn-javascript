# День 25. Меняем страницу

<Subtitle>Выжимка лекции: текст, разметка, атрибуты, классы, стили и свои данные в разметке.</Subtitle>

## Главное

<Definition>
Свойства элемента приходят по уровням: `Node` даёт `textContent`,
`Element` — `innerHTML`, атрибуты и классы, `HTMLElement` —
`innerText`, `style`, `dataset`, `hidden`.
У текстового узла нет ни классов, ни стиля: он не элемент.
</Definition>

## Текст и разметка

```js
const el = document.querySelector("#info");
el.textContent = "текст";          // теги останутся буквами; стирает всех детей
el.innerText;                      // "текст" — как на экране, без спрятанного
el.innerHTML = "<b>жирный</b>";     // строка разбирается как HTML
el.insertAdjacentHTML("beforeend", "<i>в конец</i>");   // рядом, старое не трогает
```

<Remember>
**Данные — только через `textContent`.** Через `innerHTML`
строка из данных станет разметкой, а обработчик вроде `onerror` в ней — кодом (XSS).
Нужны и разметка, и данные — разметку пишем своей строкой, данные кладём в готовый
элемент текстом.
</Remember>

`innerHTML += …` пересобирает всё содержимое: медленно, а сохранённые
ссылки на старые элементы ведут в никуда. Дописывать — через `insertAdjacentHTML`.

## Атрибуты

```js
const link = document.querySelector("nav a");
link.getAttribute("href");         // "#list" — как в разметке, или null
link.href;                         // полный адрес — свойство-отражение
link.setAttribute("title", "…");
link.removeAttribute("title");
link.hasAttribute("title");        // false — атрибут убран
```

| Атрибут | Свойство |
| --- | --- |
| `id` | `el.id` — `""`, если атрибута нет |
| `class` | `el.className`, `el.classList` |
| `data-group-name` | `el.dataset.groupName` |
| `hidden` | `el.hidden` — `true` / `false` |

<Remember>
Всё, что читается со страницы, — **строки**: `setAttribute("title", null)`
запишет `"null"`, а `dataset.id + 1` даст `"21"`. Число —
через `Number`. У атрибутов-флажков важно наличие: `hidden="false"` элемент прячет.
</Remember>

## Классы и стиль

```js
const li = document.querySelector(".absent");   // Мерет
li.classList.add("star", "late");
li.classList.remove("late");
li.classList.toggle("star");         // false — был, убрал; не было бы — true
li.classList.toggle("star", li.dataset.id === "2");   // по условию: true
li.classList.contains("absent");     // true
li.classList.replace("absent", "late");   // true — заменил

li.className = "star";               // осторожно: стирает все остальные классы

const percent = 75;
li.style.backgroundColor = "#f5f3ff";   // имена «верблюдом»
li.style.width = percent + "%";         // единицы обязательны
li.style.color = "";                    // убрать
```

<NoteBox>
`style` видит только встроенный стиль: цвет от класса он не покажет. Ошибки в
нём молчат — число без единиц, опечатка в значении или в имени просто ничего не делают.
Поэтому **оформление — классами** с именами по смыслу (`absent`,
а не `gray`), а `style` — только для того, что вычисляет программа.
</NoteBox>

## Свои данные

```js
const meret = document.querySelector('[data-id="2"]');
meret.dataset.id;                   // "2" из data-id="2" — строка
Number(meret.dataset.id) + 1;       // 3
meret.dataset.groupName = "JS-1";   // появится data-group-name="JS-1"
delete meret.dataset.groupName;     // true — и атрибут исчез
```

Имя из разметки в код: убираем `data-`, каждый дефис с буквой после него
превращается в большую букву. Элемент с данными легко найти селектором по атрибуту:
`[data-name="Сапар"]`. А на дне 27 `dataset` подскажет, по какому
студенту щёлкнули.

## Спрятать и прокрутить

```js
const secret = document.querySelector("#secret");
secret.hidden = true;                          // спрятать
secret.hidden = false;                         // показать

const footer = document.querySelector("footer");
footer.scrollIntoView({ behavior: "smooth" }); // плавно прокрутить к элементу
```
