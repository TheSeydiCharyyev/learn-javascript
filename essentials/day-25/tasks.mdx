# День 25. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем на учебной странице из лекции (папка `day-25`), задание 7 — в папке `day-25/tabel`. Перед каждым заданием обновляйте страницу (<Kbd>F5</Kbd>), чтобы начинать с исходного вида.</Subtitle>

## Разминка

<Task title="1. Три способа прочитать" level="easy" time="6">
<Goal>увидеть разницу между `textContent`, `innerText` и `innerHTML`.</Goal>

Выведите в консоль все три свойства сначала у абзаца `#info`, потом
у `main`. Для `main` проверьте через `includes`,
в каком из трёх есть слово «Контрольная».

<Hint>
У `#info` два свойства совпадут, а третье будет с тегом. У `main`
разойдутся все три: смотрите на спрятанный абзац и на отступы из файла.
</Hint>

<Criteria>
- все шесть значений выведены и записаны;
- объяснено, откуда в `innerHTML` взялся `<b>`;
- объяснено, почему «Контрольная» есть только в двух из трёх;
- записано, какое свойство вы возьмёте, чтобы показать текст пользователю, и почему.
</Criteria>
</Task>

<Task title="2. Текст или разметка" level="easy" time="7">
<Goal>увидеть, как одна строка ведёт себя в двух свойствах.</Goal>

```js
const p = document.querySelector("footer p");

p.textContent = "<b>Мары</b>, 2026";
console.log(p.children.length, p.innerHTML);

p.innerHTML = "<b>Мары</b>, 2026";
console.log(p.children.length, p.textContent);
```

Предскажите четыре значения, запустите, посмотрите на страницу после каждой записи.

<Hint>
После первой записи `innerHTML` покажет теги странно — через
`&lt;` и `&gt;`. Так браузер записывает угловые скобки,
которые должны остаться буквами.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- объяснено, откуда в `innerHTML` взялись `&lt;` и `&gt;`;
- записано, какой из двух способов годится для имени, пришедшего из формы;
- тот же абзац сделан приёмом «разметка своя, данные текстом»: `<b>`
  из своей строки, «Мары» — через `textContent`.
</Criteria>
</Task>

<Task title="3. Атрибуты ссылки" level="easy" time="7">
<Goal>пройти все четыре метода атрибутов и одно отражение.</Goal>

Возьмите вторую ссылку в `nav`. Сравните `getAttribute("href")`
и свойство `href`. Проверьте, есть ли у ссылки `title`, поставьте его,
прочитайте, запишите в него `null`, прочитайте снова и уберите.

<Hint>
После записи `null` проверьте не только значение, но и `typeof`.
</Hint>

<Criteria>
- записаны оба варианта адреса и объяснено, откуда разница;
- после записи `null` записан ответ `getAttribute` и его тип;
- в конце `hasAttribute("title")` даёт `false`;
- во вкладке Elements прослежено, как атрибут появлялся и исчезал.
</Criteria>
</Task>

## Основные задания

<Task title="4. Классы" level="medium" time="12">
<Goal>менять классы у многих элементов разом и не терять чужие классы.</Goal>

Одним `forEach` по всем `li` дайте класс `star` тем,
кто был на занятии, — через `toggle` с условием. Проверьте, у кого теперь
`star`. Затем вторым `forEach` переключите всем класс
`absent` и проверьте, кто теперь «отсутствует».

<Hint>
«Был на занятии» — значит, нет класса `absent`:
`!li.classList.contains("absent")`. После второго перебора отсутствующими
должны оказаться ровно те, у кого звезда.
</Hint>

<Criteria>
- звезда ровно у трёх студентов — Аман, Гүлнар, Огулджан;
- после переключения отсутствующими стали те же трое;
- у Мерет сделано `className = "star"` — записано, какие классы пропали;
- вызван `classList.add("star absent")` — записан текст ошибки и исправлен вызов.
</Criteria>
</Task>

<Task title="5. Стиль или класс" level="medium" time="12">
<Goal>сравнить два способа оформления на одной задаче.</Goal>

Сделайте заголовок фиолетовым на светлом фоне с отступом 8 пикселей: сначала через
`style` (три свойства), потом — через класс `accent`, который вы
добавите в `<style>` страницы. Потом уберите оформление в обоих вариантах.

<Hint>
Для `style` понадобятся `color`, `backgroundColor`
и `padding`. Прочитайте `getAttribute("style")` — цвет фона
вернётся не в том виде, в каком вы его записали.
</Hint>

<Criteria>
- оба варианта дают одинаковый вид;
- записано, в каком виде вернулся цвет фона;
- проверено, что `fontSize = 24` и опечатка `colour`
  ничего не меняют, — и что ошибки при этом нет;
- посчитано, сколько строк кода нужно, чтобы убрать оформление в каждом варианте;
- сделан вывод, когда брать класс, а когда `style`.
</Criteria>
</Task>

<Task title="6. Данные в разметке" level="medium" time="13">
<Goal>хранить числа в `data-`атрибутах и не спотыкаться о строки.</Goal>

Соберите массив номеров из `data-id` всех пунктов и посчитайте сумму.
Потом раздайте пунктам оценки из массива через `dataset.mark` и найдите
селектором тех, у кого 5. Посчитайте средний балл, читая оценки обратно из `dataset`.

```js
const marks = [5, 3, 4, 5, 4];   // по порядку пунктов списка
```

<Hint>
Сумма номеров должна быть 15, а средний балл — 4.2. Если вышло
`"012345"`, вспомните разбор из лекции: где нужен `Number`?
</Hint>

<Criteria>
- сумма номеров равна 15, средний балл — 4.2;
- селектор `[data-mark="5"]` нашёл двоих — Амана и Сапара;
- во вкладке Elements видны появившиеся атрибуты `data-mark`;
- объяснено, почему после `dataset.mark = 5` значение читается строкой;
- добавлен атрибут через `dataset.lastVisit` — записано, как он называется в разметке.
</Criteria>
</Task>

<Task title="7. «Табель» в цвете" level="medium" time="13">
<Goal>раскрасить строки по вердикту, не записав в код ни одного цвета.</Goal>

Скопируйте папку `day-24/tabel` в `day-25/tabel` и перестройте:

- функция `write` удалена, тексты пишутся прямо через `textContent`;
- каждая строка получает класс по вердикту из объекта `VERDICT_CLASS`,
  строка без оценок — класс `empty`;
- цвета классов — в `<style>` страницы;
- в строке хранится имя студента: `dataset.name`;
- под таблицей абзац «Отличников: 2 из 5».

<Criteria>
- числа совпали с днём 24, строки окрашены: две зелёные, по одной голубой и жёлтой,
  Гүлнар — серым курсивом;
- в `app.js` нет ни одного цвета;
- строка Сапара найдена селектором `[data-name="Сапар"]`;
- имя Амана заменено на `<b>Аман</b>` — проверено, что на
  странице видны теги, а не жирный шрифт;
- подставлен вердикт, которого нет в таблице классов, — записано, какой класс
  получила строка.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Безопасная карточка" level="hard" time="10">
<Goal>выводить чужие данные в свою разметку так, чтобы они не стали кодом.</Goal>

Добавьте на страницу пустой `<div id="card"></div>` и напишите
`showStudent(card, student)`: разметку карточки — заголовок и абзац —
она пишет своей строкой, а имя и оценки кладёт в них текстом.

<Example>
```js
showStudent(card, { name: "Аман", marks: [5, 4, 5] });
// <h3>Аман</h3><p class="marks">Оценки: 5, 4, 5</p>

showStudent(card, { name: "<img src=x onerror=alert(1)>", marks: [3] });
// имя видно буквами, окно alert не появляется
```
</Example>

<Hint>
`card.innerHTML = '<h3></h3><p class="marks"></p>'`, дальше
`querySelector` внутри карточки и `textContent`. Оценки в строку
склеит `join` из дня 19.
</Hint>

<Criteria>
- оба вызова дают ожидаемый вид, `alert` не срабатывает;
- проверено, что внутри карточки нет ни одного `img`;
- имя сохранено ещё и в `dataset.name`;
- для сравнения опасная строка записана через `innerHTML` — записано,
  что произошло, и объяснено почему.
</Criteria>
</Task>

<Task title="9. Шесть подвохов" level="hard" time="10">
<Goal>собрать вместе всё, что сегодня молчит или удивляет.</Goal>

```js
// 1
const h = document.querySelector("#title");
h.style.fontSize = 24;
console.log(h.style.fontSize);

// 2
console.log(document.querySelector("li").dataset.id + 1);

// 3
const secret = document.querySelector("#secret");
secret.setAttribute("hidden", "false");
console.log(secret.hidden);

// 4
const meret = document.querySelector(".absent");
meret.className = "star";
console.log(meret.classList.contains("student"));

// 5
document.querySelector("#list").textContent = "Список:";
console.log(document.querySelectorAll("li").length);

// 6
document.querySelector("h1").classList.add("star absent");
```

<Hint>
Падает только последний. Остальные пять работают молча — и каждый делает не то,
чего, скорее всего, ждал автор. Первый печатает пустую строку.
</Hint>

<Criteria>
- предсказания записаны до запуска;
- для шестого записан точный текст ошибки;
- для каждого из первых пяти объяснено, что пошло не так;
- все шесть переписаны так, чтобы делать то, что, видимо, хотел автор.
</Criteria>
</Task>
