## Warm-up

<Task title="1. Create and insert" level="easy" time="6">
<Goal>go through the three steps “create — fill — insert” and see each of them.</Goal>

Create the list item “Nazik” with the class `student` and the attribute
`data-id="6"`. Print `isConnected` and the number of items on the page
before inserting and after. Then create “Ilýas” and put him first.

<Hint>
The number of items on the page is `document.querySelectorAll("li").length`.
Before inserting it does not change, however you fill the new element.
</Hint>

<Criteria>
- before inserting `isConnected` is `false`, there are 5 items;
- after — `true`, 6 items, Nazik is the last;
- Ilýas is inserted with `prepend` and stands first;
- it is written down what `append` returned, and it is explained why.
</Criteria>
</Task>

<Task title="2. Four places" level="easy" time="7">
<Goal>tell inserting inside from inserting next to it.</Goal>

Create four paragraphs with the texts “before”, “at the start”, “at the end”, “after” and put
them around the list `#list`, one for each method: `before`,
`prepend`, `append`, `after`. Print
the `innerHTML` of `main` and find all four.

<Hint>
Two paragraphs will end up inside `<ul>` — next to the items, two outside —
next to the list itself. A paragraph inside a list formally breaks the markup, but for
the experiment it does not matter.
</Hint>

<Criteria>
- all four paragraphs stand where expected;
- it is written down which two are inside `ul` and which two are outside;
- `after` is called on a new paragraph that is not inserted — it is written down what happened;
- the same experiment is repeated with strings instead of paragraphs.
</Criteria>
</Task>

<Task title="3. Move or copy" level="easy" time="7">
<Goal>make sure that inserting moves, and a copy is made explicitly.</Goal>

Move the first list item to the end with `append` and count the items.
Then insert its deep copy at the end and count again. Compare a deep and
a shallow copy. Finally, copy the heading `#title` and insert the copy into the footer.

<Hint>
After copying the heading, check `querySelectorAll("#title").length`.
What needs to be done with the copy before inserting?
</Hint>

<Criteria>
- after moving there are still 5 items, after the copy — 6;
- it is written down how a shallow copy differs from a deep one;
- two elements with `id="title"` are found, and this is fixed by changing
  the copy’s `id`;
- it is explained why a node cannot stand in two places.
</Criteria>
</Task>

<Task title="5. A list from an array" level="medium" time="13">
<Goal>write a function that redraws a list from data.</Goal>

Write `toItem(name)` and `renderList(list, names)` from the lecture.
Call `renderList` three times: with three names, with the same ones again
and with an empty array. Then teach the items to number themselves.

<Example>
```js
renderList(list, ["Aman", "Meret", "Gülnar"]);
// <li>1. Aman</li><li>2. Meret</li><li>3. Gülnar</li>
```

</Example>

<Hint>

`toItem` has a second parameter, it gets that number — starting from zero.
</Hint>

<Criteria>

- the items are numbered from one;
- clearing is temporarily removed from `renderList` — it is written down what happened
  after the second call;

</Task>

<Task title="6. Student cards" level="medium" time="12">
<Goal>build an element with children in the right order.</Goal>

Write `makeCard(student)`: it returns a `<div class="card">`
with a heading with the name, a paragraph “Marks: …” and a paragraph “Average: …” with two digits after
the point. Insert the cards of all students into `main` with one line.

```js
const group = [
  { name: "Aman", marks: [5, 4, 5] },
  { name: "Meret", marks: [3, 4] },
  { name: "Sapar", marks: [5, 5, 4, 5] },

```

<Hint>
First create all four elements, then fill them, then
`card.append(name, marks, avg)`. The average mark — with `reduce`
and `toFixed(2)`.
</Hint>

<Criteria>
- there are three cards on the page, the averages are 4.67, 3.50, 4.75;
- all the data is written through `textContent`;
- the cards are inserted with one `append` call;
- it is explained why a card is built before inserting, not on the page.
</Criteria>
</Task>

<Task title="9. Six catches" level="hard" time="10">
<Goal>gather everything that behaves unexpectedly today.</Goal>

```js
// 1
const li = document.createElement("li");
li.textContent = "Nazik";
console.log(document.querySelectorAll("li").length);

// 2
const list = document.querySelector("#list");
console.log(list.append(li));

// 3
list.append(list.firstElementChild);
console.log(list.children.length);

// 4
for (const item of list.children) {
  item.remove();
}
console.log(list.children.length);

// 5
const p = document.createElement("p");
p.after("text");
console.log(p.nextSibling);

// 6
list.appendChild("Ilýas");
```

<Hint>
The fragments go in a row, and each depends on the previous ones. Only the last one crashes.
In the fourth, work out on paper which numbers are removed at each step.
</Hint>

<Criteria>
- the predictions are written down before running;
- for the sixth the exact error text is written down;
- for each of the first five it is explained where the answer came from;
- the fourth is rewritten so that all the items are removed.
</Criteria>
</Task>
