# День 26. Создаём и удаляем элементы

<Subtitle>Выжимка лекции: создать, вставить, перенести, скопировать, удалить — и собрать кусок дерева.</Subtitle>

## Главное

<Definition>
Порядок всегда один: **создать, наполнить, вставить**. Созданный элемент
живёт в памяти и на странице не виден, пока его не вставили: `isConnected` —
`false`.
</Definition>

```js
const list = document.querySelector("#list");
const li = document.createElement("li");   // создать
li.textContent = "Назик";                    // наполнить — данные только текстом
li.classList.add("student");
list.append(li);                             // вставить
```

## Куда вставить

```js
const a = document.createElement("li");
const p = document.createElement("p");
const title = document.querySelector("#title");

list.append(a, "текст");  // внутрь, в конец; узлы и строки, сколько угодно
list.prepend(a);          // внутрь, в начало
title.before(p);          // рядом, перед элементом
title.after(p);           // рядом, после элемента
list.append(...[...list.children].reverse());   // массив элементов — одним вызовом
```

<Remember>
`append` ничего не возвращает: `const x = list.append(li)` даст
`undefined`. Всё, что не узел, он превращает в текст — даже `null`
и `undefined`. `before` и `after` у элемента без родителя
молча ничего не делают.
</Remember>

## Перенести, скопировать, удалить, заменить

```js
list.prepend(list.lastElementChild);   // вставка существующего — ПЕРЕНОС

const el = document.querySelector(".absent");
el.cloneNode(true);                     // копия с содержимым; без true — пустая оболочка
el.remove();                            // убрать; объект остаётся в переменной

const old = document.querySelector(".absent");
old.replaceWith(el, "текст");           // поставить другое на место
```

<Remember>
Узел не может стоять в двух местах: вставка забирает его со старого. Нужна копия —
`cloneNode(true)`, и сразу смените ей `id`, иначе на странице
окажутся два одинаковых.
</Remember>

<KeyPoint>
`for...of` по `list.children` с `remove` удаляет
каждый второй: живая коллекция сжимается на ходу. Удалять всех —
`querySelectorAll(...).forEach((x) => x.remove())`, очистить целиком —
`list.textContent = ""`.
</KeyPoint>

## Старый набор `Node`

| Старый | Новый |
| --- | --- |
| `parent.appendChild(node)` | `parent.append(node)` |
| `parent.insertBefore(node, ref)` | `ref.before(node)` |
| `parent.removeChild(node)` | `node.remove()` |
| `parent.replaceChild(newNode, oldNode)` | `oldNode.replaceWith(newNode)` |

Старые методы вызываются у родителя, берут один узел, строк не принимают
(`appendChild("текст")` — `TypeError`) и возвращают узел.
`insertBefore(node, null)` вставляет в конец. У `replaceChild`
сначала новый, потом старый.

## Собрать и нарисовать

```js
function toItem(name) {
  const li = document.createElement("li");   // создаём сверху вниз…
  li.textContent = name;
  return li;                                 // …и отдаём, ещё не вставив
}

function renderList(list, names) {
  list.textContent = "";                     // перерисовать = очистить…
  list.append(...names.map(toItem));         // …и вставить заново, разом
}
```

Детей прикрепляют к родителю снизу вверх, а на страницу готовый кусок попадает
один раз. Для данных `createElement` с `textContent` безопаснее
`innerHTML` с шаблонной строкой. Перестановка — это вставка в новом порядке:
`list.append(...[...list.children].reverse())`.

## Ошибки вставки

| Что сделали | Что скажет Chrome |
| --- | --- |
| вставили предка внутрь потомка | `HierarchyRequestError: … The new child element contains the parent.` |
| `removeChild` не у настоящего родителя | `NotFoundError: … is not a child of this node.` |
| `appendChild` со строкой | `TypeError: … parameter 1 is not of type 'Node'.` |

Дерево не даёт сделать из себя не дерево: кругов в нём не бывает.
Новые методы от части этих ошибок избавляют — `el.remove()` сам знает родителя.
