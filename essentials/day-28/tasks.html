День 28. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–5, 8 и 9 делаем на анкете из лекции (папка day-28): разметку и app.js возьмите из раздела 2 и добавьте в <style> правило .invalid { outline: 2px solid #b91c1c; }. Задание 6 — на странице группы из прошлых дней, задание 7 — в папке day-28/tabel.

Разминка

1. Анкета
Легко6 мин

научиться читать и писать значения полей.

В консоли прочитайте через form.elements все значения анкеты: имя, оценки, флажок, группу. Заполните поля руками, снимите флажок, выберите JS-2 — прочитайте снова. Затем запишите в поле имени «Аман» из кода.

У флажка нужно checked, у группы переключателей — form.elements.group.value.
  • записаны значения до и после ручного заполнения;
  • записан typeof значения поля оценок, в которое набрано «5»;
  • проверено, что после снятия флажка атрибут checked в разметке остался;
  • выведено form.name — объяснено, что вернулось и почему.
2. input и change
Легко7 мин

увидеть, когда приходит каждое из двух событий.

Повесьте на поле имени и на флажок оба слушателя: input и change. Каждый пишет в консоль имя события и текущее значение. Наберите имя, уйдите из поля клавишей Tab, щёлкните флажок. Потом смените значения из кода.

Значение в консоль удобно выводить через JSON.stringify — тогда видно и пустую строку, и пробелы.
  • записано, сколько раз пришёл input и сколько change при наборе пятибуквенного имени;
  • записан порядок событий при щелчке по флажку;
  • проверено, что запись из кода не вызвала ни одного события;
  • объяснено, какое событие взять для живого поиска, а какое — для сохранения выбора.
3. Счётчик букв
Легко7 мин

отвечать на ввод на ходу.

Под полем имени показывайте «Букв: N». Если букв больше 20, дописывайте «— слишком длинно» и подсвечивайте поле классом invalid; как только букв снова 20 или меньше — подсветку снимайте.

// набрали «Огулджан Ильясовна Бер»:
// Букв: 22 — слишком длинно, у поля класс invalid
Одна строка управляет классом в обе стороны: toggle со вторым аргументом из дня 25.
  • счётчик меняется на каждую букву и на каждое стирание;
  • подсветка появляется на 21-й букве и исчезает, когда стёрли лишнее;
  • записано, считаются ли пробелы, и решено, нужно ли их считать;
  • имя вписано из кода — объяснено, почему счётчик не обновился.

Основные задания

4. Отправка без перезагрузки
Средне12 мин

перехватить отправку формы и разобраться, что делает браузер без нас.

По отправке анкеты пишите на странице «Добавлен: имя» и очищайте форму. Проверьте отправку щелчком и клавишей Enter в поле. Потом временно уберите preventDefault и посмотрите на адрес страницы.

Слушайте submit формы, а не click кнопки. После отправки форму очищает одна строка — form.reset().
  • обе отправки — щелчком и Enter — дают сообщение и не перезагружают страницу;
  • без preventDefault записан адрес, который получила страница, и объяснено, откуда в нём каждая часть;
  • в форму добавлена кнопка «Подсказка» — объяснено, почему она отправляет форму, и исправлено атрибутом;
  • вместе с формой сбрасывается и сообщение — через событие reset.
5. Проверка ввода
Средне13 мин

проверять данные по одной причине за раз и понятно сообщать об ошибке.

Перед «Добавлен» проверяйте по порядку: имя не пустое; в имени хотя бы 2 буквы; оценки введены; каждая оценка — цифра от 2 до 5. Сообщение об ошибке — на странице, поле с ошибкой подсвечено и получает фокус.

// пусто                  → Введите имя
// «И»                    → Имя слишком короткое
// «Ильяс», без оценок    → Введите оценки
// «Ильяс», «5 7»         → Оценки — цифры от 2 до 5
// «Ильяс», «5 4»         → Добавлен: Ильяс
Оценки — символы строки без пробелов, как в лекции. Проверка «каждая» — это every из дня 20. Каждую ошибку удобно вернуть строкой из отдельной функции check(), а пустая строка значит «всё хорошо».
  • все пять строк примера дают указанный ответ;
  • подсветка снимается, как только человек начинает исправлять поле;
  • имя из одних пробелов считается пустым;
  • объяснено, почему проверки идут по одной и почему именно в таком порядке.
6. Живой поиск
Средне12 мин

отвечать на ввод, пряча и показывая элементы.

На странице группы добавьте над списком поле поиска и абзац под ним. По каждой букве прячьте студентов, в чьём имени нет набранного, и пишите «Найдено: N». Если не нашлось никого — «Никого не нашли».

trim, toLowerCase и includes из дня 16 делают поиск нечувствительным к регистру и пробелам; прятать — свойством hidden из дня 25.
  • «а» оставляет четверых, «ман» — одного, «  МЕРЕТ» — Мерет;
  • пустое поле снова показывает всех;
  • при нуле найденных появляется «Никого не нашли»;
  • объяснено, почему здесь input, а не change.
7. «Табель» с формой
Средне13 мин

добавлять студентов через форму с проверкой.

Скопируйте day-27/tabel в day-28/tabel и добавьте:

  • над таблицей форму: имя, оценки через пробел, кнопка «Добавить»;
  • проверки: пустое имя, повтор имени, нет оценок — сообщение на странице и фокус в поле;
  • новую строку через makeReport, makeRow и addDeleteButton, итог пересчитан, форма очищена;
  • confirm перед удалением строки.
  • «Ильяс», «5 4 9» дают зелёную строку 4.50, 4, 5, 67% и итог «3 из 6»;
  • «  Аман » не добавляется: «Такой студент уже есть»;
  • при Отмене в confirm строка остаётся;
  • makeReport не изменилась ни в одной строке;
  • объяснено, почему проверка повтора защищает удаление со дня 27.

Со звёздочкой

8. Форма туда и обратно
Сложно10 мин

собрать форму в объект и восстановить её из объекта.

Напишите readForm(form), которая возвращает объект со всеми значениями анкеты, и fillForm(form, data), которая раскладывает такой объект обратно по полям. Проверьте круг: заполнить → записать строкой JSON → reset → разобрать строку → fillForm.

const saved = JSON.stringify(readForm(form));
// '{"name":"Ильяс","marks":"5 4 5","present":false,"group":"JS-2"}'
form.reset();
fillForm(form, JSON.parse(saved));   // поля снова как были, включая JS-2
Значение группы переключателей можно не только читать, но и записывать: form.elements.group.value = "JS-2" отметит нужный переключатель.
  • после круга JSON.stringify(readForm(form)) === saved — true;
  • флажок и переключатель восстановились;
  • записано, какие события пришли во время fillForm, и объяснено почему;
  • объяснено, где этот круг пригодится на дне 31, когда появится хранилище браузера.
9. Шесть подвохов
Сложно10 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

В поле оценок набрано «5», в окне prompt нажмут «Отмена».

form.elements.name.addEventListener("input", () => console.log("input!"));

console.log(form.elements.marks.value + 1);                    // 1
console.log(form.name);                                        // 2
form.elements.name.value = "Аман";                             // 3
console.log(form.elements.name.textContent);                   // 4
console.log(Number(form.elements.marks.value) + Number(""));   // 5
console.log(prompt("Имя?").trim());                            // 6
Третья строка ничего не печатает сама — вопрос в том, напечатает ли что-то слушатель. Падает только шестая. В пятой одно из слагаемых неожиданно оказывается нулём.
  • предсказания записаны до запуска;
  • для шестой записан точный текст ошибки;
  • для каждой из первых пяти объяснено, откуда взялся ответ;
  • все шесть переписаны так, чтобы делать то, что, видимо, хотел автор.
