<Task title="5. Your own function with a promise" level="medium" time="13">
<Goal>wrap “the data will come later” in a promise — the way a server does it.</Goal>

Write `loadStudent(name)`: after 500 ms the promise is fulfilled with the student object
from the `group` array, and if there is no such student, it is rejected with the error
“No student: name”. Spaces at the edges of the name do not get in the way. Then write
`averageOf(name)`: it prints the average mark with two digits or the text of the error,
and at the end, in any case, “request finished”.

<Example>
```js
const group = [
  { name: "Aman", marks: [5, 4, 4] },
  { name: "Meret", marks: [3, 3, 4] },
  { name: "Sapar", marks: [5, 5, 4, 5] },
];

averageOf("Meret");   // in 500 ms: Meret: 3.33, then “request finished”
averageOf("Ilýas");   // in 500 ms: No student: Ilýas, then “request finished”
```
</Example>

<Hint>
Inside `new Promise` — `setTimeout`, inside the timer — `find`
from day 20 and exactly one of two calls: `resolve(student)` or
`reject(new Error(…))`. The average — with `reduce`.
</Hint>

<Criteria>
- both examples give what is stated, and “&nbsp;&nbsp;Sapar&nbsp;” gives “Sapar: 4.75”;
- `loadStudent("Meret")` is called in the console without `then` — the state
  of the promise right away and after 500 ms is written down;
- `reject` is replaced with `throw` for a while — it is written down what the
  console showed and what state the promise stayed in, and it is explained why;
- it is explained how `loadStudent` is similar to a request to a server, which will come on day 31.
</Criteria>
</Task>

<Task title="9. Six catches" level="hard" time="10">
<Goal>gather together everything that behaves unexpectedly today.</Goal>

Each line does not do what the author apparently wanted. For each one write down a prediction:
what will appear in the console, and when.

```js
console.log(1, typeof setTimeout(() => {}, 0));                     // 1
setTimeout(console.log("2"), 100);                                  // 2
const p = later(3, 100);
console.log(p);                                                     // 3
p.then((x) => { x * 10; }).then((y) => console.log(y));             // 4
Promise.reject(new Error("five")).finally(() => console.log("5"));  // 5
new Promise(() => {                                                 // 6
  setTimeout(() => { throw new Error("six"); }, 0);
}).catch(() => console.log("6: caught"));
```

<Hint>
No line stops the others: an error in one does not get in the way of the next ones.
In two lines the error will stay uncaught.
</Hint>

<Criteria>
- the predictions are written down before running;
- for lines 5 and 6 the exact text of the red messages in the console is written down;
- for each line it is explained where the result came from;
- all six are rewritten to do what the author wanted.
</Criteria>
</Task>
