# День 32. Мини-проект: каталог с данными с сервера

<Subtitle>Выжимка лекции: как устроено приложение, которое ждёт сервер, и как проверить, что проект готов.</Subtitle>

## Где что живёт

| Данные | Где | Когда появляются |
| --- | --- | --- |
| книги | сервер: `catalog.json` | после `load()` |
| избранное | `localStorage` | при старте, пишется в конце `render` |
| поиск, жанр, флажок | переменные | меняют слушатели |

```js
let books = [];                                                // придут с сервера
let favorites = JSON.parse(localStorage.getItem(KEY)) ?? [];   // сначала прочитать!

async function load() {
  try {
    const response = await fetch("catalog.json");
    if (!response.ok) throw new Error(`сервер ответил ${response.status}`);
    books = await response.json();
    makeGenreButtons();   // один раз — не в render
    render();             // первый показ — только когда данные есть
  } catch (err) {
    error.textContent = `Не удалось загрузить каталог: ${err.message}`;
  } finally {
    loading.hidden = true;
  }
}
```

<KeyPoint>
Страница, которая ждёт сервер, всегда в одном из трёх состояний: загрузка, данные или
ошибка — и каждое человек должен видеть. «Загрузка…» убирают в `finally`, иначе
при ошибке она повиснет рядом с сообщением. `catch` ловит и ошибки в нашем
коде: текст на странице — первое, что читают при любой странности.
</KeyPoint>

## Фильтр из нескольких условий

```js
function isVisible(book) {
  const text = `${book.title} ${book.author}`.toLowerCase();
  if (!text.includes(query)) return false;                              // поиск
  if (genre !== "все" && book.genre !== genre) return false;           // жанр
  if (onlyFavorites && !favorites.includes(book.id)) return false;      // избранное
  return true;                                                          // прошла всё
}
```

<Remember>
Каждая проверка только **отказывает**, а `true` — одной строкой в
конце. Ранний `return true` («жанр „все“ — показываем») отключает все проверки
ниже. Поиск приводит к нижнему регистру обе стороны. Избранное хранит номера книг, а
не копии: всё остальное о книге всегда берётся свежим с сервера.
</Remember>

Кнопки жанров строятся из данных: жанр добавляется, если `!names.includes(genre)`.
Новый жанр на сервере сам получит кнопку. Вызывать это нужно один раз, после загрузки:
из `render` кнопки множились бы после каждого действия.

## Чек-лист готовности

Проект готов, когда каждая строка проверена руками через Live Server.

| Что проверить | Как |
| --- | --- |
| загрузка | «Загрузка…», потом восемь карточек и «Показано: 8 из 8» |
| ошибка | файл переименован — понятный текст, «Загрузка…» исчезла |
| поиск | «толст» и «ТОЛСТОЙ» — «Война и мир»; «xyz» — «Ничего не нашлось» |
| жанры | шесть кнопок из данных, выбранная выделена |
| вместе | поиск, жанр и «Только избранное» работают одновременно |
| избранное | звезду можно поставить и снять, карточка выделена |
| память | после обновления избранное на месте, а поиск и жанр сброшены |
| хранилище | в `catalog:favorites` — массив чисел, а не строк |
| консоль | ни одной красной строки, кроме 404, если его устраивали нарочно |

## Четыре ошибки по симптомам

| Симптом | Причина |
| --- | --- |
| поиск не работает при «все» | ранний `return true` |
| после обновления избранное пусто, в хранилище `"[]"` | хранилище не прочитано, `render` его затёр |
| звезда не загорается, в хранилище `["5"]` | номер строкой, без `Number` |
| ошибка есть, а «Загрузка…» висит | уборка не в `finally` |
