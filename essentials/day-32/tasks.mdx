# День 32. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 собирают каталог из лекции в папке `day-32/catalog` по этапам, с проверкой каждого этапа в консоли. Задания 4–8 — доработки того же каталога: делайте их по очереди и после каждой проверяйте, что старое не сломалось. Для задания 9 нужна копия папки после задания 3. Всё открываем через Live Server.</Subtitle>

## Разминка

<Task title="1. Сервер и данные" level="easy" time="6">
<Goal>начать проект с данных и проверить их до первой строки кода.</Goal>

Создайте `catalog.json` и `index.html` из разделов 3 и 5 лекции. Пока
`app.js` пуст, спросите сервер из консоли. Потом положите в `app.js`
данные из раздела 4 и поиск элементов из раздела 5.

<Hint>
`await` в консоли Chrome работает без `async` — день 31.
</Hint>

<Criteria>
- из консоли получены 8 книг, из них 2 романа;
- запрос к `katalog.json` дал статус 404;
- после второй части — `[books.length, favorites, genres.children.length, loading.hidden]`
  равно `[0, [], 0, false]`;
- объяснено, почему у каждой книги есть `id`, хотя названия разные.
</Criteria>
</Task>

<Task title="2. Загрузка и карточки" level="easy" time="7">

<Hint>

</Hint>

<Criteria>
- записан текст ошибки на странице, пока `makeGenreButtons` не написана, и объяснено, почему её поймал `catch`;
- `makeCard(books[4]).outerHTML` совпадает с лекцией, а при `favorites = [5]` — класс `"card favorite"`;
- кнопок жанров шесть, выделенной пока нет;
- `makeGenreButtons()` вызвана в консоли второй раз — записано, сколько стало кнопок, и объяснено.
</Criteria>
</Task>

## Основные задания

<Task title="4. Защита хранилища" level="medium" time="12">
<Goal>не дать испорченному хранилищу сломать страницу.</Goal>

Сначала на готовом каталоге запишите в хранилище по очереди `"[object Object]"`
и `"5"` и обновите страницу — запишите, что случилось. Потом замените чтение
избранного функцией `readFavorites()`: если в хранилище не массив или его не
разобрать, она возвращает пустой массив.

<Hint>
`JSON.parse` — внутри `try...catch` из дня 11. Массив ли это —
`Array.isArray` из дня 19.
</Hint>

<Criteria>
- до защиты: с `"5"` на странице «Не удалось загрузить каталог: favorites.includes is not a function», с `"[object Object]"` — «Загрузка…» висит;
- после защиты оба случая дают восемь карточек, а хранилище становится `"[]"`;
- `"[99]"` после защиты остаётся в хранилище и ничему не мешает;
- объяснено, почему с `"5"` ошибка появилась в `#error`, а с `"[object Object]"` — нет.
</Criteria>
</Task>

<Task title="5. Сортировка" level="medium" time="12">
<Goal>добавить ещё одно поле выбора и провести его через `render`.</Goal>

Под жанрами — три кнопки: «как в каталоге», «новые сначала», «по названию». Выбор
хранится в переменной `sort` и работает вместе с поиском, жанром и избранным.

<Hint>
В `render` сначала отберите видимые, потом отсортируйте копию через
`toSorted` (день 20). Строки сравниваются `<` (день 7):
`(a, b) => (a.title < b.title ? -1 : 1)`. Для наших названий этого хватает;
сортировка с учётом всех правил языка (буква «Ё») — в курсе 2.
</Hint>

<Criteria>
- «по названию» — первая «Война и мир», последняя «Хоббит»;
- «новые сначала» — первый «Гарри Поттер и философский камень», последняя «Капитанская дочка»;
- «новые сначала» и жанр «фэнтези» — «Гарри Поттер…», затем «Хоббит»;
- после сортировки порядок в `books` прежний — объяснено, что сломалось бы с `sort` вместо `toSorted`.
</Criteria>
</Task>

<Task title="6. «Показать ещё»" level="medium" time="13">
<Goal>показывать длинный список частями.</Goal>

Каталог показывает по четыре карточки. Кнопка «Показать ещё» под списком добавляет
следующие четыре и прячется, когда показано всё. Новый поиск, жанр или флажок снова
начинают с четырёх.

<Hint>
Ещё одно поле данных — `let limit = 4`. В `render` — `slice(0, limit)`
из дня 19. Кнопку прячет `render`: она видна, только если видимых больше, чем `limit`.
</Hint>

<Criteria>
- при открытии — четыре карточки, «Показано: 4 из 8», кнопка видна;
- после «Показать ещё» — восемь карточек, кнопки нет;
- поиск «ин» — четыре карточки и кнопка; после щелчка — пять, кнопки нет;
- объяснено, почему `limit` сбрасывается в слушателях, а не в `render`.
</Criteria>
</Task>

<Task title="7. Поиск и жанр на время вкладки" level="medium" time="13">
<Goal>выбрать хранилище под задачу.</Goal>

Поиск и выбранный жанр переживают обновление страницы, но в новой вкладке каталог
открывается чистым. Поле поиска показывает сохранённый текст.

<Hint>
Читать — там же, где объявлены `query` и `genre`, с `??`;
записывать — в конце `render`. Поле поиска заполнить до первого показа:
`search.value = query`.
</Hint>

<Criteria>
- «ин» и «фэнтези», обновили — две карточки, в поле «ин», выделена «фэнтези»;
- та же страница в новой вкладке — поле пустое, «все», «Показано: 8 из 8»;
- избранное по-прежнему живёт в `localStorage` и видно в обеих вкладках;
- объяснено, почему поиск — в `sessionStorage`, а избранное — в `localStorage`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Второй файл: авторы" level="hard" time="10">
<Goal>собрать страницу из двух запросов.</Goal>

Рядом с `catalog.json` — файл `authors.json` с годами жизни. После
загрузки книг загрузите и его, а в карточке после имени автора покажите годы.

```js
[
  { "name": "Александр Пушкин", "born": 1799, "died": 1837 },
  { "name": "Фёдор Достоевский", "born": 1821, "died": 1881 },
  { "name": "Лев Толстой", "born": 1828, "died": 1910 },
  { "name": "Артур Конан Дойл", "born": 1859, "died": 1930 },
  { "name": "Джон Толкин", "born": 1892, "died": 1973 },

  { "name": "Джоан Роулинг", "born": 1965 }
```

<Hint>

`died`, тот `undefined`.
</Hint>

<Criteria>
- все восемь карточек с годами, у Роулинг — «род. 1965»;
- без `authors.json` — «Не удалось загрузить каталог: сервер ответил 404»;
- автор, которого нет в файле, показан без скобок;
- объяснено, почему запросы идут по очереди и что было бы, если бы второй не ждал первого.
</Criteria>
</Task>

<Task title="9. Три жалобы" level="hard" time="10">
<Goal>искать ошибку от симптома.</Goal>

Одноклассник прислал каталог и три жалобы:

- «„хоббит“ находится, а „Хоббит“ — нет».
- «После каждого действия кнопок жанров становится больше».
- «Звезду нельзя снять».

От программы лекции его `app.js` отличается фрагментами ниже; кроме того,
из `load` убран вызов `makeGenreButtons`. Внесите их в копию каталога
и воспроизведите каждую жалобу.

```js
// в слушателе поиска
query = search.value.trim();

// в render, после карточек
makeGenreButtons();

// в слушателе списка
if (favorites.includes(id)) {
  favorites.filter((f) => f !== id);
} else {
  favorites.push(id);
}
```

<Hint>
Для каждой жалобы спросите консоль: `query`, `genres.children.length`,
`favorites`. Данные подскажут, какая строка виновата.
</Hint>

<Criteria>
- каждая жалоба воспроизведена и сопоставлена со своей строкой;
- записано, сколько кнопок жанров после открытия и после первой буквы поиска;
- объяснено, почему `filter` без присваивания ничего не меняет;
- все три места исправлены, жалобы больше не повторяются.
</Criteria>
</Task>
