# День 34. Итоговый проект: реализация

<Subtitle>Выжимка лекции: работа по плану, текущий элемент по кругу, пустое состояние, план и факт.</Subtitle>

## Одна задача за раз

Взяли задачу плана → заменили заглушку кодом → проверили руками и в консоли → отметили
в плане с настоящими минутами → следующая. Тогда ошибка всегда в последнем куске. Перед
большой правкой — копия папки проекта. Застряли — прочитать красную строку до конца,
спросить данные, запустить функции-проверки; не помогло за 10 минут — вернуться к копии и
идти меньшими шагами.

## Текущий элемент по кругу

```js
function current() {
  const cards = deck();
  return cards.length === 0 ? null : cards[position % cards.length];   // null — пусто
}

againButton.addEventListener("click", () => {
  position++;          // просто растёт — % держит в границах колоды
  flipped = false;     // новая карточка — словом
  render();
});
```

<KeyPoint>
Текущую карточку не хранят, а вычисляют из колоды и позиции: копия устарела бы после
первого «Знаю». Остаток от деления ходит по кругу — после последней снова первая, и
колода может стать короче без ошибок. Без `%` — `undefined` и
`Cannot read properties of undefined (reading 'word')`.
</KeyPoint>

Данные, которые зависят от других данных, сбрасываются вместе с ними: сменилась
карточка — `flipped = false`; сменилась тема — ещё и `position = 0`.
Иначе следующая карточка откроется сразу переводом.

## Пустое состояние и сброс

```js
knowButton.hidden = current() === null;   // в render: невозможное не предлагаем
if (current() === null) return;           // в слушателе: всё равно защищаемся
if (!confirm("Забыть все выученные слова?")) return;
learned = [];                             // сбрасывают данные, а не хранилище
```

<Remember>
`undefined` — «такого места нет», чаще всего ошибка. `null` — «мы
сами сказали: ничего нет», его ждут и проверяют. Хранилище — копия данных: удалить ключ
бесполезно, `render` тут же запишет старый `learned` обратно.
</Remember>

## Ошибки по симптомам

| Симптом | Причина |
| --- | --- |
| `reading 'word'` у `undefined` после последней карточки | нет `%`: номер вышел за колоду |
| следующая карточка сразу с переводом | `flipped` не сброшен при смене карточки |
| `reading 'id'` у `null` | кнопка видна и не защищена на пустой колоде |
| «Начать сначала» ничего не сбросил | удалён ключ хранилища, а не данные |

## Чек-лист готовности дня 34

| Что | Готово, когда |
| --- | --- |
| задачи дня | у каждой в плане отметка и настоящие минуты |
| таблица возможностей | каждая строка: работает, с оговоркой или перенесена |
| функции-проверки | молчат и возвращают данные как было |
| пустые состояния | понятный текст, лишние кнопки спрятаны, слушатели защищены |
| сохранение | после обновления на месте; сброс не возвращается |
| консоль | ни одной красной строки в обычной работе |
| план дня 35 | пересчитан; без «потом» помещается в 90 минут |

Новая идея посреди работы не делается, а записывается в «потом» с минутами. Перерасход
времени — не повод ускоряться, а повод пересчитать следующий день и выбросить задачу с
отметкой `later`.
