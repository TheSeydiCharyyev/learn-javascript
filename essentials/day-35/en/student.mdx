<Subtitle>A summary of the lecture: a phone, edge cases, data at the entrance, someone else’s code.</Subtitle>

## A phone

From a phone in the same Wi-Fi network you open the address of the computer from `ipconfig`
(the IPv4 line) instead of `127.0.0.1`: `http://192.168.1.23:5500/index.html`.
It does not open — use the phone mode of DevTools, <Kbd>Ctrl</Kbd> +
<Kbd>Shift</Kbd> + <Kbd>M</Kbd>.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  button { font-size: 18px; padding: 10px 16px; margin: 0 8px 8px 0; }
  .card { … overflow-wrap: anywhere; }
</style>
```

<KeyPoint>
Without the viewport line a phone builds the page 980 wide and shrinks it:
`innerWidth` is 980 instead of 360. You check the worst: a narrow screen, a finger (a button
21 pixels high means a miss), the longest word.
</KeyPoint>

## Data is checked at the entrance

```js
function readLearned() {
  try {
    const saved = JSON.parse(localStorage.getItem(KEY));
    return Array.isArray(saved) ? saved : [];   // always an array
  } catch {
    return [];                                  // a broken string
  }
}

// in load, after words = await response.json():
if (words.length === 0) throw new Error("the file has no words");
learned = learned.filter((id) => words.some((w) => w.id === id));
trainer.hidden = false;   // the last line of try
```

| Case | Without a check |
| --- | --- |
| `"[object Object]"` in storage | the script fails, “Loading…” hangs |
| `"5"` in storage | “Could not load the words” — untrue |
| a number that is not in the file | “Learned: 9 of 8” |
| an empty `[]` in the file | “All the words of this topic are learned!”, “Learned: 0 of 0” |
| no file, an extra comma | an error, and under it the frame and the buttons |

<Remember>
`catch` catches any error from `try`, not only the one you were thinking about.
`console.assert` talks to the developer, `throw` with a clear text —
to the person.
</Remember>

## Shuffling

```js
for (let i = result.length - 1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i + 1));   // from 0 to i, not to the end of the array
  const temp = result[i];
  result[i] = result[j];
  result[j] = temp;
}
```

`sort(() => Math.random() - 0.5)` shuffles unevenly: in Chrome two
orders of three numbers out of six come out twice as often. After shuffling, a check must
guard the rule (“the first card is the first in the deck”), not the order.
