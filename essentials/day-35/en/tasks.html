Day 35. Tasks

Lessons 2 and 3, 90 minutes. Warm-up — 20 minutes, main tasks — 50 minutes, starred tasks — 20 minutes. The warm-up is on the example of the “Cards”: copy the folder day-34/cards to day-35/cards and finish it by the lecture. The main tasks are in your own project, as on day 34: before a big edit — a copy of the folder, after every task — a check and a note of the minutes in plan.md. We open everything through Live Server.

9. A simplified shuffle
Hard10 min

check a shuffle by counting and explain where the skew comes from.

A classmate “simplified” shuffle: the random place is chosen from the whole array, not from the part that has not been touched yet.

function simpleShuffle(list) {
  const result = [...list];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * result.length);
    const temp = result[i];
    result[i] = result[j];
    result[j] = temp;
  }
  return result;
}

With the function count from section 10, count how often each order of three numbers comes out with shuffle and with simpleShuffle.

For three numbers the loop makes two steps. How many choices does each step have in shuffle, and how many in simpleShuffle? Write out all the paths on paper and see what order comes out at the end of each one.
  • for both functions all six counts are written down;
  • the orders that come out more often with simpleShuffle are named, and how many times more often;
  • all the paths of both functions are written out: how many there are and how many lead to each order;
  • it is explained why shuffle has no skew.
