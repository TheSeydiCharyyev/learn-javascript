## Телефон

С телефона в той же сети Wi-Fi открывают адрес компьютера из `ipconfig`
(строка IPv4) вместо `127.0.0.1`: `http://192.168.1.23:5500/index.html`.
Не открывается — режим телефона в DevTools, <Kbd>Ctrl</Kbd> +
<Kbd>Shift</Kbd> + <Kbd>M</Kbd>.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  button { font-size: 18px; padding: 10px 16px; margin: 0 8px 8px 0; }
  .card { … overflow-wrap: anywhere; }
</style>
```

<KeyPoint>
Без строки viewport телефон строит страницу шириной 980 и уменьшает её:
`innerWidth` — 980 вместо 360. Проверяют худшее: узкий экран, палец (кнопка в
21 пиксель — промах), самое длинное слово.
</KeyPoint>

## Данные проверяют на входе

```js
function readLearned() {
  try {
    const saved = JSON.parse(localStorage.getItem(KEY));
    return Array.isArray(saved) ? saved : [];   // всегда массив
  } catch {
    return [];                                  // испорченная строка
  }
}

// в load, после words = await response.json():
if (words.length === 0) throw new Error("в файле нет слов");
learned = learned.filter((id) => words.some((w) => w.id === id));
trainer.hidden = false;   // последняя строка try
```

| Случай | Без проверки |
| --- | --- |
| `"[object Object]"` в хранилище | скрипт падает, «Загрузка…» висит |
| `"5"` в хранилище | «Не удалось загрузить слова» — неправда |
| номер, которого нет в файле | «Выучено: 9 из 8» |
| пустой `[]` в файле | «Все слова темы выучены!», «Выучено: 0 из 0» |
| нет файла, лишняя запятая | ошибка, а под ней рамка и кнопки |

<Remember>
`catch` ловит любую ошибку из `try`, не только ту, о которой думали.
`console.assert` говорит с разработчиком, `throw` с понятным текстом —
с человеком.
</Remember>

## Перемешивание

```js
for (let i = result.length - 1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i + 1));   // от 0 до i, не до конца массива
  const temp = result[i];
  result[i] = result[j];
  result[j] = temp;
}
```

`sort(() => Math.random() - 0.5)` перемешивает неровно: в Chrome два
порядка трёх чисел из шести выпадают вдвое чаще. После перемешивания проверка должна
сторожить правило («первая карточка — первая в колоде»), а не порядок.

## Чужой код и отзыв

| Проход | Что делать |
| --- | --- |
| 1. запустить | пройти сценарий, записать симптомы |
| 2. карта | данные, функции, слушатели |
| 3. одно действие | от щелчка до экрана и хранилища |

Замечание: где · что сделал · что увидел · что ожидал; догадка — в конце. Сначала
ошибки, потом чтение. На каждое замечание к своему коду — ответ: сделать, объяснить или
отложить. Перед ответом — повторить самому.
