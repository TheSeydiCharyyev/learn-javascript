<Task title="9. Упрощённое перемешивание" level="hard" time="10">
<Goal>проверить перемешивание счётом и объяснить, откуда перекос.</Goal>

Одноклассник «упростил» `shuffle`: случайное место выбирается из всего
массива, а не из ещё не тронутой части.

```js
function simpleShuffle(list) {
  const result = [...list];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * result.length);
    const temp = result[i];
    result[i] = result[j];
    result[j] = temp;
  }
  return result;
}
```

Посчитайте функцией `count` из раздела 10, как часто выпадает каждый
порядок трёх чисел у `shuffle` и у `simpleShuffle`.

<Hint>
Для трёх чисел цикл делает два шага. Сколько вариантов у каждого шага в
`shuffle` и сколько в `simpleShuffle`? Выпишите все пути на
бумаге и посмотрите, какой порядок получается в конце каждого.
</Hint>

<Criteria>
- для обеих функций записаны все шесть чисел счёта;
- названы порядки, которые у `simpleShuffle` выпадают чаще, и во сколько раз;
- выписаны все пути обеих функций: сколько их и сколько приходится на каждый порядок;
- объяснено, почему у `shuffle` перекоса нет.
</Criteria>
</Task>
