The reviewer and grading

A good question is specific, it is answered with code or a check, and it is about the project, not about the person. Feedback is one strong side with a place in the code and one suggestion that can be checked. Grading is five criteria of 0–2 points each: works, phone, edge cases, code, answers. Complexity and the number of lines are not graded.
