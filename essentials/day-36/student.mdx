## Семь минут

| Часть | Минуты | Что в ней |
| --- | --- | --- |
| фраза | 0,5 | что это, что делает, чем полезно — без слов о технике |
| показ | 3 | на телефоне, по сценарию: действие → что изменилось |
| решение | 1 | что решали · как сделали · что было бы иначе · чем проверили |
| ошибка | 1 | симптом · как нашли · причина · исправление · проверка, чтобы не вернулась |
| вопросы | 1,5 | первый — от проверяющего |

```js
// перед показом — начальное состояние:
localStorage.removeItem("cards:learned");   // и сразу обновить, иначе render запишет learned обратно

// сломалось на показе — красная строка вслух, потом данные:
[words.length, learned, topic, position, flipped];
```

Хронометрист запускает в консоли `schedule(defense)` и по
`setTimeout` на каждую часть — сообщения приходят на 0; 0,5; 3,5; 4,5; 5,5 и 7
минуте.

| Решение для рассказа | Что было бы иначе |
| --- | --- |
| текущая карточка вычисляется, а не хранится | выученное слово остаётся на экране, счётчик считает его дважды |
| кнопки тем — из данных | новая тема в файле без кнопки |
| запись в хранилище — в конце `render` | новый слушатель забыл сохранить |
| данные проверяются на входе | проверки в каждой функции |

<Remember>
`127.0.0.1:5500` и адрес сети — для браузера разные сайты, у каждого своё
хранилище. Выученное на телефоне не видно на компьютере, открытом по
`127.0.0.1`.
</Remember>

## Ответы на вопросы

| Вопрос | Ход |
| --- | --- |
| «Где …?» | показать место в коде, не пересказывать |
| «Что будет, если …?» | проверить в консоли за минуту |
| «Почему не …?» | назвать причину или «не проверял — в „потом“» |

<KeyPoint>
Не знать ответ — не ошибка, выдумать — ошибка. Опыт в консоли оставляет следы в
хранилище: после него — «Начать сначала».
</KeyPoint>

Что показали проверки «Карточек»: два слова с одним номером уходят вместе; две вкладки
затирают прогресс друг друга; на десяти тысячах слов `learned.includes` становится
заметно медленным (`Set` — курс 2); перемешивание стоит после
`makeTopicButtons()`: если раньше, кнопки тем прыгают вместе со словами.

```js
function testInput() {
  const saved = localStorage.getItem(KEY);
  localStorage.setItem(KEY, "[object Object]");
  console.assert(readLearned().length === 0, "испорченная строка — пустой массив");
  localStorage.setItem(KEY, "5");
  console.assert(readLearned().length === 0, "не массив — пустой массив");
  localStorage.setItem(KEY, saved);   // вернуть как было
}
```

## Проверяющий и оценка

Хороший вопрос конкретный, на него отвечают кодом или проверкой, он о проекте, а не о
человеке. Отзыв — одна сильная сторона с местом в коде и одно предложение, которое можно
проверить. Оценка — пять критериев по 0–2 балла: работает, телефон, крайние случаи, код,
ответы. Сложность и число строк не оцениваются.
