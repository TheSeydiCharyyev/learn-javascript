# День 1. Области видимости и замыкания

<Subtitle>Выжимка лекции: где видна переменная, как ищется имя, что такое замыкание и зачем оно нужно.</Subtitle>

## Главное

<Definition>
**Замыкание** — функция вместе со ссылкой на окружение, в котором она создана.
Есть у каждой функции. Заметно, когда функция переживает вызов, внутри которого родилась,
и уносит с собой его переменные.
</Definition>

<KeyPoint>
Что видит функция, решает **место, где она написана**, а не место, откуда
её вызвали. Такая область видимости называется лексической.
</KeyPoint>

## Области видимости

| Область | Создаёт | Видно |
| --- | --- | --- |
| глобальная | весь скрипт | везде |
| функции | каждый вызов | внутри функции |
| блока | `{ }`, только `let` и `const` | внутри блока |
| модуля | файл-модуль (день 30) | в этом файле |

## Поиск имени

```js
const mark = 5;

function outer() {
  const student = "Сапар";
  function inner() {
    const mark = 4;               // затеняет внешнюю
    console.log(student, mark);   // Сапар 4 — student нашлась в outer
  }
  inner();
}

outer();
```

<Remember>
Своя область → внешняя **по тексту программы** → … → глобальная →
`ReferenceError`. Первая находка побеждает.
\
Осторожно с `name`: это свойство окна браузера, опечатка в нём не упадёт,
а даст пустую строку.
</Remember>

## Спецификация, ECMA-262

<NoteBox>
**9.1** — запись окружения хранит имена кода; создаётся при каждом выполнении
функции, блока, `catch`. Поле `[[OuterEnv]]` — ссылка наружу,
у глобальной записи — `null`.
\
**9.1.1** — виды: Declarative (блоки), Function (вызовы функций),
Module (модули), Global (скрипт), Object (`with`).
\
**9.1.2** — `GetIdentifierReference`: запись `null` —
имя не найдено; `HasBinding` отвечает «да» — нашли; иначе то же во внешней записи.
\
**10.2** — слот функции `[[Environment]]`: окружение, где её
создали. Это и есть замыкание.
</NoteBox>

## Замыкание

```js
function makeCounter() {
  let count = 0;
  return () => ++count;
}

const a = makeCounter();
const b = makeCounter();
a();
a();
console.log(a(), b());   // 3 1 — у каждого вызова своя count
```

<Remember>
Каждый вызов функции — **новая запись окружения**. Своё у замыкания только
то, что объявлено внутри вызова. Переменная снаружи фабрики — общая на всех.
</Remember>

## Переменная, а не значение

```js
let lesson = "замыкания";
const show = () => console.log(lesson);
lesson = "this";
show();                                    // this — читает переменную сейчас

const remember = (value) => () => value;   // «фотография» — через параметр
const saved = remember(lesson);
lesson = "прототипы";
console.log(saved());                      // this
```

## Фабрики и спрятанные данные

```js
function makeRangeCheck(min, max) {
  return (n) => n >= min && n <= max;      // границы «запеклись»
}
console.log([5, 9, 3, 0].filter(makeRangeCheck(2, 5)));   // (2) [5, 3]

function makeList() {
  const items = [];                        // снаружи не видно
  return {
    add: (item) => items.push(item),
    all: () => [...items],                 // наружу — только копия
  };
}
```

<Remember>
Спрятанное живёт в записи окружения вызова фабрики. Наружу — **только функции
и копии**: вернёте сам массив — его изменят снаружи.
</Remember>

## Цикл: var и let

```js
for (var i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 0);   // 4, 4, 4 — одна i на весь цикл
}
for (let j = 1; j <= 3; j++) {
  setTimeout(() => console.log(j), 0);   // 1, 2, 3 — своя j на каждый проход
}
```

<Remember>
В цикле, где создаются функции, — **только `let`**
(или `for...of` с `const`). В старом коде с `var` ту же
задачу решали фабрикой.
</Remember>

<NoteBox>
**Память.** Пока функция жива, живо и её окружение. Берите в замыкание
нужное — число, а не весь массив ради длины. Снимайте ненужные слушатели через
`removeEventListener`: вместе со слушателем отпустится его окружение.
</NoteBox>
