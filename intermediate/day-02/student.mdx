# День 2. this: call, apply, bind

<Subtitle>Выжимка лекции: чему равен `this`, где он теряется и как его задать или закрепить.</Subtitle>

## Главное

<Definition>
**`this`** — скрытый параметр вызова. Его значение решает
**способ вызова**, а не место, где функция написана. Это единственное
исключение из правила дня 1.
</Definition>

| Вызов | `this` |
| --- | --- |
| `obj.method()` | объект слева от точки |
| `f()` | обычный скрипт — глобальный объект; строгий режим — `undefined` (день 3) |
| `f.call(x)`, `f.apply(x)`, `f.bind(x)` | `x` |
| `new F()` | новый объект (день 7) |
| стрелочная | своего нет — берёт у функции, внутри которой написана |

## Метод и потерянный this

```js
const progress = {
  learned: [1, 2],
  count() {
    return this.learned.length;
  },
};

progress.count();            // 2 — через точку
const count = progress.count;
count();                     // TypeError: Cannot read properties of undefined (reading 'length')
```

<KeyPoint>
**Метод без скобок — функция без объекта.** `this` теряется, когда метод
кладут в переменную, отдают таймеру, методу массива или обработчику события. В обработчике
`this` — элемент, на котором висит слушатель.
</KeyPoint>

<Remember>
Потерянный `this` не всегда падает: у глобального объекта есть `name`,
`status`, `length`. Проверяйте не только «нет ли ошибки»,
но и «то ли напечаталось».
</Remember>

## Стрелочные

```js
const timer = {
  seconds: 0,
  start() {
    setTimeout(() => {
      this.seconds = this.seconds + 1;   // this метода start
    }, 0);
  },
};
```

<Remember>
Методом стрелочную **не делают**, внутри метода — **делают**.
`this` стрелочной не меняется ничем, даже `call` и `bind`.
В спецификации у её записи окружения `HasThisBinding` отвечает «нет», и поиск идёт
наружу, как поиск переменной.
</Remember>

## call, apply, bind

```js
function describe(prefix) {
  return `${prefix} ${this.student}`;
}
const sapar = { student: "Сапар" };

describe.call(sapar, "Студент");     // вызвать сейчас, аргументы через запятую
describe.apply(sapar, ["Студент"]);  // вызвать сейчас, аргументы массивом
const d = describe.bind(sapar);      // НЕ вызывает: новая функция, this = sapar навсегда
d("Студент");                        // "Студент Сапар"

function list() {
  return [].join.call(arguments, ", ");   // заимствование метода
}
Math.max.apply(null, [5, 4, 9]);     // 9 — старый способ; сегодня Math.max(...marks)

function multiply(a, b) { return a * b; }
const double = multiply.bind(null, 2);   // частичное применение: double(21) — 42
```

<Remember>
**A**pply — **A**rray, **C**all — **C**omma.
`bind` закрепляет навсегда: ни точка, ни `call`, ни второй
`bind` не перепривяжут.
</Remember>

## Три лекарства для колбэка

```js
const card = { word: "teacher", show() { console.log(this.word); } };

setTimeout(card.show.bind(card), 0);   // bind
setTimeout(() => card.show(), 0);      // стрелочная обёртка — вызов через точку
// внутри метода того же объекта: setTimeout(() => this.show(), 0);
```

<NoteBox>
**bind и removeEventListener.** `bind` каждый раз создаёт
**новую** функцию, а снять можно только ту же самую (день 27). Привязанную
функцию сохраняют в переменную: `const onClick = obj.m.bind(obj);`
\
**Ошибка дня.** Встроенный метод вызван не на том объекте:
`Illegal invocation`, `this is not a Date object.`,
`Bind must be called on a function`. На MDN — одна страница,
«X.prototype.y called on incompatible type» (по Firefox).
</NoteBox>

## Замыкание или this

Замыкание (день 1): данные спрятаны, методы можно отдавать колбэком как есть.
`this`: данные открыты в свойствах, методы при передаче нужно привязывать, зато
их можно сделать общими для многих объектов — к этому ведут прототипы и классы, дни 7–10.
