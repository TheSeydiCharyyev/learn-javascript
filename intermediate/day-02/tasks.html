Разминка

1. Кто слева от точки
Легко7 мин

определять this по форме вызова.

Предскажите три строки, потом проверьте.

function greet() {
  return `Салам, ${this.student}!`;
}

const aman = { student: "Аман", greet };
const group = { title: "1-А", leader: aman };

console.log(aman.greet());
console.log(group.leader.greet());
const g = aman.greet;
console.log(g());
  • три предсказания записаны до запуска;
  • для каждой строки записано, чему равен this;
  • объяснено, почему в третьей строке не ошибка, а undefined;
  • свойство student переименовано в name (в объекте и в функции) — записано, что стало с третьей строкой и почему.

function introduce(greeting, mark) {

const sapar = { student: "Сапар" };

Получите строку «Салам, я Сапар, оценка 5» тремя способами: через call, через apply и через bind с последующим вызовом.

4. Три потерянных this
Средне12 мин

найти и починить потерю this в трёх разных колбэках.

const journal = {
  title: "Журнал 1-А",
  marks: [],
  add(mark) {
    this.marks.push(mark);
  },
  report() {
    console.log(`${this.title}: ${this.marks.join(", ")}`);
  },
};

const reportButton = document.createElement("button");
reportButton.textContent = "Отчёт";
document.body.append(reportButton);

[5, 4, 5].forEach(journal.add);
setTimeout(journal.report, 0);
reportButton.addEventListener("click", journal.report);

Программа падает. Чините ошибки по одной: после каждой починки запускайте снова и смотрите, где упадёт теперь. Не забудьте нажать на кнопку.

Для каждой ошибки ответьте на вопрос: кто вызвал метод и что оказалось слева от точки? У кнопки, в отличие от окна, свойство title есть — проверьте, что оно равно, набрав reportButton.title.
  • записан точный текст каждой из трёх ошибок и момент, когда она появилась;
  • для каждой записано, чему был равен this;
  • три места починены тремя разными способами: второй аргумент forEach, bind, стрелочная обёртка;
  • после починки и таймер, и кнопка печатают «Журнал 1-А: 5, 4, 5».

6. bind как фабрика
Средне12 мин

использовать bind для частичного применения и сравнить его с фабрикой.

function format(currency, amount) {
  return `${amount.toFixed(2)} ${currency}`;
}
const inManat = format.bind(null, "TMT");
inManat(12.5);    // "12.50 TMT"
inManat.length;   // 1
  • Сделайте inManat и inDollars через bind.
  • Сделайте то же фабрикой дня 1: makeFormatter(currency).
  • Предскажите и проверьте: const show = card.show.bind(card); show.bind({ word: "water" })(), где card — карточка из раздела 9 лекции.
  • обе версии форматируют одинаково на трёх суммах;
  • записано, чему равен length у версии с bind и у версии с фабрикой, и почему;
  • предсказание про двойной bind записано до проверки и объяснено;
  • записано, какую версию вы бы выбрали и почему.

8. Свой bind
Сложно10 мин

собрать bind из замыкания (день 1) и call (сегодня).

Напишите myBind(fn, thisValue, ...preset): возвращает функцию, которая вызывает fn с this, равным thisValue, и аргументами — сначала preset, потом переданными при вызове.

const card = { word: "teacher", show() { return this.word; } };
const show = myBind(card.show, card);
show();                         // "teacher"
show.call({ word: "water" });   // "teacher" — как у настоящего bind

function sum3(a, b, c) { return a + b + c; }
const plus3 = myBind(sum3, null, 1, 2);
plus3(3);                       // 6
plus3.length;                   // 0 — а у настоящего bind было бы 1
  • все ответы примера совпали;
  • записано, какие переменные лежат в записи окружения вызова myBind;
  • объяснено, почему show.call(...) не меняет this;
  • записано, чем ваша версия отличается от настоящего bind — хотя бы length.
9. Шесть вызовов
Сложно10 мин

предсказать this в обычных и стрелочных функциях.

const box = {
  label: "коробка",
  regular() { return this.label; },
  arrow: () => this.label,
  nested() {
    const inner = () => this.label;
    return inner();
  },
  nestedFn() {
    function inner() { return this.label; }
    return inner();
  },
};

console.log(box.regular());
console.log(box.arrow());
console.log(box.nested());
console.log(box.nestedFn());
console.log(box.regular.call({ label: "другая" }));
console.log(box.arrow.call({ label: "другая" }));
  • шесть предсказаний записаны до запуска;
  • каждый ответ объяснён строкой таблицы раздела 2 лекции;
  • объяснено, почему nested и nestedFn отвечают по-разному, словами спецификации: HasThisBinding и [[OuterEnv]];
  • nestedFn починен двумя способами, не превращая inner в стрелочную.
