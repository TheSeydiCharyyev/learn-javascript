## Разминка

<Task title="1. Кто слева от точки" level="easy" time="7">
<Goal>определять `this` по форме вызова.</Goal>

Предскажите три строки, потом проверьте.

```js
function greet() {
  return `Салам, ${this.student}!`;
}

const aman = { student: "Аман", greet };
const group = { title: "1-А", leader: aman };

console.log(aman.greet());
console.log(group.leader.greet());
const g = aman.greet;
console.log(g());
```

<Criteria>
- три предсказания записаны до запуска;
- для каждой строки записано, чему равен `this`;
- объяснено, почему в третьей строке не ошибка, а `undefined`;
- свойство `student` переименовано в `name` (в объекте и в функции) —
  записано, что стало с третьей строкой и почему.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Свой bind" level="hard" time="10">
<Goal>собрать `bind` из замыкания (день 1) и `call` (сегодня).</Goal>

Напишите `myBind(fn, thisValue, ...preset)`: возвращает функцию, которая
вызывает `fn` с `this`, равным `thisValue`, и аргументами —
сначала `preset`, потом переданными при вызове.

<Example>
```js
const card = { word: "teacher", show() { return this.word; } };
const show = myBind(card.show, card);
show();                         // "teacher"
show.call({ word: "water" });   // "teacher" — как у настоящего bind

function sum3(a, b, c) { return a + b + c; }
const plus3 = myBind(sum3, null, 1, 2);
plus3(3);                       // 6
plus3.length;                   // 0 — а у настоящего bind было бы 1
```
</Example>

<Criteria>
- все ответы примера совпали;
- записано, какие переменные лежат в записи окружения вызова `myBind`;
- объяснено, почему `show.call(...)` не меняет `this`;
- записано, чем ваша версия отличается от настоящего `bind` — хотя бы
  `length`.
</Criteria>
</Task>

<Task title="9. Шесть вызовов" level="hard" time="10">
<Goal>предсказать `this` в обычных и стрелочных функциях.</Goal>

```js
const box = {
  label: "коробка",
  regular() { return this.label; },
  arrow: () => this.label,
  nested() {
    const inner = () => this.label;
    return inner();
  },
  nestedFn() {
    function inner() { return this.label; }
    return inner();
  },
};

console.log(box.regular());
console.log(box.arrow());
console.log(box.nested());
console.log(box.nestedFn());
console.log(box.regular.call({ label: "другая" }));
console.log(box.arrow.call({ label: "другая" }));
```

<Criteria>
- шесть предсказаний записаны до запуска;
- каждый ответ объяснён строкой таблицы раздела 2 лекции;
- объяснено, почему `nested` и `nestedFn` отвечают по-разному,
  словами спецификации: `HasThisBinding` и `[[OuterEnv]]`;
- `nestedFn` починен двумя способами, не превращая `inner`
  в стрелочную.
</Criteria>
</Task>
