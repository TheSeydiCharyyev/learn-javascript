# День 3. Строгий режим и глобальный объект

<Subtitle>Выжимка лекции: как включить строгий режим, что он меняет, чего не ловит, и как устроена глобальная область.</Subtitle>

## Главное

<Definition>
**Строгий режим** превращает тихие ошибки обычного режима в явные и запрещает
несколько опасных записей ещё до запуска. **Глобальный объект** — объект
со встроенными именами; во всех средах его зовут `globalThis`.
</Definition>

## Как включить

```js
"use strict";       // ПЕРВОЙ инструкцией файла — строгий весь файл

function f() {
  "use strict";     // первой инструкцией функции — строгая только f
}
```

<Remember>
Не первой строкой — просто строка, режим обычный. Модули (день 30) и классы (день 8) строгие
всегда. Выключить строгий режим нельзя. В консоли директива действует только в том же вводе.
</Remember>

## Тихо → громко

| Что | Обычный | Строгий |
| --- | --- | --- |
| `totl = 5` без объявления | новая глобальная | `ReferenceError` |
| запись, добавление, `delete` у замороженного | молча / `false` | `TypeError` |
| `undefined = 1` | молча | `TypeError` |
| `this` вызова без объекта | глобальный объект | `undefined` |
| `f.call(null)`, `f.call(5)` | глобальный объект, обёртка | `null`, `5` |
| `arguments` после изменения параметра | меняется вместе с ним | копия на момент вызова |

<KeyPoint>
Потерянный метод в строгом режиме падает сразу: `Cannot read properties of undefined
(reading 'learned')` называет то место, где потерялся объект.
</KeyPoint>

## Запреты до запуска (SyntaxError)

<NoteBox>
`eval` и `arguments` как имена — `Unexpected eval or arguments in strict mode`
\
`delete x` — `Delete of an unqualified identifier in strict mode.`
\
директива при параметре по умолчанию — `Illegal 'use strict' directive in function with non-simple parameter list`
\
`implements interface let package private protected public static yield` — `Unexpected strict mode reserved word`
\
функция с меткой — `In strict mode code, functions can only be declared at top level or inside a block.`
\
`010` — `Octal literals are not allowed in strict mode.` (пишите `0o10`)
\
`"\05"` — `Octal escape sequences are not allowed in strict mode.`
\
а ещё: повтор имён параметров, `with`.
</NoteBox>

<Remember>
Строгий режим **не ловит** опечатку в имени свойства (`quiz.positon = 1` —
законно) и логические ошибки. Полный список его правил — приложение C спецификации ECMA-262,
у каждого пункта номер раздела.
</Remember>

## Глобальный объект

```js
var a = 1;            // объектная часть: свойство глобального объекта
let b = 2;            // декларативная часть: в globalThis её нет
function c() {}       // объектная часть

console.log(globalThis.a, globalThis.b, typeof globalThis.c);   // 1 undefined function
console.log(globalThis === window);                           // true — в браузере
```

<Remember>
Глобальная запись окружения (9.1.1.4) — две части: **объектная** (глобальный
объект: встроенное, `var`, `function`) и **декларативная**
(`let`, `const`, `class`). Поиск имени смотрит в обе,
`globalThis` — только в первую. `let` верхнего уровня видна во всех
обычных скриптах страницы.
</Remember>

<NoteBox>
**`name`.** Свойство окна. `var name = 5` → строка
`"5"`; `let name = 5` → число, окно не тронуто.
`let undefined` — `SyntaxError`: это имя занято навсегда.
\
**Практика.** Проверка возможности — `typeof globalThis[имя]`;
общее для скриптов — одно имя с объектом внутри; лучше — модули.
</NoteBox>
