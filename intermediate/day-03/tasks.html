День 3. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–4 делаем в консоли — каждый фрагмент в отдельном вводе, иначе директива одного фрагмента подействует на следующий. Дальше — в папке day-03 курса 2.

Разминка

1. Тихо или громко
Легко7 мин

увидеть три тихие ошибки и услышать их в строгом режиме.

const settings = Object.freeze({ theme: "светлая" });
settings.theme = "тёмная";
settings.size = 14;
counter = 1;
console.log(settings.theme, settings.size, globalThis.counter);
  • вывод предсказан до запуска и объяснён по каждому из трёх значений;
  • первой строкой добавлено "use strict"; — записан текст первой ошибки;
  • каждая из трёх подозрительных строк обёрнута в свой try...catch, и записаны все три текста ошибок;
  • для каждой строки указана строка таблицы раздела 3 лекции.
2. Где действует директива
Легко6 мин

понять, на что распространяется "use strict".

Три фрагмента, каждый — в отдельном вводе консоли. Предскажите вывод.

// А
"use strict";
function a() { return this; }
console.log(a());
// Б
function b() {
  "use strict";
  return this;
}
function c() { return this === globalThis; }
console.log(b(), c());
// В
console.log("начало");
"use strict";
function d() { return this === globalThis; }
console.log(d());
  • предсказания записаны до запуска;
  • для фрагмента Б объяснено, почему b и c из одного ввода отвечают по-разному;
  • для фрагмента В объяснено, почему директива не сработала;
  • фрагмент А снова запущен без комментария // А — записано, изменилось ли что-нибудь и почему.
3. Семь запретов
Легко7 мин

получить в Chrome все семь ошибок дня и найти им замену.

Каждую строку запустите отдельно, с "use strict"; в начале того же ввода: let eval = 1; · let x = 1; delete x; · function f(a = 1) { "use strict"; } (здесь директива уже внутри) · let package = 1; · label: function g() {} · console.log(010); · console.log("\05");.

  • для каждой строки записан точный текст ошибки Chrome;
  • для каждой предложена правильная запись, которая делает то, что хотели;
  • записано, почему ни одна строка не успела выполнить ничего до ошибки;
  • для двух строк проверено, что без директивы ошибки нет, и записано, что они делают.

Основные задания

4. this в двух режимах
Средне12 мин

составить таблицу this для обоих режимов.

function who() {
  return this;
}

const box = { label: "коробка", who };

console.log(who() === globalThis);
console.log(who.call(null) === globalThis);
console.log(typeof who.call(5));
console.log(box.who() === box);

Запустите как есть, потом с "use strict"; первой строкой.

  • заполнена таблица: четыре вызова × два режима;
  • каждое различие объяснено строкой приложения C или раздела 4 лекции;
  • объяснено, почему box.who() одинаков в обоих режимах;
  • добавлен пятый вызов — через setTimeout — и записано, что он печатает в обоих режимах.
5. Две половины глобальной области
Средне12 мин

проверить устройство глобальной записи окружения.

var a = "var";
let b = "let";
const c = "const";
function d() {}

console.log(globalThis.a, globalThis.b, globalThis.c, typeof globalThis.d);

Затем сделайте страницу с двумя скриптами first.js и second.js. В первом объявите let shared = 1; и var old = 2;, во втором напечатайте shared, old, globalThis.shared и globalThis.old, а последней строкой второго скрипта объявите let shared = 3;.

Если второй скрипт не напечатал ничего, это тоже ответ. Подумайте, когда SyntaxError останавливает скрипт: на своей строке или раньше.
  • вывод первого фрагмента предсказан и объяснён частями глобальной записи;
  • записано, что напечатал второй скрипт и какая ошибка появилась;
  • объяснено, почему второй скрипт не напечатал даже строки, стоящие до let shared = 3;
  • после удаления последней строки записан вывод второго скрипта, и каждое значение объяснено.
6. Охота на случайные глобальные
Средне10 мин

найти опечатки, которые обычный режим спрятал в глобальный объект.

const before = Object.keys(globalThis);

let total = 0;
let count = 0;

function addMark(mark) {
  totl = total + mark;
  count = count + 1;
}

function reset() {
  total = 0;
  cuont = 0;
}

addMark(5);
addMark(4);
reset();

console.log(Object.keys(globalThis).filter((key) => !before.includes(key)));
  • записано, какие имена нашлись, и для каждого — строка, которая его создала;
  • объяснено, почему в списке нет addMark и reset, хотя объявления function — свойства глобального объекта;
  • добавлен "use strict"; — записан текст первой ошибки;
  • опечатки исправлены, программа в строгом режиме проходит, список пуст.
7. Итоговый проект в строгом режиме
Средне16 мин

включить строгий режим в настоящей программе.

Возьмите свой итоговый проект Essentials (или «Карточки» из лекций дней 33–36). Скопируйте его в папку day-03 и добавьте первой строкой app.js "use strict";.

  • Запустите проект и пройдите все его возможности руками.
  • Запустите все проверки проекта, если они есть (в «Карточках» — testDeck(), testCurrent(), testInput()).
  • Сделайте нарочную опечатку в присваивании одной из переменных состояния и проверьте, что строгий режим её поймал.
  • директива стоит первой инструкцией — проверено через this функции, вызванной без объекта;
  • записано всё, что сломалось, с текстами ошибок, и как исправлено; если не сломалось ничего — так и записано;
  • нарочная опечатка дала ReferenceError — записан текст, опечатка убрана;
  • записан список имён проекта, которые есть в globalThis, и объяснено, почему среди них нет ваших let и const.

Со звёздочкой

8. Приложение C своими руками
Сложно10 мин

проверить спецификацию в браузере.

Откройте приложение C. Выберите пять пунктов, которых не было в лекции и в заданиях выше. Для каждого напишите два коротких фрагмента — обычный и строгий — и проверьте разницу в Chrome.

  • пять пунктов пересказаны своими словами, у каждого — номер раздела из приложения;
  • для каждого — два фрагмента и записанный результат обоих;
  • если пункт проверить пока нельзя (нужен материал будущих дней) — записано, какой день его откроет;
  • отмечен пункт, который показался самым полезным, и объяснено почему.
9. arguments в двух режимах
Сложно10 мин

разобраться в связи arguments с параметрами.

function sloppy(a, b) {
  a = 10;
  arguments[1] = 20;
  return [a, b, arguments[0], arguments[1]];
}

function strict(a, b) {
  "use strict";
  a = 10;
  arguments[1] = 20;
  return [a, b, arguments[0], arguments[1]];
}

console.log(sloppy(1, 2));
console.log(strict(1, 2));
  • оба массива предсказаны до запуска;
  • для каждого из восьми чисел объяснено, откуда оно взялось;
  • найден пункт приложения C, который описывает разницу, записан номер раздела;
  • записано, почему связь параметров с arguments опасна в большой функции.
