# День 3. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–4 делаем в консоли — каждый фрагмент в отдельном вводе, иначе директива одного фрагмента подействует на следующий. Дальше — в папке `day-03` курса 2.</Subtitle>

## Разминка

<Task title="1. Тихо или громко" level="easy" time="7">
<Goal>увидеть три тихие ошибки и услышать их в строгом режиме.</Goal>

```js
const settings = Object.freeze({ theme: "светлая" });
settings.theme = "тёмная";
settings.size = 14;
counter = 1;
console.log(settings.theme, settings.size, globalThis.counter);
```

<Criteria>
- вывод предсказан до запуска и объяснён по каждому из трёх значений;
- первой строкой добавлено `"use strict";` — записан текст первой ошибки;
- каждая из трёх подозрительных строк обёрнута в свой `try...catch`,
  и записаны все три текста ошибок;
- для каждой строки указана строка таблицы раздела 3 лекции.
</Criteria>
</Task>

<Task title="2. Где действует директива" level="easy" time="6">
<Goal>понять, на что распространяется `"use strict"`.</Goal>

Три фрагмента, каждый — в отдельном вводе консоли. Предскажите вывод.

```js
// А
"use strict";
function a() { return this; }
console.log(a());
```

```js
// Б
function b() {
  "use strict";
  return this;
}
function c() { return this === globalThis; }
console.log(b(), c());
```

```js
// В
console.log("начало");
"use strict";
function d() { return this === globalThis; }
console.log(d());
```

<Criteria>
- предсказания записаны до запуска;
- для фрагмента Б объяснено, почему `b` и `c` из одного ввода
  отвечают по-разному;
- для фрагмента В объяснено, почему директива не сработала;
- фрагмент А снова запущен без комментария `// А` — записано, изменилось ли
  что-нибудь и почему.
</Criteria>
</Task>

<Task title="3. Семь запретов" level="easy" time="7">
<Goal>получить в Chrome все семь ошибок дня и найти им замену.</Goal>

Каждую строку запустите отдельно, с `"use strict";` в начале того же ввода:
`let eval = 1;` ·

`function f(a = 1) { "use strict"; }` (здесь директива уже внутри) ·
`let package = 1;` ·
`label: function g() {}` ·
`console.log(010);` ·
`console.log("\05");`.

<Criteria>
- для каждой строки записан точный текст ошибки Chrome;
- для каждой предложена правильная запись, которая делает то, что хотели;
- записано, почему ни одна строка не успела выполнить ничего до ошибки;
- для двух строк проверено, что без директивы ошибки нет, и записано, что они делают.
</Criteria>
</Task>

## Основные задания

<Task title="4. this в двух режимах" level="medium" time="12">
<Goal>составить таблицу `this` для обоих режимов.</Goal>

```js
function who() {
  return this;
}

const box = { label: "коробка", who };

console.log(who() === globalThis);
console.log(who.call(null) === globalThis);
console.log(typeof who.call(5));
console.log(box.who() === box);
```

Запустите как есть, потом с `"use strict";` первой строкой.

<Criteria>
- заполнена таблица: четыре вызова × два режима;
- каждое различие объяснено строкой приложения C или раздела 4 лекции;
- объяснено, почему `box.who()` одинаков в обоих режимах;
- добавлен пятый вызов — через `setTimeout` — и записано, что он печатает
  в обоих режимах.
</Criteria>
</Task>

<Task title="5. Две половины глобальной области" level="medium" time="12">
<Goal>проверить устройство глобальной записи окружения.</Goal>

```js
var a = "var";
let b = "let";
const c = "const";
function d() {}

console.log(globalThis.a, globalThis.b, globalThis.c, typeof globalThis.d);
```

Затем сделайте страницу с двумя скриптами `first.js` и `second.js`.
В первом объявите `let shared = 1;` и `var old = 2;`, во втором
напечатайте `shared`, `old`, `globalThis.shared` и
`globalThis.old`, а последней строкой второго скрипта объявите
`let shared = 3;`.

<Hint>
Если второй скрипт не напечатал ничего, это тоже ответ. Подумайте, когда
`SyntaxError` останавливает скрипт: на своей строке или раньше.
</Hint>

<Criteria>
- вывод первого фрагмента предсказан и объяснён частями глобальной записи;
- записано, что напечатал второй скрипт и какая ошибка появилась;
- объяснено, почему второй скрипт не напечатал даже строки, стоящие до
  `let shared = 3`;
- после удаления последней строки записан вывод второго скрипта, и каждое
  значение объяснено.
</Criteria>
</Task>

<Task title="6. Охота на случайные глобальные" level="medium" time="10">
<Goal>найти опечатки, которые обычный режим спрятал в глобальный объект.</Goal>

```js
const before = Object.keys(globalThis);

let total = 0;
let count = 0;

function addMark(mark) {
  totl = total + mark;
  count = count + 1;
}

function reset() {
  total = 0;
  cuont = 0;
}

addMark(5);
addMark(4);
reset();

console.log(Object.keys(globalThis).filter((key) => !before.includes(key)));
```

<Criteria>
- записано, какие имена нашлись, и для каждого — строка, которая его создала;
- объяснено, почему в списке нет `addMark` и `reset`, хотя
  объявления `function` — свойства глобального объекта;
- добавлен `"use strict";` — записан текст первой ошибки;
- опечатки исправлены, программа в строгом режиме проходит, список пуст.
</Criteria>
</Task>

<Task title="9. arguments в двух режимах" level="hard" time="10">
<Goal>разобраться в связи `arguments` с параметрами.</Goal>

```js
function sloppy(a, b) {
  a = 10;
  arguments[1] = 20;
  return [a, b, arguments[0], arguments[1]];
}

function strict(a, b) {
  "use strict";
  a = 10;
  arguments[1] = 20;
  return [a, b, arguments[0], arguments[1]];
}

console.log(sloppy(1, 2));
console.log(strict(1, 2));
```

<Criteria>
- оба массива предсказаны до запуска;
- для каждого из восьми чисел объяснено, откуда оно взялось;
- найден пункт приложения C, который описывает разницу, записан номер раздела;
- записано, почему связь параметров с `arguments` опасна в большой функции.
</Criteria>
</Task>
