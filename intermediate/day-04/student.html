День 4. Функция как объект: свойства и arguments

Выжимка лекции: name, length, свои свойства функции, arguments, конструктор Function, обёртки once и memo.

Главное

Функция — объект, который можно вызвать. У неё есть ссылка на окружение (день 1), собственные свойства name и length, общие методы call, apply, bind, toString — и можно добавить свои свойства.

name и length — только для чтения (раздел 20.2.4): обычный режим молчит, строгий бросает TypeError. В Object.keys их не видно. length — сколько объявлено, arguments.length — сколько передали.

Свои свойства

function greet(student) {
  greet.calls = greet.calls + 1;
  return `Салам, ${student}!`;
}
greet.calls = 0;

Удобно для отладки и пометок. Но свойство видно и меняется снаружи — данные, которые надо защитить, держат в замыкании.

arguments

Похож на массив (номера и length), перебирается в for...of, свой на каждый вызов. В массив: [...arguments], Array.from(arguments), [].slice.call(arguments). В новом коде — ...rest.

  const inner = () => arguments.length;   // стрелочная берёт arguments у outer
  return inner(1, 2, 3);
}

Function и toString

new Function("a", "b", "return a + b") — функция из строк. Её окружение — всегда глобальное (замыкания нет), строка становится кодом (опасно), часто запрещена настройками сайта. Не пишем.
return на верхнем уровне скрипта — SyntaxError: Illegal return statement.
toString() — исходник целиком, с комментариями; у встроенных и привязанных — [native code]. Для отладки — да, для логики — нет.

Обёртки

function once(fn) {
  let done = false;
  let result;
  return function (...args) {          // обычная функция: нужен свой this
    if (!done) {
      done = true;
      result = fn.apply(this, args);   // передать this и все аргументы
    }
    return result;
  };
}

function memo(fn) {
  const cache = {};                    // ключи — строки! Map — день 14
  return function (key) {
    if (!Object.hasOwn(cache, key)) {
      cache[key] = fn.call(this, key);
    }
    return cache[key];
  };
}
Обёртка = замыкание для состояния + обычная function + fn.apply(this, args). Обёртка — другая функция: своё name (обычно пустое) и свой length.
