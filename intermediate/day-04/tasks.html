День 4. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 и 5 делаем в консоли, остальные — в папке day-04 курса 2.

Разминка

1. Восемь имён
Легко7 мин

предсказывать name по тому, как функция создана.

function first() {}
const second = function () {};
const third = () => {};
const fourth = function inner() {};
const box = { fifth() {}, sixth: () => {} };
const seventh = first.bind(null);
const eighth = new Function("return 8");

console.log(first.name, second.name, third.name, fourth.name);
console.log(box.fifth.name, box.sixth.name, seventh.name, eighth.name);
  • восемь имён предсказаны до запуска;
  • для каждого — строка таблицы раздела 2 лекции;
  • объяснено, почему у fourth имя не "fourth";
  • найден способ получить функцию с пустым именем, записан и проверен.
2. Шесть длин
Легко6 мин

применить правило «до первого умолчания или остаточного».

console.log(
  function (a, b, c) {}.length,
  function (a, b = 2, c) {}.length,
  function (...all) {}.length,
  function (a, { b, c }) {}.length,
  ((a, b) => a + b).length,
  function (a, b, c) {}.bind(null, 1, 2).length,
);
  • шесть чисел предсказаны до запуска;
  • для второй функции объяснено, почему не считается c;
  • для последней — откуда взялось число;
  • записано, чем length отличается от arguments.length.
3. Старый arguments
Легко7 мин

прочитать и переписать код со старым arguments.

function total() {
  let sum = 0;
  for (let i = 0; i < arguments.length; i++) {
    sum += arguments[i];
  }
  return sum;
}

console.log(total(5, 4, 3));

Перепишите total с ...marks и reduce (день 20). Потом предскажите вывод этой функции:

function wrap() {
  const count = () => arguments.length;
  return count("x", "y");
}

console.log(wrap(1, 2, 3, 4));
  • новая total даёт тот же ответ и для пустого вызова;
  • новая total записана стрелочной функцией — объяснено, почему со старой так было нельзя;
  • вывод wrap предсказан и объяснён: чьи аргументы считает стрелочная;
  • записано, что изменится, если wrap сделать стрелочной.

Основные задания

4. Счётчик двумя способами
Средне10 мин

сравнить свойство функции и замыкание на одной задаче.

  • Напишите greet(student), которая сама считает свои вызовы в свойстве greet.calls и запоминает последний аргумент в greet.last.
  • Напишите фабрику makeCounted(fn): возвращает обёртку, которая вызывает fn и считает вызовы в замыкании, и отдельную функцию, которая этот счёт сообщает.
  • оба способа считают верно на пяти вызовах;
  • для первого показано, как сбросить или испортить счёт снаружи, одной строкой;
  • для второго записано, можно ли сделать то же, и почему;
  • записано, какой способ вы выбрали бы для отладки, а какой — для данных программы.
5. Только для чтения
Средне8 мин

проверить признаки свойств name и length.

  • Попробуйте записать в name и в length функции новое значение — в обычном режиме и в строгом. Запишите, что получилось.
  • Попробуйте удалить name через delete и посмотрите, что стало с именем функции.
  • Сравните Object.keys функции до и после того, как добавите ей своё свойство.
  • записаны результаты обеих записей в обоих режимах и точный текст ошибки;
  • записано, что вернул delete и каким стало name после него;
  • каждый результат объяснён одним из трёх признаков из раздела 4 лекции;
  • записан вопрос, на который вы ждёте ответа завтра, на дне 5.
6. Одна отправка
Средне12 мин

применить once к методу объекта и к кнопке.

Напишите once и объект form с полем sent и методом send(text), который печатает Отправлено: текст, увеличивает this.sent и возвращает номер отправки. Сделайте метод одноразовым: form.send = once(form.send). На странице — кнопка «Отправить», которая вызывает form.send("Салам").

  • сколько бы раз ни нажали кнопку, в консоли одна строка «Отправлено», а form.sent равно 1;
  • каждое нажатие получает номер первой отправки — проверено;
  • once переписана со стрелочной функцией внутри — записано, что сломалось и какой строкой вывода это видно;
  • записаны name и length метода до и после обёртки.
7. memo и числа Фибоначчи
Средне20 мин

увидеть на числах, сколько работы экономит запоминание.

Числа Фибоначчи: первые два — 0 и 1, каждое следующее — сумма двух предыдущих. Рекурсивная функция из дня 12 Essentials записывается так:

function fib(n) {
  fib.calls = fib.calls + 1;
  return n < 2 ? n : fib(n - 1) + fib(n - 2);
}
fib.calls = 0;

console.log(fib(10), fib.calls);
  • Посчитайте fib(20) и число вызовов. Сбросьте счётчик перед подсчётом.
  • Напишите memo и сделайте fastFib, которая внутри вызывает себя, fastFib, а не fib. Посчитайте те же числа.
  • Найдите дыру ключей-строк: оберните в memo функцию (x) => typeof x и вызовите её с 1, потом с "1".
Если fastFib внутри зовёт обычную fib, запоминается только самый внешний вызов — и выигрыша почти нет. Рекурсия должна идти через обёртку.
  • fib(10) = 55, fib(20) = 6765 у обеих версий;
  • записано число вызовов fib(20) без памяти и с памятью — разница больше чем в тысячу раз;
  • после fastFib(20) вызов fastFib(30) сделал всего десять новых настоящих подсчётов — проверено и объяснено;
  • дыра ключей показана: "1" получил ответ, посчитанный для числа 1.

Со звёздочкой

8. Обёртка-журнал
Сложно10 мин

написать обёртку, которой нужны и name, и this, и arguments.

Напишите logged(fn): обёртка печатает имя исходной функции, аргументы и результат каждого вызова, а возвращает результат как есть.

const greet = logged(function greet(student) {
  return `Салам, ${student}!`;
});

greet("Аман");
// в консоли: greet("Аман") → "Салам, Аман!"
  • строка журнала совпадает с примером, аргументы и результат — через JSON.stringify;
  • обёртка работает с методом объекта, который читает this, — проверено;
  • обёртка работает с любым числом аргументов;
  • записано, что вышло при попытке присвоить обёртке имя исходной функции в строгом режиме.
9. Function против замыкания
Сложно10 мин

увидеть, откуда функция берёт окружение.

const level = "весь скрипт";

function test() {
  const level = "функция test";
  const a = () => level;
  const b = new Function("return level");
  return [a(), b()];
}

console.log(test());
  • вывод предсказан до запуска;
  • для a и b записано, какая запись окружения стала их [[Environment]];
  • объяснено, почему b нашла level, хотя это const, а не свойство глобального объекта (день 3, две половины);
  • первая строка удалена — записано, что стало с выводом, и точный текст ошибки.
