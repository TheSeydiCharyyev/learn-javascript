День 5. Свойства изнутри: дескрипторы, геттеры и сеттеры

Выжимка лекции: дескриптор и три признака, Object.defineProperty, кто что видит при переборе, геттеры и сеттеры, сокращённая запись методов.

Главное

Дескриптор — объект, который описывает свойство: значение (или геттер и сеттер) и три признака — writable, enumerable, configurable. Свойство из литерала или присваивания получает все три true. 
function greet() {}

Object.getOwnPropertyDescriptor({ name: "Аман" }, "name");
// {value: 'Аман', writable: true, enumerable: true, configurable: true}
Object.getOwnPropertyDescriptor(greet, "name");
// {value: 'greet', writable: false, enumerable: false, configurable: true}

Три признака

Признак falseОбычный режимСтрогий режим
writableзапись молча не срабатываетTypeError: Cannot assign to read only property
enumerableне видно в Object.keys, for...in, JSON, spread, Object.assign
configurabledelete даёт falsedelete — TypeError
Object.defineProperty(obj, "x", дескриптор): для нового свойства всё, что не указали, — false; для существующего меняет только указанное. Если менять нельзя — TypeError: Cannot redefine property в любом режиме. name функции: writable: false, но configurable: true — присвоить нельзя, переопределить можно.

Геттеры и сеттеры

const student = {
  get mark() {                   // чтение student.mark — без скобок
    return this._mark;
  },
  set mark(value) {              // запись student.mark = 4 — проверка
    if (Number.isInteger(value) && value >= 2 && value <= 5) {
      this._mark = value;
    }
  },
};
Object.defineProperty(student, "_mark", { value: 5, writable: true });   // служебное, скрыто

student.mark = 7;               // не принято
JSON.stringify(student);        // '{"mark":5}'
Геттер — без параметров (иначе SyntaxError), сеттер — ровно с одним. Свойство только с геттером: запись молчит, в строгом режиме — Cannot set property … which has only a getter. В сеттере x нельзя писать this.x — бесконечная рекурсия, RangeError. Скрытое поле не защищено: student._mark = 100 сработает.

Дескриптор аксессора: {get: ƒ, set: ƒ, enumerable, configurable} — без value и writable. Смешать оба вида в одном дескрипторе нельзя.

Методы, копии, hasOwnProperty

show() {} — то же свойство, что show: function () {}, но у метода нет prototype и с new его не вызвать (день 7). Имя может быть вычисляемым: [field]() {}.
Spread и Object.assign вызывают геттеры и кладут в копию значения; assign к тому же вызывает сеттеры. Копия вместе с геттерами: Object.defineProperties({}, Object.getOwnPropertyDescriptors(obj)).
obj.hasOwnProperty("x") — старый вариант; пишем Object.hasOwn(obj, "x").
  1. Найдите в своём итоговом проекте Essentials значение, которое вычисляют из других данных. Сделайте его геттером и проверьте, что оно пересчитывается само.
  2. Добавьте сеттер с проверкой к одному полю проекта, служебное поле спрячьте через defineProperty и убедитесь, что JSON его не содержит.
  3. Прочитайте на MDN учебник Enumerability and ownership of properties. Найдите в его таблицах строку Object.getOwnPropertySymbols и запишите, чем она отличается от строки getOwnPropertyNames.
  4. Откройте в спецификации раздел 6.1.7.1 Property Attributes и перескажите своими словами описания [[Writable]] и [[Configurable]].
