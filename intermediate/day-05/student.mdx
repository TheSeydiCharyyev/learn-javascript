# День 5. Свойства изнутри: дескрипторы, геттеры и сеттеры

<Subtitle>Выжимка лекции: дескриптор и три признака, `Object.defineProperty`, кто что видит при переборе, геттеры и сеттеры, сокращённая запись методов.</Subtitle>

## Главное

<Definition>
**Дескриптор** — объект, который описывает свойство: значение (или геттер
и сеттер) и три признака — `writable`, `enumerable`,
`configurable`. Свойство из литерала или присваивания получает все три
`true`.
</Definition>

```js
function greet() {}

Object.getOwnPropertyDescriptor({ name: "Аман" }, "name");
// {value: 'Аман', writable: true, enumerable: true, configurable: true}
Object.getOwnPropertyDescriptor(greet, "name");
// {value: 'greet', writable: false, enumerable: false, configurable: true}
```

## Три признака

<table>
<thead>
<tr><th>Признак `false`</th><th>Обычный режим</th><th>Строгий режим</th></tr>
</thead>
<tbody>
<tr><td>`writable`</td><td>запись молча не срабатывает</td><td>`TypeError: Cannot assign to read only property`</td></tr>
<tr><td>`enumerable`</td><td colSpan="2">не видно в `Object.keys`, `for...in`, JSON, spread, `Object.assign`</td></tr>
<tr><td>`configurable`</td><td>`delete` даёт `false`</td><td>`delete` — `TypeError`</td></tr>
</tbody>
</table>

<Remember>
`Object.defineProperty(obj, "x", дескриптор)`: для **нового** свойства
всё, что не указали, — `false`; для **существующего** меняет только
указанное. Если менять нельзя — `TypeError: Cannot redefine property` в любом режиме.
`name` функции: `writable: false`, но `configurable: true` —
присвоить нельзя, переопределить можно.
</Remember>

## Кто что видит

| Инструмент | Что видит |
| --- | --- |
| `Object.keys`, JSON, spread, `assign` | свои перечисляемые |
| `Object.getOwnPropertyNames` | все свои строковые, и неперечисляемые |
| `obj.propertyIsEnumerable("x")` | своё и перечисляемое? |
| `Object.hasOwn` | свои, любые |
| `in`, `for...in` | и унаследованные (день 7) |

## Геттеры и сеттеры

```js
const student = {
  get mark() {                   // чтение student.mark — без скобок
    return this._mark;
  },
  set mark(value) {              // запись student.mark = 4 — проверка
    if (Number.isInteger(value) && value >= 2 && value <= 5) {
      this._mark = value;
    }
  },
};
Object.defineProperty(student, "_mark", { value: 5, writable: true });   // служебное, скрыто

student.mark = 7;               // не принято
JSON.stringify(student);        // '{"mark":5}'
```

<KeyPoint>
Геттер — без параметров (иначе `SyntaxError`), сеттер — ровно с одним. Свойство
только с геттером: запись молчит, в строгом режиме —
`Cannot set property … which has only a getter`. В сеттере `x` нельзя
писать `this.x` — бесконечная рекурсия, `RangeError`. Скрытое поле
не защищено: `student._mark = 100` сработает.
</KeyPoint>

Дескриптор аксессора: `{get: ƒ, set: ƒ, enumerable, configurable}` — без
`value` и `writable`. Смешать оба вида в одном дескрипторе нельзя.

## Методы, копии, hasOwnProperty

<NoteBox>
`show() {}` — то же свойство, что `show: function () {}`, но у метода
нет `prototype` и с `new` его не вызвать (день 7). Имя может быть
вычисляемым: `[field]() {}`.
\
Spread и `Object.assign` вызывают геттеры и кладут в копию значения;
`assign` к тому же вызывает сеттеры. Копия вместе с геттерами:
`Object.defineProperties({}, Object.getOwnPropertyDescriptors(obj))`.
\
`obj.hasOwnProperty("x")` — старый вариант; пишем `Object.hasOwn(obj, "x")`.
</NoteBox>
