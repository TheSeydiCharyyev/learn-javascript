Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 и 6 делаем в консоли, остальные — в папке day-05 курса 2.

Разминка

предсказывать дескриптор по тому, как свойство появилось.

function greet(student) {}
const student = {
  name: "Аман",
  get title() {
    return `студент ${this.name}`;
  },
};
const marks = [5, 4, 3];

console.log(Object.getOwnPropertyDescriptor(student, "name"));
console.log(Object.getOwnPropertyDescriptor(student, "title"));

  • для каждого признака false записано, какое действие со свойством не выйдет;
  • объяснено, почему Object.keys(Math) пустой, хотя Math.max можно и прочитать, и даже заменить.

5. Длина урока
Средне12 мин

проверка в сеттере и скрытое служебное поле.

Сделайте объект lesson со свойством minutes: сеттер принимает только целые числа от 1 до 90, остальное отклоняет с сообщением в консоли. Значение хранится в служебном поле _minutes, созданном через defineProperty. Добавьте геттер label, который возвращает строку вида 45 мин.

lesson.minutes = 45;
lesson.minutes = 0;      // минуты 0 не приняты
lesson.minutes = 120;    // минуты 120 не приняты
lesson.minutes = "45";   // минуты 45 не приняты
lesson.minutes = 4.5;    // минуты 4.5 не приняты
console.log(lesson.label, JSON.stringify(lesson));
  • четыре неверных значения отклонены, lesson.minutes осталось 45;
  • последняя строка печатает 45 мин {"minutes":45} — для этого label сделан неперечисляемым;
  • Object.keys(lesson) — ['minutes'];
  • записано, что даёт lesson._minutes = 500 и почему это не защита.

7. Честные name и length обёртки
Средне20 мин

исправить недостаток обёрток дня 4 через дескрипторы.

Функция run из раздела 3 лекции дня 4 даёт второй аргумент только тем проверкам, у которых length больше 1:

function run(check) {
  if (check.length > 1) {
    return check("слово", "подробно");
  }
  return check("слово");
}

const detailed = (word, mode) => `проверено ${mode}: ${word}`;
console.log(run(detailed));
  • Возьмите once из дня 4 и вызовите run(once(detailed)).
  • Напишите помощник describe(wrapper, fn, prefix): через defineProperty он даёт обёртке имя prefix + " " + fn.name и length исходной функции, а возвращает обёртку.
  • Используйте его внутри once и снова вызовите run.
  • без помощника run(once(detailed)) печатает проверено undefined: слово — объяснено по length обёртки;
  • с помощником вывод тот же, что у run(detailed), имя — once detailed;
  • по getOwnPropertyDescriptor проверено, что writable у нового name остался false, и объяснено почему;
  • помощник применён и к memo дня 4.

9. Наблюдатель за свойством
Сложно10 мин

превратить готовое свойство-данные в аксессор, не меняя код снаружи.

Напишите watch(obj, key): после вызова каждая запись в свойство печатает старое и новое значение, а чтение работает как раньше. Значение храните в замыкании.

const quiz = { position: 0, flipped: false };
watch(quiz, "position");
quiz.position = 2;
quiz.position = quiz.position + 1;
// в консоли: position: 0 → 2
//            position: 2 → 3
  • строки журнала совпадают с примером;
  • Object.keys(quiz) и JSON.stringify(quiz) такие же, как без watch, — объяснено правилом 2 раздела 6 лекции;
  • у quiz не появилось ни одного нового свойства;
  • записано, что будет при watch для свойства с configurable: false, и точный текст ошибки.
