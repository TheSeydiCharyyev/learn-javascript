# День 5. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 и 6 делаем в консоли, остальные — в папке `day-05` курса 2.</Subtitle>

## Разминка

<Task title="1. Пять дескрипторов" level="easy" time="7">
<Goal>предсказывать дескриптор по тому, как свойство появилось.</Goal>

```js
function greet(student) {}
const student = {
  name: "Аман",
  get title() {
    return `студент ${this.name}`;
  },
};
const marks = [5, 4, 3];

console.log(Object.getOwnPropertyDescriptor(student, "name"));
console.log(Object.getOwnPropertyDescriptor(student, "title"));
console.log(Object.getOwnPropertyDescriptor(marks, "length"));
console.log(Object.getOwnPropertyDescriptor(greet, "length"));
console.log(Object.getOwnPropertyDescriptor(Math, "max"));
```

<Criteria>
- пять дескрипторов предсказаны до запуска, хотя бы признаки `true`/`false`;
- для каждого записано, свойство-данные это или аксессор;
- для каждого признака `false` записано, какое действие со свойством не выйдет;
- объяснено, почему `Object.keys(Math)` пустой, хотя `Math.max`
  можно и прочитать, и даже заменить.
</Criteria>
</Task>

<Task title="2. Кто что видит" level="easy" time="6">
<Goal>применить таблицу раздела 4 лекции.</Goal>

```js
const box = { a: 1 };
Object.defineProperty(box, "b", { value: 2 });
Object.defineProperty(box, "c", { value: 3, enumerable: true });

console.log(Object.keys(box));
console.log(Object.getOwnPropertyNames(box));
console.log(JSON.stringify(box));
console.log("b" in box, Object.hasOwn(box, "b"), box.propertyIsEnumerable("b"));
for (const key in box) {
  console.log(key);
}
```

<Criteria>
- вывод предсказан до запуска, строка за строкой;
- для каждой строки названа строка таблицы раздела 4;
- записано, что станет с `box.c` после `box.c = 30` и почему;
- записано, какие признаки у `a`, `b` и `c`, — проверено
  через `getOwnPropertyDescriptor`.
</Criteria>
</Task>

## Основные задания

<Task title="4. Группа с вычисляемыми свойствами" level="medium" time="10">
<Goal>заменить ручной пересчёт геттерами.</Goal>

```js
const group = {
  students: [
    { name: "Аман", marks: [5, 4, 5] },
    { name: "Мерет", marks: [4, 4, 3] },
    { name: "Сапар", marks: [5, 5] },
  ],
};
```

- Добавьте в `group` три геттера: `count` — число студентов,
  `best` — имя студента с лучшим средним, `average` — средняя всех
  оценок группы.
- Добавьте студента `{ name: "Айна", marks: [4, 5] }` через
  `group.students.push(...)` и прочитайте геттеры снова.
- В строгом режиме попробуйте `group.count = 10`.

<Criteria>
- до добавления: `3`, `Сапар`, `4.375`; после — `4`,
  `Сапар`, `4.4`, и никакого другого кода между чтениями;
- геттеры читаются без скобок, внутри — `this`, а не имя `group`;
- записан точный текст ошибки строгого режима;
- записано, почему `count` лучше геттером, чем полем, которое обновляют вручную.
</Criteria>
</Task>

<Task title="5. Длина урока" level="medium" time="12">
<Goal>проверка в сеттере и скрытое служебное поле.</Goal>

Сделайте объект `lesson` со свойством `minutes`: сеттер принимает
только целые числа от 1 до 90, остальное отклоняет с сообщением в консоли. Значение хранится
в служебном поле `_minutes`, созданном через `defineProperty`. Добавьте
геттер `label`, который возвращает строку вида `45 мин`.

<Example>
```js
lesson.minutes = 45;
lesson.minutes = 0;      // минуты 0 не приняты
lesson.minutes = 120;    // минуты 120 не приняты
lesson.minutes = "45";   // минуты 45 не приняты
lesson.minutes = 4.5;    // минуты 4.5 не приняты
console.log(lesson.label, JSON.stringify(lesson));
```
</Example>

<Criteria>
- четыре неверных значения отклонены, `lesson.minutes` осталось 45;
- последняя строка печатает `45 мин {"minutes":45}` — для этого
  `label` сделан неперечисляемым;
- `Object.keys(lesson)` — `['minutes']`;
- записано, что даёт `lesson._minutes = 500` и почему это не защита.
</Criteria>
</Task>

<Criteria>

- объяснено, почему одно действие бросает ошибку в обоих режимах;
- записано, совпали ли дескрипторы двух констант признак за признаком;

</Criteria>
</Task>

<Task title="7. Честные name и length обёртки" level="medium" time="20">
<Goal>исправить недостаток обёрток дня 4 через дескрипторы.</Goal>

Функция `run` из раздела 3 лекции дня 4 даёт второй аргумент только тем проверкам,
у которых `length` больше 1:

```js
function run(check) {
  if (check.length > 1) {
    return check("слово", "подробно");
  }
  return check("слово");
}

const detailed = (word, mode) => `проверено ${mode}: ${word}`;
console.log(run(detailed));
```

- Возьмите `once` из дня 4 и вызовите `run(once(detailed))`.
- Напишите помощник `describe(wrapper, fn, prefix)`: через `defineProperty`
  он даёт обёртке имя `prefix + " " + fn.name` и `length` исходной функции,
  а возвращает обёртку.
- Используйте его внутри `once` и снова вызовите `run`.

<Criteria>
- без помощника `run(once(detailed))` печатает `проверено undefined: слово` —
  объяснено по `length` обёртки;
- с помощником вывод тот же, что у `run(detailed)`, имя — `once detailed`;
- по `getOwnPropertyDescriptor` проверено, что `writable` у нового
  `name` остался `false`, и объяснено почему;
- помощник применён и к `memo` дня 4.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Полная копия" level="hard" time="10">
<Goal>сравнить три способа копирования на объекте со всеми видами свойств.</Goal>

Соберите объект: обычное свойство `name`, скрытое `_mark`, геттер
`mark` и сеттер `mark` с проверкой из лекции. Напишите `clone(obj)`
через дескрипторы и сравните три копии: `{ ...obj }`, `Object.assign({}, obj)`
и `clone(obj)`.

<Criteria>
- в таблице для каждой копии записано: есть ли `_mark`, чем стал `mark`
  (данные или аксессор), работает ли проверка в сеттере;
- показано, что у `clone` геттер читает своё `_mark`, а не оригинала;
- объяснено, почему у spread-копии `mark = 7` «срабатывает»;
- записано, почему и `clone` — поверхностная копия, на примере с массивом.
</Criteria>
</Task>

<Task title="9. Наблюдатель за свойством" level="hard" time="10">
<Goal>превратить готовое свойство-данные в аксессор, не меняя код снаружи.</Goal>

Напишите `watch(obj, key)`: после вызова каждая запись в свойство печатает старое
и новое значение, а чтение работает как раньше. Значение храните в замыкании.

<Example>
```js
const quiz = { position: 0, flipped: false };
watch(quiz, "position");
quiz.position = 2;
quiz.position = quiz.position + 1;
// в консоли: position: 0 → 2
//            position: 2 → 3
```
</Example>

<Criteria>
- строки журнала совпадают с примером;
- `Object.keys(quiz)` и `JSON.stringify(quiz)` такие же, как без
  `watch`, — объяснено правилом 2 раздела 6 лекции;
- у `quiz` не появилось ни одного нового свойства;
- записано, что будет при `watch` для свойства с `configurable: false`,
  и точный текст ошибки.
</Criteria>
</Task>
