# День 6. Защита объектов, Object.is и логическое присваивание

<Subtitle>Выжимка лекции: три уровня защиты, глубокая заморозка, четыре сравнения, `||=`, `&&=`, `??=`, общие методы объектов.</Subtitle>

## Три уровня защиты

| Функция | добавлять | удалять | записывать | Проверка |
| --- | --- | --- | --- | --- |
| `preventExtensions` | нет | да | да | `isExtensible` → `false` |
| `seal` | нет | нет | да | `isSealed` → `true` |
| `freeze` | нет | нет | нет | `isFrozen` → `true` |

<Definition>
`seal` = запрет расширения + `configurable: false` всем свойствам;
`freeze` = то же + `writable: false` свойствам-данным. В спецификации
обе — операция SetIntegrityLevel (7.3.15). Все три функции необратимы и возвращают тот же объект.
</Definition>

<Remember>
Нарушение защиты: обычный режим молчит, строгий бросает `TypeError`
(`Cannot add property x, object is not extensible`). `defineProperty`
и методы массива (`push`, `pop`, `sort`) бросают ошибку
**в любом режиме**. Аксессоры замороженного объекта продолжают работать.
</Remember>

```js
function deepFreeze(obj) {
  Object.freeze(obj);
  for (const value of Object.values(obj)) {
    if (typeof value === "object" && value !== null && !Object.isFrozen(value)) {
      deepFreeze(value);   // freeze неглубокий: вложенное — рекурсией
    }
  }
  return obj;
}
```

## Четыре сравнения

| Сравнение | Где | `NaN`, `NaN` | `0`, `-0` |
| --- | --- | --- | --- |
| `==` | старый код; приводит типы | не равны | равны |
| `===` | наш код, `indexOf`, `switch` | не равны | равны |
| SameValueZero | `includes`, `Map`, `Set` | равны | равны |
| `Object.is` (SameValue) | `defineProperty` | равны | не равны |

<KeyPoint>
Объекты все четыре сравнивают по ссылке. `-0` дают `Math.round(-0.4)`
и `0 * -5`; строка и JSON теряют минус. `Object.is` нужен редко:
для `NaN` есть `Number.isNaN`.
</KeyPoint>

`==` по шагам (IsLooselyEqual, 7.2.13): одинаковый тип — как `===`;
`null` равен только `undefined`; строка рядом с числом становится числом;
`true` и `false` — числами 1 и 0; объект — примитивом. После каждого
превращения — с начала. `[] == false`: `false` → `0`,
`[]` → `""` → `0`, итог `true`.

## Логическое присваивание

```js
const options = { timer: 0, title: "", name: "  Аман " };

options.timer ??= 10;                  // a ?? (a = b): 0 остался
options.title ||= "Карточки";          // a || (a = b): "" заменили
options.name &&= options.name.trim();   // a && (a = b): обрезали
```

<Remember>
Записи может не быть вовсе: правая часть не вычисляется, сеттер не вызывается, заморозка не
мешает. `??` с `||` и `&&` — только в скобках
(`Unexpected token`); унарный минус слева от `**` — тоже.
\
Память в одну строку: `return (cache[key] ??= fn.call(this, key));` — но ответ
`undefined` она не запоминает, тогда нужен `Object.hasOwn`, как на дне 4.
</Remember>

## У каждого объекта

<NoteBox>
`toString` → `"[object Object]"`; одолженный через `call`
называет вид: `[object Array]`, `[object Null]`. `valueOf`
обычного объекта — он сам; `toLocaleString` вызывает `toString`.
`Object(5)` — обёртка, `Object(null)` — `{}`,
`Object(obj) === obj`. Объект в примитив: сначала `valueOf`, потом
`toString`; в шаблоне и `String` — наоборот. Откуда это всё берётся — день 7.
</NoteBox>
