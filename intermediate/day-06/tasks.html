День 6. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, остальные — в папке day-06 курса 2.

Разминка

1. Три ступени
Легко7 мин

применить таблицу трёх уровней защиты.

const a = Object.preventExtensions({ x: 1, y: 2 });
const b = Object.seal({ x: 1, y: 2 });
const c = Object.freeze({ x: 1, y: 2 });

for (const obj of [a, b, c]) {
  obj.x = 10;
  obj.z = 3;
  delete obj.y;
}

console.log(a, b, c);
console.log(Object.isExtensible(a), Object.isSealed(b), Object.isFrozen(c));
  • обе строки вывода предсказаны до запуска;
  • для каждого объекта каждая из трёх строк цикла объяснена строкой таблицы раздела 2 лекции;
  • с "use strict" записано, на какой строке цикла падает программа, и точный текст ошибки;
  • записано, запечатан ли a после цикла, — проверено Object.isSealed(a).
2. Четыре сравнения
Легко6 мин

предсказывать результат каждого сравнения на особых значениях.

const pairs = [[NaN, NaN], [0, -0], ["1", 1], [null, undefined], [[], []]];

for (const [x, y] of pairs) {
  console.log(x == y, x === y, Object.is(x, y), [x].includes(y));
}
  • таблица 5 × 4 заполнена до запуска и сверена с выводом;
  • для каждого столбца названа операция спецификации;
  • объяснено, почему в последней строке все четыре — false;
  • объяснено, почему === и includes расходятся только в одной строке.
3. Умолчания и скобки
Легко7 мин

различать три логических присваивания и чинить ошибки скобок.

let a = 0, b = "", c = null, d = "Мары";

a ||= 5;
b ??= "Ашхабад";
c ??= "Дашогуз";
d &&= d.toUpperCase();
console.log(a, JSON.stringify(b), c, d);

Потом запустите отдельно две строки:

const power = -3 ** 2;
const city = "" ?? null || "Мары";
  • вывод первого куска предсказан; для каждой переменной записано условие её оператора;
  • для двух строк записаны точные тексты ошибок;
  • каждая строка исправлена двумя способами расстановки скобок, оба результата записаны;
  • записано, при каком a строка a ||= 5 не изменит переменную.

5. Свои seal и freeze
Средне12 мин

повторить шаги SetIntegrityLevel инструментами дня 5.

Напишите mySeal(obj) и myFreeze(obj) без Object.seal и Object.freeze: только preventExtensions, getOwnPropertyNames и defineProperty. Обе возвращают тот же объект.

  • на объекте { a: 1, b: 2 } дескрипторы после mySeal совпадают с дескрипторами после Object.seal, а Object.isSealed — true;
  • то же для myFreeze и Object.isFrozen;
  • myFreeze проверена на объекте с геттером: геттер после неё работает, как после Object.freeze;
  • записано, что случилось с геттером в первой версии, если вы ставили writable: false всем свойствам подряд, — и почему (шаг 4 SetIntegrityLevel).
6. Чистка загруженных данных
Средне8 мин

выбирать между ??=, ||= и &&= по смыслу данных.

const students = JSON.parse(`[
  {"name": "  Аман ", "group": "1-А", "marks": [5, 4]},
  {"name": "Мерет", "marks": null},
  {"name": "", "group": null},
  {"name": "   ", "group": "2-Б"}

Одним циклом приведите каждого студента в порядок: имя без пробелов по краям, пустое имя — "без имени", нет группы — "1-А", нет оценок — пустой массив. Одна строка на правило, без if.

7. Поиск со своими правилами
Средне20 мин

написать все четыре сравнения функциями и проверить их на одном поиске.

  • Напишите findAll(list, value, same): возвращает массив номеров элементов, для которых same(элемент, value) — true.
  • Напишите sameValueZero(x, y) без includes: через Object.is и одну проверку для нулей.
  • Ищите в массиве [0, -0, NaN, "0", null, undefined, NaN] значения 0, NaN и undefined четырьмя сравнениями: ==, ===, Object.is, sameValueZero.
  • таблица 3 × 4 заполнена; например, 0 через Object.is — [0], NaN через sameValueZero — [2, 6], undefined через == — [4, 5];
  • объяснено, почему 0 через == нашёл ещё и "0";
  • sameValueZero сверена с [x].includes(y) на всех парах из массива;
  • записано, какому сравнению соответствуют indexOf и includes.

8. Заморозка по кругу
Сложно10 мин

понять, зачем в deepFreeze проверка isFrozen.

const group = { title: "1-А", students: [] };
const aman = { name: "Аман", group };
group.students.push(aman);

console.log(aman.group.students[0].group.title);
  • deepFreeze без проверки !Object.isFrozen(value) запущена на group — записан текст ошибки и объяснено, откуда она;
  • с проверкой заморожены все три объекта — group, массив и aman;
  • найден случай, когда проверка ошибается: объект заморожен обычным freeze заранее, а его вложенный массив — нет; показано, что deepFreeze его пропустит;
  • предложено исправление этого случая, хотя бы словами.
9. Заморожен, но живой
Сложно10 мин

отличить неизменный объект от неизменных данных.

function makeCounter() {
  let count = 0;
  return Object.freeze({
    get value() {
      return count;
    },
    increment() {
      count = count + 1;
    },
  });
}

const counter = makeCounter();
counter.increment();
counter.increment();
console.log(counter.value, Object.isFrozen(counter));
  • вывод предсказан и объяснён: чем заморожен объект и почему счёт всё равно растёт;
  • в строгом режиме записаны тексты ошибок для counter.value = 10 и counter.increment = null — и почему они разные;
  • записано, что именно не может изменить посторонний код, а что может только сам объект;
  • сравнено со счётчиком на замыкании дня 1: что даёт здесь freeze сверх замыкания.
