# День 6. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, остальные — в папке `day-06` курса 2.</Subtitle>

## Разминка

<Task title="1. Три ступени" level="easy" time="7">
<Goal>применить таблицу трёх уровней защиты.</Goal>

```js
const a = Object.preventExtensions({ x: 1, y: 2 });
const b = Object.seal({ x: 1, y: 2 });
const c = Object.freeze({ x: 1, y: 2 });

for (const obj of [a, b, c]) {
  obj.x = 10;
  obj.z = 3;
  delete obj.y;
}

console.log(a, b, c);
console.log(Object.isExtensible(a), Object.isSealed(b), Object.isFrozen(c));
```

<Criteria>
- обе строки вывода предсказаны до запуска;
- для каждого объекта каждая из трёх строк цикла объяснена строкой таблицы раздела 2 лекции;
- с `"use strict"` записано, на какой строке цикла падает программа, и точный текст ошибки;
- записано, запечатан ли `a` после цикла, — проверено `Object.isSealed(a)`.
</Criteria>
</Task>

<Task title="2. Четыре сравнения" level="easy" time="6">
<Goal>предсказывать результат каждого сравнения на особых значениях.</Goal>

```js
const pairs = [[NaN, NaN], [0, -0], ["1", 1], [null, undefined], [[], []]];

for (const [x, y] of pairs) {
  console.log(x == y, x === y, Object.is(x, y), [x].includes(y));
}
```

<Criteria>
- таблица 5 × 4 заполнена до запуска и сверена с выводом;
- для каждого столбца названа операция спецификации;
- объяснено, почему в последней строке все четыре — `false`;
- объяснено, почему `===` и `includes` расходятся только в одной строке.
</Criteria>
</Task>

<Task title="3. Умолчания и скобки" level="easy" time="7">
<Goal>различать три логических присваивания и чинить ошибки скобок.</Goal>

```js
let a = 0, b = "", c = null, d = "Мары";

a ||= 5;
b ??= "Ашхабад";
c ??= "Дашогуз";
d &&= d.toUpperCase();
console.log(a, JSON.stringify(b), c, d);
```

Потом запустите отдельно две строки:

```js
const power = -3 ** 2;
```

```js
const city = "" ?? null || "Мары";
```

<Criteria>
- вывод первого куска предсказан; для каждой переменной записано условие её оператора;
- для двух строк записаны точные тексты ошибок;
- каждая строка исправлена двумя способами расстановки скобок, оба результата записаны;
- записано, при каком `a` строка `a ||= 5` не изменит переменную.
</Criteria>
</Task>

## Основные задания

<Task title="4. Настройки под замком" level="medium" time="10">
<Goal>увидеть, где кончается обычная заморозка.</Goal>

```js
const config = {
  title: "Карточки",
  limits: { perDay: 20, perSession: 5 },
  topics: ["школа", "еда", "дом"],
};
```

- Заморозьте `config` через `Object.freeze` и в строгом режиме попробуйте
  три записи: `config.title = "Слова"`, `config.limits.perDay = 50`,
  `config.topics.push("спорт")`. Каждую — в своём `try...catch`.
- Напишите `deepFreeze` и повторите опыт на свежем объекте.

<Criteria>
- после `freeze` первая запись упала, а вторая и третья прошли — записано,
  что стало с `perDay` и с массивом;
- после `deepFreeze` упали все три — записаны три текста ошибок;
- для `config`, `config.limits` и `config.topics` записан
  `Object.isFrozen` до и после;
- объяснено, почему не помогло бы и `const config`.
</Criteria>
</Task>

<Task title="5. Свои seal и freeze" level="medium" time="12">
<Goal>повторить шаги SetIntegrityLevel инструментами дня 5.</Goal>

Напишите `mySeal(obj)` и `myFreeze(obj)` без `Object.seal`
и `Object.freeze`: только `preventExtensions`, `getOwnPropertyNames`
и `defineProperty`. Обе возвращают тот же объект.

<Criteria>
- на объекте `{ a: 1, b: 2 }` дескрипторы после `mySeal` совпадают
  с дескрипторами после `Object.seal`, а `Object.isSealed` — `true`;
- то же для `myFreeze` и `Object.isFrozen`;
- `myFreeze` проверена на объекте с геттером: геттер после неё работает, как
  после `Object.freeze`;
- записано, что случилось с геттером в первой версии, если вы ставили `writable: false`
  всем свойствам подряд, — и почему (шаг 4 SetIntegrityLevel).
</Criteria>
</Task>

<Task title="6. Чистка загруженных данных" level="medium" time="8">
<Goal>выбирать между `??=`, `||=` и `&&=` по смыслу данных.</Goal>

```js
const students = JSON.parse(`[
  {"name": "  Аман ", "group": "1-А", "marks": [5, 4]},
  {"name": "Мерет", "marks": null},
  {"name": "", "group": null},
  {"name": "   ", "group": "2-Б"}
]`);
```

Одним циклом приведите каждого студента в порядок: имя без пробелов по краям, пустое имя —
`"без имени"`, нет группы — `"1-А"`, нет оценок — пустой массив. Одна строка
на правило, без `if`.

<Criteria>
- `JSON.stringify(students)` даёт
  `[{"name":"Аман","group":"1-А","marks":[5,4]},{"name":"Мерет","marks":[],"group":"1-А"},{"name":"без имени","group":"1-А","marks":[]},{"name":"без имени","group":"2-Б","marks":[]}]`;
- для каждой строки цикла записано, почему выбран именно этот оператор;
- на четвёртом студенте объяснено, почему строка с `&&=` стоит раньше
  строки с `||=`;
- записано, откуда в JSON такой порядок ключей у второго и третьего студента.
</Criteria>
</Task>

<Task title="7. Поиск со своими правилами" level="medium" time="20">
<Goal>написать все четыре сравнения функциями и проверить их на одном поиске.</Goal>

- Напишите `findAll(list, value, same)`: возвращает массив номеров элементов,
  для которых `same(элемент, value)` — `true`.
- Напишите `sameValueZero(x, y)` без `includes`: через
  `Object.is` и одну проверку для нулей.
- Ищите в массиве `[0, -0, NaN, "0", null, undefined, NaN]` значения
  `0`, `NaN` и `undefined` четырьмя сравнениями:
  `==`, `===`, `Object.is`, `sameValueZero`.

<Criteria>
- таблица 3 × 4 заполнена; например, `0` через `Object.is` —
  `[0]`, `NaN` через `sameValueZero` — `[2, 6]`,
  `undefined` через `==` — `[4, 5]`;
- объяснено, почему `0` через `==` нашёл ещё и `"0"`;
- `sameValueZero` сверена с `[x].includes(y)` на всех парах из массива;
- записано, какому сравнению соответствуют `indexOf` и `includes`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Заморозка по кругу" level="hard" time="10">
<Goal>понять, зачем в `deepFreeze` проверка `isFrozen`.</Goal>

```js
const group = { title: "1-А", students: [] };
const aman = { name: "Аман", group };
group.students.push(aman);

console.log(aman.group.students[0].group.title);
```

<Criteria>
- `deepFreeze` без проверки `!Object.isFrozen(value)` запущена на
  `group` — записан текст ошибки и объяснено, откуда она;
- с проверкой заморожены все три объекта — `group`, массив и `aman`;
- найден случай, когда проверка ошибается: объект заморожен обычным `freeze`
  заранее, а его вложенный массив — нет; показано, что `deepFreeze` его пропустит;
- предложено исправление этого случая, хотя бы словами.
</Criteria>
</Task>

<Task title="9. Заморожен, но живой" level="hard" time="10">
<Goal>отличить неизменный объект от неизменных данных.</Goal>

```js
function makeCounter() {
  let count = 0;
  return Object.freeze({
    get value() {
      return count;
    },
    increment() {
      count = count + 1;
    },
  });
}

const counter = makeCounter();
counter.increment();
counter.increment();
console.log(counter.value, Object.isFrozen(counter));
```

<Criteria>
- вывод предсказан и объяснён: чем заморожен объект и почему счёт всё равно растёт;
- в строгом режиме записаны тексты ошибок для `counter.value = 10` и
  `counter.increment = null` — и почему они разные;
- записано, что именно не может изменить посторонний код, а что может только сам объект;
- сравнено со счётчиком на замыкании дня 1: что даёт здесь `freeze` сверх замыкания.
</Criteria>
</Task>
