# День 7. Прототипы: цепочка, Object.create, new и instanceof

<Subtitle>Выжимка лекции: прототип и цепочка, поиск и запись свойств, `Object.create`, функция-конструктор и `new`, `instanceof`, словарь без прототипа.</Subtitle>

## Главное

<Definition>
**Прототип** — объект, на который ссылается скрытый слот `[[Prototype]]`
другого объекта. Цепочка прототипов кончается `null`. Чтение свойства идёт по цепочке:
своё → прототип → … → `null` → `undefined`.
</Definition>

```js
const student = { name: "Аман" };
Object.getPrototypeOf(student) === Object.prototype;   // true: там toString
Object.getPrototypeOf(Object.prototype);               // null
Object.getPrototypeOf([]) === Array.prototype;         // map, filter, push…
Object.getPrototypeOf(() => 1) === Function.prototype; // call, apply, bind
```

<Remember>
Метод лежит в прототипе, один на всех, а работает с `this` того объекта, у которого
его вызвали. Запись создаёт **своё** свойство и затеняет унаследованное; исключения —
сеттер в цепочке и унаследованное свойство только для чтения (запись пропадает).
`for...in` перебирает и унаследованные перечисляемые, `Object.keys` — только свои.
</Remember>

## Создать и проверить

| Запись | Что делает |
| --- | --- |
| `Object.create(proto)` | новый объект с прототипом `proto`; второй аргумент — дескрипторы |
| `{ __proto__: proto, … }` | то же в литерале — стандарт; `obj.__proto__` — устарело |
| `Object.getPrototypeOf(obj)` | прочитать прототип |
| `proto.isPrototypeOf(obj)` | есть ли `proto` в цепочке `obj` |
| `Object.setPrototypeOf(obj, p)` | сменить: медленно; цикл и нерасширяемый объект — `TypeError` |

## Конструктор и new

```js
function Student(name, marks) {   // с большой буквы: «вызывать с new»
  this.name = name;
  this.marks = marks;
}
Student.prototype.average = function () {
  return this.marks.reduce((a, b) => a + b, 0) / this.marks.length;
};

const aman = new Student("Аман", [5, 4, 5]);
aman.average();                                  // 4.666666666666667
Student.prototype.constructor === Student;       // true
```

Метод в конструкторе (`this.greet = function () {…}`) — своя копия у каждого объекта
и ключ в `Object.keys`. Метод в `prototype` — одна функция на всех, и метод,
добавленный позже, сразу есть у всех уже созданных объектов.

<KeyPoint>
`new F()`: 1) объект с прототипом `F.prototype`; 2) вызов `F` с
`this` — этим объектом; 3) тело пишет свойства; 4) вернуть объект (или объект из
`return`). Без `new` `this` — окно или, в строгом режиме,
`undefined`. Стрелочные и методы — не конструкторы (`is not a constructor`),
`new F?.()` — `SyntaxError`. Заменили `prototype` целиком —
потеряли `constructor`.
</KeyPoint>

## instanceof и словарь

<NoteBox>
`x instanceof F` — есть ли `F.prototype` в цепочке `x`.
Примитив — `false`, `Object.create(null) instanceof Object` — `false`,
после смены прототипа ответ меняется. Массив проверяют `Array.isArray`.
\
`Object.create(null)` — словарь без унаследованных ключей: слово
`"constructor"` не сломает счёт. Но у него нет и `toString`,
`hasOwnProperty` — пишем `Object.hasOwn`. Встроенные прототипы не расширяем.
</NoteBox>
