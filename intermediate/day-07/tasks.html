День 7. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, остальные — в папке day-07 курса 2.

Разминка

1. Чья это цепочка
Легко7 мин

видеть цепочку прототипов знакомых значений.

function chain(value) {
  const names = [];
  let p = Object.getPrototypeOf(value);
  while (p !== null) {
    names.push(p.constructor.name);
    p = Object.getPrototypeOf(p);
  }
  return names.join(" → ");
}

console.log(chain({}));
console.log(chain([5, 4]));
console.log(chain(function greet() {}));
console.log(chain(new Date()));
console.log(chain(new RangeError("ошибка")));
  • пять строк предсказаны до запуска;
  • объяснено, как цепочка RangeError объясняет «потомков» из дня 11 Essentials;
  • предсказаны и проверены chain("abc") и chain(Object.create(null)) — записано, почему у строки цепочка вообще есть;
  • записано, что делает строка p.constructor.name и откуда у прототипа constructor.

const base = {

  • записано, что напечатает последняя строка, если вместо delete aman.kind написать delete base.kind.

5. Свой new
Средне12 мин

повторить четыре шага new обычной функцией.

Напишите create(F, ...args), которая делает то же, что new F(...args), без слова new: Object.create, apply (день 2) и проверка результата.

  • с Student из лекции create(Student, "Аман", [5, 4]) даёт объект, для которого instanceof Student — true, а average() — 4.5;
  • с Maker из раздела 7 лекции возвращается {b: 2};
  • каждый шаг в коде подписан номером шага из лекции;
  • со стрелочной функцией записан текст ошибки и объяснено, на каком шаге и почему она возникла.

7. Свой instanceof
Средне20 мин

повторить алгоритм OrdinaryHasInstance.

Напишите isInstance(value, F) без instanceof и isPrototypeOf: только Object.getPrototypeOf и цикл. Проверьте на парах:

function Student(name) {
  this.name = name;
}
const aman = new Student("Аман");

const pairs = [
  [aman, Student], [aman, Object], [[], Array], [[], Object],
  ["abc", String], [Object.create(null), Object],
  [new RangeError("x"), Error], [Student, Function],
];

console.log(pairs.map(([value, F]) => value instanceof F).join(" "));
  • на всех восьми парах ответы isInstance совпали с instanceof: true true true true false false true true;
  • после Object.setPrototypeOf(aman, null) обе проверки дают false для Student и Object;
  • если справа не функция, isInstance бросает TypeError, как instanceof;
  • объяснено, почему Student instanceof Function — true, а Student instanceof Student — false.

8. Цепочка из трёх звеньев
Сложно10 мин

построить цепочку вручную и вызвать метод из звена выше.

const cardBase = {
  flip() {
    this.flipped = !this.flipped;
    return this.text();
  },
  text() {
    return this.flipped ? this.translation : this.word;
  },
};

Сделайте exampleCard = Object.create(cardBase) со своим методом text: он возвращает текст базовой карточки и пример в скобках. Создайте карточку Object.create(exampleCard) со словом book, переводом книга и примером I read a book.

  • card.text() — book (I read a book), card.flip() — книга (I read a book);
  • базовый текст получен через cardBase.text.call(this) — записано, что будет, если написать this.text(), и точный текст ошибки;
  • проверено isPrototypeOf обоих звеньев и записано Object.keys(card);
  • нарисована цепочка карточки до null.
