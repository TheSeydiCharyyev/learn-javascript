## Разминка

<Task title="1. Чья это цепочка" level="easy" time="7">
<Goal>видеть цепочку прототипов знакомых значений.</Goal>

```js
function chain(value) {
  const names = [];
  let p = Object.getPrototypeOf(value);
  while (p !== null) {
    names.push(p.constructor.name);
    p = Object.getPrototypeOf(p);
  }
  return names.join(" → ");
}

console.log(chain({}));
console.log(chain([5, 4]));
console.log(chain(function greet() {}));
console.log(chain(new Date()));
console.log(chain(new RangeError("ошибка")));
```

<Criteria>
- пять строк предсказаны до запуска;
- объяснено, как цепочка `RangeError` объясняет «потомков» из дня 11 Essentials;
- предсказаны и проверены `chain("abc")` и `chain(Object.create(null))` —
  записано, почему у строки цепочка вообще есть;
- записано, что делает строка `p.constructor.name` и откуда у прототипа `constructor`.
</Criteria>
</Task>

- записано, что напечатает последняя строка, если вместо `delete aman.kind`
  написать `delete base.kind`.

<Task title="4. Конструктор группы" level="medium" time="10">

<Task title="6. Словарь без ловушек" level="medium" time="8">

Посчитайте слова дважды: в `{}` и в `Object.create(null)`, правилом

<Task title="7. Свой instanceof" level="medium" time="20">
<Goal>повторить алгоритм OrdinaryHasInstance.</Goal>

Напишите `isInstance(value, F)` без `instanceof` и `isPrototypeOf`:
только `Object.getPrototypeOf` и цикл. Проверьте на парах:

```js
function Student(name) {
  this.name = name;
}
const aman = new Student("Аман");

const pairs = [
  [aman, Student], [aman, Object], [[], Array], [[], Object],
  ["abc", String], [Object.create(null), Object],
  [new RangeError("x"), Error], [Student, Function],
];

console.log(pairs.map(([value, F]) => value instanceof F).join(" "));
```

<Criteria>
- на всех восьми парах ответы `isInstance` совпали с `instanceof`:
  `true true true true false false true true`;
- после `Object.setPrototypeOf(aman, null)` обе проверки дают `false`
  для `Student` и `Object`;
- если справа не функция, `isInstance` бросает `TypeError`, как
  `instanceof`;
- объяснено, почему `Student instanceof Function` — `true`, а
  `Student instanceof Student` — `false`.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Цепочка из трёх звеньев" level="hard" time="10">
<Goal>построить цепочку вручную и вызвать метод из звена выше.</Goal>

```js
const cardBase = {
  flip() {
    this.flipped = !this.flipped;
    return this.text();
  },
  text() {
    return this.flipped ? this.translation : this.word;
  },
};
```

Сделайте `exampleCard = Object.create(cardBase)` со своим методом `text`:
он возвращает текст базовой карточки и пример в скобках. Создайте карточку
`Object.create(exampleCard)` со словом `book`, переводом `книга`
и примером `I read a book`.

<Criteria>
- `card.text()` — `book (I read a book)`, `card.flip()` —
  `книга (I read a book)`;
- базовый текст получен через `cardBase.text.call(this)` — записано, что будет,
  если написать `this.text()`, и точный текст ошибки;
- проверено `isPrototypeOf` обоих звеньев и записано `Object.keys(card)`;
- нарисована цепочка карточки до `null`.
</Criteria>
</Task>
