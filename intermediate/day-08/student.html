День 8. Классы: конструктор, методы, поля

Выжимка лекции: класс как запись функции-конструктора, constructor, методы и геттеры, поля, потерянный this, отличия от функции-конструктора.

Главное

Класс — запись функции-конструктора и её prototype в одном месте. typeof класса — "function"; методы лежат в Класс.prototype; цепочка, instanceof и constructor — как на дне 7. 
class Card {
  flipped = false;                  // поле: своё у каждого объекта
  handleFlip = () => this.flip();   // поле-стрелка: не теряет this

  constructor(word, translation) {  // при new, после полей
    this.word = word;
    this.translation = translation;
  }

  flip() {                          // метод: в Card.prototype, неперечисляемый
    this.flipped = !this.flipped;
    return this.text();
  }

  text() {
    return this.flipped ? this.translation : this.word;
  }

  get label() {                     // геттер: тоже в Card.prototype
    return `карточка ${this.word}`;
  }
}

const card = new Card("bread", "хлеб");
card.handleFlip();                  // "хлеб"

Сеттер в классе проверяет значение и при создании: this.mark = mark в конструкторе находит сеттер по цепочке. Но поле с тем же именем (mark = 7;) определяет своё свойство и обходит сеттер — так не пишут. Метод, который возвращает this, позволяет цепочку: new Deck().add("book").add("water").

Порядок при new

1) объект с прототипом Card.prototype; 2) поля сверху вниз, this — новый объект; 3) тело constructor; 4) вернуть объект. Поле не видит того, что запишет конструктор: total = this.items.length — TypeError. Конструктор перезаписывает одноимённое поле.

Отделённый метод класса (const f = card.flip) теряет this и падает: режим строгий. Лечение — поле-стрелка, this.flip = this.flip.bind(this) в конструкторе или обёртка () => card.flip() в месте вызова. Поле-стрелка — своя копия функции в каждом объекте и ключ в Object.keys.
Выражение класса: const C = class {}; class Inner {} в выражении — имя видно только внутри. Класс, возвращённый из функции, может нести настройки в замыкании. Конструктор один (A class may only have one constructor); в поле нельзя arguments — SyntaxError. После JSON.parse объект восстанавливают через new: поля-стрелки создаёт только конструктор.
