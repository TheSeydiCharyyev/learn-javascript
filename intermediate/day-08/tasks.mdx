## Разминка

<Task title="1. Переписать на класс" level="easy" time="7">
<Goal>перевести функцию-конструктор дня 7 в класс без потерь.</Goal>

```js
function Group(title) {
  this.title = title;
  this.students = [];
}
Group.prototype.add = function (name, marks) {
  this.students.push({ name, marks });
};
Group.prototype.count = function () {
  return this.students.length;
};

const group = new Group("1-А");
group.add("Аман", [5, 4]);
console.log(group.count(), Object.keys(Group.prototype));
```

<Criteria>
- написан класс `Group`: `students` — поле, `title` —
  в конструкторе, методы — в теле класса;
- с классом последняя строка печатает `1 []` — объяснено, куда делись
  `add` и `count`;
- проверено, что `group instanceof Group` и `group.constructor === Group`
  у обеих версий одинаковы;
- записано, почему `students` можно сделать полем, а `title` — нет.
</Criteria>
</Task>

<Task title="2. Поля, конструктор, перебор" level="easy" time="6">
<Goal>предсказывать порядок создания и то, что видит перебор.</Goal>

```js
class Lesson {
  minutes = 45;
  title = `урок на ${this.minutes} минут`;

  constructor(minutes) {
    if (minutes) {
      this.minutes = minutes;
    }
  }

  describe() {
    return `${this.title}, на деле ${this.minutes}`;
  }
}

const short = new Lesson();
const long = new Lesson(90);
console.log(short.describe());
console.log(long.describe());
console.log(Object.keys(long));
for (const key in long) {
  console.log(key);
}
```

<Criteria>
- весь вывод предсказан до запуска;
- объяснено, почему у `long` в заголовке 45, а не 90;
- объяснено, почему `describe` нет ни в `Object.keys`, ни в `for...in`;
- `title` переделан так, чтобы у `long` он говорил о 90 минутах.
</Criteria>
</Task>

<Task title="6. Поле или конструктор" level="medium" time="8">

```js
  total = this.items.length;

  constructor(items) {

  }
}

const basket = new Basket(["book", "pen"]);
console.log(basket.total);
```

<Criteria>
- записан точный текст ошибки и объяснён порядком создания;
- исправлено тремя способами: в конструкторе, геттером, полем `items = []`
  перед `total` плюс запись в конструкторе;
- для каждого способа проверено, что покажет `total` после
  `basket.items.push("bag")`;
- записано, какой способ даёт всегда верное число и почему.
</Criteria>
</Task>
