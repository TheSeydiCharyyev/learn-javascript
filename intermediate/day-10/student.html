День 10. Наследование: extends и super

Выжимка лекции: две цепочки extends, конструктор наследника, порядок создания, super.method(), new.target, наследник Array, композиция.

Главное

class Card {
  constructor(word) {
    this.word = word;
  }

  text() {
    return this.word;
  }

  static make(...args) {
    return new this(...args);            // создаёт объект «своего» класса
  }
}

class ExampleCard extends Card {
  constructor(word, example) {
    super(word);                         // до первого this, один раз
    this.example = example;
  }

  text() {
    return `${super.text()} — ${this.example}`;   // версия родителя + своё
  }
}

ExampleCard.make("book", "I read a book").text();   // "book — I read a book"
extends ставит две связи: ExampleCard.prototype → Card.prototype (методы объектов) и ExampleCard → Card (статические элементы). Без своего конструктора наследник получает constructor(...args) { super(...args); }.

Полиморфизм: один вызов card.text() — у каждого класса свой ответ, и код, который показывает карточки, не проверяет их вид. Встроенный пример наследования — виды ошибок: RangeError extends Error, своё name в прототипе затеняет родительское. Примесь — функция (Base) => class extends Base { … }: одно поведение для классов из разных семейств, ведь родитель у класса только один.

Порядок new Child()

Начало конструктора Child (без this) → super(): родитель создаёт объект с прототипом Child.prototype, его поля, его тело → поля Child → остаток конструктора Child. Метод наследника, вызванный из конструктора родителя, полей наследника ещё не видит.

super, приватное, new.target

super привязан к месту, где метод написан ([[HomeObject]]), а не к объекту вызова; работает и в литерале с прототипом. Наследник не видит #-полей родителя (SyntaxError), но поля у объекта есть, и методы родителя с ними работают. В статических методах пишите Base.#x, а не this.#x. new.target — undefined без new; в конструкторе родителя — класс наследника: так запрещают создавать общий класс.
class Words extends Array: Words.from, of, filter, map возвращают Words; new Words(3) — пустой массив длины 3. Наследование — когда объект является родителем; когда лишь использует — композиция: приватное поле с объектом и только нужные методы.
  1. Найдите в своём проекте два похожих объекта и вынесите общее в родительский класс. Покажите, где пригодился super.method().
  2. Добавьте в родительский класс проверку new.target, чтобы его нельзя было создать напрямую.
  3. Прочитайте на MDN раздел «Avoiding inheritance» страницы extends и перескажите пример ReadOnlyMap: почему наследование там не сработало.
  4. Найдите в спецификации раздел 13.3.7.1 и выпишите шаги super(...) своими словами.
