# День 10. Наследование: extends и super

<Subtitle>Выжимка лекции: две цепочки `extends`, конструктор наследника, порядок создания, `super.method()`, `new.target`, наследник `Array`, композиция.</Subtitle>

## Главное

```js
class Card {
  constructor(word) {
    this.word = word;
  }

  text() {
    return this.word;
  }

  static make(...args) {
    return new this(...args);            // создаёт объект «своего» класса
  }
}

class ExampleCard extends Card {
  constructor(word, example) {
    super(word);                         // до первого this, один раз
    this.example = example;
  }

  text() {
    return `${super.text()} — ${this.example}`;   // версия родителя + своё
  }
}

ExampleCard.make("book", "I read a book").text();   // "book — I read a book"
```

<Definition>
`extends` ставит две связи: `ExampleCard.prototype` → `Card.prototype`
(методы объектов) и `ExampleCard` → `Card` (статические элементы).
Без своего конструктора наследник получает `constructor(...args) { super(...args); }`.
</Definition>

**Полиморфизм:** один вызов `card.text()` — у каждого класса свой ответ, и код,
который показывает карточки, не проверяет их вид. Встроенный пример наследования — виды ошибок:
`RangeError extends Error`, своё `name` в прототипе затеняет родительское.
**Примесь** — функция `(Base) => class extends Base { … }`: одно поведение
для классов из разных семейств, ведь родитель у класса только один.

## Порядок new Child()

<Remember>
Начало конструктора `Child` (без `this`) → `super()`: родитель создаёт
объект с прототипом `Child.prototype`, его поля, его тело → поля `Child` →
остаток конструктора `Child`. Метод наследника, вызванный из конструктора родителя, полей
наследника ещё не видит.
</Remember>

| Ошибка | Когда |
| --- | --- |
| `Must call super constructor in derived class before accessing 'this'…` | `this` до `super()` или `super()` не вызван |
| `Super constructor may only be called once` | второй `super()` |
| `Derived constructors may only return object or undefined` | наследник вернул число |
| `'super' keyword unexpected here` | `super` вне метода или `super()` без `extends` |

## super, приватное, new.target

<KeyPoint>
`super` привязан к месту, где метод написан (`[[HomeObject]]`), а не к объекту
вызова; работает и в литерале с прототипом. Наследник не видит `#`-полей родителя
(`SyntaxError`), но поля у объекта есть, и методы родителя с ними работают. В статических
методах пишите `Base.#x`, а не `this.#x`. `new.target` —
`undefined` без `new`; в конструкторе родителя — класс наследника: так
запрещают создавать общий класс.
</KeyPoint>

<NoteBox>
`class Words extends Array`: `Words.from`, `of`, `filter`,
`map` возвращают `Words`; `new Words(3)` — пустой массив длины 3.
Наследование — когда объект *является* родителем; когда лишь *использует* —
композиция: приватное поле с объектом и только нужные методы.
</NoteBox>
