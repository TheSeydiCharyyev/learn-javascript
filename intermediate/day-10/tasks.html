День 10. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем в файлах папки day-10 курса 2 с Live Server.

Разминка

1. Две цепочки
Легко7 мин

видеть, что и откуда наследуется.

class Person {
  static city = "Мары";

  constructor(name) {
    this.name = name;
  }

  introduce() {
    return `Я ${this.name}`;
  }
}

class Teacher extends Person {
  introduce() {
    return `${super.introduce()}, учитель`;
  }
}

const aina = new Teacher("Айна");
console.log(aina.introduce(), Teacher.city, Object.keys(aina));
console.log(Object.getPrototypeOf(Teacher) === Person, Object.getPrototypeOf(Teacher.prototype) === Person.prototype, aina instanceof Person);
  • вывод предсказан до запуска;
  • нарисованы обе цепочки — объектов и классов — со всеми звеньями до конца;
  • объяснено, где найдено Teacher.city и почему aina.city — undefined;
  • записано, откуда у Teacher конструктор, если в классе его нет.

Основные задания

4. Иерархия фигур
Средне12 мин

построить иерархию из трёх классов с общим классом наверху.

Shape — общий класс: создать его нельзя, у него метод describe(), который возвращает «имя класса, площадь N», и метод area(), который бросает ошибку «не реализовано». Rectangle(width, height) — наследник с настоящей площадью. Square(side) — наследник Rectangle.

  • new Shape() — TypeError, new Square(4).describe() — "Square, площадь 16";
  • Square вызывает super(side, side) и не переписывает area;
  • имя класса в describe взято не строкой, а из объекта — проверено на обоих наследниках;
  • new Square(2) instanceof Rectangle и instanceof Shape — true, записаны обе цепочки Square.
5. Оценки — наследник Array
Средне12 мин

дополнить массив своими методами.

Класс Marks extends Array: геттеры average и best, метод above(n) — оценки выше n.

  • для Marks.from([5, 4, 5, 3, 5]) среднее — 4.4, лучшая — 5;
  • above(4) возвращает Marks, и у результата сразу работает average — 5;
  • записано, что даёт new Marks(5) и почему, и как получить массив из одной оценки 5;
  • проверены Array.isArray, JSON.stringify и подпись в консоли.
6. Приватное в семье
Средне8 мин

увидеть границы приватного при наследовании.

Класс Counter: приватное #value, метод increment(), статическое приватное #instances и статический метод create(), который считает созданные объекты. Наследник StepCounter добавляет метод double(), который увеличивает счёт дважды.

  • сначала в double написано this.#value += 2 — записан текст ошибки и объяснено, почему;
  • double переписан через унаследованный increment и работает;
  • create сначала считал this.#instances++ — показано, что StepCounter.create() падает, и записан текст;
  • после исправления счёт общий: два create у родителя и один у наследника — 3.
7. Стопка: наследование против композиции
Средне20 мин

сравнить два устройства одного и того же класса.

Стопка карточек — кладём сверху, берём сверху. Напишите её дважды: StackArray extends Array с методом peek() и Stack с приватным массивом #items и методами push, pop, peek и геттером size.

  • обе стопки после push("a"), push("b"), pop() дают peek() — "a";
  • показано, как сломать правило «брать только сверху» у StackArray одной строкой — и что у Stack так нельзя;
  • в таблице для обеих записаны Array.isArray, JSON.stringify, Object.keys и работа for...of;
  • записано, какую выбрали бы для «Карточек» и почему — словами «является» и «использует».

9. super в литерале
Сложно10 мин

проверить на опыте, что super привязан к месту в тексте.

const lesson = {
  title() {
    return "урок";
  },
};

const exam = {
  __proto__: lesson,
  title() {
    return `${super.title()} → экзамен`;
  },
};

console.log(exam.title());
  • вывод предсказан и объяснён;
  • метод exam.title переставлен в третий объект с другим прототипом — записано, чей title позвал super, и почему;
  • для сравнения написан вариант через Object.getPrototypeOf(this).title.call(this) и показано, где он ведёт себя иначе;
  • объяснено словом [[HomeObject]], чем super отличается от this.
