## Разминка

<Task title="1. Две цепочки" level="easy" time="7">
<Goal>видеть, что и откуда наследуется.</Goal>

```js
class Person {
  static city = "Мары";

  constructor(name) {
    this.name = name;
  }

  introduce() {
    return `Я ${this.name}`;
  }
}

class Teacher extends Person {
  introduce() {
    return `${super.introduce()}, учитель`;
  }
}

const aina = new Teacher("Айна");
console.log(aina.introduce(), Teacher.city, Object.keys(aina));
console.log(Object.getPrototypeOf(Teacher) === Person, Object.getPrototypeOf(Teacher.prototype) === Person.prototype, aina instanceof Person);
```

<Criteria>
- вывод предсказан до запуска;
- нарисованы обе цепочки — объектов и классов — со всеми звеньями до конца;
- объяснено, где найдено `Teacher.city` и почему `aina.city` — `undefined`;
- записано, откуда у `Teacher` конструктор, если в классе его нет.
</Criteria>
</Task>

## Основные задания

<Task title="4. Иерархия фигур" level="medium" time="12">
<Goal>построить иерархию из трёх классов с общим классом наверху.</Goal>

`Shape` — общий класс: создать его нельзя, у него метод `describe()`, который
возвращает `«имя класса, площадь N»`, и метод `area()`, который бросает ошибку
«не реализовано». `Rectangle(width, height)` — наследник с настоящей площадью.
`Square(side)` — наследник `Rectangle`.

<Criteria>
- `new Shape()` — `TypeError`, `new Square(4).describe()` —
  `"Square, площадь 16"`;
- `Square` вызывает `super(side, side)` и не переписывает `area`;
- имя класса в `describe` взято не строкой, а из объекта — проверено на обоих
  наследниках;
- `new Square(2) instanceof Rectangle` и `instanceof Shape` — `true`,
  записаны обе цепочки `Square`.
</Criteria>
</Task>

- `above(4)` возвращает `Marks`, и у результата сразу работает

</Task>

<Task title="6. Приватное в семье" level="medium" time="8">
<Goal>увидеть границы приватного при наследовании.</Goal>

Класс `Counter`: приватное `#value`, метод `increment()`,
статическое приватное `#instances` и статический метод `create()`, который
считает созданные объекты. Наследник `StepCounter` добавляет метод
`double()`, который увеличивает счёт дважды.

<Criteria>
- сначала в `double` написано `this.#value += 2` — записан текст ошибки
  и объяснено, почему;
- `double` переписан через унаследованный `increment` и работает;
- `create` сначала считал `this.#instances++` — показано, что
  `StepCounter.create()` падает, и записан текст;
- после исправления счёт общий: два `create` у родителя и один у наследника — 3.
</Criteria>
</Task>

<Task title="9. super в литерале" level="hard" time="10">
<Goal>проверить на опыте, что `super` привязан к месту в тексте.</Goal>

```js
const lesson = {
  title() {
    return "урок";
  },
};

const exam = {
  __proto__: lesson,
  title() {
    return `${super.title()} → экзамен`;
  },
};

console.log(exam.title());
```

<Criteria>
- вывод предсказан и объяснён;
- метод `exam.title` переставлен в третий объект с другим прототипом — записано,
  чей `title` позвал `super`, и почему;
- для сравнения написан вариант через `Object.getPrototypeOf(this).title.call(this)`
  и показано, где он ведёт себя иначе;
- объяснено словом `[[HomeObject]]`, чем `super` отличается от `this`.
</Criteria>
</Task>
