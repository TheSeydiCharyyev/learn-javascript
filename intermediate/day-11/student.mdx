# День 11. Символы и протоколы итерации

<Subtitle>Выжимка лекции: символ и его описание, ключи-символы, реестр, встроенные символы, два договора протокола итерации, итераторы массива, метод `return`.</Subtitle>

## Главное

```js
const LEARNED = Symbol("learned");                 // новый уникальный символ
const card = { word: "book", [LEARNED]: true };

JSON.stringify(card);                               // '{"word":"book"}' — символа не видно
Object.getOwnPropertySymbols(card);                 // [Symbol(learned)]
Symbol.for("app.key") === Symbol.for("app.key");    // true — общий символ из реестра

const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {                             // перебираемый: выдаёт итератор
    let current = this.from;
    const last = this.to;
    return {
      next() {                                      // итератор: один шаг
        return current <= last
          ? { value: current++, done: false }
          : { value: undefined, done: true };
      },
    };
  },
};

const all = [...range];                             // [1, 2, 3]
const [a, b] = range;                               // a = 1, b = 2
```

<Definition>
**Перебираемый объект** — у него есть метод `[Symbol.iterator]()`, который
возвращает итератор. **Итератор** — объект с методом `next()`, который
возвращает `{ value, done }`. `for...of`, spread, деструктуризация массива
и `Array.from` берут итератор один раз и зовут `next()`, пока
`done` не станет `true`.
</Definition>

**Символ** не равен ничему, кроме себя; описание читают через `description`.
`new Symbol()` — `TypeError: Symbol is not a constructor`; `"" + sym` —
`Cannot convert a Symbol value to a string`, явно — `String(sym)`.
`Symbol.for(key)` возвращает общий символ из реестра, `Symbol.keyFor(sym)` — его
строку. **Встроенные символы** вроде `Symbol.iterator` — ключи протоколов,
которые язык ищет сам.

## Кто видит ключ-символ

| Не видят | Видят |
| --- | --- |
| `Object.keys`, `values`, `entries`, `for...in`, JSON, `getOwnPropertyNames` | `getOwnPropertySymbols`, spread `{...obj}`, `Object.assign`, `in`, `Object.hasOwn` |

## Итераторы массива

<Remember>
`keys()` — номера, `values()` — значения (это та же функция, что
`[Symbol.iterator]`), `entries()` — пары `[номер, значение]`.
Итератор одноразовый: его `[Symbol.iterator]()` возвращает его самого. Он не копирует
массив и читает его на каждом шаге, а исчерпанный не оживает. Дырки он проходит как
`undefined`.
</Remember>

<KeyPoint>
Метод `return()` итератора язык зовёт, когда перебор бросили: `break`,
`return`, ошибка в теле, деструктуризация взяла не всё. Нарушил договор —
`TypeError`: `x is not iterable`, `Result of the Symbol.iterator method is not
an object`, `Iterator result 5 is not an object`.
</KeyPoint>

<NoteBox>
Строка перебирается по кодовым точкам: `[..."😀"].length` — 1, а `length` — 2.
`arguments` и `NodeList` перебираются функцией `Array.prototype.values`.
Проверка: `typeof value?.[Symbol.iterator] === "function"`.
</NoteBox>
