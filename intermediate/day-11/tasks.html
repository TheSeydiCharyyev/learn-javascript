День 11. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем в файлах папки day-11 курса 2 с Live Server.

Разминка

1. Одинаковые, но разные
Легко7 мин

отличать описание символа от самого символа.

const a = Symbol("урок");
const b = Symbol("урок");
const c = Symbol.for("урок");
const d = Symbol.for("урок");

console.log(a === b, c === d, a === c, a.description === b.description);
console.log(a.toString(), typeof a, Symbol.keyFor(a), Symbol.keyFor(d));
console.log(String(c), c.description.length);
  • три строки вывода предсказаны до запуска;
  • объяснено, почему a и b не равны, хотя описания совпадают;
  • объяснено, почему Symbol.keyFor(a) — undefined;
  • записано, что даст console.log("урок: " + a), и два способа это исправить.
2. Кто видит секрет
Легко7 мин

знать, какие инструменты видят какие ключи.

const secret = Symbol("secret");
const lesson = { title: "Итераторы", [secret]: 42 };
Object.defineProperty(lesson, "room", { value: 12, enumerable: false });

const seen = [];
for (const key in lesson) {
  seen.push(key);
}
console.log(Object.keys(lesson), seen, JSON.stringify(lesson));
console.log(Object.getOwnPropertyNames(lesson), Object.getOwnPropertySymbols(lesson));
console.log({ ...lesson }[secret], { ...lesson }.room, secret in lesson, "room" in lesson);
  • вывод предсказан до запуска;
  • составлена таблица: восемь инструментов из кода — строки, три ключа title, room, secret — столбцы, в клетках «видит» или «нет»;
  • объяснено, почему spread скопировал secret, но не скопировал room;
  • записано, каким одним вызовом получить значение 42, не зная переменной secret.
3. Итератор руками
Легко6 мин

проходить итератор вызовами next().

const it = ["a", "b"].entries();
console.log(it.next());
console.log(it.next().value);
console.log(it.next());
console.log(it.next().done);

const k = ["a", "b"].keys();
console.log([...k], [...k]);
  • все пять строк предсказаны до запуска, в первой раскрыт value;
  • объяснено, почему второй [...k] пустой;
  • entries() заменён на values() и [Symbol.iterator]() — записано, что изменилось;
  • записано, что выведет console.log([...["a", "b"].keys()], [...["a", "b"].keys()]) и почему второй массив здесь не пустой.

Основные задания

4. Диапазон с шагом
Средне12 мин

сделать перебираемый объект, который считает значения на ходу.

Функция range(from, to, step = 1) возвращает перебираемый объект с числами от from до to включительно через step. Шаг может быть отрицательным. Массив чисел внутри не хранится.

  • [...range(1, 10, 3)] — [1, 4, 7, 10], и тот же объект, разложенный второй раз, даёт то же самое;
  • [...range(5, 1, -2)] — [5, 3, 1], [...range(3, 1)] — пустой массив;
  • Math.max(...range(1, 5)) — 5, const [a, b] = range(10, 20, 5) — 10 и 15;
  • объяснено, где хранится текущее число и почему второй проход начинается сначала.
5. Стопка перебирается
Средне12 мин

выполнить протокол итерации в классе с приватными данными.

Возьмите класс Stack из задания 7 дня 10 (приватный массив #items, push, pop, peek, size). Тогда for...of по нему давал is not iterable. Научите стопку перебираться сверху вниз.

  • после push("a"), push("b"), push("c") цикл for...of печатает c, b, a;
  • [...stack] — ['c', 'b', 'a'], и после этого size по-прежнему 3;
  • записано, почему не подходит короткое return this.#items[Symbol.iterator](); и для какого класса дня 10 оно подходит — проверено на ReadOnlyWords;
  • #items снаружи по-прежнему недоступен.
6. Метка, которая не мешает
Средне10 мин

пометить чужие объекты, не портя их данные.

Есть список students из объектов { name } — он пришёл из JSON, и его снова сохранят в JSON. Отметьте пришедших на урок символом VISITED.

  • после отметки двух учеников JSON.stringify(students) и Object.keys каждого — такие же, как до отметки;
  • число пришедших считается через filter по метке;
  • для сравнения сделано то же строковым ключом _visited — записано, что изменилось в JSON;
  • объяснено, почему здесь не подходит приватное поле #visited дня 9.
7. for...of своими руками
Средне16 мин

повторить работу цикла по шагам раздела 14.

Напишите forOf(iterable, callback) без for...of: функция берёт итератор и вызывает callback для каждого значения. Если callback вернул false, перебор останавливается.

  • значения массива [1, 2, 3], строки "ab" и arguments функции, вызванной с "x", "y", собираются в строку "1 2 3 a b x y";
  • forOf({}, …) и forOf(null, …) бросают TypeError со своим текстом;
  • при остановке по false вызывается return() итератора, если он есть, — проверено итератором, который печатает в консоль;
  • к каждой строке функции записано, какой шаг раздела 14 лекции она повторяет.

Со звёздочкой

8. Бесконечный счётчик
Сложно10 мин

работать с итератором, у которого нет конца.

idMaker() возвращает перебираемый итератор номеров 0, 1, 2… без конца. firstN(iterable, n) возвращает массив из первых n значений.

  • для const ids = idMaker() вызов firstN(ids, 3) — [0, 1, 2], следующий firstN(ids, 2) — [3, 4]; объяснено, почему не с нуля;
  • firstN(idMaker(), 0) — пустой массив, firstN([7, 8], 5) — [7, 8];
  • объяснено без запуска, что сделает вкладка на [...idMaker()];
  • записано, что сломается в firstN, если убрать из итератора [Symbol.iterator]() { return this; }.
9. Когда зовут return
Сложно10 мин

проверить на опыте, когда язык закрывает итератор.

Сделайте перебираемый объект с тремя значениями, у итератора которого next() и return() печатают, что их вызвали.

  • для семи случаев сначала предсказано, будет ли return(), потом проверено: полный for...of, break, return из функции, ошибка в теле цикла, const [a] = obj, const [a, b, c, d] = obj, [...obj];
  • записано, сколько раз вызван next() в случае const [a, b, c, d] = obj и почему return() там нет;
  • объяснено, почему итератор массива после break продолжает с того же места (раздел 9 лекции), — по тому, есть ли у него return;
  • записано, что напечатает for...of, если последний результат — { value: 99, done: true }.
