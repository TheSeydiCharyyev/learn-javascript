День 13. Iterator и его методы

Выжимка лекции: где живут методы итераторов, ленивость, помощники и потребители, бесконечные последовательности, Iterator.from, наследники Iterator, concat и zip.

Главное

function* naturals() {
  let n = 1;
  while (true) yield n++;
}

const squares = naturals()                 // бесконечный источник
  .filter((n) => n % 2 === 1)              // помощник: лениво
  .map((n) => n * n)                       // помощник: лениво
  .take(4)                                 // помощник: не больше 4, потом закрыть источник
  .toArray();                              // потребитель: вся работа здесь
// [1, 9, 25, 49]

const sum = [5, 3, 4].values().reduce((a, b) => a + b, 0);   // 12 — у массива сначала values()
Методы лежат в Iterator.prototype — их получают генераторы и все встроенные итераторы, но не массивы. Помощники (map, filter, take, drop, flatMap) возвращают новый итератор и ничего не считают до next(). Потребители (toArray, reduce, forEach, join, some, every, find, includes) перебирают сразу и возвращают результат.

Ленивость: массив работает этажами — map по всем значениям, потом filter по всем; итератор — конвейером, одно значение через все звенья. Нет промежуточных массивов, лишнее не считается, можно работать с бесконечным. toArray() — последним.

Массив или итератор? Данные уже в массиве, их немного, нужны номера и несколько проходов — методы массива. Данных много или они бесконечны, нужен кусок или первое подходящее, источник — генератор — методы итератора. flatMap итератора разворачивает любые итераторы (массив — только массивы), но строку из колбэка не примет.

Бесконечный источник

БезопасноНужен take
map, filter, drop, take, flatMap; find/some/includes, если ответ есть toArray, reduce, forEach, join; every, если все подходят
Помощник и источник — одна последовательность: «размножить» итератор нельзя. take(n), отдав n, закрывает источник (finally генератора выполнится); some, every, find, includes закрывают итератор, найдя ответ. Порядок звеньев важен: drop(2).take(5) ≠ take(5).drop(2).

Правильный итератор

Iterator.from(x) оборачивает итератор, у которого есть только next, и даёт ему методы; правильный возвращает как есть; строку перебирает по знакам, число — TypeError. class X extends Iterator { next() { … } } — свой правильный итератор; new Iterator() — Abstract class Iterator not directly constructable.
Iterator.concat(a, b) — значения подряд; Iterator.zip([a, b]) — пары, по умолчанию до самого короткого; zipKeyed({ k: a }) — объекты. По спецификации помощник — генератор с меткой «Iterator Helper» (раздел 27.1.2): Yield, пауза, закрытие.
