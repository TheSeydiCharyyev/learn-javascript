## Разминка

<Task title="1. Объект против Map" level="easy" time="7">
<Goal>видеть, во что превращаются ключи.</Goal>

```js
const marks = {};
marks[1] = "число";
marks["1"] = "строка";
marks[{ name: "Аман" }] = 5;
console.log(Object.keys(marks), marks[1]);

const map = new Map();
map.set(1, "число").set("1", "строка").set({ name: "Аман" }, 5);
console.log(map.size, map.get(1), map.get({ name: "Аман" }));
```

<Criteria>
- обе строки вывода предсказаны до запуска;
- объяснено, откуда в объекте ключ `'[object Object]'` и почему `marks[1]` —
  «строка»;
- объяснено, почему `map.get({ name: "Аман" })` — `undefined`, и код исправлен
  так, чтобы получить 5;
- записано, сколько записей в каждой коллекции.
</Criteria>
</Task>

<Task title="2. Порядок и размер" level="easy" time="6">
<Goal>предсказывать порядок записей `Map`.</Goal>

```js
const m = new Map([["c", 3], ["a", 1]]);
m.set("b", 2);
m.set("c", 30);
m.delete("a");
m.set("a", 10);
console.log([...m.keys()], m.size, m.get("c"));
console.log(m);
```

<Criteria>
- вывод предсказан до запуска, вторая строка — в виде, как её покажет консоль;
- объяснено, почему `"c"` осталась первой, а `"a"` стала последней;
- то же сделано объектом `{ c: 3, a: 1 }` и `delete` — записан порядок
  `Object.keys`;
- записано, где у объекта оказались бы ключи `10` и `2`.
</Criteria>
</Task>

<Task title="3. WeakMap: можно или нельзя" level="easy" time="7">
<Goal>знать, что принимает `WeakMap`.</Goal>

Для `const wm = new WeakMap();` предскажите, что даст каждая строка: значение или ошибку.

1. `wm.set("a", 1)`
2. `wm.set({}, 1)`
3. `wm.set(Symbol("x"), 1)`
4. `wm.set(Symbol.for("x"), 1)`
5. `wm.size`
6. `wm.get(1)`
7. `wm.has("x")`
8. `for (const x of wm) {}`

<Criteria>
- для каждой строки записан результат или текст ошибки, потом проверено;
- ошибок ровно три — для каждой объяснена причина;
- объяснено, почему `Symbol("x")` можно, а `Symbol.for("x")` нельзя;
- объяснено, почему `get(1)` не падает, хотя `set(1, …)` упал бы.
</Criteria>
</Task>

</Criteria>
</Task>

<Criteria>

- для сравнения сохранено через `Object.fromEntries` — записано, какого типа стали
  ключи и что это меняет;
- объяснено, почему восстановленные значения — уже другие объекты;
- записано, почему `Map` с ключами-объектами нельзя восстановить так, чтобы прежние
  ключи снова работали.
</Criteria>
</Task>
