# День 15. Set, WeakSet и операции над множествами

<Subtitle>Выжимка лекции: пять операций `Set`, что считается одинаковым, `Set` против массива, операции над множествами и похожие на множество объекты, `WeakSet` для отметок.</Subtitle>

## Главное

```js
const topics = new Set(["циклы", "массивы", "циклы"]);   // Set(2) — повтор выпал; только с new
topics.add("классы").add("циклы");                      // add возвращает множество; повтор не добавится
topics.has("массивы");                                  // true
topics.delete("массивы");                               // true — было что удалять
const total = topics.size;                              // 2 — свойство, не метод

for (const t of topics) {}                              // элементы в порядке добавления
topics.forEach((t) => {});                              // элемент приходит первым и вторым аргументом

const unique = [...new Set([2, 4, 2, 5])];              // [2, 4, 5] — без повторов
```

<Definition>
`Set` — множество: каждое значение встречается в нём не больше одного раза. Одинаковые значения —
по SameValueZero: `NaN` находится, `-0` = `0`, `1` и
`"1"` разные, объект — по ссылке. Метода `get` нет: на вопрос «есть ли» отвечает
`has`.
</Definition>

**Порядок** — первого добавления; удалённый и добавленный заново элемент уходит в конец.
`keys` — то же, что `values` и `[Symbol.iterator]`; `entries` даёт
`[x, x]`. Итераторы — с методами дня 13.

## Set или массив

| Массив | Set |
| --- | --- |
| важны номер, порядок, повторы; сортировка; `includes` ищет перебором | главный вопрос «есть ли» — `has` быстро; уникальность; `delete` по значению; операции над множествами |

## Операции над множествами

| Метод | Результат |
| --- | --- |
| `a.union(b)` | всё из обоих; сначала `a`, потом новое из `b` |
| `a.intersection(b)` | общее; в порядке меньшего |
| `a.difference(b)` | есть в `a`, нет в `b` |
| `a.symmetricDifference(b)` | есть ровно в одном |
| `isSubsetOf`, `isSupersetOf`, `isDisjointFrom` | `true` / `false` |

<Remember>
Каждая операция возвращает новый `Set`, исходные не меняются. JSON:
`JSON.stringify(set)` — `"{}"`; сохранять `JSON.stringify([...set])`, читать
`new Set(JSON.parse(text))`. Равны ли два множества: `a.size === b.size &&
a.isSubsetOf(b)`; `===` сравнивает ссылки.
</Remember>

<KeyPoint>
Аргумент операций — `Set` или похожий объект: `size`, `has()`,
`keys()`. `Map` подходит — как множество своих ключей; массив — нет:
`The .size property is NaN`. Алгоритм перебирает меньшее из двух; `union` и
`symmetricDifference` всегда зовут `keys()`.
</KeyPoint>

## WeakSet

<NoteBox>
Держит элементы слабо: недостижимый объект забирает сборщик мусора вместе с отметкой. Элемент — объект или
`Symbol()`, но не `Symbol.for(…)`: иначе `Invalid value used in weak set`.
Есть `add`, `has`, `delete`; нет `size`, перебора и
`clear`. Для чего: отметка «уже обработан» при обходе объектов с циклами, «уже подписан» у кнопки —
без свойств на самих объектах.
</NoteBox>
