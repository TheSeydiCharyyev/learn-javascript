Разминка

1. Что окажется в множестве
Легко7 мин

предсказывать содержимое и порядок Set.

const s = new Set([3, 1, 3]);
s.add("3").add(1).add(NaN).add(NaN);
s.delete(3);
s.add(3);
console.log(s.size, [...s]);
console.log(s.has(Number("3")), s.has("1"), new Set([{ id: 1 }, { id: 1 }]).size);
  • обе строки вывода предсказаны до запуска;
  • объяснено, почему в множестве есть и 3, и "3", а NaN — один;
  • объяснено, почему 3 оказалась последней, а 1 — первой;
  • объяснено, почему последнее число второй строки — 2.

3. Операции на бумаге
Легко7 мин

знать, что и в каком порядке возвращает каждая операция.

Для const a = new Set([1, 2, 3, 4]); и const b = new Set([3, 4, 5]); запишите результат каждой строки, потом проверьте.

  1. a.union(b)
  2. a.intersection(b)
  3. a.difference(b)
  4. b.difference(a)
  5. a.symmetricDifference(b)
  6. b.symmetricDifference(a)
  7. new Set([3, 4]).isSubsetOf(a)
  8. a.isDisjointFrom(new Set([5, 6]))
  • для каждой строки записан результат вместе с порядком элементов, потом проверено;
  • объяснено, почему b.symmetricDifference(a) — {5, 1, 2}, а не {1, 2, 5};
  • для двух операций нарисованы круги Венна с закрашенной частью;
  • записано, каким методом проверить отношение строки 7 со стороны a и что он ответит.

9. Живой перебор
Сложно10 мин

объяснять перебор по спецификации.

const s = new Set([1, 2, 3]);
const seen = [];
for (const x of s) {
  seen.push(x);
  if (x === 1) s.delete(2);
  if (x === 3) s.add(4);
}
console.log(seen);
const it = s.values();
it.next();
s.clear();
s.add(5);
console.log(it.next().value, s.size);
  • обе строки вывода предсказаны до запуска;
  • по шагам delete и add из раздела 24.2.4 объяснено, почему 2 пропущена, а 4 пройдена;
  • по примечанию к clear (24.2.4.2) объяснено, почему итератор после очистки нашёл 5;
  • перебор переписан на forEach — результат [1, 3, 4] тот же.
