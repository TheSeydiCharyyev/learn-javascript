```js

s.delete(3);
s.add(3);
console.log(s.size, [...s]);
console.log(s.has(Number("3")), s.has("1"), new Set([{ id: 1 }, { id: 1 }]).size);
```

<Criteria>
- обе строки вывода предсказаны до запуска;
- объяснено, почему в множестве есть и `3`, и `"3"`, а `NaN` — один;
- объяснено, почему `3` оказалась последней, а `1` — первой;
- объяснено, почему последнее число второй строки — 2.
</Criteria>
</Task>

<Task title="3. Операции на бумаге" level="easy" time="7">
<Goal>знать, что и в каком порядке возвращает каждая операция.</Goal>

1. `a.union(b)`

- для двух операций нарисованы круги Венна с закрашенной частью;
- записано, каким методом проверить отношение строки 7 со стороны `a` и что он ответит.
</Criteria>

<Task title="9. Живой перебор" level="hard" time="10">
<Goal>объяснять перебор по спецификации.</Goal>

```js
const s = new Set([1, 2, 3]);
const seen = [];
for (const x of s) {
  seen.push(x);
  if (x === 1) s.delete(2);
  if (x === 3) s.add(4);
}
console.log(seen);
const it = s.values();
it.next();
s.clear();
s.add(5);
console.log(it.next().value, s.size);
```

<Criteria>
- обе строки вывода предсказаны до запуска;
- по шагам `delete` и `add` из раздела 24.2.4 объяснено, почему 2 пропущена, а 4
  пройдена;
- по примечанию к `clear` (24.2.4.2) объяснено, почему итератор после очистки нашёл 5;
- перебор переписан на `forEach` — результат `[1, 3, 4]` тот же.
</Criteria>
</Task>
