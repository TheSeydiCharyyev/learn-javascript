# День 16. Мини-проект: журнал группы на классах

<Subtitle>Выжимка лекции: как устроена программа на классах и как проверить, что проект готов.</Subtitle>

## Части программы

```js
"use strict";                                    // 1. строгий режим, настройки — deepFreeze
const SETTINGS = deepFreeze({ title: "JS-1", marks: [2, 3, 4, 5], excellent: 4.5 });

class Student {                                  // 2. классы: данные и правила
  #marks = [];
  get marks() { return [...this.#marks]; }       // копию, не сам массив
  addMark(mark) { /* проверка, throw RangeError */ }
}
class Group {
  #students = new Map();                         // ученики по номеру
  #topics = new Set();                           // темы без повторов
  *[Symbol.iterator]() { yield* this.#students.values(); }
}

const group = new Group(SETTINGS.title);         // 3. данные журнала
// 4. элементы страницы — один раз; 5. makeRow и render — показ из группы
// 6. слушатели: метод класса → render(); 7. первый показ — render()
```

<KeyPoint>
Правило — в классе, показ — в `render`, слушатель — между ними. Метод класса либо меняет
данные, либо бросает ошибку с текстом для человека; слушатель ловит её в `try...catch` и
показывает `e.message`. Проверку нельзя обойти: любой код добавляет ученика через
`group.add`.
</KeyPoint>

Снаружи видны только геттеры и методы. `id` и `name` — геттеры без сеттеров,
`average` и `isExcellent` вычисляются при чтении, номер выдаёт `static #count`.
Группа перебирается своим генератором, а методы дня 13 работают через `Iterator.from(group)`.

## От элемента к объекту

```js
function studentOf(element) {
  return group.get(Number(element.closest("tr").dataset.id));   // "2" → 2: ключи Map не строки
}

rows.append(...Iterator.from(group).filter(isVisible).map(makeRow));   // строки без лишнего массива
submitWith(studentForm, (name) => group.add(name));                   // метод — через стрелку
```

<Remember>
Из `dataset` приходят строки: `group.get("2")` — `undefined`,
`addMark("5")` — ошибка. Метод, переданный как колбэк без стрелки, теряет `this`.
</Remember>

## Ошибки по симптомам

| Симптом | Причина |
| --- | --- |
| средний больше 5, оценки меняются сами | геттер отдал сам приватный массив |
| `Iterator.from called on non-object` под формой | метод передан без объекта |
| «Оценка 5: можно только …5» | строка из `dataset` без `Number` |
| таблица пустая, ошибка про `join` | `yield* this.#students` без `.values()` |

## Чек-лист готовности

| Что проверить | Как |
| --- | --- |
| первый показ | три ученика; «Учеников: 3 · средний по группе: 4.39 · отличников: 2» |
| добавление | имя без пробелов по краям, в конце таблицы; пустое и повтор — сообщение |
| оценки | средний пересчитан; 4,5 — уже отличник |
| удаление и фильтр | «✕» удаляет нажатого при любом фильтре; итоги — по всей группе |
| темы | повтор — «Тема «…» уже есть» |
| консоль | нет ошибок; `[...group]` совпадает с таблицей |
