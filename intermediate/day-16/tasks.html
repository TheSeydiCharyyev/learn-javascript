День 16. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Проект — в папке journal: index.html с разметкой раздела 7 и app.js, запуск через Live Server. Каждую доработку делайте в копии папки.

Разминка

В app.js пока только разделы 3–5 лекции: настройки, два класса и данные журнала.

  • new Student("Гүлнар") с оценками 5 и 4: средний 4.5, isExcellent — true, номер — 4, хотя в группе её нет; объяснено, откуда 4;

  • записано, что вернул group.get(4) и почему.

Основные задания

4. Сортировка по среднему
Средне12 мин

добавить второй порядок перебора, не трогая данные.

Генератор *byAverage() в Group выдаёт учеников от большего среднего к меньшему, ученики без оценок — в конце. Кнопка «По среднему» рядом с фильтрами включает и выключает этот порядок.

Отсортируйте копию: [...this].toSorted(…), а средний null замените на -1 через ??. В render вместо group перебирается group.byAverage(), когда порядок включён.
  • [...group.byAverage()].map((s) => s.name) — ['Айна', 'Аман', 'Мерет'], а [...group] — по-прежнему в порядке добавления;
  • новый ученик «Сапар» без оценок в byAverage — последним;
  • с сортировкой и фильтром «Отличники» в таблице две строки: Айна, Аман;
  • объяснено, почему сортировка не меняет #students.
5. Посещаемость тем
Средне12 мин

применить операции над множествами в проекте.

У ученика приватное множество посещённых тем. group.visit(id, topic) отмечает посещение существующей темы, group.missed(id) возвращает Set пропущенных. В таблице — колонка «Пропустил».

  • Аман был на «классы» и «Map» — [...group.missed(1)] — ['Set']; Айна не была нигде — пропустила 3 темы;
  • group.visit(1, "циклы") — ошибка «Нет темы «циклы»»; повторное посещение «Map» не меняет число посещённых тем Амана — 2;
  • пропущенные считаются операцией дня 15, без цикла;
  • после новой темы «генераторы» у Амана пропущено 2 темы — объяснено, почему ничего не пришлось пересчитывать.
6. Отменить оценку
Средне12 мин

добавить правило в класс и кнопку в строку.

Метод undoMark() убирает последнюю оценку и возвращает её; если оценок нет — ошибка «Оценок нет». В строке — кнопка «↶», неактивная, когда оценок нет.

  • у Амана undoMark() вернул 5, оценки — [5, 4], средний 4.50 — по-прежнему отличник;
  • после двух отмен у Мерета средний «—», а «↶» в его строке неактивна (disabled);
  • третья отмена из консоли — Error: Оценок нет;
  • объяснено, как слушатель таблицы отличает «↶» от кнопок оценок.
7. Две группы
Средне14 мин

работать с несколькими объектами одного класса.

Вторая группа JS-2: Гүлнар и Сапар, темы «классы», «генераторы», «регулярные выражения». Метод adopt(student) принимает в группу готового ученика вместе с оценками.

  • общие темы двух групп — ['классы'], темы JS-1, которых нет у JS-2, — ['Map', 'Set']; оба ответа — операциями дня 15;
  • Мерет переведён в JS-2: в JS-1 два ученика, в JS-2 три, оценки Мерета — [3, 4];
  • после перевода js1.get(2) — undefined, а js2.get(2).name — «Мерет»: номер не изменился;
  • adopt не пускает повтор имени и объект, который не Student, — записаны тексты ошибок.

Со звёздочкой

8. Сохранение
Сложно10 мин

сохранять объекты с приватными полями.

Журнал переживает обновление страницы: в конце render группа сохраняется в localStorage, при загрузке — читается.

toData() у ученика — { id, name, marks }, у группы — { title, students, topics } (день 9). static fromData(data) в каждом классе восстанавливает объект; внутри класса ему доступны приватные поля нового объекта. Счётчику #count нужен наибольший восстановленный номер.
  • JSON.stringify(group) до доработки — "{}"; записано почему;
  • «Сапар» с оценками 4 и 5, удаление Мерета, обновление страницы — в таблице Аман, Айна, Сапар, у Сапара средний 4.50;
  • новый ученик после этого получает номер 5; объяснено, какой номер он получил бы без восстановления #count и что стало бы с Сапаром;
  • при пустом хранилище — три исходных ученика.
9. Три жалобы
Сложно10 мин

искать ошибку от симптома, начиная с вопроса «что в данных?».

Одноклассник прислал свой журнал и три жалобы:

  • «У Амана в журнале 4, 5, 5, хотя ставили 5, 4, 5. И в консоли оценки такие же».
  • «Все строки подсвечены, „Отличники“ показывают всех. Ошибок в консоли нет».
  • «Добавляю тему — под формой: Cannot read properties of undefined (reading '#topics')».

От программы лекции его app.js отличается в этих местах:

// в Student — вместо геттеров marks и isExcellent
get marks() {
  return this.#marks;
}
isExcellent() {
  return this.average !== null && this.average >= SETTINGS.excellent;
}

// в makeRow
marks.textContent = student.marks.sort().join(", ");

// внизу программы
submitWith(topicForm, group.addTopic);
Поставьте Аману оценку из консоли: group.get(1).addMark(4), посмотрите group.get(1).marks, потом вызовите render() и посмотрите снова.
  • каждая жалоба воспроизведена и сопоставлена со своим фрагментом;
  • показано, что данные меняет показ: после addMark(4) оценки — [4, 5, 5, 4], а после render() — [4, 4, 5, 5];
  • объяснено, почему вторая ошибка не даёт ни одной ошибки в консоли;
  • все три исправлены, а оценки на экране по-прежнему отсортированы — сортируется копия.
