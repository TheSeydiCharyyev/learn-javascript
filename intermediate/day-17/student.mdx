# День 17. Регулярные выражения: шаблон, флаги, классы, квантификаторы

<Subtitle>Выжимка лекции: как создать шаблон, проверить строку и найти позицию, из чего шаблон состоит и где его ловушки.</Subtitle>

## Главное

```js
const re = /fo+/i;                    // литерал; new RegExp("fo+", "i") — то же самое
re.test("Table FOOTBALL");            // true — нашлось где-то в строке
"table football".search(/fo+/);       // 6 — с какого символа; не нашлось — -1
re.source + " " + re.flags;           // "fo+ i"
new RegExp("\\d+").source;            // "\d+" — в строке обратную черту пишут дважды
```

<Definition>
**Регулярное выражение** — шаблон для поиска в тексте, объект `RegExp`. Литерал
`/…/флаги` разбирается при загрузке скрипта, конструктор `new RegExp(строка, флаги)` — во
время работы, когда шаблон приходит из данных.
</Definition>

## Из чего состоит шаблон

| Запись | Смысл |
| --- | --- |
| `кот` | буквальные символы — ровно «кот» |
| `\. \* \/ \\` | особый символ как есть; особые: `^ $ \ . * + ? ( ) [ ] { } \|` |
| `[абв] [0-9] [^0-9]` | один символ из набора / любой, кроме |
| `\d \w \s`, `\D \W \S` | цифра, `[A-Za-z0-9_]`, пробельный; и наоборот |
| `.` | любой символ, кроме переноса строки |
| `\n \t \u200B` | символ по имени или номеру |
| `? * + {n} {n,} {n,m}` | сколько раз повторить предыдущий элемент |
| `a\|b` | один из вариантов; самый низкий приоритет |
| флаги `i`, `g` | без учёта регистра; все совпадения |

<Remember>
Ловушки: `[а-я]` без «ё» и «ү» — диапазон это номера Юникода, вся кириллица —
`[\u0400-\u04FF]`; `\w` не знает кириллицы; `/\d*/` подходит к любой строке;
`{1, 3}` с пробелом — буквальный текст; `\.png|jpg` — это «.png» или «jpg»;
`"5.0".search(".")` — 0, строка становится шаблоном; с флагом `g` `test`
чередует ответы.
</Remember>

<KeyPoint>
Проверка ввода сегодня — «есть ли запрещённое» плюс длина: `text.length === 6 && !/\D/.test(text)`.
`test` ищет «где-то в строке», поэтому `/\d{6}/` пропустит и «7440001»; «вся строка» —
якоря `^` и `$` дня 18.
</KeyPoint>

<NoteBox>
Шаблон из ввода человека: `new RegExp(query, "i")`. Точка, плюс и скобки в запросе — особые символы:
«5.0» найдёт «540», «c++» — `SyntaxError: … Nothing to repeat`. Ошибку конструктора ловят
`try...catch`; экранирование запроса — `RegExp.escape` дня 19.
</NoteBox>
