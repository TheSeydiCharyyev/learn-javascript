День 18. Группы и проверки позиции: exec, match, matchAll

Выжимка лекции: якоря и проверки позиции, группы и ссылки, три способа достать найденное и свойство lastIndex.

Главное

/^\d{6}$/.test("744000");                                     // true — вся строка, ровно шесть цифр
const m = /(?<day>\d{2})\.(?<month>\d{2})/.exec("Дата: 12.10");   // ['12.10', '12', '10', index: 6, …]
m.groups.day;                                                 // "12" — группы всегда строки
"a1b22".match(/\d+/g);                                        // ['1', '22'] — с g только строки
[..."a1b22".matchAll(/\d+/g)].map((x) => x.index);           // [1, 3] — результаты как у exec

Позиция

ЗаписьСмысл
^, $начало и конец строки; с флагом m — каждой строки текста
\b, \Bграница слова / не граница — только для латиницы и цифр
x(?=y), x(?!y)справа y / справа не y
(?<=y)x, (?<!y)xслева y / слева не y
Проверки позиции символов не забирают. Граница русского слова — своя: (?<![а-яё])кот(?![а-яё]); /\bкот\b/ не найдёт «кот» никогда.

Группы

(…) — группа: квантификатор и | на целую часть и запоминание текста. Номера — по открывающим скобкам слева направо; не участвовала — undefined. (?:…) — без запоминания, номер не занимает. (?<имя>…) — ещё и в m.groups.имя (объект без прототипа). \1, \k<имя> — тот же текст ещё раз.

Как достать найденное

МетодБез gС g
re.exec(s)первое совпадение: массив с группами, index, input, groupsследующее с lastIndex
s.match(re)то же, что execвсе совпадения строками, без групп
s.matchAll(re)TypeErrorитератор exec-результатов; шаблон копирует
lastIndex — свойство шаблона, а не строки. С g: удача — конец совпадения, неудача — 0. Поэтому test с g чередует ответы. Ничего не нашлось — null: s.match(re) ?? []. Не ставьте литерал в условие while и берегитесь пустых совпадений — надёжнее matchAll.
Жадный .+ берёт как можно больше, ленивый .+? — как можно меньше. Флаги: m — построчно, s — точка берёт перенос, y — строго с lastIndex, d — indices. (?i:…) — флаг только для части шаблона.

  2. Найдите в своих данных текст «ключ: значение» по строкам и разберите его matchAll с флагами gm и именованными группами.
  3. Прочитайте пример «Using lastIndex» на странице lastIndex и объясните, почему второй exec вернул пустую строку.
