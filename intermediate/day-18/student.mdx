# День 18. Группы и проверки позиции: exec, match, matchAll

<Subtitle>Выжимка лекции: якоря и проверки позиции, группы и ссылки, три способа достать найденное и свойство `lastIndex`.</Subtitle>

## Главное

```js
/^\d{6}$/.test("744000");                                     // true — вся строка, ровно шесть цифр
const m = /(?<day>\d{2})\.(?<month>\d{2})/.exec("Дата: 12.10");   // ['12.10', '12', '10', index: 6, …]
m.groups.day;                                                 // "12" — группы всегда строки
"a1b22".match(/\d+/g);                                        // ['1', '22'] — с g только строки
[..."a1b22".matchAll(/\d+/g)].map((x) => x.index);           // [1, 3] — результаты как у exec
```

## Позиция

| Запись | Смысл |
| --- | --- |
| `^`, `$` | начало и конец строки; с флагом `m` — каждой строки текста |
| `\b`, `\B` | граница слова / не граница — только для латиницы и цифр |
| `x(?=y)`, `x(?!y)` | справа y / справа не y |
| `(?<=y)x`, `(?<!y)x` | слева y / слева не y |

<KeyPoint>
Проверки позиции символов не забирают. Граница русского слова — своя:
`(?<![а-яё])кот(?![а-яё])`; `/\bкот\b/` не найдёт «кот» никогда.
</KeyPoint>

## Группы

<Definition>
`(…)` — группа: квантификатор и `|` на целую часть и запоминание текста. Номера — по
открывающим скобкам слева направо; не участвовала — `undefined`. `(?:…)` — без запоминания,
номер не занимает. `(?<имя>…)` — ещё и в `m.groups.имя` (объект без прототипа).
`\1`, `\k<имя>` — тот же текст ещё раз.
</Definition>

## Как достать найденное

| Метод | Без `g` | С `g` |
| --- | --- | --- |
| `re.exec(s)` | первое совпадение: массив с группами, `index`, `input`, `groups` | следующее с `lastIndex` |
| `s.match(re)` | то же, что `exec` | все совпадения строками, без групп |
| `s.matchAll(re)` | `TypeError` | итератор exec-результатов; шаблон копирует |

<Remember>
`lastIndex` — свойство шаблона, а не строки. С `g`: удача — конец совпадения, неудача — 0.
Поэтому `test` с `g` чередует ответы. Ничего не нашлось — `null`:
`s.match(re) ?? []`. Не ставьте литерал в условие `while` и берегитесь пустых совпадений —
надёжнее `matchAll`.
</Remember>

<NoteBox>
Жадный `.+` берёт как можно больше, ленивый `.+?` — как можно меньше. Флаги: `m` —
построчно, `s` — точка берёт перенос, `y` — строго с `lastIndex`, `d` —
`indices`. `(?i:…)` — флаг только для части шаблона.
</NoteBox>
