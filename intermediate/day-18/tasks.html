День 18. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем в файлах папки day-18 курса 2 с Live Server. replace и split — завтра, сегодня обходимся без них.

Разминка

1. Вся строка или где-то
Легко7 мин

читать якоря и границы слова.

  1. /\d{3}/.test("12345")
  2. /^\d{3}$/.test("12345")
  3. /^Мары/.test("Город Мары")
  4. /Мары$/.test("Город Мары")
  5. /\bjs\b/i.test("Курс JS-1")
  6. /\bкурс\b/i.test("Курс JS-1")
  7. /^[^0-9]/.test("1 курс")
  8. /^$/.test("")
  • все восемь ответов записаны до проверки, ошибки разобраны;
  • объяснено, почему строка 5 — true, а строка 6 — false;
  • для строки 7 названы оба значения ^ в этом шаблоне;
  • строка 6 исправлена проверками позиции так, чтобы ответ стал true.
2. Группы по номерам
Легко6 мин

знать, что лежит в массиве-результате.

Шаблон /(\w+)@(\w+)\.(\w+)/, строка «Почта: aman@mail.tm».

  • записаны [0]–[3] и index: «aman@mail.tm», «aman», «mail», «tm», 7;
  • группы переименованы в user, domain, zone — данные взяты деструктуризацией из groups;
  • зона сделана незахватывающей группой — длина массива стала 3;
  • для /((\d+)-(\d+))/.exec("12-34") записаны группы 1–3 — «12-34», «12», «34» — и объяснено, почему внешняя группа первая.
3. exec или match
Легко7 мин

предсказывать результаты трёх методов.

Строка const s = "a1 b22 c333";.

  • s.match(/\d+/)[0] — «1», s.match(/\d+/g) — ['1', '22', '333']: предсказано до проверки;
  • для const re = /\d+/g; два вызова re.exec(s) дали «1» и «22», после них re.lastIndex — 6; объяснено, откуда 6;
  • после ещё двух exec результат — null, а lastIndex — 0;
  • [...s.matchAll(/\d+/g)].length — 3, а "abc".match(/\d/g) ?? [] — пустой массив; объяснено, зачем ?? [].

Основные задания

4. Дата и время
Средне12 мин

разбирать строку именованными группами и проверять её целиком.

Функция parseDateTime(text) принимает «ДД.ММ.ГГГГ ЧЧ:ММ» и возвращает объект с числами или null. Разделитель даты — точка или косая черта, но одинаковый в обоих местах.

  • «12.10.2026 14:30» — {day: 12, month: 10, year: 2026, hour: 14, minute: 30}, и «12/10/2026 14:30» — то же;
  • «12.10.2026», «1.10.2026 14:30» и «12/10.2026 14:30» — null; одинаковость разделителя проверена ссылкой \k<имя>;
  • по результату собран Date, его getHours() — 14;
  • объяснено, почему без Number часы и минуты были бы строками.
5. Хэштеги и упоминания
Средне12 мин

собирать все совпадения и отсекать лишние.

Пост: «Сдали #экзамен! Спасибо @aman и @meret_2010. Пишите aman@mail.tm #Экзамен #JS #js #каникулы».

  • все хэштеги — пять, с кириллическими; разных без учёта регистра — три: Set из дня 15;
  • упоминания — ['@aman', '@meret_2010']: точка после имени не попала;
  • адрес почты не принят за упоминание — ретроспективная проверка «слева не буква, не цифра и не точка»;
  • для каждого хэштега через matchAll выведен номер символа, с которого он начинается.
6. Повторы слов
Средне12 мин

искать повторы в русском и английском тексте.

Текст: «Мы мы пошли в в школу. The the end. Кот котлета.»

  • найдены повторы ['Мы', 'в', 'The'] одним шаблоном с флагами gi через matchAll;
  • «Кот котлета» не считается повтором — объяснено почему;
  • версия со \b нашла только «The» — объяснено почему;
  • для каждого повтора выведено его место в тексте: 0, 12, 23.
7. Импорт расписания
Средне14 мин

разбирать многострочный текст без split.

const schedule = `пн 09:00 Математика
пн 10:00 Физика
вт 9:00 Химия
ср 11:30 JS
чт 25:00 История`;
  • шаблон с флагами gm, якорями и именованными группами day, time, subject нашёл три урока; «9:00» и «25:00» отброшены — часы только от 00 до 23;
  • через Map.groupBy (день 14) по дню: «пн» — 2 урока, «ср» — 1;
  • без флага m не найдено ни одного урока — объяснено почему;
  • записано, какая строка расписания попала бы в результат без проверки часов.

Со звёздочкой

8. Свой matchAll
Сложно10 мин

понять, от каких ловушек спасает matchAll.

Функция allMatches(text, re) возвращает массив exec-результатов циклом exec.

Работайте с копией: new RegExp(re.source, …) с флагом g. После пустого совпадения сдвиньте lastIndex на единицу сами — так делает спецификация в 22.2.9.
  • для /\d+/g на «a1 b22 c333» — те же три совпадения с теми же index, что у matchAll;
  • для /x*/g на «ab» — три пустых совпадения с index 0, 1, 2, как у matchAll, и цикл не завис;
  • lastIndex исходного шаблона после вызова — по-прежнему 0;
  • шаблон без флага g тоже работает — функция сама добавляет g к копии.
9. Пароль на проверках позиции
Сложно10 мин

складывать несколько условий в один шаблон.

isStrong(password): не короче 8 символов, есть цифра, строчная и заглавная латинская буква, нет пробелов и первый символ не цифра.

  • «Aman2010x» — true; «Aman 2010x», «2Amanxxxx», «AMAN2010X», «Aman201» — false;
  • все условия — опережающими проверками от одной позиции ^; объяснено, почему они друг другу не мешают;
  • объяснено, зачем в (?=.*\d) нужно .*;
  • написана версия из нескольких test без проверок позиции и записано, какая понятнее.
