День 19. Замена и разбиение: replace, replaceAll, split

Выжимка лекции: замена первого и всех совпадений, шаблоны $ и функция замены, разбиение строки по шаблону и экранирование ввода.

Главное

"a-b-c".replace("-", "+");                                 // "a+b-c" — строка: только первое
"a-b-c".replace(/-/g, "+");                                // "a+b+c" — шаблон с g: все
"a-b-c".replaceAll("-", "+");                              // "a+b+c" — все, без шаблона
"12.10.2026".replace(/(\d+)\.(\d+)\.(\d+)/, "$3-$2-$1");   // "2026-10-12"
"Аман, Мерет;Гүлнар".split(/\s*[,;]\s*/);                  // ['Аман', 'Мерет', 'Гүлнар']
new RegExp(RegExp.escape("c++"), "i").test("C++");         // true — ввод стал буквальным

Замена

В строке заменыЧто вставится
$&всё совпадение
$1 … $99, $<имя>группа по номеру или имени — только у регулярки
$`, $'часть строки до совпадения и после
$$знак «$»
Функция замены вызывается на каждое совпадение: (match, p1, …, pN, offset, string, groups); groups приходит, только если в шаблоне есть имена. Что функция вернула, то и встанет — строкой, без разбора $. Группа, которая не участвовала, — undefined (в строке замены — пустая строка). Сколько групп, заранее неизвестно — (match, ...args) и поиск offset с конца.
replace заменяет больше одного раза только с регуляркой с флагом g. replaceAll с регуляркой без g — TypeError. Забытый второй аргумент превращается в строку «undefined». Исходная строка не меняется никогда — метод возвращает новую.

Разбиение

ВызовРезультат
"a,b".split(",")['a', 'b'] — разделитель выпадает
",a,".split(",")['', 'a', ''] — пустые по краям
"abc".split("")по символам (16-битным частям)
"a1b2".split(/(\d)/)['a', '1', 'b', '2', ''] — группа вставлена
"a,b,c".split(",", 2)['a', 'b'] — limit
"".split(",")[''], а "".split("") — []
Несколько разделителей — класс: split(/\s*[,;]\s*/); строки текста — split(/\r?\n/); слова — trim().split(/\s+/). Флаги g и y на split не влияют.
RegExp.escape(ввод) экранирует особые символы, первую латинскую букву или цифру и знаки препинания: «c++» → \x63\+\+. Нужен, когда ввод вставляют в шаблон. Простую замену текста делает replaceAll со строкой — без шаблона. Строковые методы зовут re[Symbol.replace], [Symbol.split] и соседей; копию шаблона через Symbol.species делают split и matchAll.
