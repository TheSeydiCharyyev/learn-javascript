День 20. Unicode в строках и регулярных выражениях

Выжимка лекции: три уровня строки, половинки без пары, флаги u и v, классы \p{…}, normalize и String.raw.

Главное

"🙂".length;                                // 2 — две 16-битные части
[..."🙂"].length;                           // 1 — одна кодовая точка
/^.$/u.test("🙂");                          // true — с флагом u пара — один символ
"Gülnar dünýä".match(/\p{L}+/gu);           // ['Gülnar', 'dünýä'] — буквы любого алфавита
"e\u0301".normalize() === "\u00E9";         // true — одна форма записи
String.raw`\d+\.\d+`.length;                // 8 — косые остались в строке

Три уровня

УровеньКто считает так
16-битные частиlength, s[i], slice, split(""), charCodeAt, шаблон без u
кодовые точкиfor...of, [...s], codePointAt, String.fromCodePoint, шаблон с u/v
графемы«👍🏽», «🇹🇲» — один знак, но две точки; Intl.Segmenter — курс 3
Символ вне базовой плоскости (эмодзи) хранится суррогатной парой: старшая половинка D800–DBFF и младшая DC00–DFFF. Половинка без пары появляется, если резать строку по частям. isWellFormed() находит такие половинки, toWellFormed() меняет их на «�» (U+FFFD); encodeURI на них падает.

Шаблоны

ЗаписьЧто значит
\p{L}, \p{Lu}, \p{Ll}буква, заглавная, строчная — любого алфавита
\p{N}, \p{M}, \p{Sc}цифра, знак над буквой, знак валюты
\p{sc=Cyrillic}, \p{Script=Latin}письменность
\P{…}всё, кроме
[\p{L}--[a-z]], [A&&B], \q{abc}только с v: вычитание, пересечение, строка в классе
Без флага u запись \p{L} — это текст «p{L}», и ошибки нет. С флагом старые вольности (\-, одинокая {, \00) становятся SyntaxError — строгий режим для шаблонов. u и v вместе нельзя. \b и \w и с флагом — только ASCII; граница слова — (?<!\p{L})слово(?!\p{L}).

Нормализация и String.raw

"\u00E9" и "e\u0301" выглядят одинаково, но === даёт false. normalize() — форма NFC (собрать), "NFD" — разложить, "NFKC"/"NFKD" — ещё и упростить «ﬀ», «①». Поиск без диакритики: normalize("NFD").replace(/\p{M}/gu, ""), но «й» и «ё» тоже распадутся. Неизвестная форма — RangeError.
Тег: f`a${x}b` вызывает f(['a', 'b'], x); у массива кусков есть raw — текст как написан. String.raw склеивает raw с подстановками: new RegExp(String.raw`^\d+$`) без удвоения косых. Тег с ?. — SyntaxError.
