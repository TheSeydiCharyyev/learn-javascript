День 21. BigInt и Date целиком: разбор строк, UTC, сеттеры

Выжимка лекции: целые любого размера, дата как один момент, разбор строк, сеттеры с переносом и превращения даты. Примеры — для пояса Ашхабада (UTC+5).

Главное

9007199254740993n + 2n;                            // 9007199254740995n — точно
BigInt("9007199254740993") === 9007199254740993n;   // true — большое число строкой
5n / 2n;                                            // 2n — дробь отбрасывается
new Date("2026-10-12").getHours();                  // 5 — дата без времени читается как UTC
new Date(2026, 2, 0).getDate();                     // 28 — последний день февраля
new Date(2026, 9, 12) - new Date(2026, 9, 11);      // 86400000 — сутки в миллисекундах

Дата

Дата — одно число: миллисекунды от 1970-01-01T00:00Z. Пояс в ней не хранится — его берут с устройства. get…/set… читают и пишут по местному времени, getUTC…/setUTC… — по UTC. getTimezoneOffset() — разница в минутах, минус значит «восточнее UTC»: Ашхабат — −300. getDay() — день недели, 0 — воскресенье.
СтрокаКак читается
"2026-10-12"полночь UTC — 5 утра в Ашхабаде
"2026-10-12T00:00"полночь по-местному
"2026-10-12T00:00Z", "…+03:00"с явным поясом — как написано
"12.10.2026" и прочеекак решит движок: Chrome — 10 декабря; разбирайте сами
Сеттеры меняют дату на месте и переносят лишнее: setDate(32) — следующий месяц, setDate(0) — последний день прошлого, 31 января плюс месяц — 3 марта. Перед сеттером делайте копию new Date(date). Date.UTC(…) возвращает число по UTC, new Date(2026) — это 2026 миллисекунд.
d + 1 — строка (дата превращается в текст), d - 1 и d < e — числа. JSON.stringify пишет дату ISO-строкой по UTC через toJSON; неверная дата — null. Обратно — reviver: key === "when" ? new Date(value) : value.
Строки: toString (местное время и пояс на языке браузера), toDateString, toTimeString, toUTCString, toISOString; для людей — toLocaleDateString. Ошибки BigInt: Division by zero, Exponent must be positive, «not an integer», Cannot convert a BigInt value to a number, Cannot convert … to a BigInt.

  2. Напишите daysInMonth(year, month) через нулевое число следующего месяца.
  3. Прочитайте на странице BigInt раздел «Use within JSON» и объясните, почему reviver пишут под форму данных.
  4. Найдите в спецификации MakeDay (21.4.1.28) и объясните по шагам, почему месяц 12 — это январь следующего года.
