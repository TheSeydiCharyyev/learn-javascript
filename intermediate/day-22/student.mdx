# День 22. Temporal: PlainDate, PlainTime, PlainDateTime и Now

<Subtitle>Выжимка лекции: классы `Temporal` без пояса, создание, поля, сдвиг, разница, сравнение, JSON и «сегодня».</Subtitle>

## Главное

```js
Temporal.PlainDate.from("2026-01-31").add({ months: 1 }).toString();   // "2026-02-28" — без переноса в март
new Temporal.PlainDate(2026, 10, 12).month;                             // 10 — месяц с единицы
Temporal.PlainDate.from("2026-10-18").dayOfWeek;                        // 7 — воскресенье, понедельник — 1
Temporal.PlainDate.from("2026-10-12").until("2027-01-01").days;         // 81
Temporal.PlainDate.compare("2026-10-12", "2026-10-20");                 // -1
JSON.stringify({ next: Temporal.PlainDate.from("2026-10-12") });        // '{"next":"2026-10-12"}'
```

<Definition>
Объекты `Temporal` **неизменяемы**: `with`, `add`,
`subtract` возвращают новый объект, а поля — только для чтения. Строка `d.add({ days: 1 });`
без присваивания не делает ничего. Строка разбирается строго — только формат RFC 9557 (`YYYY-MM-DD`),
иначе `RangeError`; объект подгоняется настройкой `overflow`: `"constrain"` (по
умолчанию) или `"reject"`.
</Definition>

## Date и PlainDate

| Задача | Date | PlainDate |
| --- | --- | --- |
| месяц | `getMonth()`, 0–11 | `month`, 1–12 |
| день недели | `getDay()`, 0 — воскресенье | `dayOfWeek`, 7 — воскресенье |
| длина месяца | `new Date(y, m + 1, 0).getDate()` | `daysInMonth` |
| плюс 20 дней | копия и `setDate(getDate() + 20)` | `d.add({ days: 20 })` |
| дней между | `Date.UTC` от частей, деление на 86400000 | `a.until(b).days` |
| раньше ли | `a < b` | `Temporal.PlainDate.compare(a, b) < 0` |

<KeyPoint>
Внутри `add` сначала годы и месяцы, потом число подгоняется к длине месяца, потом недели и дни:
31 января + `{ months: 1, days: 31 }` — 31 марта. `a.until(b)` — «b минус a»,
`a.since(b)` — «a минус b»; `{ largestUnit: "months" }` разбивает ответ на месяцы и дни.
</KeyPoint>

<Remember>
`<`, `-` и `+` с датами `Temporal` — `TypeError`:
`valueOf` бросает ошибку нарочно. Сравнивают `equals` и `compare`, сортируют
`list.sort(Temporal.PlainDate.compare)`. В JSON дата уходит строкой сама, обратно — reviver с
`Temporal.PlainDate.from`.
</Remember>

<NoteBox>
`PlainDateTime` выбрасывает смещение из строки («…+03:00») без пересчёта, а `Z` не
принимает: момент с поясом — `ZonedDateTime` дня 24. `Temporal.Now` зовите в одном месте,
«сегодня» передавайте функциям параметром. Ошибки Chrome начинаются с «Temporal error:».
</NoteBox>
