# День 23. Temporal: Duration, PlainYearMonth, PlainMonthDay

<Subtitle>Выжимка лекции: длительности и их строки, перенос, перевод в число, дата-опора, месяц года и день месяца.</Subtitle>

## Главное

```js
Temporal.Duration.from({ minutes: 45 * 108 }).total("hours");                    // 81 — курс в часах
Temporal.Duration.from("PT100H100M").round({ largestUnit: "days" }).toString();   // "P4DT5H40M"
Temporal.Duration.from({ months: 1 }).total({ unit: "days", relativeTo: "2026-02-01" });   // 28
Temporal.Duration.compare("PT90M", "PT1H30M");                                    // 0 — одна длина
Temporal.PlainYearMonth.from("2026-10").daysInMonth;                              // 31
Temporal.PlainMonthDay.from("02-29").toPlainDate({ year: 2027 }).toString();      // "2027-02-28"
```

## Строка длительности

| Строка | Значит |
| --- | --- |
| `P81D` | 81 день |
| `P1M` / `PT1M` | месяц / минута — `M` до и после `T` |
| `P1DT12H` | 1 день 12 часов |
| `PT9.58S` | 9 секунд 580 миллисекунд |
| `-PT1H30M` | минус полтора часа — знак один на всё |
| `PT0S` | ноль |

<Definition>
`Duration` — десять целых полей одного знака, от `years` до `nanoseconds`, плюс
`sign` и `blank`. Поля хранятся как дали: `PT100H100M` не переносится сам.
`round` переносит лишнее до `largestUnit` и округляет до `smallestUnit`;
`total` возвращает число в одной единице.
</Definition>

<KeyPoint>
Годы, месяцы и недели — **календарные единицы**: их длина в днях зависит от даты. Для них
`total`, `round` и `compare` требуют `relativeTo` — дату-опору, а
`add` двух длительностей не работает вовсе: складывайте через дату,
`start.add(a).add(b).since(start)`.
</KeyPoint>

<Remember>
`a > b` и `a + b` у длительностей — `TypeError`. Сравнение —
`Temporal.Duration.compare` (годится для `sort`), сумма — `a.add(b)`, число —
`total`. Строки не сравнивать: `"PT3S" > "PT1M"` — `true`.
</Remember>

## Месяц года и день месяца

|  | PlainYearMonth | PlainMonthDay |
| --- | --- | --- |
| пример | `"2026-10"` — октябрь 2026 | `"10-12"` — 12 октября каждого года |
| поля | `year`, `month`, `daysInMonth`, `inLeapYear`… | `monthCode`, `day` — и всё |
| арифметика | `add`, `until` — только годы и месяцы | нет; только `equals`, `with` |
| в дату | `toPlainDate({ day: 1 })` | `toPlainDate({ year: 2027 })` |

## Какой класс взять

| Что нужно хранить | Класс | День |
| --- | --- | --- |
| дату занятия, срок сдачи | `PlainDate` | 22 |
| время звонка, будильник | `PlainTime` | 22 |
| урок «12 октября в 9:00» по местному времени | `PlainDateTime` | 22 |
| сколько длилось, через сколько повторить | `Duration` | 23 |
| отчёт за месяц, страницу календаря | `PlainYearMonth` | 23 |
| день рождения, ежегодный праздник | `PlainMonthDay` | 23 |
| созвон в одно мгновение для разных городов | `ZonedDateTime`, `Instant` | 24 |

<NoteBox>
Опорный год `PlainMonthDay` — 1972-й, поэтому `"02-29"` допустим. В 2027 году он подгоняется
к 28 февраля. `toLocaleString("ru-RU")` у этих двух классов даёт «Mismatched calendars» — календарь
передают в настройках (день 25).
</NoteBox>
