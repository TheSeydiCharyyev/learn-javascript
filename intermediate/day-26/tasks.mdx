<Task title="9. Четыре ловушки" level="hard" time="10">
<Goal>находить ошибки в своих классах ошибок.</Goal>

```js
class AppError extends Error {
  constructor(message) {
    super(message);
  }
}
class ValidationError extends AppError {
  constructor(message, field) {
    super(message);
    this.field = field;
  }
}
function save(text) {
  try {
    return JSON.parse(text);
  } catch (err) {
    throw new AppError("настройки не сохранены", { cause: err });
  }
}
function handle(e) {
  if (e instanceof AppError) return `ошибка программы: ${String(e)}`;
  if (e instanceof ValidationError) return `поле ${e.field}`;
  return "неизвестно";
}
console.log(handle(new ValidationError("нет имени", "name")));
try { save("{"); } catch (e) { console.log(handle(e), "cause" in e); }
console.log(handle(new TypeError("опечатка")));
```

<Criteria>
- программа печатает «ошибка программы: Error: нет имени», «ошибка программы: Error: настройки не сохранены
  false» и «неизвестно» — для каждой строки названа причина;
- после исправлений: «поле name», «ошибка программы: AppError: настройки не сохранены true»;
- третий вызов бросает `TypeError: опечатка` из `handle`, а не возвращает
  «неизвестно»;
- все четыре исправления — в классах и в `handle`, вызовы внизу не менялись.
</Criteria>
</Task>
