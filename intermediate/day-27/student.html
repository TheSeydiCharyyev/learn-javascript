День 27. Промисы целиком: all, allSettled, any, race, withResolvers, try

Выжимка лекции: четыре способа ждать несколько промисов, AggregateError, таймаут, withResolvers и try.

Главное

Promise.all([Promise.resolve(1), 2]);                                  // выполнится: [1, 2] — в порядке входа
Promise.allSettled([Promise.reject(new Error("x"))]);                  // выполнится: [{ status: "rejected", reason }]
Promise.any([Promise.reject(new Error("x")), Promise.resolve("ok")]);  // выполнится: "ok" — отказы пропущены
Promise.race([new Promise(() => {}), "сразу"]);                         // выполнится: "сразу" — первый завершившийся
Promise.any([]).catch((e) => e.name);                                  // "AggregateError" — все (ноль) отказали
Promise.try(() => JSON.parse("{")).catch((e) => e.name);               // "SyntaxError" — промис, а не throw

Четыре способа ждать

МетодВыполняетсяОтклоняется
allвсе выполнились — массив значений в порядке входапервый же отказ
allSettledвсе завершились — отчёты { status, value | reason }никогда
anyпервый успехвсе отказали — AggregateError
raceкак первый завершившийся, успехом или отказом
Независимые загрузки запускают все сразу: const [a, b] = await Promise.all([fa(), fb()]) — время как у самой долгой. Три await подряд складывают времена. В all передают вызовы, а не функции. Запущенные заранее промисы не ждут по одному: отказ второго, пока ждём первого, — «Uncaught (in promise)».
AggregateError — наследник Error для нескольких ошибок: new AggregateError(errors, message, { cause }), причины — в неперечисляемом массиве errors, в порядке входа. От Promise.any в Chrome текст — «All promises were rejected». Одна поломка с пояснением — cause, несколько независимых — AggregateError.
Таймаут: Promise.race([задача, таймер]).finally(() => clearTimeout(timer)). Ни один метод не отменяет проигравших — они доработают сами. Promise.withResolvers() отдаёт { promise, resolve, reject } — выполнить промис можно из обработчика события. Promise.try(f, ...args) вызывает f сразу и любой исход превращает в промис. Promise.race([]) не завершится никогда.

  2. Напишите withTimeout по памяти и проверьте на быстрой и медленной загрузке.
