День 27. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем в файлах папки day-27 курса 2 с Live Server, в Chrome. В начале app.js — три помощника дня 30 Essentials (wait, later, failLater, раздел 1 лекции). Время округляйте до сотен миллисекунд, как since в лекции.

Разминка

1. Что вернёт
Легко7 мин

знать, чем завершается каждый метод.

  1. Promise.all([1, Promise.resolve(2)])
  2. Promise.all([]) — сразу, без ожидания
  3. Promise.race([]) через секунду
  4. Promise.any([])
  5. Promise.allSettled([Promise.reject(new Error("x"))])
  6. Promise.all(5) — бросит ошибку или вернёт промис?
  7. new AggregateError([]).message
  8. Promise.resolve(p) === p для const p = Promise.resolve(1)
  • все ответы записаны до проверки, ошибки разобраны;
  • для строк 3 и 4 объяснено, почему пустой массив даёт такие разные исходы;
  • для строки 5 объяснено, почему промис выполнен, хотя внутри отказ;
  • для строки 6 объяснено, где искать ошибку — в catch, а не в try.
2. Какой метод
Легко6 мин

выбирать способ ожидания по задаче.

  1. Журнал показывают, только когда пришли и список группы, и оценки.
  2. Нужно отчитаться, какие из десяти файлов загрузились, а какие нет.
  3. Колода лежит на трёх зеркалах, годится любая копия.
  4. Ответа ждём не дольше двух секунд.
  5. Нужен ответ первого сервера, даже если это отказ: по нему видно, жива ли сеть.
  • для каждой строки назван метод: all, allSettled, any, race, race;
  • для строки 3 объяснено, почему не race, а для строки 5 — почему не any;
  • для строки 4 написан вызов withTimeout из лекции.
3. Что и когда напечатается
Легко7 мин

предсказывать исход по времени каждого промиса.

const start = Date.now();
const since = () => `${Math.round((Date.now() - start) / 100) * 100} мс`;
const a = later("A", 200);
const b = failLater("B", 300);
const c = later("C", 100);
Promise.race([a, b, c]).then((v) => console.log("race", v, since()));
Promise.any([b, a]).then((v) => console.log("any", v, since()));
Promise.all([a, c]).then((v) => console.log("all", v, since()));
Promise.allSettled([a, b]).then((r) => console.log("allSettled", r.length, since()));
Promise.all([a, b, c]).catch((e) => console.log("all отклонён", e.message, since()));
  • пять строк записаны до запуска, со временем;
  • в Chrome: «race C 100 мс», «any A 200 мс», «all (2) ['A', 'C'] 200 мс», «allSettled 2 300 мс», «all отклонён B 300 мс» — расхождения с записанным разобраны;
  • объяснено, почему any не отклонился, хотя b стоит в нём первым.

Основные задания

4. Журнал группы одной загрузкой
Средне12 мин

загружать независимые данные сразу.

loadClass() — async-функция. Группа ["Аман", "Мерет", "Сапар"] приходит через 300 мс, расписание ["пн", "ср", "пт"] — через 200, оценки { Аман: [5, 4] } — через 100 (later).

  • результат — строка «3 ученика, занятия: пн, ср, пт, оценки у 1», готова за 300 мс;
  • загрузки идут через Promise.all, результат разобран деструктуризацией;
  • если расписание — failLater("расписание: 500", 200), напечатано «Не загрузилось: расписание: 500» через 200 мс;
  • версия с тремя await подряд занимает 600 мс — записано почему.
5. Отчёт о пяти файлах
Средне13 мин

собирать отчёт через allSettled.

Файлы: group.json — ответ через 100 мс, schedule.json — отказ «404» через 200, marks.json — ответ через 150, words.json — ответ через 50, photos.json — отказ «нет сети» через 300.

  • напечатано «загружено 3 из 5: group.json, marks.json, words.json»;
  • и «не загружено: schedule.json (404), photos.json (нет сети)» — в порядке списка, а не готовности;
  • отчёт готов за 300 мс, и отказ ни одного файла не обрывает остальные;
  • имена файлов и обещания хранятся в одном массиве объектов, без отдельного массива имён.
6. Самый быстрый сервер
Средне13 мин

ждать первого успеха и разбирать AggregateError.

fastest(servers) возвращает промис ответа первого успешного сервера или текст о неудаче.

  • fastest([later("Мары", 300), failLater("Ашхабад", 100), later("Дашогуз", 200)]) — «Дашогуз» через 200 мс;
  • если все отказали (Ашхабад через 100, Мары через 50) — «все серверы молчат: Ашхабад, Мары», причины в порядке списка;
  • fastest([]) — «серверов нет»: пустой список узнан по errors.length;
  • записано, что вернул бы Promise.race для первого вызова и почему.
7. Таймаут без хвостов
Средне12 мин

ограничивать время и убирать за собой.

withTimeout(promise, ms) — как в лекции. В таймер добавьте console.log("таймер сработал").

  • withTimeout(later("ok", 100), 300) — «ok», а «таймер сработал» не появилось: таймер снят;
  • withTimeout(later("ok", 500), 300) — «таймер сработал» и ошибка «нет ответа за 300 мс» через 300 мс;
  • withTimeout(Promise.reject(new Error("сразу")), 300) отклонён ошибкой «сразу», а не таймаутом;
  • записано, что стало с медленной загрузкой после таймаута.

Со звёздочкой

8. Свой Promise.all
Сложно10 мин

повторить PerformPromiseAll из спецификации.

Возьмите Promise.withResolvers(), массив values, счётчик с начальным значением 1 и номер каждого элемента в замыкании (день 1). Каждый элемент пропустите через Promise.resolve.
  • myAll([later("A", 300), later("B", 100), "C"]) — ['A', 'B', 'C'] через 300 мс;
  • myAll([]) выполнен сразу пустым массивом;
  • myAll([failLater("x", 100), failLater("y", 50)]) отклонён ошибкой «y»;
  • работает с Set; объяснено, зачем счётчик начинается с 1.
9. Повтор с отчётом
Сложно10 мин

собирать причины неудач в AggregateError.

retry(fn, times) вызывает fn(номерПопытки), пока она не удастся, но не больше times раз. Если все попытки не удались — AggregateError со всеми причинами.

  • для fn = (n) => (n < 3 ? failLater(`попытка ${n}: нет связи`, 50) : later("данные", 50)) retry(fn, 3) даёт «данные»;
  • retry(fn, 2) — AggregateError «2 попытки не удались», errors: «попытка 1: нет связи», «попытка 2: нет связи»;
  • функция, которая бросает сразу (() => { throw new Error("сразу"); }), тоже повторяется: при times 2 — две причины «сразу»;
  • попытки идут по очереди, а не все сразу — объяснено, почему здесь не Promise.all.
