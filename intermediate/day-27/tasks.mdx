## Разминка

<Task title="1. Что вернёт" level="easy" time="7">
<Goal>знать, чем завершается каждый метод.</Goal>

1. `Promise.all([1, Promise.resolve(2)])`
2. `Promise.all([])` — сразу, без ожидания
3. `Promise.race([])` через секунду
4. `Promise.any([])`
5. `Promise.allSettled([Promise.reject(new Error("x"))])`
6. `Promise.all(5)` — бросит ошибку или вернёт промис?
7. `new AggregateError([]).message`
8. `Promise.resolve(p) === p` для `const p = Promise.resolve(1)`

<Criteria>
- все ответы записаны до проверки, ошибки разобраны;
- для строк 3 и 4 объяснено, почему пустой массив даёт такие разные исходы;
- для строки 5 объяснено, почему промис выполнен, хотя внутри отказ;
- для строки 6 объяснено, где искать ошибку — в `catch`, а не в `try`.
</Criteria>
</Task>

<Task title="2. Какой метод" level="easy" time="6">
<Goal>выбирать способ ожидания по задаче.</Goal>

1. Журнал показывают, только когда пришли и список группы, и оценки.
2. Нужно отчитаться, какие из десяти файлов загрузились, а какие нет.
3. Колода лежит на трёх зеркалах, годится любая копия.
4. Ответа ждём не дольше двух секунд.
5. Нужен ответ первого сервера, даже если это отказ: по нему видно, жива ли сеть.

<Criteria>
- для каждой строки назван метод: `all`, `allSettled`, `any`,
  `race`, `race`;
- для строки 3 объяснено, почему не `race`, а для строки 5 — почему не `any`;
- для строки 4 написан вызов `withTimeout` из лекции.
</Criteria>
</Task>

<Task title="3. Что и когда напечатается" level="easy" time="7">
<Goal>предсказывать исход по времени каждого промиса.</Goal>

```js
const start = Date.now();
const since = () => `${Math.round((Date.now() - start) / 100) * 100} мс`;
const a = later("A", 200);
const b = failLater("B", 300);
const c = later("C", 100);
Promise.race([a, b, c]).then((v) => console.log("race", v, since()));
Promise.any([b, a]).then((v) => console.log("any", v, since()));
Promise.all([a, c]).then((v) => console.log("all", v, since()));
Promise.allSettled([a, b]).then((r) => console.log("allSettled", r.length, since()));
Promise.all([a, b, c]).catch((e) => console.log("all отклонён", e.message, since()));
```

<Criteria>
- пять строк записаны до запуска, со временем;
- в Chrome: «race C 100 мс», «any A 200 мс», «all (2) \['A', 'C'\] 200 мс», «allSettled 2 300 мс», «all
  отклонён B 300 мс» — расхождения с записанным разобраны;
- объяснено, почему `any` не отклонился, хотя `b` стоит в нём первым.
</Criteria>
</Task>

## Основные задания

<Task title="4. Журнал группы одной загрузкой" level="medium" time="12">
<Goal>загружать независимые данные сразу.</Goal>

`loadClass()` — `async`-функция. Группа `["Аман", "Мерет", "Сапар"]` приходит
через 300 мс, расписание `["пн", "ср", "пт"]` — через 200, оценки `{ Аман: [5, 4] }` — через
100 (`later`).

<Criteria>
- результат — строка «3 ученика, занятия: пн, ср, пт, оценки у 1», готова за 300 мс;
- загрузки идут через `Promise.all`, результат разобран деструктуризацией;
- если расписание — `failLater("расписание: 500", 200)`, напечатано «Не загрузилось:
  расписание: 500» через 200 мс;
- версия с тремя `await` подряд занимает 600 мс — записано почему.
</Criteria>
</Task>

<Task title="5. Отчёт о пяти файлах" level="medium" time="13">
<Goal>собирать отчёт через `allSettled`.</Goal>

Файлы: group.json — ответ через 100 мс, schedule.json — отказ «404» через 200, marks.json — ответ через 150,
words.json — ответ через 50, photos.json — отказ «нет сети» через 300.

<Criteria>
- напечатано «загружено 3 из 5: group.json, marks.json, words.json»;
- и «не загружено: schedule.json (404), photos.json (нет сети)» — в порядке списка, а не готовности;
- отчёт готов за 300 мс, и отказ ни одного файла не обрывает остальные;

<Task title="6. Самый быстрый сервер" level="medium" time="13">
<Goal>ждать первого успеха и разбирать `AggregateError`.</Goal>

`fastest(servers)` возвращает промис ответа первого успешного сервера или текст о неудаче.

<Criteria>
- `fastest([later("Мары", 300), failLater("Ашхабад", 100), later("Дашогуз", 200)])` — «Дашогуз»
  через 200 мс;
- если все отказали (Ашхабад через 100, Мары через 50) — «все серверы молчат: Ашхабад, Мары», причины в
  порядке списка;
- `fastest([])` — «серверов нет»: пустой список узнан по `errors.length`;
- записано, что вернул бы `Promise.race` для первого вызова и почему.
</Criteria>
</Task>

<Task title="7. Таймаут без хвостов" level="medium" time="12">
<Goal>ограничивать время и убирать за собой.</Goal>

`withTimeout(promise, ms)` — как в лекции. В таймер добавьте `console.log("таймер
сработал")`.

<Criteria>
- `withTimeout(later("ok", 100), 300)` — «ok», а «таймер сработал» не появилось: таймер снят;
- `withTimeout(later("ok", 500), 300)` — «таймер сработал» и ошибка «нет ответа за 300 мс» через
  300 мс;
- `withTimeout(Promise.reject(new Error("сразу")), 300)` отклонён ошибкой «сразу», а не таймаутом;
- записано, что стало с медленной загрузкой после таймаута.
</Criteria>
</Task>

<Task title="9. Повтор с отчётом" level="hard" time="10">
<Goal>собирать причины неудач в `AggregateError`.</Goal>

`retry(fn, times)` вызывает `fn(номерПопытки)`, пока она не удастся, но не больше
`times` раз. Если все попытки не удались — `AggregateError` со всеми причинами.

<Criteria>
- для ``fn = (n) => (n < 3 ? failLater(`попытка ${n}: нет связи`, 50) : later("данные", 50))``
  `retry(fn, 3)` даёт «данные»;
- `retry(fn, 2)` — `AggregateError` «2 попытки не удались», `errors`: «попытка 1:
  нет связи», «попытка 2: нет связи»;
- функция, которая бросает сразу (`() => { throw new Error("сразу"); }`), тоже повторяется: при
  `times` 2 — две причины «сразу»;
- попытки идут по очереди, а не все сразу — объяснено, почему здесь не `Promise.all`.
</Criteria>
</Task>
