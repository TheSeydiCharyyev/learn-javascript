День 28. async-функции изнутри и очередь микрозадач

Выжимка лекции: задачи и микрозадачи, порядок вывода, тело async-функции, выражение async function, где можно await.

Главное

setTimeout(() => console.log("5: таймер — следующая задача"), 0);
Promise.resolve().then(() => console.log("3: then — микрозадача"));
(async () => {
  console.log("1: до await — сразу");
  await null;
  console.log("4: после await — микрозадача, после then выше");
})();
console.log("2: конец скрипта");

Порядок выполнения

Задача — порция работы: скрипт целиком, сработавший таймер, событие. Выполняется до конца. Микрозадача — функция then, catch, finally или продолжение после await. После каждой задачи браузер выполняет все микрозадачи, в порядке постановки, включая добавленные по ходу, — и только потом берёт следующую задачу.

Async-функция всегда возвращает новый промис: return его выполняет, throw — отклоняет, и из вызова ошибка не вылетает. Чтобы catch поймал отказ возвращаемого промиса, пишут return await внутри try. Заодно функция останется в стеке ошибки строкой «at async имя», а медленнее справочник его не считает.
Выражение: const f = async function name() { … } — имя видно только внутри. Сразу вызванная: (async () => { … })() — в скобках. await можно только в async-функциях, async-генераторах (день 29) и модулях (день 30); в обычном колбэке — SyntaxError. По очереди: for...of с await; все сразу: await Promise.all(items.map(f)). forEach ничего не ждёт.
AsyncFunction не глобальный: async function () {}.constructor. Его конструктор опасен, как Function(); у async-функций нет prototype, и new с ними — TypeError. В спецификации: then только ставит задание (27.2.2), задание начинается при пустом стеке (9.5), await — это then с продолжением функции (Await, 27.7.5.3).
  1. Напишите свою задачу на порядок вывода из шести строк (таймер, then, await) и дайте решить соседу; проверьте в Chrome.
  2. Найдите в своём проекте forEach с async-колбэком или два await подряд и решите, что там нужно: по очереди или все сразу.
  3. Прочитайте на странице async function expression раздел «Async IIFE» и выпишите, зачем там стрелка в скобках.
  4. Найдите в ECMA-262 раздел 27.2.5.4.1 PerformPromiseThen и выпишите, что делает then с уже выполненным промисом.
