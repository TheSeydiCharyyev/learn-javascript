# День 28. async-функции изнутри и очередь микрозадач

<Subtitle>Выжимка лекции: задачи и микрозадачи, порядок вывода, тело async-функции, выражение async function, где можно await.</Subtitle>

## Главное

```js
setTimeout(() => console.log("5: таймер — следующая задача"), 0);
Promise.resolve().then(() => console.log("3: then — микрозадача"));
(async () => {
  console.log("1: до await — сразу");
  await null;
  console.log("4: после await — микрозадача, после then выше");
})();
console.log("2: конец скрипта");
```

## Порядок выполнения

<Definition>
**Задача** — порция работы: скрипт целиком, сработавший таймер, событие. Выполняется до конца.
**Микрозадача** — функция `then`, `catch`, `finally` или продолжение
после `await`. После каждой задачи браузер выполняет **все** микрозадачи, в порядке
постановки, включая добавленные по ходу, — и только потом берёт следующую задачу.
</Definition>

| Что | Когда выполнится |
| --- | --- |
| обычный код, исполнитель `new Promise`, async-функция до первого `await` | сразу |
| `then` выполненного промиса, код после `await` (даже `await 5`) | микрозадачей, после текущего кода |
| следующий `then` цепочки | когда выполнился предыдущий — цепочки идут вперемешку |
| `setTimeout(f, 0)`, щелчок | следующей задачей, после всех микрозадач |
| микрозадачи слушателей при щелчке мышью | после каждого слушателя; при `button.click()` из кода — после всего скрипта |

<KeyPoint>
Async-функция всегда возвращает новый промис: `return` его выполняет, `throw` — отклоняет, и
из вызова ошибка не вылетает. Чтобы `catch` поймал отказ возвращаемого промиса, пишут
`return await` внутри `try`. Заодно функция останется в стеке ошибки строкой «at async имя»,
а медленнее справочник его не считает.
</KeyPoint>

<Remember>
Выражение: `const f = async function name() { … }` — имя видно только внутри. Сразу вызванная:
`(async () => { … })()` — в скобках. `await` можно только в async-функциях, async-генераторах
(день 29) и модулях (день 30); в обычном колбэке — `SyntaxError`. По очереди: `for...of` с
`await`; все сразу: `await Promise.all(items.map(f))`. `forEach` ничего не ждёт.
</Remember>

<NoteBox>
`AsyncFunction` не глобальный: `async function () {}.constructor`. Его конструктор опасен, как
`Function()`; у async-функций нет `prototype`, и `new` с ними — `TypeError`.
В спецификации: `then` только ставит задание (27.2.2), задание начинается при пустом стеке (9.5),
`await` — это `then` с продолжением функции (Await, 27.7.5.3).
</NoteBox>
