День 29. Асинхронные итераторы и генераторы, for await...of

Выжимка лекции: async function*, for await...of, очередь вызовов, Symbol.asyncIterator, Array.fromAsync.

Главное

async function* pages() {
  try {
    yield await later(["book", "water"], 100);
    yield later(["apple"], 100);          // yield ждёт промис сам
    yield ["teacher"];
  } finally {
    console.log("закрыт");                // после break — до выхода из цикла
  }
}
(async () => {
  for await (const page of pages()) {
    console.log(page.join(", "));
    if (page.includes("apple")) break;
  }
  console.log(await Array.fromAsync(pages()));
})();

Асинхронный генератор — функция async function*: в теле можно и await, и yield. Вызов возвращает объект AsyncGenerator, тело начинается на первом next(). Записи: объявление, выражение, метод async *name() {}; стрелочной нет. yield промис и return промис ждут промис сами — value промисом не бывает.

Частые ошибки: for await вне async-функции — SyntaxError: Unexpected reserved word; for...of по асинхронному генератору — TypeError: gen is not iterable; for await по числу — 5 is not async iterable. Методы генератора и Array.fromAsync ошибку не бросают, а отклоняют свой промис.
Асинхронный генератор ленив: следующее значение он готовит, только когда его попросили. Постраничная загрузка останавливается на нужной странице, а тики «раз в секунду» не копятся, пока цикл занят, — в отличие от setInterval.
next, return и throw возвращают промисы. Вызовы, сделанные, пока генератор занят, встают в очередь и выполняются по порядку. return(v) на yield работает как return v в этом месте — finally выполнится. Свой перебор: { async *[Symbol.asyncIterator]() { … } }.
await Array.fromAsync(source, mapFn) — массив из асинхронного, обычного или похожего на массив источника; значения берёт по одному. Promise.all ждёт все сразу. Методов map и take у асинхронных итераторов нет — их пишут сами, асинхронными генераторами. AsyncGeneratorFunction не глобальный, у объекта генератора есть [Symbol.asyncIterator]() и [Symbol.asyncDispose](), но нет [Symbol.iterator]. Спецификация: очередь [[AsyncGeneratorQueue]] и пять состояний — раздел 27.6.
