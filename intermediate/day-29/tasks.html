День 29. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания делаем в файлах папки day-29 курса 2 с Live Server, в Chrome; в начале app.js — помощники дня 30 Essentials (wait, later, failLater). Время в выводе округляйте до 100 мс, как в лекции.

Разминка

1. Что вернёт
Легко7 мин

знать устройство асинхронных генераторов.

  1. typeof (async function* () {})
  2. (async function* () { yield 1; })().next() — что за значение и в каком состоянии сразу после вызова
  3. Object.prototype.toString.call((async function* () {})())
  4. Symbol.iterator in (async function* () {})()
  5. typeof (async function* () {})().map
  6. new (async function* () {})()
  7. await (async function* () { return later("итог", 100); })().next() внутри async-функции
  8. typeof AsyncGeneratorFunction
  • все ответы записаны до проверки, ошибки разобраны;
  • для строки 2 объяснено, почему промис ещё ожидает, хотя yield 1 стоит первой строкой;
  • для строки 7 объяснено, почему value — строка, а не промис;
  • для строки 8 записано, как всё же достать AsyncGeneratorFunction.
2. Порядок вывода
Легко7 мин

видеть, как по очереди работают генератор и цикл.

async function* gen() {
  console.log("g1");
  yield "a";
  console.log("g2");
  yield "b";
  console.log("g3");
}
(async () => {
  console.log("начало");
  for await (const x of gen()) {
    console.log("цикл", x);
  }
  console.log("конец");
})();
console.log("скрипт");
  • порядок записан до запуска;
  • в Chrome: начало, g1, скрипт, цикл a, g2, цикл b, g3, конец — расхождения разобраны;
  • объяснено, почему «g1» печатается раньше «скрипт», а «цикл a» — позже.
3. Массив или генератор
Легко6 мин

понимать, когда начинается работа.

Три загрузки: later("Аман", 300), later("Мерет", 100), later("Сапар", 200).

  1. массив из трёх промисов под for...of;
  2. тот же массив под for await, с временем от начала цикла;
  3. асинхронный генератор names() с тремя yield later(…) под for await, с временем от начала цикла.
  • для 1: три Promise {<pending>};
  • для 2: имена в порядке массива, все три — на 300 мс;
  • для 3: те же имена на 300, 400 и 600 мс;
  • записано, почему во втором случае Мерет не пришёл раньше Амана, а в третьем время сложилось.

Основные задания

4. Журнал по страницам
Средне13 мин

прятать страницы сервера за асинхронным генератором.

Сервер отдаёт журнал по две записи: loadPage(n) возвращает через 100 мс { students, next }, где next — номер следующей страницы или null.

const journal = [
  [{ name: "Аман", mark: 5 }, { name: "Мерет", mark: 4 }],
  [{ name: "Сапар", mark: 3 }, { name: "Айна", mark: 2 }],
  [{ name: "Гульнар", mark: 5 }, { name: "Ильяс", mark: 4 }],
  [{ name: "Джерен", mark: 4 }, { name: "Батыр", mark: 5 }],
];
  • loadPage считает запросы, генератор students() отдаёт учеников по одному, а в finally печатает «запросов: N»;
  • await Array.fromAsync(students()) — 8 учеников, «запросов: 4»;
  • поиск первого с оценкой ниже 3 через for await и break — Айна, «запросов: 2»;
  • средний балл всех учеников через for await, без массива, — 4;
  • записано, сколько запросов сделает версия «сначала Array.fromAsync, потом find» и почему.
5. Звонок
Средне12 мин

писать генератор «раз в секунду».

countdown(from, ms) — асинхронный генератор: через каждые ms отдаёт from, from - 1, … , 1, а в finally печатает «отсчёт закончен».

  • for await по countdown(3, 1000) печатает «осталось 3», «осталось 2», «осталось 1» на 1000, 2000 и 3000 мс, потом «отсчёт закончен» и «Звонок!»;
  • с break на 2 «осталось 1» не печатается, а «отсчёт закончен» — печатается, до строки после цикла;
  • с await wait(1500) в теле цикла значения приходят раз в 2500 мс — объяснено, почему не раз в 1000;
  • записано, сколько раз за то же время сработал бы setInterval(…, 1000).
6. Свои помощники
Средне13 мин

писать для асинхронных потоков методы, которых у них нет.

Асинхронные генераторы take(source, n), map(source, fn), filter(source, fn) работают с любым асинхронно перебираемым source. Источник для проверки — every(ms) из раздела 10 лекции, с finally.

  • await Array.fromAsync(take(map(filter(every(100), (t) => t % 2 === 0), (t) => t * 10), 3)) — [20, 40, 60] после шести тиков, около 600 мс;
  • «таймер остановлен» из every печатается раньше результата;
  • take(every(100), 0) сразу даёт пустой массив и не ждёт ни одного тика;
  • записано, почему нельзя написать every(100).take(3), как на дне 13.
7. Array.fromAsync или Promise.all
Средне12 мин

выбирать способ собрать результаты.

Источник: function* requests() { for (const ms of [300, 100, 200]) yield later(ms, ms); }.

  • await Array.fromAsync(requests()) — [300, 100, 200] за 600 мс;
  • await Promise.all(requests()) — тот же массив за 300 мс;
  • await Array.fromAsync([later(300, 300), later(100, 100), later(200, 200)]) — за 300 мс, и записано, почему не за 600;
  • await Array.fromAsync({ length: 2, 0: "a", 1: later("b", 100) }, (s) => s.toUpperCase()) — ['A', 'B'];
  • записано, какой способ взять, если сервер принимает запросы только по одному.

Со звёздочкой

8. Перебор руками
Сложно10 мин

выполнять договор асинхронного итератора без генератора.

Класс Countdown: new Countdown(from, ms), метод [Symbol.asyncIterator]() возвращает объект с next() и return(), написанными руками, без async function*.

next() возвращает later({ value, done: false }, ms), пока счёт не дошёл до нуля, а потом — Promise.resolve({ value: undefined, done: true }). Счётчик держите в замыкании внутри [Symbol.asyncIterator]().
  • for await по new Countdown(3, 100) — 3, 2, 1 за 300 мс;
  • два цикла подряд по одному объекту дают два полных отсчёта;
  • break вызывает return(), и он печатает «остановлен»; цикл до конца его не вызывает;
  • await Array.fromAsync(new Countdown(2, 100)) — [2, 1].
9. Не дольше 150 мс
Сложно10 мин

ограничивать ожидание каждого значения.

withTimeout(source, ms) — асинхронный генератор: отдаёт значения source, но если очередное не пришло за ms, бросает TimeoutError — свой класс ошибки дня 26 — и закрывает источник. Источник для проверки:

async function* slowPages() {
  try {
    yield await later("стр. 1", 100);
    yield await later("стр. 2", 300);
    yield "стр. 3";
  } finally {
    console.log("источник закрыт");
  }
}
Итератор источника — source[Symbol.asyncIterator](). Каждый шаг — Promise.race([it.next(), timeout]), как withTimeout дня 27; в finally — it.return().
  • с лимитом 150 мс: «стр. 1», потом catch ловит ошибку, у которой name — «TimeoutError», текст — «нет значения за 150 мс» и instanceof TimeoutError — true;
  • ошибка приходит примерно через 250 мс от старта (100 + 150), а «источник закрыт» печатается около 400 мс;
  • с лимитом 400 мс — все три страницы и «источник закрыт» в конце;
  • записано, почему с await it.return() ошибка приходит только около 400 мс — по очереди вызовов из раздела 6 лекции.
