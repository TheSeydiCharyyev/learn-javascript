День 30. Модули: import и export

Выжимка лекции: type="module", формы export и import, живые привязки, отличия от обычного скрипта, порядок выполнения.

Главное

<!-- index.html — открывать через Live Server -->
<script type="module" src="main.js"></script>
// counter.js
export let count = 0;
export function increment() {
  count++;
}
export default "счётчик";
// main.js
import title, { count, increment } from "./counter.js";
import * as counter from "./counter.js";
increment();
console.log(title, count, counter.count);   // счётчик 1 1 — живая привязка

Модуль — файл со своей областью верхнего уровня: наружу выходит только то, что помечено export. Живая привязка — импорт не копирует значение, а смотрит в переменную модуля-владельца: владелец меняет, импортёр видит; присвоить импорт — TypeError: Assignment to constant variable. Экспорт по умолчанию — для одного значения, которое представляет весь модуль; именованные — когда значений несколько. import { x } from — не деструктуризация объекта по умолчанию.
Путь начинается с ./, ../ или / и кончается .js; «голое» имя работает только с картой импорта <script type="importmap">. С адреса file:// модули не загрузятся (ошибка CORS) — нужен сервер.
Модуль всегда строгий, this на верхнем уровне — undefined, его var не попадает в window, await и for await разрешены наверху. Выполняется он один раз, после разбора страницы. Импорты поднимаются: зависимости выполняются первыми, обходом в глубину. Если main.js импортирует a.js и b.js, а оба — c.js, порядок такой: c, a, b, main. Объект модуля — с прототипом null, запечатан, ключи по алфавиту; записать в него нельзя — TypeError.
Три этапа (ECMA-262, 16.2): загрузка и разбор (404, CORS, SyntaxError), связывание («does not provide an export named …», «conflicting star exports»), выполнение. Ошибка на первых двух — не выполнится ни один модуль. import { … } не на верхнем уровне модуля — Unexpected token '{', в обычном скрипте — Cannot use import statement outside a module. Цикл, где переменную читают до объявления, — ReferenceError.
  1. Разложите свой проект с двумя-тремя скриптами по модулям и уберите из него все глобальные переменные.
  2. Откройте страницу с модулями двойным щелчком и через Live Server и выпишите, что сказала консоль.
  3. Прочитайте в учебнике JavaScript modules раздел «Cyclic imports» и повторите оба примера.
  4. Найдите в ECMA-262 раздел 9.1.1.5.5 CreateImportBinding и выпишите, чем косвенная привязка отличается от обычной.
