День 30. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Каждое задание — своя папка внутри day-30 курса 2: index.html с <script type="module" src="main.js"></script>, модули рядом, открывать через Live Server в Chrome. Помощники (wait, later, failLater) — модуль helpers.js из раздела 10 лекции.

Разминка

1. Что выведет
Легко7 мин

знать формы импорта и свойства модуля.

// lesson.js
export const title = "Модули";
export let day = 30;
export default "урок";
export function next() {
  day++;
}

Что получится в main.js:

  1. import * as L from "./lesson.js"; и Object.keys(L)
  2. import lesson from "./lesson.js"; и lesson
  3. import { day, next } from "./lesson.js";, вызов next() и day
  4. после этого day = 40;
  5. L.title = "JSON";
  6. this на верхнем уровне main.js
  7. import { lesson } from "./lesson.js";
  8. typeof window.title и typeof window.L
  • все ответы записаны до проверки, ошибки разобраны;
  • для строки 3 объяснено, почему day изменился, хотя main.js его не трогал;
  • для строки 7 объяснено, почему имени lesson нет, хотя строка 2 работала;
  • тексты ошибок строк 4, 5 и 7 совпали с записанными.
2. Порядок выполнения
Легко7 мин

предсказывать обход графа модулей.

// z.js
console.log("z");
// x.js
import "./z.js";
console.log("x");
// y.js
import "./x.js";
import "./z.js";
console.log("y");
// main.js
import "./y.js";
import "./x.js";
console.log("main");
  • граф нарисован стрелками, порядок записан до запуска;
  • в Chrome: z, x, y, main — расхождения разобраны;
  • объяснено, почему z.js и x.js напечатали по одной строке, хотя каждый импортирован дважды;
  • записано, что изменится, если в index.html подключить main.js два раза.
3. Найдите ошибку
Легко6 мин

узнавать ошибки модулей по тексту.

  1. index.html подключает <script src="main.js">, а в main.js есть import;
  2. import { words } from "words.js";
  3. import { count } from "./words.js";, а в words.js — function count() без export;
  4. в одном файле export default 1; и export default 2;;
  5. if (debug) { import { log } from "./log.js"; } в модуле;
  6. страница с модулями открыта двойным щелчком.
  • для каждой строки записан текст Chrome и проверен;
  • для каждой — исправление, после которого программа работает;
  • для строк 3 и 6 записано, выполнились ли хоть какие-то модули.

Основные задания

4. Журнал: данные, расчёты, вывод
Средне13 мин

делить программу на модули по задачам.

// data.js
export const group = "JS-2";
export default [
  { name: "Сапар", marks: [4, 4, 5] },
  { name: "Гульнар", marks: [5, 5, 4] },
  { name: "Ильяс", marks: [3, 5, 4] },
];

calc.js экспортирует average(marks) и countFives(students), view.js по умолчанию — row(student), main.js собирает всё вместе.

  • вывод: «Группа JS-2», «Сапар: 4.33», «Гульнар: 4.67», «Ильяс: 4.00», «пятёрок: 4»;
  • calc.js импортируют view.js и main.js, а его первая строка console.log("calc.js загружен") печатается один раз;
  • без export у countFives Chrome пишет does not provide an export named 'countFives', и «Группа JS-2» не печатается — объяснено почему;
  • ни один модуль не обращается к переменным другого, кроме импортированных.
5. Счётчик попыток
Средне12 мин

пользоваться живыми привязками.

attempts.js экспортирует let attempts = 0, let lastWord = null и функции attempt(word) (увеличивает счёт и запоминает слово) и reset(). stats.js импортирует оба значения и экспортирует summary() — строку «попыток: N, последнее: слово».

  • после трёх attempt в main.js и attempts, и summary() показывают 3 и последнее слово;
  • после reset() оба показывают 0 и null;
  • attempts = 0; в main.js даёт TypeError: Assignment to constant variable.;
  • записано, почему владелец экспортирует функцию reset, а не просит импортёров обнулить счёт.
6. Один вход для библиотеки
Средне13 мин

собирать модули через export … from.

Папка lib: words.js экспортирует words, count (длину массива) и по умолчанию строку «Слова»; stats.js — count (число выученных) и percent(part, whole). lib/index.js пересылает всё, а main.js импортирует только из "./lib/index.js".

  • с двумя export * имя count пропадает из объекта модуля, а прямой import { count } даёт conflicting star exports for name 'count';
  • после исправления export { count as wordCount } from … и export { count as learnedCount } from … оба значения доступны;
  • «Слова» доступна как title, а не через export * — объяснено почему;
  • Object.keys объекта модуля lib/index.js — в алфавитном порядке, записан.
7. Модуль, который ждёт
Средне12 мин

пользоваться await на верхнем уровне.

settings.js печатает «settings.js: загружаю», ждёт await later({ theme: "dark" }, 300) и экспортирует результат. Соседний theme.js печатает «theme.js». main.js импортирует оба и печатает тему.

  • порядок: «settings.js: загружаю», «theme.js», «тема: dark» — объяснено, почему theme.js не ждал;
  • main.js выполняется не раньше чем через 300 мс — проверено по времени;
  • с failLater("нет связи", 200) консоль показывает Uncaught Error: нет связи, а main.js не выполняется;
  • записано, чем это отличается от отклонённого промиса в async-функции дня 28.

Со звёздочкой

8. Разорвать цикл
Сложно10 мин

понимать циклы модулей.

// deck.js
import { describe } from "./stats.js";
export const deck = ["book", "water", "bread"];
console.log(describe());
// stats.js
import { deck } from "./deck.js";
export const size = deck.length;
export function describe() {
  return `в колоде ${size}`;
}

main.js — одна строка import "./deck.js";.

  • текст ошибки записан заранее и совпал: Cannot access 'deck' before initialization;
  • исправление 1: stats.js читает deck только внутри describe — печатается «в колоде 3»;
  • исправление 2: колода переезжает в третий модуль words.js, цикла больше нет — та же строка;
  • для обоих объяснено по живым привязкам, почему ошибка ушла.
9. Общее хранилище
Сложно10 мин

прятать состояние в модуле.

store.js держит let state = { learned: 0 } и список подписчиков, не экспортируя их, и отдаёт функции get(), update(changes) и subscribe(fn). Модули header.js и footer.js подписываются и печатают learned, main.js вызывает update({ learned: 2 }).

  • после update оба подписчика напечатали 2, get().learned — 2;
  • первая строка store.js (console.log("store.js")) печатается один раз, хотя его импортируют три модуля;
  • в консоли DevTools typeof state — "undefined": состояние снаружи не достать;
  • import * as store и store.get = null дают TypeError — текст записан.
