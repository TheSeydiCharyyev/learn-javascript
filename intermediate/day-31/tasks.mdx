# День 31. Задания

<Subtitle>Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Каждое задание — своя папка внутри `day-31` курса 2: `index.html` с `<script type="module" src="main.js"></script>`, модули и `.json` рядом, открывать через Live Server в Chrome.</Subtitle>

## Разминка

<Task title="1. Что выведет" level="easy" time="7">
<Goal>знать `import()`, `import.meta` и правила JSON.</Goal>

Рядом лежат `m.js` с одной строкой `export default 5;` и `data.json` с текстом
`{"a": 1}`. Что даст в `main.js`:

1. `import("./m.js") instanceof Promise`
2. `(await import("./m.js")).default`
3. `const load = import;`
4. `import.meta.url`, если `main.js` лежит в папке `app`
5. `Object.keys(await import("./data.json", { with: { type: "json" } }))`
6. `JSON.parse('{"x": 1, "x": 2}').x`
7. `JSON.stringify({ a: 1 }, null, 15).split("\n")[1].length`
8. `JSON.stringify({ code: JSON.rawJSON("007") })`

<Criteria>
- все ответы записаны до проверки, ошибки разобраны;
- для строки 5 объяснено, почему ключ один;
- для строки 7 — откуда число, по правилу отступа;
- для строки 8 — почему ошибка, хотя `"007"` — строка.
</Criteria>
</Task>

<Task title="2. Порядок обхода" level="easy" time="7">
<Goal>знать, в каком порядке работают reviver и replacer.</Goal>

```js
// main.js
const text = '{"a": [1, {"b": 2}], "c": 3}';
const reviverKeys = [];
const data = JSON.parse(text, function (key, value) {
  reviverKeys.push(key === "" ? '""' : key);
  return value;
});
const replacerKeys = [];
JSON.stringify(data, function (key, value) {
  replacerKeys.push(key === "" ? '""' : key);
  return value;
});
console.log(reviverKeys.join(" "));
console.log(replacerKeys.join(" "));
```

<Criteria>
- обе строки записаны до запуска;
- в Chrome: `0 b 1 a c ""` и `"" a 0 1 b c` — расхождения разобраны;
- нарисовано дерево данных, и на нём проставлены оба порядка, как на схеме раздела 12 лекции.
</Criteria>
</Task>

## Основные задания

<Task title="4. Язык по выбору" level="medium" time="12">
<Goal>загружать модули по вычисленному пути.</Goal>

В папке `lang` — `ru.js`, `tk.js`, `en.js`: каждый первой строкой печатает
своё имя и экспортирует по умолчанию `{ hello: … }` («Привет», «Salam», «Hello»).
`loadLang(code)` — `async`-функция: загружает `./lang/${code}.js`, а если такого нет —
печатает «нет языка код» и загружает `ru`.

<Criteria>
- `(await loadLang("tk")).hello` — «Salam»;
- `loadLang("de")` печатает «нет языка de» и отдаёт «Привет»;
- после трёх вызовов `loadLang("tk")` строка `tk.js` напечатана один раз;
- `Promise.all` по `["ru", "tk", "en"]` — «Привет, Salam, Hello».
</Criteria>
</Task>

<Task title="5. Журнал из JSON" level="medium" time="13">
<Goal>брать данные из JSON-модуля и помнить, что он общий.</Goal>

```js file="students.json"
[
  { "name": "Аман", "marks": [5, 4, 5] },
  { "name": "Мерет", "marks": [3, 4, 4] },
  { "name": "Айна", "marks": [5, 5, 5] }

```

Модуль `report.js` импортирует `students.json` и экспортирует `report()` — строки
«имя: средний» с двумя знаками. Модуль `bonus.js` импортирует тот же JSON и всем добавляет оценку 5.

<Criteria>
- без `bonus.js`: «Аман: 4.67», «Мерет: 3.67», «Айна: 5.00»;
- если `main.js` импортирует `bonus.js`, отчёт меняется: «Аман: 4.75», «Мерет: 4.00»,
  «Айна: 5.00» — объяснено почему;
- `bonus.js` переписан так, что работает с копией (`JSON.parse(JSON.stringify(…))` дня
  23 Essentials), и отчёт снова как в первом пункте;
- без `with { type: "json" }` записан текст ошибки Chrome.
</Criteria>
</Task>

## Со звёздочкой

<Task title="8. Свой обход для reviver" level="hard" time="10">
<Goal>повторить InternalizeJSONProperty.</Goal>

`revive(value, reviver)` принимает уже разобранные данные и обходит их, как
`JSON.parse`: оборачивает в `{ "": value }`, рекурсией идёт по свойствам и элементам, потом
зовёт `reviver.call(holder, key, value)`; `undefined` удаляет свойство.

<Criteria>
- на тексте задания 2 порядок ключей совпадает с `JSON.parse`: `0 b 1 a c ""`;
- reviver, удаляющий все числа 2, даёт тот же результат, что и в `JSON.parse`:
  `{"a":[1,{}],"c":3}`;
- `this` в reviver — объект-хозяин, проверено для ключа `b`;
- записано, чего ваш обход не умеет по сравнению с настоящим (`context`).
</Criteria>
</Task>

<Task title="9. Уроки по номеру" level="hard" time="10">
<Goal>сочетать `import()` и `import.meta`.</Goal>

В папке `lessons` — `1.js` и `2.js`, одинаковые по коду: модуль печатает «урок N
загружен» и экспортирует `number`, который вычисляет из `import.meta.url` — из имени своего же
файла. `open(n)` загружает `./lessons/${n}.js` и печатает «урок N»; если файла нет —
«урока N нет».

<Criteria>
- `open(1)`, `open(2)`, `open(1)`, `open(5)` печатают: «урок 1
  загружен», «урок 1», «урок 2 загружен», «урок 2», «урок 1», «урока 5 нет»;
- код `1.js` и `2.js` одинаковый — номер берётся только из адреса;
- `import.meta.resolve("./lessons/5.js")` не бросает ошибку, хотя файла нет, — объяснено.
</Criteria>
</Task>
