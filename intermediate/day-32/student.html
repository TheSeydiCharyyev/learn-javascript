День 32. Мини-проект: расписание занятий на модулях

Выжимка лекции: как разложена программа по модулям и как проверить, что проект готов.

Части программы

// data/groups.json, data/js-1.json …   данные: группы и занятия, даты строками ISO
// errors.js    class ScheduleError extends Error — текст для человека, исходная ошибка в cause
// lesson.js    class Lesson — PlainDateTime.from(start), Duration.from(duration), get end, isPast(now), static compare
// load.js      loadGroup: import(`./data/${id}.json`, { with: { type: "json" } }), catch → ScheduleError
//              loadSchedule: (await Promise.all(groups.map(loadGroup))).flat().toSorted(Lesson.compare)
// format.js    TEXT по локалям; formatRange — дата и время; NumberFormat — часы; локаль в каждый вызов
// search.js    matcher(query): new RegExp(RegExp.escape(query.trim()), "i")
// main.js      состояние: locale, query, lessons; render(); слушатели; await loadSchedule на верхнем уровне
У каждого модуля одна задача, и каждый проверяется отдельно — временным main.js, потому что из консоли переменные модулей не видны. Данные — в JSON, правило — в модуле, показ — в render, слушатель меняет состояние и зовёт render. Новая группа — строка в groups.json и файл, код не меняется.
Сравнивать Temporal — только compare, складывать длительности — только add. Intl без локали берёт язык браузера. Ввод человека — RegExp.escape и textContent: текст никогда не становится шаблоном или HTML. Promise.all роняет всё при одном отказе.
Отладка: из консоли модуль не виден, поэтому на время работы в конец main.js дописывают одно имя — globalThis.debug с геттерами lessons и state. Геттеры читают переменные в момент обращения; обычное свойство запомнило бы старый массив. Перед сдачей эти строки удаляют.

Чек-лист готовности

Что проверитьКак
первый показшесть занятий по времени, три серые; «Занятий: 6 · часов: 9,5 · ближайшее через 1 дн. 2 ч»
поиск«c++» — два занятия, «.*» — «Ничего не нашлось», «МОДУЛИ» — одно
язык«EN» меняет заголовок, даты, числа: «Lessons: 6 · hours: 9.5 · next in 1 day, 2 hr»
ошибка загрузкигруппа без файла — текст ScheduleError и причина из cause
консольбез ошибок при любом вводе в поиск
