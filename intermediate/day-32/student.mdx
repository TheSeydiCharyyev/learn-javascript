# День 32. Мини-проект: расписание занятий на модулях

<Subtitle>Выжимка лекции: как разложена программа по модулям и как проверить, что проект готов.</Subtitle>

## Части программы

```js
// data/groups.json, data/js-1.json …   данные: группы и занятия, даты строками ISO
// errors.js    class ScheduleError extends Error — текст для человека, исходная ошибка в cause
// lesson.js    class Lesson — PlainDateTime.from(start), Duration.from(duration), get end, isPast(now), static compare
// load.js      loadGroup: import(`./data/${id}.json`, { with: { type: "json" } }), catch → ScheduleError
//              loadSchedule: (await Promise.all(groups.map(loadGroup))).flat().toSorted(Lesson.compare)
// format.js    TEXT по локалям; formatRange — дата и время; NumberFormat — часы; локаль в каждый вызов
// search.js    matcher(query): new RegExp(RegExp.escape(query.trim()), "i")
// main.js      состояние: locale, query, lessons; render(); слушатели; await loadSchedule на верхнем уровне
```

<KeyPoint>
У каждого модуля одна задача, и каждый проверяется отдельно — временным `main.js`, потому что из
консоли переменные модулей не видны. Данные — в JSON, правило — в модуле, показ — в `render`,
слушатель меняет состояние и зовёт `render`. Новая группа — строка в `groups.json` и файл, код
не меняется.
</KeyPoint>

<Remember>
Сравнивать `Temporal` — только `compare`, складывать длительности — только `add`.
`Intl` без локали берёт язык браузера. Ввод человека — `RegExp.escape` и
`textContent`: текст никогда не становится шаблоном или HTML. `Promise.all` роняет всё при
одном отказе.
</Remember>

<NoteBox>
Отладка: из консоли модуль не виден, поэтому на время работы в конец `main.js` дописывают одно имя —
`globalThis.debug` с геттерами `lessons` и `state`. Геттеры читают переменные в
момент обращения; обычное свойство запомнило бы старый массив. Перед сдачей эти строки удаляют.
</NoteBox>

## Ошибки по симптомам

| Симптом | Причина |
| --- | --- |
| на «c++» старый список, в консоли «Nothing to repeat» | нет `RegExp.escape` |
| английские подписи, но «9,5» | локаль не передана в `Intl` |
| «Занятий: 0», под списком «Temporal error» | дата в JSON не в ISO; `Promise.all` уронил все группы |
| пустая страница, «Expected a JavaScript-or-Wasm module script» | JSON-модуль без `with { type: "json" }` |

## Чек-лист готовности

| Что проверить | Как |
| --- | --- |
| первый показ | шесть занятий по времени, три серые; «Занятий: 6 · часов: 9,5 · ближайшее через 1 дн. 2 ч» |
| поиск | «c++» — два занятия, «.\*» — «Ничего не нашлось», «МОДУЛИ» — одно |
| язык | «EN» меняет заголовок, даты, числа: «Lessons: 6 · hours: 9.5 · next in 1 day, 2 hr» |
| ошибка загрузки | группа без файла — текст `ScheduleError` и причина из `cause` |
| консоль | без ошибок при любом вводе в поиск |
