День 32. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Проект — в папке schedule с файлами лекции, запуск через Live Server. Каждую доработку делайте в копии папки. «Сейчас» — по-прежнему 27 октября 2026, 12:00.

Разминка

1. Модули по отдельности
Легко7 мин

проверить модули до того, как появится страница.

В папке пока только data/, errors.js, lesson.js и load.js; main.js — временный.

  • занятие «C++ и шаблоны» из data/cpp-1.json: конец 2026-10-31T10:30:00, isPast(now) — false, день недели — 6;
  • (await loadGroup({ id: "js-2", name: "JS-2" })).length — 2, у обоих занятий группа «JS-2»;
  • у ошибки loadGroup({ id: "py-1", name: "PY-1" }): instanceof Error — true, Error.isError — true, name причины — «TypeError»;
  • записано, почему проверка — временным main.js, а не в консоли.
2. Intl на двух языках
Легко6 мин

предсказывать вывод format.js.

  • заранее записано и совпало: line для «C++ и шаблоны» — «сб, 31 окт., 09:00–10:30 · C++-1 · C++ и шаблоны · ауд. 301» и «Sat, Oct 31, 9:00 – 10:30 AM · C++-1 · C++ и шаблоны · room 301»;
  • hours всех шести занятий — «9,5» и «9.5»;
  • now.until(...) до этого занятия по-русски и по-английски — «3 дн. 21 ч» и «3 days, 21 hr»;
  • when с локалью "tk" — записано, на каком языке он пишет и почему (день 25), а почему line с той же локалью падает с TypeError.
3. Сборка и сценарий
Легко7 мин

собрать расписание и проверить его руками.

  • папка собрана по лекции, консоль без ошибок, первый показ совпал с чек-листом конспекта;
  • сценарий раздела 14 пройден: каждая строка таблицы совпала;
  • после сценария «EN» и поиск «шаблоны» — «Lessons: 1 · hours: 1.5 · next in 3 days, 21 hr»;
  • все четыре крайних случая раздела 14 воспроизведены.

Основные задания

4. Фильтр по группе
Средне13 мин

добавить состояние и кнопки из данных.

Под кнопками языка — кнопки групп: «Все» и по одной на группу из groups.json, построенные кодом. Новое состояние group — null или название группы; render фильтрует и по нему.

  • «JS-2» — «Занятий: 2 · часов: 4 · ближайшее через 1 дн. 22 ч»;
  • «JS-1» и поиск «c++» — «Ничего не нашлось»; «Все» — снова шесть занятий с тем же поиском — два;
  • кнопки групп появились из JSON: новая группа в groups.json даёт новую кнопку без правки кода;
  • выбранная кнопка выделена, как языковая.
5. Устойчивая загрузка
Средне12 мин

показывать то, что загрузилось, и честно сообщать об остальном.

loadSchedule на Promise.allSettled возвращает { lessons, errors }: занятия удачных групп и массив ScheduleError неудачных. Под списком — по строке на каждую ошибку.

  • группа py-1 без файла: шесть занятий и строка «Не удалось загрузить расписание PY-1: Failed to fetch dynamically imported module: …»;
  • и py-1, и дата "27.10.2026 10:00" в js-2.json: четыре занятия, «Занятий: 4 · часов: 5,5 · ближайшее через 1 дн. 2 ч» и две строки ошибок;
  • без ошибок список ошибок пуст и не виден;
  • записано, чем отчёт allSettled отличается от отказа all (день 27).
6. Занятия по дням
Средне13 мин

группировать даты и подписывать их на двух языках.

Вместо одного списка — заголовок дня и его занятия. Группировка — Map.groupBy по lesson.start.toPlainDate().toString(), заголовок — toLocaleString с { weekday: "long", day: "numeric", month: "long" }.

  • пять дней: 26, 27, 28, 29 и 31 октября; первый заголовок — «понедельник, 26 октября», по-английски — «Monday, October 26»;
  • с поиском «c++» — два дня;
  • порядок дней — по времени, без отдельной сортировки: объяснено, почему его сохраняет Map.groupBy;
  • в строке занятия день больше не повторяется — только время.
7. Подсветка найденного
Средне12 мин

выделять совпадение, не превращая текст в HTML.

Найденная часть названия обёрнута в <mark>. Название делится split по шаблону с группой (день 19), куски с совпадением становятся элементами mark, остальные — текстом.

  • поиск «мод» — в строке «Модули: import и export» выделено «Мод» — в регистре названия, а не запроса;
  • поиск «c++» — выделено «C++» в обоих занятиях; «(regexp)» — «(RegExp)»;
  • innerHTML в программе не появился;
  • без поиска ни одного mark.

Со звёздочкой

8. Группа по кнопке
Сложно10 мин

загружать часть данных по требованию.

У группы cpp-1 в groups.json появляется "lazy": true: при открытии её не грузят, а кнопка «Показать C++-1» загружает и вставляет её занятия.

  • при открытии — «Занятий: 4 · часов: 7 · ближайшее через 1 дн. 2 ч», файл cpp-1.json не запрашивался;
  • после кнопки — шесть занятий по времени, «часов: 9,5»;
  • второе нажатие ничего не дублирует, а файл запрошен один раз;
  • записано, какой день курса объясняет, почему повторный import() не ходит в сеть.
9. Три жалобы
Сложно10 мин

искать ошибку от симптома.

Одноклассник прислал своё расписание и три жалобы:

  1. «Список есть, а строки итога нет. В консоли что-то про valueOf».
  2. «Ищу „и“ — находит четыре занятия, хотя „и“ есть во всех шести названиях».
  3. «Нажимаю EN — ничего не меняется, а в консоли Cannot read properties of undefined (reading 'title')».

От программы лекции его файлы отличаются в этих местах:

// format.js, в hours
const total = lessons.reduce((sum, lesson) => sum + lesson.duration, 0);
// search.js
const pattern = new RegExp(RegExp.escape(clean), "gi");
// main.js, в слушателе языков
locale = button.textContent;
  • каждая жалоба воспроизведена и сопоставлена со своим фрагментом;
  • для первой записан полный текст ошибки и объяснено, почему список успел появиться, а итог — нет;
  • для второй объяснено по дню 18, почему пропали именно два занятия;
  • все три исправлены, сценарий раздела 14 снова проходит.
