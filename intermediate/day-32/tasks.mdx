## Основные задания

<Task title="4. Фильтр по группе" level="medium" time="13">
<Goal>добавить состояние и кнопки из данных.</Goal>

Под кнопками языка — кнопки групп: «Все» и по одной на группу из `groups.json`, построенные кодом.
Новое состояние `group` — `null` или название группы; `render` фильтрует и по нему.

<Criteria>
- «JS-2» — «Занятий: 2 · часов: 4 · ближайшее через 1 дн. 22 ч»;
- «JS-1» и поиск «c++» — «Ничего не нашлось»; «Все» — снова шесть занятий с тем же поиском — два;
- кнопки групп появились из JSON: новая группа в `groups.json` даёт новую кнопку без правки кода;
- выбранная кнопка выделена, как языковая.
</Criteria>
</Task>

<Task title="5. Устойчивая загрузка" level="medium" time="12">
<Goal>показывать то, что загрузилось, и честно сообщать об остальном.</Goal>

`loadSchedule` на `Promise.allSettled` возвращает `{ lessons, errors }`: занятия
удачных групп и массив `ScheduleError` неудачных. Под списком — по строке на каждую ошибку.

<Criteria>
- группа `py-1` без файла: шесть занятий и строка «Не удалось загрузить расписание PY-1: Failed to
  fetch dynamically imported module: …»;
- и `py-1`, и дата `"27.10.2026 10:00"` в `js-2.json`: четыре занятия, «Занятий: 4 ·
  часов: 5,5 · ближайшее через 1 дн. 2 ч» и две строки ошибок;
- без ошибок список ошибок пуст и не виден;
- записано, чем отчёт `allSettled` отличается от отказа `all` (день 27).
</Criteria>
</Task>

<Task title="6. Занятия по дням" level="medium" time="13">
<Goal>группировать даты и подписывать их на двух языках.</Goal>

`lesson.start.toPlainDate().toString()`, заголовок — `toLocaleString` с
`{ weekday: "long", day: "numeric", month: "long" }`.

<Criteria>
- пять дней: 26, 27, 28, 29 и 31 октября; первый заголовок — «понедельник, 26 октября», по-английски —
  «Monday, October 26»;
- с поиском «c++» — два дня;
- порядок дней — по времени, без отдельной сортировки: объяснено, почему его сохраняет `Map.groupBy`;
- в строке занятия день больше не повторяется — только время.
</Criteria>
</Task>

<Task title="7. Подсветка найденного" level="medium" time="12">

<Criteria>
- поиск «мод» — в строке «Модули: import и export» выделено «Мод» — в регистре названия, а не запроса;
- поиск «c++» — выделено «C++» в обоих занятиях; «(regexp)» — «(RegExp)»;
- `innerHTML` в программе не появился;
- без поиска ни одного `mark`.
</Criteria>
</Task>

<Task title="9. Три жалобы" level="hard" time="10">
<Goal>искать ошибку от симптома.</Goal>

Одноклассник прислал своё расписание и три жалобы:

1. «Список есть, а строки итога нет. В консоли что-то про valueOf».
2. «Ищу „и“ — находит четыре занятия, хотя „и“ есть во всех шести названиях».
3. «Нажимаю EN — ничего не меняется, а в консоли Cannot read properties of undefined (reading 'title')».

От программы лекции его файлы отличаются в этих местах:

```js
// format.js, в hours
const total = lessons.reduce((sum, lesson) => sum + lesson.duration, 0);
// search.js
const pattern = new RegExp(RegExp.escape(clean), "gi");
// main.js, в слушателе языков
locale = button.textContent;
```

<Criteria>
- каждая жалоба воспроизведена и сопоставлена со своим фрагментом;
- для первой записан полный текст ошибки и объяснено, почему список успел появиться, а итог — нет;
- для второй объяснено по дню 18, почему пропали именно два занятия;
- все три исправлены, сценарий раздела 14 снова проходит.
</Criteria>
</Task>
