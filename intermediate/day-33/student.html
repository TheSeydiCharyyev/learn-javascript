Выжимка лекции: семь шагов от идеи к плану в курсе 2 и что должно быть готово к концу дня.

Обязательны классы, модули, асинхронная загрузка и хотя бы одно из: Map/Set, регулярные выражения, Temporal/Intl. Не нужны модули — идея мала. Код — только на шестом шаге.

Проверки — на своей странице

// tests.js — открыт в соседней вкладке через test.html
console.assert(cards.every((c) => Number.isInteger(c.id) && c.word && c.translation), "у карточки не хватает поля");
console.assert(new Set(cards.map((c) => c.id)).size === cards.length, "номера повторяются");
console.log("проверки закончены");   // последняя строка: проверки дошли до конца

Консоль не видит переменных модулей, а страница проверок перезапускается при каждом сохранении и берёт классы без main.js. Хорошая страница проверок молчит до последней строки.

Два сторожа

Конструктор класса не создаёт объект с плохими данными: Card ловит опечатку в поле и номер-строку, Deck — повтор номера в своём файле. Повтор номера в разных файлах находит только страница проверок: она читает все данные сразу.

Заглушка модуля

export async function loadDeck(info, progress) {
  return new Deck([], progress);   // заглушка: пустая колода — тот же тип
}
То же имя экспорта и тот же тип. Без export — ошибка связывания: не выполнится ни один модуль, и «Загрузка…» повиснет. Без return — undefined, и первая же проверка упадёт. Путь import() считается от адреса модуля, fetch — от страницы.

Не помещается в 180 минут двух дней — режьте объём, а не качество.

  1. Доведите свой чек-лист дня 33 до конца — все десять строк.
  2. Напротив каждой темы курса 2 в таблице возможностей запишите модуль, в котором она будет.
  3. Добавьте в данные ещё несколько объектов и убедитесь, что страница проверок молчит.
  4. К дню 34: выпишите первую задачу плана и проверку, которая скажет, что она готова.
