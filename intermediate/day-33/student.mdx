# День 33. Итоговый проект: замысел и план

<Subtitle>Выжимка лекции: семь шагов от идеи к плану в курсе 2 и что должно быть готово к концу дня.</Subtitle>

## Семь шагов

| Шаг | Что получается |
| --- | --- |
| идея | данные, действие человека, память, интерес — и место для курса 2 |
| одно предложение | кому, что делает, зачем |
| возможности | таблица «что — как проверить — из курса 2», списки «потом» и «не делает» |
| данные | JSON-файлы и страница проверок `test.html` |
| макет | узкий рисунок, у каждой части подпись: из каких данных и методов |
| каркас | рама, модули-заглушки, слушатели с планом внутри, первый шаг |
| план | задачи по дням с минутами; сумма дня не больше 90 |

<KeyPoint>
Обязательны классы, модули, асинхронная загрузка и хотя бы одно из: `Map`/`Set`,
регулярные выражения, `Temporal`/`Intl`. Не нужны модули — идея мала. Код — только на
шестом шаге.
</KeyPoint>

## Проверки — на своей странице

```js
// tests.js — открыт в соседней вкладке через test.html
console.assert(cards.every((c) => Number.isInteger(c.id) && c.word && c.translation), "у карточки не хватает поля");
console.assert(new Set(cards.map((c) => c.id)).size === cards.length, "номера повторяются");
console.log("проверки закончены");   // последняя строка: проверки дошли до конца
```

Консоль не видит переменных модулей, а страница проверок перезапускается при каждом сохранении и берёт классы
без `main.js`. Хорошая страница проверок молчит до последней строки.

## Два сторожа

<Remember>
Конструктор класса не создаёт объект с плохими данными: `Card` ловит опечатку в поле и номер-строку,
`Deck` — повтор номера в своём файле. Повтор номера в разных файлах находит только страница проверок:
она читает все данные сразу.
</Remember>

## Заглушка модуля

```js
export async function loadDeck(info, progress) {
  return new Deck([], progress);   // заглушка: пустая колода — тот же тип
}
```

<Remember>
То же имя экспорта и тот же тип. Без `export` — ошибка связывания: не выполнится ни один модуль, и
«Загрузка…» повиснет. Без `return` — `undefined`, и первая же проверка упадёт. Путь
`import()` считается от адреса модуля, `fetch` — от страницы.
</Remember>
