## 1. Как работать по плану {#how}

## 3. Сначала — карточка на экране {#current}

В Essentials текущую карточку возвращала функция `current` в `app.js`. В курсе 2 её место —
в классе: колода знает, какие карточки показать сегодня, а `main.js` знает только номер места
`position`. Метод получает место и дату и ничего не меняет:

```js
// deck.js: новый метод после due
  // карточка на месте position, по кругу; null — на сегодня карточек нет
  cardAt(position, today) {
    const cards = this.due(today);
    return cards.length === 0 ? null : cards[position % cards.length];
  }
```

Остаток от деления — тот же, что в Essentials: `position` растёт без конца, а карточки идут по кругу.
`null` — честный ответ «на сегодня всё». И раз это метод класса, его проверяют на странице проверок, без
`main.js` и без щелчков:

```js page="test.html"
// tests.js, перед «проверки закончены»
const fresh = new Deck(school, new Map());
console.assert(fresh.cardAt(0, today)?.word === "book", "первая карточка — book");
console.assert(fresh.cardAt(3, today)?.word === "book", "после последней — снова первая");
console.assert(new Deck(school.slice(0, 1), later).cardAt(0, today) === null, "всё отложено — карточки нет");
```

В Essentials такую функцию проверял `testCurrent`: он подменял переменные программы и возвращал их
назад. Теперь подменять нечего — для проверки создают отдельную колоду с нужным прогрессом, а программа на

— на случай, когда колоды нет в `opened`, потому что она не загрузилась: тогда и карточки нет.

```js
// main.js: новая функция перед render
// карточка на экране; null — на сегодня всё
function current() {
  return opened.get(chosen)?.cardAt(position, today) ?? null;
}
```

## 5. Задача 2: «Знаю» {#know}

«Знаю» — метод `know` по правилу дня 22: пауза — шаг × 2 дней, шаг удваивается. Сначала проверки —
что должно стать с прогрессом после одного и двух «Знаю»:

```js page="test.html"
// tests.js, перед «проверки закончены»
const progress = new Map();
const food = new Deck(all[1].cards.map((item) => new Card(item)), progress);
food.know(4, today);
console.assert(String(progress.get(4)?.next) === "2026-10-28", "первое «Знаю» — повтор через 2 дня");
food.know(4, today.add({ days: 2 }));
console.assert(String(progress.get(4)?.next) === "2026-11-01", "второе — ещё через 4 дня");
console.assert(food.due(today).length === 2, "bread ушла из сегодняшних");
console.assert(throws(() => food.know(1, today)), "know пропустил чужой номер");
```

Четыре красные строки на заглушке. Заметьте `String(progress.get(4)?.next)`: пока прогресса нет,

на первой строке, как заглушка без `return` на дне 33. Первая попытка метода:

```js page="test.html"
// deck.js: так НЕ надо
  know(id, today) {
    if (!this.#cards.has(id)) throw new CardsError(`в колоде нет карточки ${id}`);
    const state = this.#progress.get(id) ?? { next: today, step: 1 };
    state.next.add({ days: state.step * 2 });
    state.step *= 2;
    this.#progress.set(id, state);
  }
```

<ResultBox>

Сторож чужого номера работает, а даты — нет. На странице это выглядело бы так: «Знаю» — и карточка на месте.
Причина — в строке `state.next.add(…)`: даты `Temporal` не меняются (день 22),
`add` возвращает новую дату, а старая остаётся. Результат никуда не записан, день повтора так и остался
сегодняшним. Правильно — собрать новый объект прогресса:

```js page="test.html"
// deck.js: настоящий know
  know(id, today) {
    if (!this.#cards.has(id)) throw new CardsError(`в колоде нет карточки ${id}`);
    const step = this.#progress.get(id)?.step ?? 1;
    this.#progress.set(id, { next: today.add({ days: step * 2 }), step: step * 2 });
  }
```

Пауза считается от дня, когда нажали «Знаю», а не от прошлой даты повтора. Если ученик пропустил неделю и
вернулся 5 ноября, карточка с повтором 1 ноября уже в колоде, а «Знаю» отложит её до 13 ноября — на 8 дней от
сегодняшнего. Пропущенные дни не съедают паузу.

Теперь слушатель. Строка `flipped = false` — правило дня 34 Essentials: что зависит от текущей
карточки, сбрасывается вместе с ней, иначе следующая откроется переводом. А `position` не меняется:
отложенная карточка ушла из `due`, и на её место встала следующая.

## 7. Задача 4: кнопки колод {#decks}

Кнопки строятся один раз из `decks.json`, как кнопки тем в Essentials:

```js
// main.js: новая функция перед render
// кнопки колод — из decks.json, один раз
function makeDeckButtons() {
  deckButtons.append(...decks.map((info) => {
    const button = document.createElement("button");
    button.textContent = info.name;
    button.dataset.deck = info.id;
    return button;
  }));
}
```

```js
// main.js: замена слушателя кнопок колод
deckButtons.addEventListener("click", async (event) => {
  const button = event.target.closest("button");
  if (!button) return;
  chosen = button.dataset.deck;
  position = 0;
  flipped = false;
  await openDeck();
});
```

```js
// main.js: конец
makeDeckButtons();
await openDeck();
```

```js
// main.js, в конец render
  deckButtons.querySelectorAll("button").forEach((b) => b.classList.toggle("active", b.dataset.deck === chosen));
```

Слушатель — `async`: при первом выборе колоды `openDeck` ждёт `import()` её
файла. Позиция и `flipped` сбрасываются — они зависят от колоды. Выделенную кнопку, как и всё на
странице, рисует `render`.

Как в Essentials, запись — одной строкой в конце `render`: он вызывается после каждого изменения.

Почему в `render`, а не в слушателе «Знаю»? Прогресс меняет не только он — в задаче 6 появится
«Начать сначала». Запись в одном месте сохранит и сброс, без новой строки.

### Разбор: JSON.stringify вместо save

```js
// так НЕ надо — последняя строка render
  localStorage.setItem(KEY, JSON.stringify(progress));
```

**Шаг 1. Симптом.** «Знаю» на book — «teacher», всё как надо. Обновили страницу — пустая карточка,
пустой счётчик, а в консоли `Uncaught TypeError: this[#progress].get is not a function`. Ошибка
указывает на `deck.js`, хотя там ничего не меняли.

**Шаг 2. Что в хранилище?** `localStorage.getItem("cards2:progress")` — `"{}"`.
`JSON.stringify` не умеет `Map` (день 31) и записал пустой объект. При открытии
`load("{}")` вернул обычный объект, не `null`, и `?? new Map()` не сработал: колоды
получили вместо `Map` объект без метода `get`. Ошибка сделана в одной строке
`main.js`, а всплыла после обновления в другом модуле. **Шаг 3.** Хранилище пишет и читает
одна пара функций — `save` и `load` из `storage.js`.

Вторая половина строки 8 — «28 октября вернулись». Поменяйте учебное «сегодня» в `main.js` на
`"2026-10-28"` и обновите страницу: снова «book», «На сегодня: 3 из 3». «Знаю» в этот день отложит её
до 1 ноября — шаг уже 2, пауза 4 дня. Потом верните 26 октября.

## 9. Задача 6: «На сегодня всё» и «Начать сначала» {#empty}

Когда отложены все карточки колоды, кнопкам «Знаю» и «Повторить» нечего делать — их прячем. Окончательный
`render`:

```js
// main.js: замена render
function render() {
  const deck = opened.get(chosen);
  const word = current();
  card.textContent = word === null ? "На сегодня всё" : (flipped ? word.translation : word.word);
  knowButton.hidden = word === null;
  againButton.hidden = word === null;
  counter.textContent = `На сегодня: ${deck.due(today).length} из ${deck.size}`;
  deckButtons.querySelectorAll("button").forEach((b) => b.classList.toggle("active", b.dataset.deck === chosen));
  localStorage.setItem(KEY, save(progress));
}
```

«Начать сначала» необратимо — сначала `confirm` (день 28 Essentials). А очищает прогресс
`clear` — метод `Map` дня 14:

```js
// main.js: замена слушателя «Начать сначала»
resetButton.addEventListener("click", () => {
  if (!confirm("Забыть весь прогресс?")) return;
  progress.clear();
  position = 0;
  flipped = false;
  render();
});
```

## 10. Разбор: сброс, который не сбросил {#bug-reset}

Почему `clear()`, а не новый пустой `Map`? Попробуем:

```js
// main.js: так НЕ надо
resetButton.addEventListener("click", () => {
  if (!confirm("Забыть весь прогресс?")) return;
  progress = new Map();
  position = 0;
  flipped = false;
  render();
});
```

**Шаг 1. Симптом.** «Знаю», «Начать сначала», OK — на странице «teacher», «На сегодня: 2 из 3», а в
консоли `Uncaught TypeError: Assignment to constant variable.` (день 4 Essentials): `progress`
объявлен через `const`.

**Шаг 2. Заменим `const` на `let`.** Ошибки нет, но на странице всё те же
«teacher» и «2 из 3». А после обновления — снова все три карточки: сброс «сработал», но не сразу. Подсказку даёт
хранилище: сразу после сброса `localStorage.getItem("cards2:progress")` — `{"$map":[]}`, пусто,
а экран по-прежнему считает book отложенной. Хранилище и экран разошлись — значит, у них разные источники.

**Шаг 3. Причина.** `Map` один, а держат его несколько: имя `progress` в
`main.js` и `#progress` каждой открытой колоды — его передали им в конструкторе.

<Scheme src="scheme-bug-reset.svg">clear() очищает тот Map, который видят все; присваивание перевешивает одно имя</Scheme>

`progress = new Map()` перевешивает только имя в `main.js`. Колоды по-прежнему смотрят на
старый `Map`, и `render` показывает старый прогресс, а `save` пишет новый,
пустой, — поэтому сброс виден только после обновления. `clear()` очищает тот самый `Map`,
который видят все. Правило: общий объект меняют, а не подменяют, — и `const` это правило сторожит.
Ошибка шага 1 была подсказкой, а не помехой.

## 11. Программа целиком {#whole}

```js
// main.js
import decks from "./data/decks.json" with { type: "json" };
import { save, load } from "./storage.js";
import { loadDeck } from "./load.js";

const KEY = "cards2:progress";
const today = Temporal.PlainDate.from("2026-10-26");            // учебное «сегодня»; в жизни — Temporal.Now.plainDateISO()
const progress = load(localStorage.getItem(KEY)) ?? new Map();  // номер карточки → { next, step }, на все колоды
const opened = new Map();                                        // id колоды → Deck: каждая грузится один раз
let chosen = decks[0].id;                                        // id выбранной колоды
let position = 0;                                                // какая карточка колоды на экране
let flipped = false;                                             // виден ли перевод

const deckButtons = document.querySelector(".decks");
const loading = document.querySelector("#loading");
const error = document.querySelector("#error");
const card = document.querySelector("#card");
const knowButton = document.querySelector("#know");
const againButton = document.querySelector("#again");
const counter = document.querySelector("#counter");
const resetButton = document.querySelector("#reset");
console.assert(![deckButtons, loading, error, card, knowButton, againButton, counter, resetButton].includes(null), "на странице нет элемента");

// карточка на экране; null — на сегодня всё
function current() {
  return opened.get(chosen)?.cardAt(position, today) ?? null;
}

// кнопки колод — из decks.json, один раз
function makeDeckButtons() {
  deckButtons.append(...decks.map((info) => {
    const button = document.createElement("button");
    button.textContent = info.name;
    button.dataset.deck = info.id;
    return button;
  }));
}

// страница из данных
function render() {
  const deck = opened.get(chosen);
  const word = current();
  card.textContent = word === null ? "На сегодня всё" : (flipped ? word.translation : word.word);
  knowButton.hidden = word === null;
  againButton.hidden = word === null;
  counter.textContent = `На сегодня: ${deck.due(today).length} из ${deck.size}`;
  deckButtons.querySelectorAll("button").forEach((b) => b.classList.toggle("active", b.dataset.deck === chosen));
  localStorage.setItem(KEY, save(progress));
}

// открыть выбранную колоду; с сервера — только в первый раз
async function openDeck() {
  try {
    if (!opened.has(chosen)) opened.set(chosen, await loadDeck(decks.find((d) => d.id === chosen), progress));
  } catch (err) {
    error.textContent = `${err.message}: ${err.cause.message}`;
  }
  loading.hidden = true;
  if (opened.has(chosen)) render();
}

deckButtons.addEventListener("click", async (event) => {
  const button = event.target.closest("button");
  if (!button) return;
  chosen = button.dataset.deck;
  position = 0;
  flipped = false;
  await openDeck();
});
card.addEventListener("click", () => {
  if (current() === null) return;   // переворачивать нечего
  flipped = !flipped;
  render();
});
knowButton.addEventListener("click", () => {
  const word = current();
  if (word === null) return;
  opened.get(chosen).know(word.id, today);
  flipped = false;
  render();
});
againButton.addEventListener("click", () => {
  position++;
  flipped = false;
  render();
});
resetButton.addEventListener("click", () => {
  if (!confirm("Забыть весь прогресс?")) return;
  progress.clear();
  position = 0;
  flipped = false;
  render();
});

makeDeckButtons();
await openDeck();
```

Сравните с каркасом дня 33: имена, переменные и порядок частей те же, заглушки стали кодом, добавились
`current` и `makeDeckButtons`. В `deck.js` — новый `cardAt` и настоящий
`know`; `card.js`, `load.js`, `errors.js` и `storage.js` не
менялись. Что спрашивают на защите и где ответ:

| Вопрос | Где ответ |
| --- | --- |
| почему пауза растёт: 2 дня, потом 4, потом 8? | `know`, правило дня 22 |
| что будет после последней карточки? | `%` в `cardAt`: снова первая |
| почему файл колоды скачивается один раз? | `opened` и `import()` дня 31 |
| почему `clear()`, а не `new Map()`? | разбор раздела 10 |

| --- | --- | --- |

<Selfcheck>
1. Почему текущую карточку выбирает метод `cardAt` колоды, а не функция в `main.js`?
   <Answer>Тогда её проверяет страница проверок — без разметки, щелчков и `main.js`. В
   `main.js` остаётся только номер места `position`.</Answer>
2. Почему «Знаю» с `state.next.add(…)` не откладывает карточку?
   <Answer>Даты `Temporal` не меняются: `add` возвращает новую дату, а результат никуда
   не записан. Нужно положить в прогресс новый объект с новой датой.</Answer>
3. Почему проверки `know` пишут `String(progress.get(4)?.next)`?
   <Answer>Пока прогресса нет, `?.` даёт `undefined`, и проверка проваливается, а не
   падает. Иначе страница проверок остановилась бы на первой строке.</Answer>
4. Без `%` в `cardAt` страница не падает. Что она показывает и почему?
   <Answer>После трёх «Повторить» — «На сегодня всё» при счётчике «3 из 3». `cards[3]` —
   `undefined`, а `?? null` в `current` выдал его за «карточек нет».</Answer>
5. Почему сброс через `progress = new Map()` виден только после обновления?
   <Answer>Колоды держат старый `Map` — его передали им в конструкторе. Присваивание перевешивает
   одно имя: экран показывает старый прогресс, а `save` пишет новый, пустой.</Answer>
6. Задачи дня заняли на 10 минут больше плана. Что делать?
   <Answer>Не ускоряться, а пересчитать следующий день: задача «потом» уходит в запас, и главное помещается.
   Новые идеи — тоже в «потом».</Answer>
</Selfcheck>
