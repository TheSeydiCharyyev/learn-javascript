День 34. Итоговый проект: реализация

Выжимка лекции: задача с проверками раньше кода, логика в классе, общий Map, план и факт.

Одна задача за раз

Взяли задачу плана → дописали проверки на вкладке, заглушка их проваливает → заменили заглушку кодом → вкладка молчит, руками работает → отметка в плане с настоящими минутами. Перед большой правкой — копия папки. Застряли — красная строка целиком, вкладка проверок, разметка и хранилище из консоли; 10 минут без толку — назад к копии.

Логика — в классе

cardAt(position, today) {
  const cards = this.due(today);
  return cards.length === 0 ? null : cards[position % cards.length];
}
Метод колоды проверяется на странице проверок без разметки и щелчков; в main.js остаётся только position. ?? null в current смешивает undefined и null: без % страница не падает, а молча пишет «На сегодня всё». Ловит это вкладка.

Даты и общий прогресс

this.#progress.set(id, { next: today.add({ days: step * 2 }), step: step * 2 });
progress.clear();                                   // не progress = new Map()
add не меняет дату, а возвращает новую — результат нужно записать. Один Map прогресса держат main.js и все открытые колоды: его очищают, а не подменяют. const сторожит это правило — ошибка присваивания подсказывает, а не мешает. Пишет и читает хранилище одна пара функций — save и load: JSON.stringify превращает Map в "{}", и ошибка всплывёт после обновления совсем в другом модуле.

Пауза считается от дня, когда нажали «Знаю»: пропущенные дни её не съедают. Два быстрых щелчка по колодам ничего не путают — chosen прочитан до await, а render рисует ту колоду, что выбрана сейчас.
