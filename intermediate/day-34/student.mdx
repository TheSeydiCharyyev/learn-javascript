## Логика — в классе

```js
cardAt(position, today) {
  const cards = this.due(today);
  return cards.length === 0 ? null : cards[position % cards.length];
}
```

<Remember>
Метод колоды проверяется на странице проверок без разметки и щелчков; в `main.js` остаётся только
`position`. `?? null` в `current` смешивает `undefined` и
`null`: без `%` страница не падает, а молча пишет «На сегодня всё». Ловит это вкладка.
</Remember>

## Даты и общий прогресс

```js
this.#progress.set(id, { next: today.add({ days: step * 2 }), step: step * 2 });
progress.clear();                                   // не progress = new Map()
```

<Remember>
`add` не меняет дату, а возвращает новую — результат нужно записать. Один `Map` прогресса
держат `main.js` и все открытые колоды: его очищают, а не подменяют. `const` сторожит это
правило — ошибка присваивания подсказывает, а не мешает. Пишет и читает хранилище одна пара функций —
`save` и `load`: `JSON.stringify` превращает `Map` в
`"{}"`, и ошибка всплывёт после обновления совсем в другом модуле.
</Remember>

Пауза считается от дня, когда нажали «Знаю»: пропущенные дни её не съедают. Два быстрых щелчка по колодам ничего
не путают — `chosen` прочитан до `await`, а `render` рисует ту колоду, что выбрана
сейчас.

## Ошибки по симптомам

| Симптом | Причина |
| --- | --- |
| «Знаю» — карточка на месте | `next.add(…)` без записи результата |
| «На сегодня всё» при счётчике «3 из 3» | нет `%` в `cardAt`, `??` спрятал `undefined` |
| следующая карточка сразу с переводом | `flipped` не сброшен |
| сброс виден только после обновления | `progress = new Map()` вместо `clear()` |
| после обновления пусто, `this[#progress].get is not a function` | `JSON.stringify(progress)` вместо `save`: в хранилище `"{}"` |
