День 35. Итоговый проект: доработка и проверка

Выжимка лекции: телефон и его браузер, данные на входе, чужой код с вкладкой проверок, поиск по всем колодам.

Телефон и его браузер

Список проверок Essentials: строка viewport (без неё innerWidth — 980), кнопки по 45 пикселей с промежутком, у карточки overflow-wrap: anywhere. Кнопки, созданные кодом, стоят вплотную — промежуток им даёт только margin.

console.assert(document.documentElement.scrollWidth === screen.width, "страница шире экрана");
Ширину страницы сравнивают с screen.width: на телефоне innerWidth растёт вместе со страницей. Браузер, который не знает Temporal, останавливает main.js на первой строке с ним — «Загрузка…» висит. Обновить браузер заранее; где новинка есть — раздел Browser compatibility на MDN.

Ошибка вылетает там, где данными пользуются, а виновато место, где они вошли: стек читают до конца. Map проверяют вместе с записями. Отказ import() Chrome запоминает: вернули файл — обновите страницу.

Поиск по всем колодам

const reports = await Promise.allSettled(closed.map((d) => loadDeck(d, progress)));

matcher дня 32 с RegExp.escape — новая последняя строка проверяет слово и перевод; колода отбирает свои карточки методом filter. Перед поиском открываются все колоды: allSettled, а не all — иначе одна сломанная колода губит поиск целиком. Поле читают после await. «ок» и «ok» — разные символы.
