# День 35. Итоговый проект: доработка и проверка

<Subtitle>Выжимка лекции: телефон и его браузер, данные на входе, чужой код с вкладкой проверок, поиск по всем колодам.</Subtitle>

## Телефон и его браузер

Список проверок Essentials: строка viewport (без неё `innerWidth` — 980), кнопки по 45 пикселей с
промежутком, у карточки `overflow-wrap: anywhere`. Кнопки, созданные кодом, стоят вплотную — промежуток
им даёт только `margin`.

```js
console.assert(document.documentElement.scrollWidth === screen.width, "страница шире экрана");
```

<KeyPoint>
Ширину страницы сравнивают с `screen.width`: на телефоне `innerWidth` растёт вместе со
страницей. Браузер, который не знает `Temporal`, останавливает `main.js` на первой строке
с ним — «Загрузка…» висит. Обновить браузер заранее; где новинка есть — раздел Browser compatibility на MDN.
</KeyPoint>

## Данные на входе

```js
const saved = load(localStorage.getItem(KEY));
if (!(saved instanceof Map)) return new Map();
return new Map([...saved].filter(([, state]) => state?.next instanceof Temporal.PlainDate && Number.isInteger(state.step)));

if (this.#cards.size === 0) throw new CardsError("в колоде нет карточек");   // сторож в конструкторе
trainer.hidden = deck === undefined;                                         // начало render
error.textContent = "";                                                      // начало openDeck
```

| Случай | Без проверки |
| --- | --- |
| `"сломано"`, плохая дата | `main.js` падает на верхнем уровне, «Загрузка…» висит |
| `"{}"`, `"5"`, `"[]"` | пустая карточка, `this[#progress].get is not a function` в `deck.js` |
| нет файла колоды | ошибка, а под ней прошлая колода; «Повторить» — `reading 'due'` |
| пустой `[]` | «На сегодня всё», «0 из 0» |
| номер 99 | ничего: колода берёт из прогресса только своё |

<Remember>
Ошибка вылетает там, где данными пользуются, а виновато место, где они вошли: стек читают до конца.
`Map` проверяют вместе с записями. Вернули файл колоды — щёлкните ещё раз: Chrome 156 спросит сервер
снова, Chrome 155 запоминал отказ; не открылась — обновите страницу.
</Remember>

## Поиск по всем колодам

```js
const reports = await Promise.allSettled(closed.map((d) => loadDeck(d, progress)));
```

`matcher` дня 32 с `RegExp.escape` — новая последняя строка проверяет слово и перевод;
колода отбирает свои карточки методом `filter`. Перед поиском открываются все колоды:
`allSettled`, а не `all` — иначе одна сломанная колода губит поиск целиком. Поле читают после
`await`. «ок» и «ok» — разные символы.

## Чужой код

| Проход | Что делать |
| --- | --- |
| 1. запустить | сценарий и его вкладку проверок: о чём он не спросил |
| 2. карта | модули, классы, слушатели |
| 3. одно действие | от щелчка через модули до экрана и хранилища |

Замечание: где · что сделал · что увидел · что ожидал · какая проверка поймает. Класс с теми же именами можно
проверить своей вкладкой. Молчание вкладки — «верно всё, о чём спросили». На каждое замечание к своему коду —
ответ: сделать, объяснить или отложить.
